## REQUIREMENT
สร้างเว็บไซต์สำหรับระบบจองห้องประชุม
ระบบต้องสามารถ: แสดงห้องประชุม, ดูเวลาว่าง, จองห้อง, ยกเลิกการจอง, แสดงสถานะการจอง
Output: output.html เป็น Web UI Mock-up ที่เปิดและทดลองใช้งานได้

## CRITERIA
C1. มีทุกฟีเจอร์ที่ระบุไว้ในโจทย์
C2. เปิด output.html ใน headless Chromium ได้โดยไม่มี console error และทดลองใช้ทั้ง 5 ฟีเจอร์ได้ด้วยการคลิกในหน้าเว็บ (แสดงห้องประชุม ดูเวลาว่างของห้อง สร้างการจอง ยกเลิกการจองนั้น และเห็นสถานะการจองเปลี่ยนไป) โดย MERGER (N5) ต้องรันสคริปต์ Python Playwright และยกผลลัพธ์จริงมาเป็นหลักฐาน
C3. จากหน้าจอแรก เข้าถึงแต่ละฟีเจอร์ในทั้ง 5 ฟีเจอร์ได้ภายในไม่เกิน 2 คลิก โดย MERGER (N5) ระบุเส้นทางการคลิกและจำนวนคลิกของแต่ละฟีเจอร์

## TASK_GRAPH
| Node | Task | Depends on | Output |
| --- | --- | --- | --- |
| N1 | วิเคราะห์ห้าฟีเจอร์ เกณฑ์สองคลิก และกำหนดหน้าจอ DOM ID ชื่อฟังก์ชัน ข้อมูลจำลอง และ interface contract ที่ทุกส่วนใช้ร่วมกัน | - | ข้อกำหนด + contract |
| N2 | เขียน JavaScript แสดงห้อง ตรวจเวลาว่าง จอง ยกเลิก และอ่านสถานะตาม contract จาก N1 | N1 | โค้ด JavaScript |
| N3 | เขียน HTML/CSS ตามหน้าจอและ DOM ID ของ N1 โดยไม่อ่านโค้ด N2 | N1 | โค้ด HTML/CSS |
| N4 | เขียน Python Playwright ทดลองห้าฟีเจอร์ ตรวจ console error และนับคลิกเข้าถึงจากหน้าแรกตาม contract ของ N1 | N1 | สคริปต์ทดสอบ |
| N5 | รวมเว็บเป็น output.html รันสคริปต์ N4 จริง ตรวจ C1–C3 และแก้จุดเชื่อมต่อพร้อมตรวจซ้ำ | N2, N3, N4 | output.html + ผลตรวจและหลักฐาน |
