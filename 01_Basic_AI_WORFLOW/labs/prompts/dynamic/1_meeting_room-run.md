# PARAMETERS

## REQUIREMENT
สร้างเว็บไซต์สำหรับระบบจองห้องประชุม
ระบบต้องสามารถ: แสดงห้องประชุม, ดูเวลาว่าง, จองห้อง, ยกเลิกการจอง, แสดงสถานะการจอง
Output: output.html เป็น Web UI Mock-up ที่เปิดและทดลองใช้งานได้

### เกณฑ์ตรวจ C1–C3
C1. มีทุกฟีเจอร์ที่ระบุไว้ในโจทย์
C2. เปิด output.html ใน headless Chromium ได้โดยไม่มี console error และทดลองใช้ทั้ง 5 ฟีเจอร์ได้ด้วยการคลิกในหน้าเว็บ (แสดงห้องประชุม ดูเวลาว่างของห้อง สร้างการจอง ยกเลิกการจองนั้น และเห็นสถานะการจองเปลี่ยนไป) โดย EVALUATOR ต้องรันสคริปต์ Python Playwright และยกผลลัพธ์จริงมาเป็นหลักฐาน
C3. จากหน้าจอแรก เข้าถึงแต่ละฟีเจอร์ในทั้ง 5 ฟีเจอร์ได้ภายในไม่เกิน 2 คลิก โดย EVALUATOR ระบุเส้นทางการคลิกและจำนวนคลิกของแต่ละฟีเจอร์
