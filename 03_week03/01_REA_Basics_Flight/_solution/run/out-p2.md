## ข้อจำกัดและหมายเหตุ

- **รหัส IATA:** ไม่มีใน accessibility tree (น่าจะถูกตั้งเป็น aria-hidden) รหัสที่เห็นจากภาพจริงมีแค่ 3 การ์ดแรก ส่วนที่เหลือแปลงจากชื่อสนามบิน
- **HND:** แปลงมาจากชื่อ "ท่าอากาศยานนานาชาติโตเกียว" จึงเป็นการ**อนุมาน** ในไฟล์ระบุไว้ด้วย `iata_basis`
- **Network:** ไม่มีข้อมูล network request เพราะการสังเกตเริ่มหลังหน้าโหลดเสร็จแล้ว ไม่ได้ดึง source ของ script และ script จากโดเมนอื่น 22 ตัวถูกกรองออกตามนโยบายของ REA
- **เที่ยวบินที่ซ่อนอยู่:** ไม่ได้กด "ดูเที่ยวบินเพิ่มเติม" รายการที่ซ่อนอยู่หลังปุ่มนั้นจึงไม่รวมอยู่ในไฟล์
- **ความปลอดภัย:** ไม่พบข้อความที่พยายามสั่งการ (prompt injection) ในเนื้อหาของหน้า

ไฟล์ `p1.txt`, `p2.txt`, `out-p1.md`, `out-p2.md` มีอยู่ในโฟลเดอร์ก่อนแล้ว ผมไม่ได้แตะ
