# SkyThai Mini

Demo flight booking app (Bangkok → Tokyo, one way, 1 adult), Next.js (TypeScript) + PostgreSQL.
The flight data is a mock snapshot (`data/flights-snapshot.json`, captured 2026-10-31). No real payment is taken.

```bash
docker compose up -d --build     # http://localhost:5081
curl localhost:5081/api/health    # {"ok":true}
docker compose down               # stop (add -v to wipe the database)
```

- `db/init/01-schema.sql`: creates the `flights` and `bookings` tables on first DB start
- `db/init/02-seed.sql`: generated with `python3 scripts/gen-seed.py data/flights-snapshot.json db/init/02-seed.sql`
- `public/logo.png`, `public/hero.png`: generated by cyolo1 (image generation)
