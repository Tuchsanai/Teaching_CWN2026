# ทดสอบเองผ่านหมดแต่คะแนนต่ำ เพราะเคสทดสอบมาจากสมมติฐานเดียวกับโค้ด

## อาการ
- Agent รายงานว่า "ทดสอบผ่านทั้งหมด" (เช่น "assert 13 กรณี ผ่านทั้งหมด") แต่ตัวตรวจให้ผ่านเพียง 4–6 จาก 10 ข้อ
- ในคำตอบมีหัวข้อ "ตัวเลือกที่ผมตัดสินใจเอง" (ปัดเศษ, ตัวพิมพ์ tier, ชนิดข้อมูล) ซึ่งเป็นจุดที่ตัวตรวจจับพอดี

## สาเหตุ
- คำนวณค่าที่คาดหวังโดยใช้กติกาเดียวกับที่เขียนในโค้ด (เช่น floor) เคสจึงยืนยันตัวเอง ไม่มีเคสที่ชนจุดกำกวม (เศษ .5, ปัดทีละขั้น, float/bool, qty=0, CLI)
- Agent เลือกการตีความเองในจุดที่โจทย์เงียบ โดยไม่ตัดสินใจตามแนวปฏิบัติของงานเงินที่ปลอดภัยที่สุด
- t3-shipping-fee-r3: ค่าคาดที่คิดมือผิด (ลืมค่าส่งไกล) ทำให้เคสหนึ่งล้ม Agent ตัดสินว่าโค้ดถูกและไม่รันซ้ำ รอดเพราะโค้ดถูกจริง แต่เป็นนิสัยเสี่ยง

## หลักฐาน
- iteration 1: t4-cashback-r1 (13 asserts ผ่าน ได้ 0.40), t4-cashback-r3 (10/10 ผ่าน ได้ 0.40), t1-cafe-bill-r2 (ได้ 0.40), t2-split-bill-r1 (10,000 random checks ผ่าน ได้ 0.50 แต่ใช้ floor), t3-shipping-fee-r3 (ได้ 0.60)
