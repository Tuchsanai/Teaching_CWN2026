# integer-math-half-up-works: วิธีที่ได้ผล คำนวณเงินด้วยจำนวนเต็ม/Fraction แล้วปัดครึ่งขึ้นครั้งเดียวตอนท้าย

## อาการ
นี่คือหน้าวิธีที่ได้ผล ไม่ใช่ปัญหา ข้อตรวจที่ผ่านในงานที่ใช้วิธีนี้:
- t1-cafe-bill-r1, t2-split-bill-r1, t3-shipping-fee-r3 ผ่าน `contract`, `basic`, `half_up`, `no_drift`, `boundary` ครบ
- t4-cashback-r1 และ t4-cashback-r3 (ใช้จำนวนเต็มล้วนเช่นกัน) ผ่าน `contract`, `basic`, `no_drift`, `boundary` (โจทย์ cashback ไม่มีข้อ `half_up` ในรายการ)

## สาเหตุ
ที่ผ่านเพราะ Agent เลือกวิธีคำนวณที่ถูกต้องตั้งแต่ต้น:
- ไม่ใช้ `float` กับเงิน จึงไม่มีความคลาดเคลื่อนสะสม (`no_drift`)
- เก็บค่าเป็นตัวเศษ/ตัวส่วน (t1) หรือ `Fraction` (t3) หรือเลขจำนวนเต็มคูณ-หารเป็นก้อนเดียว (t2, t4) แล้วปัดเศษเพียงครั้งเดียวตอนท้ายสุด ไม่ปัดระหว่างขั้นตอน
- ปัดครึ่งขึ้นด้วยเลขจำนวนเต็มล้วน เช่น `(2 * num + den) // (2 * den)` หรือ `(x + 50) // 100` จึงได้ผลตรงกับตัวตรวจ `half_up`
- ผลลัพธ์เป็น `int` เสมอ ตรงกับสัญญา “จำนวนเต็มสตางค์” (`contract`)
- ข้อยกเว้น: ผลผ่านของ `half_up` ยืนยันเฉพาะโจทย์ที่ตัวตรวจมีข้อนี้ (t1, t2, t3) ส่วน t4 ใช้การปัดลง (floor) และไม่มีข้อ `half_up` จึงยังไม่ทราบว่าตัวตรวจ cashback ต้องการปัดแบบไหน

## หลักฐาน
งานที่ผ่านข้อเหล่านี้:
- t1-cafe-bill-r1: `num *= 95; den *= 100 ... num *= 107; den *= 100; return (2 * num + den) // (2 * den)`
- t2-split-bill-r1: `grand = (total * (100 + tip_percent) + 50) // 100; base, extra = divmod(grand, people)` ผ่าน `half_up` และ `boundary`
- t3-shipping-fee-r3: `Fraction` ตลอดสาย แล้ว `int((fee * 2 + 1) // 2)` ผ่าน `half_up`
- t4-cashback-r1/r3: `amount * rate // 1000` ผ่าน `no_drift`/`boundary`
งานที่ล้ม: ไม่มีงานที่ล้มเพราะเรื่องนี้

## วิธีแก้
ไม่ต้องแก้ แต่ให้คงวิธีนี้ไว้ในสกิล:
1. เงินทุกจำนวนเก็บเป็นสตางค์ (int) หรือ `Fraction` ห้ามใช้ `float` ระหว่างคำนวณ
2. ต่อเปอร์เซ็นต์หลายขั้น (ส่วนลด, VAT, ค่าธรรมเนียม) ด้วยการคูณตัวเศษ/ตัวส่วนสะสม แล้วปัดเศษครั้งเดียวที่ผลสุดท้าย ยกเว้นโจทย์บอกชัดให้ปัดทีละขั้น
3. ปัดครึ่งขึ้นด้วยจำนวนเต็ม `(2 * num + den) // (2 * den)` เมื่อโจทย์ไม่ได้ระบุวิธีปัด (ดูโค้ดที่ผ่านใน t1) ใช้ได้กับค่าไม่ติดลบเท่านั้น
4. เมื่อทำตามนี้แล้วอย่าลืมว่านี่แก้เพียง 5 ข้อแรก ข้อที่ตกยังต้องแก้ตามหน้า missing-input-validation, missing-cli-entrypoint, missing-test-file
