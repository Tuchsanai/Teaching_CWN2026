## ตัวอย่างเฉลย: test_020 (ร้านอาหารไทย)

```json
{"menu": [{"nm": "cashew nuts chkn", "cnt": "1", "price": "64,500"},
          {"nm": "garlic pepper beef", "cnt": "1", "price": "79,500"},
          {"nm": "red curry beef", "cnt": "1", "price": "69,500"},
          {"nm": "phad thai", "cnt": "1", "price": "64,500"},
          {"nm": "steamed rice", "cnt": "4", "price": "47,600"}],
 "sub_total": {"subtotal_price": "325,600", "service_price": "17,908", "tax_price": "34,351"},
 "total": {"total_price": "377,859"}}
```

| ช่อง | ความหมาย |
|---|---|
| `menu` | รายการอาหารในใบเสร็จ ถ้ามีรายการเดียวจะเป็น object ไม่ใช่ list |
| `nm` | ชื่อรายการตามที่พิมพ์บนใบเสร็จ |
| `cnt` | จำนวนที่สั่ง |
| `price` | ราคารวมของบรรทัดนั้น (จำนวน × ราคาต่อหน่วย) เช่น ข้าวสวย 4 ที่ = 47,600 |
| `unitprice` / `num` / `sub` | ราคาต่อหน่วย / รหัสสินค้า / ของเสริม เช่น topping (มีในบางใบ) |
| `subtotal_price` | ยอดรวมค่าอาหารก่อนค่าบริการและภาษี |
| `service_price` | ค่าบริการ (service charge) |
| `tax_price` | ภาษี (PB1 10% ของอินโดนีเซีย) |
| `total_price` | ยอดที่ต้องจ่ายจริง: 325,600 + 17,908 + 34,351 = 377,859 |
| `cashprice` / `changeprice` / `creditcardprice` / `menuqty_cnt` | เงินสดที่จ่าย / เงินทอน / จ่ายด้วยบัตร / จำนวนชิ้นรวม (มีในบางใบ) |

ตัวเลขทั้งหมดเก็บเป็นข้อความตามที่พิมพ์บนใบเสร็จ ใช้ทั้ง `,` และ `.` เป็นตัวคั่นหลักพัน และบางช่องอาจไม่มี (เป็น `null`) เช่น test_092 ไม่มี subtotal และ tax ตอนให้ VLM อ่านแล้วนำผลมาเทียบกับเฉลย จึงต้องแปลงตัวเลขให้เป็นรูปแบบเดียวกันก่อน
