## ผล Baseline: GPU 1 ใบ แบบไม่มีคิว (vapp-lab8, RTX 3090 ใบแรก)

GPU 1 ใบ รองรับผู้ใช้พร้อมกันได้ **2 คน** ที่ p95 ≤ 20 วินาที

| N | งาน/นาที | p50 (วิ) | p95 (วิ) | % ล้ม | GPU util | CPU ตัวยิง | SLO |
|---|---|---|---|---|---|---|---|
| 1 | 3.0 | 12.1 | 12.2 | 0 % | 24.9 % | 0.1 % | ผ่าน |
| 2 | 6.0 | 9.6 | 11.8 | 0 % | 45.5 % | 0.1 % | ผ่าน |
| 4 | 0.0 | 30.0 | 30.0 | 100 % | 47.0 % | 0.1 % | ไม่ผ่าน |
| 6 | 0.0 | 30.0 | 30.0 | 100 % | 47.0 % | 0.1 % | ไม่ผ่าน |

ไม่ผ่าน SLO 2 ระดับติดกัน (N=4 และ N=6) จึงหยุดไล่ N แล้วรันงานถล่มต่อ

- งานหนึ่งงาน (ใบเสร็จ 4 ใบ) ใช้ GPU ประมาณ 9–12 วินาที GPU จึงทำได้สูงสุดราว 5–6 งาน/นาที
- ที่ N=4 มีงานเข้ามาประมาณ 11 งาน/นาที เกินกำลัง GPU งานจึงต่อแถวยาวขึ้นจนผู้ใช้รอเกิน 30 วินาที แต่ server ยังอ่านงานที่ผู้ใช้เลิกรอไปแล้วต่อ ระดับ N=4 ระดับเดียวมีงานแบบนี้ 8 งาน งานใหม่จึงต้องรอหลังงานเหล่านี้และล้มตามไปทั้งหมด
- GPU util ขึ้นไม่เกินราว 47 % แม้ GPU จะไม่ว่างเลย เพราะ transformers สร้างคำตอบทีละ token และเสียเวลาฝั่ง CPU/Python ระหว่าง token
- CPU ของตัวยิงต่ำมาก (สูงสุด 2 %) จึงไม่ได้ทำให้ผลเพี้ยน

### ผลงานถล่ม (60 งานภายใน 10 วินาที)

|---|---|---|
| **2 งาน** | **58 งาน** (เกิน 30 วินาทีทั้งหมด) | **58 งาน** |

ผู้ใช้เลิกรอทุกคนภายใน 40 วินาที แต่ server อ่านต่อจนครบ 60 งานที่วินาทีที่ 621 เวลา GPU เกือบทั้งหมดจึงไปกับงานที่ไม่มีใครรอผลแล้ว

### ไฟล์ที่ได้ (ใน `multi-account:/workspace/vastapp_lab/lab8_job_queue/`)
- `code/sync_api.py`: ใช้ FastAPI ส่ง key ทาง header `X-API-Key` (key ผิดได้ 401) ใช้ GPU ใบแรกใบเดียว มี worker ตัวเดียวอ่านใบเสร็จทีละใบแบบไม่สุ่ม งานอื่นต่อแถวรอใน server และดูได้ที่ `/v1/stats` ว่าอ่านเสร็จไปกี่งาน กี่งานรออยู่ และกี่งานอ่านหลังผู้ใช้เลิกรอ
- `code/loadtest.py`: มี 3 โหมด คือ `level`, `sweep` และ `burst`
- `results/baseline/`: ผลแต่ละระดับ `level_N01–N06.json` รวมผลไล่ N ใน `sweep_summary.json` ผลงานถล่มใน `burst.json` และ log ของ server กับตัวยิง

### หมายเหตุ
- **วิธีนับ:** นับเฉพาะงานที่ส่งในช่องวินาทีที่ 15–75 ค่า p50/p95/p99 คิดรวมงานที่ล้ม โดยงานที่หมดเวลานับเป็น 30 วินาที
- **ต้องตั้ง `LD_LIBRARY_PATH`:** image ของเครื่องนี้โหลด CUDA compat lib ก่อน ทำให้ torch เปิด GPU ไม่ได้ (error 804) ผมจึงรัน server ด้วย `LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu:/usr/local/nvidia/lib64` และติดตั้ง `transformers`, `fastapi`, `uvicorn`, `python-multipart` และแพ็กเกจที่เกี่ยวข้องเพิ่มใน `/venv/main`
- **API key:** อยู่ในไฟล์ `/workspace/lab8/.api_key` บนเครื่อง (สิทธิ์ 600) ไม่ได้แสดงค่า และตรวจแล้วว่าไม่มีในไฟล์ผลหรือ log
- **การเชื่อมต่อ:** server รันแบบ `setsid nohup` ระหว่างทดสอบ SSH หลุดไป 1 ครั้ง แต่ server และตัวยิงยังทำงานต่อจนจบ

**เครื่อง vapp-lab8 (instance <id>) ยังเปิดอยู่** สถานะ running ราคาประมาณ $0.39/ชม. และ server ยังรันอยู่บน GPU 0 (port 8000)
