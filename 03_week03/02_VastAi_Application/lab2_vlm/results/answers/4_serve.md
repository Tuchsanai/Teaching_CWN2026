## สิ่งที่ทำ
- **`lab2_vlm/code/serve.sh`:** เปิด vLLM แบบ OpenAI-compatible ที่พอร์ต 8000 โหลดโมเดล Qwen3-VL-2B ครั้งเดียว แล้วใส่ LoRA adapter เฉพาะคำขอที่เรียก `receipt-ft` ทั้งสองโมเดลจึงอยู่บน RTX 4090 ใบเดียว ใช้ VRAM ราว 19 GB จาก 24 GB
  - ใช้ได้ 3 แบบ: `start` (เปิด) `status` (ดูสถานะ) `stop` (ปิด)
- **API key:** สุ่มขึ้นด้วย `openssl rand` เก็บไว้ที่ `/workspace/lab2/secret/api_key` บนเครื่องที่เช่าเท่านั้น
  - ไฟล์ตั้งสิทธิ์ 600 ให้ root อ่านได้คนเดียว (โฟลเดอร์ตั้ง 700)
  - ส่ง key ให้ vLLM ทางตัวแปร `VLLM_API_KEY` จึงไม่โผล่ในคำสั่ง `ps`
  - ตรวจแล้วว่าไม่มีค่า key อยู่ใน log
- **ทำงานต่อได้แม้การเชื่อมต่อหลุด:** server รันแยกออกจาก SSH ด้วย `setsid nohup` ถ้า vLLM ล้มจะเปิดใหม่ให้เองสูงสุด 5 ครั้ง ตอนนี้ SSH ที่ใช้สั่งเปิดปิดไปแล้ว แต่ server ยังทำงานอยู่
- **`lab2_vlm/code/receipt.env`:** มี `RECEIPT_BASE_URL=http://203.0.113.10:41234/v1` ซึ่งเป็นพอร์ต 8000 ของเครื่องที่ต่อออกภายนอก มี `RECEIPT_API_KEY` (ไม่แสดงค่า) `RECEIPT_MODEL_BASE=receipt-base` และ `RECEIPT_MODEL_FT=receipt-ft`

⚠️ **เครื่อง vapp-lab2 (instance <id>) ยังเปิดอยู่ และ server ยังรันอยู่ คิดเงินราว $0.40 ต่อชั่วโมง** พร้อมให้เว็บเรียกใช้ในขั้นถัดไป
