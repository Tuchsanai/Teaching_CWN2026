สร้างสกิล `receipt-vlm-finetune` เวอร์ชัน 0 และติดตั้งเป็นสกิลของโปรเจกต์แล้ว สกิลนี้ยังไม่เคยรันจริง ที่ตรวจแล้วมีแค่ไวยากรณ์ของสคริปต์ (bash และ Python ผ่าน) การรันจริงคือขั้นที่ 9

## สกิลทำอะไรได้
ทำงานของ LAB 2 ซ้ำได้ในคำสั่งเดียว เริ่มจากเช่าเครื่องจนถึงลบเครื่อง
1. **เช่าเครื่อง** ผ่านสกิล `vastai` เปิดพอร์ต 8000 และทดสอบความเร็วโหลดจาก Hugging Face ถ้าไม่ผ่านจะลบเครื่องแล้วเช่าเครื่องใหม่
2. **เตรียม Dataset** CORD-v2 ส่ง HF_TOKEN ผ่าน stdin เท่านั้น และตรวจว่าไม่มี token ค้างบนเครื่อง
3. **Training** เทรน LoRA แบบแยกจาก SSH ถ้าล้มจะเทรนต่อจาก checkpoint
4. **AI server** เปิด vLLM สองโมเดลคือ `receipt-base` และ `receipt-ft` แล้วทดสอบ 3 ข้อ
5. **Evaluation** วัด Base เทียบ Fine-tuned บน Test Set 100 ใบ แล้วดึงผลกลับมา
6. **เว็บสมุดรายจ่าย** เปิดได้ถ้าต้องการ
7. **ลบเครื่องและดูบิลจริง** ขั้นนี้ห้ามข้าม

สกิลยังมี:
- **เกณฑ์ตรวจผ่าน** พร้อมค่าอ้างอิงจากรอบจริง: ยอดรวมตรง 88.4% → 100% และ Item F1 69.9% → 88.4%
- **กติกาเรื่องเงิน:** ลบเครื่องเสมอ แม้งานล้มกลางทาง · เช่าได้ครั้งละ 1 เครื่อง · แตะเฉพาะเครื่องป้ายที่กำหนด · ถ้าเครื่องเปิดเกิน 2 ชั่วโมงต้องรายงานก่อนทำต่อ

**สคริปต์ที่แก้จากต้นฉบับ 2 จุด** เพื่อให้ปรับค่าได้โดยไม่ต้องเขียนโค้ดใหม่:
