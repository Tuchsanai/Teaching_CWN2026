ทำเสร็จแล้วครับ เว็บ "สมุดรายจ่ายจากใบเสร็จ" เปิดอยู่ที่ **http://localhost:3404** (docker compose project `vapp-lab2` มี Next.js + PostgreSQL) และทดสอบอ่านใบเสร็จผ่านหน้าเว็บจริงครบทั้ง 3 ใบ ใบละ 2 โมเดล

## ผลทดสอบผ่านเว็บ (ใช้โหมด "เทียบสองโมเดล")

| ใบเสร็จ | โมเดล | รายการที่อ่านถูก | ยอดรวม | เวลา (วินาที) |
|---|---|---|---|---|
| test_092 | Base | 0/1 | ❌ ผิด (เฉลย Rp 240.000) | 1.9 |
| test_092 | Fine-tuned | 1/1 | ✅ ถูก | 0.7 |
| test_051 | Base | 0/4 | ❌ ผิด (อ่านได้ 334.011 เฉลย 334.000) | 1.4 |
| test_051 | Fine-tuned | 3/4 | ✅ ถูก | 1.1 |
| test_020 | Base | 3/5 | ❌ ผิด (เฉลย Rp 377.859) | 1.3 |
| test_020 | Fine-tuned | 3/5 | ✅ ถูก | 1.0 |

- Fine-tuned อ่านยอดรวมถูกทั้ง 3 ใบ ส่วน Base ผิดทั้ง 3 ใบ
- ใน test_051 โมเดล Base ตัดชื่อเมนูสั้นลง เช่นตัด "(TA)" ออก ทำให้ผิดทุกบรรทัด ถึงราคาจะถูกเกือบทั้งหมด
- ใน test_020 ทั้งสองโมเดลสะกดชื่อผิด 2 บรรทัดเหมือนกัน คือ "chkm" (ที่ถูกคือ chkn) และ "phed thai" (ที่ถูกคือ phad thai)
- ✓/✗ ตัดสินด้วยเกณฑ์เดียวกับ `eval.py` คือบรรทัดหนึ่งถูกเมื่อชื่อสินค้าและราคาตรงเฉลย โดยไม่สนตัวพิมพ์เล็กใหญ่และสัญลักษณ์
- เวลาที่วัดคือเวลาที่ AI server ใช้ตอบ ส่งให้ทีละโมเดลเพื่อให้วัดเวลาแยกกันได้

## สิ่งที่ทำ
- **ใบเสร็จตัวอย่าง:** ดึงรูปพร้อมเฉลย 6 ใบจากเครื่อง vapp-lab2 ผ่าน container `multi-account` ได้แก่ test_016, 020, 035, 051, 063, 092 รูปอยู่ที่ `code/web/public/samples/` เฉลยอยู่ที่ `code/web/lib/samples.json`
- **หน้า "อ่านใบเสร็จ":** เลือกใบตัวอย่างหรืออัปโหลดรูปเองได้ แล้วเลือก Base, Fine-tuned หรือเทียบสองโมเดล
  - แสดงรูปคู่กับตารางรายการ ยอดก่อนภาษี ภาษี และยอดรวม เป็นหน่วย Rp
  - ถ้าเป็นใบตัวอย่าง จะขึ้น ✓/✗ ทีละบรรทัด พร้อมบอกบรรทัดในเฉลยที่อ่านไม่ตรง
  - มีปุ่ม "บันทึกเป็นรายจ่าย"
- **หน้า "รายจ่าย":** แสดงจำนวนใบ รายจ่ายรวม และตารางรายใบที่กดดูรายการหรือลบได้ ตอนนี้มี 3 ใบที่บันทึกระหว่างทดสอบ รวม Rp 951.859
- **การเรียก AI server:** อยู่ที่ `code/web/app/api/read/route.ts` ซึ่งทำงานฝั่ง server ของเว็บเท่านั้น
  - ค่าต่าง ๆ อ่านจาก `receipt.env` ผ่าน `env_file`
  - รูปถูกย่อด้วย sharp ให้ด้านยาวไม่เกิน 1280 px
  - ข้อความสั่งโมเดลคัดลอกตรงตัวอักษรจาก `receipt_data.py` ไปไว้ที่ `lib/prompt.ts`
- **ตรวจ key:** ไม่พบค่า key ในไฟล์ที่ส่งไปยังเบราว์เซอร์ และไม่พบใน log ของ container เว็บ
- **ทดสอบเพิ่ม:** ทดสอบการอัปโหลดรูปเองและการลบด้วย ใช้ได้ทั้งคู่
- **ผลทดสอบเก็บไว้ที่ `results/web/`:** ภาพหน้าจอ `read_test_092.png` `read_test_051.png` `read_test_020.png` `expenses.png` และตัวเลขใน `web_test.json`
