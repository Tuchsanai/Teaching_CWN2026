Worker ทำงานแล้วบน GPU ใบแรก (หมายเลข 0) ของเครื่อง vapp-lab9 และผ่านการทดสอบจากนอกเครื่องทั้ง 2 ข้อ

**โค้ดที่เขียน** (`lab9_hybrid/code/worker.py`)
- โหลด SDXL-Turbo ครั้งเดียวบน GPU ที่ระบุด้วย `--gpu` ใช้ค่าเดียวกับ Baseline คือภาพ 512×512, 4 steps, guidance 0 แล้วตั้ง prefetch 4 เพื่อให้ถืองานที่ยังไม่ ack ได้ไม่เกิน 4 งาน
- ได้งานแรกแล้วรออีก 30 ms เพื่อรวมงานที่ค้างในคิวเป็นชุดเดียว ไม่เกิน 4 ภาพ แล้วสร้างภาพทั้งชุดใน thread แยก การรายงานว่ายังอยู่จึงส่งได้ทุก 1 วินาทีตลอด และบอกด้วยว่ากำลังทำกี่ภาพ
- ลำดับคือ เก็บไฟล์ภาพ → แจ้ง gateway ว่าเสร็จ → ack เป็นขั้นสุดท้าย ถ้า Worker ตายกลางคัน RabbitMQ จะส่งงานที่ยังไม่ ack ให้ Worker ตัวถัดไป
- งานที่ข้อความว่างจะถูกปฏิเสธแบบไม่ใส่คืนคิว จึงไปลง Dead-letter queue (`jobs.dead`) ถ้าสร้างภาพพลาดจะลองใหม่ 1 ครั้ง

**ผลทดสอบ**
1. **งานที่ค้างจากขั้นก่อน** (`130ce94765f0`) เสร็จทันทีที่เปิด Worker ใช้ GPU 0.52 วินาที และโหลดภาพจากนอกเครื่องได้ (HTTP 200, 46 KB)
2. **ส่งงานใหม่ 8 งานพร้อมกัน** Worker รวมทำ **ครั้งละ 4 ภาพ** เป็น 2 ชุด (4 + 4) ซึ่งตรงกับตัวเลข "กำลังทำ" สูงสุดที่ gateway รายงาน คือ 4
   - ชุดละประมาณ 1.0 วินาที หรือประมาณ 0.25 วินาทีต่อภาพ เร็วกว่าทำทีละภาพ (0.47 วินาที) ประมาณ 1.9 เท่า

**เวลาตั้งแต่ส่งงานจนได้ภาพ** (วัดจากนอกเครื่อง รวมเวลาเดินทางผ่านเครือข่าย)
- งานในชุดแรก: ประมาณ 2.7 วินาที
- งานในชุดที่สอง: ประมาณ 3.2–3.8 วินาที
- ครบทั้ง 8 ภาพ: 3.78 วินาที
- ส่วนต่างระหว่างเวลา GPU (ประมาณ 1 วินาทีต่อชุด) กับเวลาที่วัดได้เกือบทั้งหมดเป็นเวลาที่ใช้ผ่านเครือข่าย ไม่ได้อยู่ที่ GPU

**สิ่งที่ควรรู้**
- **แก้ `gateway.py` 1 จุด** ให้เก็บจำนวนภาพที่ Worker กำลังทำจาก heartbeat ไว้ใน `/stats` แล้วเปิด gateway ใหม่ สถานะงานยังอยู่ครบเพราะเก็บไว้ใน SQLite
- **GPU 0 ใช้ร่วมกับ sync_server** ของขั้นก่อน ซึ่งยังเปิดอยู่และใช้หน่วยความจำประมาณ 9.5 GB ตอนอุ่นเครื่องรอบแรกจึงมีคำเตือนหน่วยความจำไม่พอ ผมเปิด VAE slicing (ถอดรหัสภาพในชุดทีละภาพ) ภาพที่ได้เหมือนเดิม และรอบหลังไม่มีคำเตือนอีก
- **มีงานทดสอบเพิ่มอีก 16 งาน** เพราะสคริปต์ทดสอบรอบแรกๆ พังเรื่องเครื่องหมายคำพูด งานเหล่านั้นถูกส่งเข้าไปแล้ว Worker ก็ทำเสร็จหมด (ครั้งละ 4 เช่นกัน)
- **ยังไม่ได้ทดสอบงานที่ข้อความว่าง** เพราะโจทย์ขอผลทดสอบแค่ 2 ข้อ และไม่อยากให้มีงานค้างใน Dead-letter queue ที่อาจกระทบขั้นถัดไป

ไม่ได้แสดงค่า key ที่ใดเลย ไฟล์ key ที่ใช้ชั่วคราวลบแล้ว ภาพและผลทดสอบอยู่ใน `lab9_hybrid/results/worker_test/` สคริปต์ทดสอบอยู่ที่ `code/test_worker.py`
