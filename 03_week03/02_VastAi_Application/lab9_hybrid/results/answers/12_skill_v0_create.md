ฉันสร้างสกิล `gpu-queue-capacity` เสร็จแล้ว และติดตั้งเป็นสกิลของโปรเจกต์ที่ `.claude/skills/gpu-queue-capacity` แล้ว ไฟล์ชุดนี้เหมือนกับ `lab9_hybrid/skill_v0` ทุกไฟล์ สกิลนี้ยังไม่ได้ลองรันบนเครื่อง Vast.ai จริง จะได้ลองครั้งแรกในขั้นที่ 13

## สกิลนี้ทำอะไร
ทำ LAB 9 ซ้ำได้ในคำสั่งเดียว คือวัดว่าบริการสร้างภาพจากข้อความ (sdxl-turbo, 512x512, 4 steps) รองรับผู้ใช้พร้อมกันได้กี่คน โดยต้องผ่านเกณฑ์ p95 ไม่เกิน 10 วินาที และงานล้มน้อยกว่า 1%

ลำดับงาน: เช่าเครื่อง 2 GPU → ติดตั้งโปรแกรมและ RabbitMQ → จับเวลาสร้างภาพ → ไล่ระดับจำนวนผู้ใช้กับ API แบบ Synchronous, ระบบผสม 1 Worker และ 2 Worker → ยิงงานเป็นก้อน 200 งาน → ฆ่า Worker กลางงานเพื่อดูว่างานไม่หาย → ได้ `metrics.json` กับกราฟ → ลบเครื่องและสรุปค่าใช้จ่ายจริง

- งานที่แตะ Vast.ai ทั้งหมดส่งต่อให้สกิล `vastai` ทำ ไม่เขียนวิธีใช้ซ้ำ
- กติกาเรื่องเงิน: ลบเครื่องเสมอแม้งานล้มกลางทาง, ห้ามเกินราคาที่ตั้งไว้, เช่าได้ทีละ 1 เครื่อง, แตะเฉพาะเครื่องป้ายของตัวเอง และถ้าเครื่องเปิดเกิน 2 ชั่วโมงต้องแจ้งก่อนทำต่อ
- เกณฑ์ตรวจผ่านมีค่าอ้างอิงจากรอบจริงไว้เทียบ: Baseline รับได้ 30 คน, ระบบผสม 1 Worker 52 คน, 2 Worker 104 คน, ฆ่า Worker แล้วงานหาย 0 งาน, ค่าใช้จ่ายทั้งรอบ $0.572

## มีไฟล์อะไร
- **`SKILL.md`** มี name และ description ที่บอกว่าใช้เมื่อไร, ตารางค่าที่ปรับได้, ตารางชุดการวัด, ขั้นตอน 7 ขั้น, เกณฑ์ตรวจผ่าน, กติกาเรื่องเงิน และรูปแบบสรุปตอนจบ
- **`scripts/`** โค้ดที่ผ่านการรันจริงจาก `lab9_hybrid/code` (ไม่รวมเว็บ):
  - ตัวบริการ: `sync_server.py`, `gateway.py`, `worker.py`
  - ตัววัด: `bench_gen.py`, `make_samples.py`, `test_worker.py`, `loadtest.py`, `killtest.py`, `report.py`, `prompts.txt`
  - `stack.sh` เป็นไฟล์ใหม่ รวมคำสั่งที่ใช้จริงใน LAB 9 ไว้ที่เดียว ได้แก่ ติดตั้งโปรแกรม, เปิด RabbitMQ, และเปิด/ปิด sync, gateway, Worker

**ส่วนที่ต่างจากโค้ดเดิมใน `lab9_hybrid/code`** (แก้เพื่อให้ขั้นที่ 13 แบบย่อทำได้):
- `loadtest.py` เพิ่มตัวเลือก `--levels` `--level-sec` `--warmup-sec` `--refine` ส่วนค่าเริ่มต้นยังเหมือนเดิม
- `report.py` ตอนนี้ขาดผล burst, ผลฆ่า Worker หรือผลระบบผสม 1 Worker ก็ได้ ไฟล์ไหนไม่มีก็ข้ามกราฟที่ต้องใช้ไฟล์นั้น ฉันลองกับผลจริงของ LAB 9 แล้ว ได้ `metrics.json` ตรงกับของเดิม และถ้ามีแค่ผล Baseline กับ 2 Worker ก็ได้ 2 กราฟ

ไฟล์อื่นไม่ได้แก้ ยกเว้นแปลงท้ายบรรทัดของ `worker.py` เป็นแบบ Linux

`stack.sh` ฉันตรวจได้แค่ว่าไวยากรณ์ถูก ยังไม่เคยรันบนเครื่องจริง ขั้นที่ 13 จะเป็นการทดสอบจริงครั้งแรก
