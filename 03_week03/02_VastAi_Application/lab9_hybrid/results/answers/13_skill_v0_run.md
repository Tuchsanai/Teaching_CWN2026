## วัดเสร็จแล้ว: GPU 1 ใบแบบ Synchronous รองรับ 40 คน ส่วนระบบผสม 2 ใบรองรับ 112 คน (2.8 เท่า)

ใช้เวลาทั้งหมด 18 นาที ค่าใช้จ่ายจริงตามบิล $0.299 และลบเครื่องเรียบร้อยแล้ว

### เครื่องที่ใช้
| รายการ | ค่า |
|---|---|
| GPU | 2 × RTX 3090 (24 GB) อยู่ในเครื่องเดียวกัน |
| ราคา | $0.347/ชม. (GPU) + $0.019/ชม. (disk) ไม่เกินเพดาน $0.60 |
| ที่ตั้ง / CPU | Missouri, US / Ryzen 7 3700X 16 threads |
| เวลาติดตั้ง | 33 วินาที |

### ตารางความจุ (SLO: รอจนได้ภาพ p95 ≤ 10 วินาที และงานล้มน้อยกว่า 1%)
| จำนวน GPU | แบบ | ความจุ N | ภาพ/วินาทีสูงสุด | p95 ที่ N นั้น | เท่าของ Baseline |
|---|---|---|---|---|---|
| 1 | Synchronous API (Baseline) | **40 คน** | 2.93 | 9.08 วินาที | 1.0× |
| 2 | ระบบผสม (คิว + Worker 2 ตัว) | **112 คน** | 7.87 | 9.61 วินาที | **2.8×** |

Efficiency คำนวณไม่ได้ เพราะรอบนี้ไม่ได้วัดระบบผสม 1 Worker ตามที่สั่ง ระดับ 40/48 และ 112/120 เป็นระดับกึ่งกลางที่สคริปต์ลองเพิ่มเองหลังเจอระดับแรกที่ไม่ผ่าน

**เหตุผลจากตัวเลข:**
- **Baseline:** ทำได้แค่ประมาณ 2.9 ภาพ/วินาทีไม่ว่า N จะเท่าไร เพราะสร้างทีละภาพ GPU util ค้างที่ประมาณ 80% เมื่อคนเพิ่มขึ้น คนที่รอก็ยาวขึ้นอย่างเดียว
- **ระบบผสม:** Worker รวมงานทำเป็น batch ละ 4 ภาพ และมี GPU 2 ใบช่วยกัน ทั้งสองใบใช้งานเกิน 90% จึงได้ 7.7–7.9 ภาพ/วินาที ประมาณ 2.7 เท่าของ Baseline
- ทั้งสองแบบไม่มีงานล้มเลยแม้แต่ระดับเดียว
- ตัวยิงโหลดใช้ CPU ไม่ถึง 2% ของคอร์เดียว จึงไม่ใช่คอขวด
