PixelQueue เปิดใช้ได้แล้วที่ http://localhost:3408 (container `vapp-lab9-web-1` โปรเจกต์ `vapp-lab9`) ทดสอบผ่านเบราว์เซอร์ครบทั้ง 3 อย่าง

| การทดสอบ | ผล | ตัวเลขที่ได้ |
|---|---|---|
| เห็น Worker 2 ตัว | ✅ ผ่าน | การ์ด gpu0 และ gpu1 ขึ้นว่า "ว่าง" ทั้งคู่ · มุมบนขวาขึ้นว่า GPU พร้อม 2/2 ตัว ใช้เวลาประมาณ 0.25 วินาทีต่อภาพ |
| ส่งงาน 1 งานจนได้ภาพ | ✅ ผ่าน | ภาพประภาคารขึ้นในหน้าเว็บ · ลำดับคิว #1 (ข้างหน้าไม่มีงาน) · รอทั้งหมด 0.5 วินาที วาดบน gpu0 |
| ส่งงานเป็นชุด 500 งาน | ✅ ผ่าน | **รับ 250 งาน · ปฏิเสธ 250 งาน** (ตอบ 429 เพราะคิวเต็ม) ใช้เวลาส่ง 7.2 วินาที · กราฟคิวขึ้นไปชนเส้นเพดาน 200 (100 × GPU 2 ตัว) แล้วค่อยๆ ลดลงจนเหลือ 0 · ตัวเลข "เสร็จแล้ว" เพิ่มจาก 3,258 เป็น 3,509 คือครบ 251 งาน (250 งานจากชุด + 1 งานเดี่ยว) ไม่มีงานหาย |

**ปัญหาที่เจอและแก้แล้ว:** ตอนคิวกำลังลด แกลเลอรีภาพล่าสุดขึ้นเป็นกรอบว่างหลายช่อง เพราะภาพแต่ละภาพต้องดึงข้ามไปถึงเครื่องบน Vast.ai ใช้ประมาณ 0.8 วินาทีต่อภาพ ขณะที่ภาพใหม่เข้ามาทุกวินาที ผมจึงให้เว็บเก็บภาพที่เสร็จแล้ว 300 ภาพล่าสุดไว้ในหน่วยความจำ การเปิดภาพเดิมซ้ำเหลือ 0.008 วินาที ตอนนี้แกลเลอรีแสดงครบ 12 ภาพ แต่ภาพใหม่ภาพแรกยังใช้เวลาประมาณ 0.8 วินาทีเท่าเดิม

**ไม่มี key ในเบราว์เซอร์:** ค้นในไฟล์ที่ส่งไปเบราว์เซอร์และในหน้าเว็บแล้ว ไม่พบค่า key · เว็บอ่าน `.env` ตอนรันเท่านั้น ไม่ได้ฝังไว้ใน image

**โครงของเว็บ**
1. `lib/gateway.js` เป็นที่เดียวที่อ่าน `T2I_BASE_URL` กับ `T2I_API_KEY` และแนบ `X-API-Key` เวลาเรียก gateway ทำงานฝั่ง server เท่านั้น
2. `app/api/*` เป็นตัวกลางระหว่างเบราว์เซอร์กับ gateway: `stats` (ตัวเลขสด), `jobs` (ส่งงาน), `jobs/[id]` (รอผลครั้งละไม่เกิน 10 วินาที), `jobs/[id]/image` (ส่งภาพพร้อมเก็บไว้ในหน่วยความจำ), `batch` (ส่งงานเป็นชุดจากฝั่ง server ครั้งละ 25 งาน แล้วนับว่ารับกี่งาน ปฏิเสธกี่งาน)
3. `app/page.js` เป็นหน้าเดียวภาษาไทย ดึงตัวเลขสดทุก 1 วินาที มีกราฟคิว 2 นาทีล่าสุดพร้อมเส้นเพดาน การ์ด Worker แกลเลอรีภาพที่มีป้ายงานด่วน และบอกให้ลองใหม่เมื่อไรถ้าคิวเต็ม
4. `Dockerfile` สร้าง Next.js เป็นแบบ standalone และ `docker-compose.yml` เปิดพอร์ต 3408 แล้วอ่านค่าจาก `.env`

⚠️ **เครื่องป้าย `vapp-lab9` บน Vast.ai ยังเปิดอยู่และคิดเงินอยู่** (Worker 2 ตัวยังทำงาน) อย่าลืมทำขั้นที่ 11 ลบเครื่อง
