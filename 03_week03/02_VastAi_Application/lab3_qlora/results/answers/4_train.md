## โค้ดทำงานอย่างไร (`lab3_qlora/code/train.py`)
1. โหลด Qwen3-4B-Instruct-2507 แบบ 4-bit (NF4) เพื่อให้ใส่ใน GPU ได้ แล้วติด LoRA rank 8 ที่ q, k, v, o, gate, up, down ทุกชั้น เทรนเฉพาะ adapter ตัวโมเดลหลักไม่ถูกแก้
2. แปลงบทสนทนาเป็น token ด้วย chat template แล้วตั้ง label เป็น -100 ทุกตำแหน่งที่ไม่ใช่คำตอบของผู้ช่วย ทำให้ loss คิดเฉพาะคำตอบ ผมตรวจกับตัวอย่างจริงแล้วว่าถูกต้อง
3. ใช้ Hugging Face Trainer: ทีละ 1 บท สะสม 8 บท, learning rate 0.0002, seed 0 วัด Validation loss ก่อนเทรนและทุก 20 step แล้วโหลด checkpoint ที่ดีที่สุดกลับมาตอนจบ
4. การเทรนต่อหลังหลุด: รันใน `tmux` บนเครื่องเช่า แม้ SSH หลุดการเทรนก็ไม่หยุด และมี `run.sh` คอยสั่งรันซ้ำให้เทรนต่อจาก checkpoint ล่าสุดเองถ้า process ตาย สคริปต์จะเขียน `progress.json` ไว้ให้ดูความคืบหน้าได้ตลอด
5. ตอนจบจะบันทึก `train_log.json` (loss ทุกช่วง เวลา VRAM ขนาด adapter) และวาดกราฟ `loss_curve.png`
