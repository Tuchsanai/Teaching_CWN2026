## ตัวอย่างเฉลย JSON: `train_353` (ใบขวาบนในภาพตัวอย่าง)

```json
{"items":[{"name":"Soft Ori 3 Top","qty":1,"price":17272},
          {"name":"Top Oreo","qty":1,"price":0},
          {"name":"Top Oreo","qty":1,"price":0},
          {"name":"Top Banana","qty":1,"price":0}],
 "subtotal":17272,"tax":1727,"total":18999}
```

| ช่อง | หมายถึง |
|---|---|
| `items` | รายการสินค้าทุกบรรทัดบนใบ เรียงตามที่พิมพ์ |
| `name` | ชื่อสินค้าตามที่พิมพ์บนใบ ไม่แก้คำสะกด เช่น "Soft Ori 3 Top" คือไอศกรีมใส่ topping 3 อย่าง |
| `qty` | จำนวนชิ้น ใบนี้ไม่ได้พิมพ์จำนวนไว้จึงใส่ 1 |
| `price` | ราคาของบรรทัดนั้นเป็นจำนวนเต็ม ("17,272" → 17272) topping Oreo, Oreo และ Banana เป็นรายการย่อย จึงแยกเป็นบรรทัดของตัวเอง ราคา 0 เพราะบนใบพิมพ์ 0 |
| `subtotal` | ยอดรวมก่อนภาษี 17272 |
| `tax` | ภาษี 1727 (ราว 10% ของ subtotal) ถ้าใบไหนไม่มีภาษี เช่น `train_234` ช่องนี้เป็น `null` |
| `total` | ยอดที่ต้องจ่ายจริง 18999 = 17272 + 1727 |
