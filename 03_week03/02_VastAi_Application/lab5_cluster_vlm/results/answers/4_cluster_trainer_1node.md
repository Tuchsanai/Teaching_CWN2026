- **B เร็วกว่า A ราว 1.7–1.8 เท่าบนเครื่องเดียวกัน:** แนวทาง A ทำงานทีละใบตามลำดับ GPU จึงว่างครึ่งหนึ่ง (util ราว 50%) ส่วน B ใช้ GPU เกือบเต็ม (85–96%) แม้ต้องเสียเวลาคำนวณซ้ำจาก GC
- **เวลา "รอ" ของ B:** คือเวลาที่ replica ซึ่งเสร็จก่อนต้องรอตัวที่ช้ากว่า เพราะใบเสร็จยาวไม่เท่ากัน การส่งข้อมูลจริงบนเครื่องเดียวใช้เวลาไม่ถึง 0.02 วินาที
- **ขนาด Gradient:** 3,833,856 ค่า × 2 byte (bf16) = 7.67 MB ต่อ replica ต่อการปรับน้ำหนัก 1 ครั้ง
- **ใบเสร็จไม่ซ้ำกัน:** ใน B แต่ละ replica ได้ใบเสร็จไม่ซ้ำกันเลย (80+80 ใบ และ 128+128 ใบ)

## โค้ดที่เขียน

- **`code/coordinator.py`:** ใช้แค่ CPU เปิดพอร์ต 9000 แล้วรับเฉพาะ replica ที่ส่งรหัสลับตรงกับไฟล์ `/workspace/lab5/cluster_secret` บนเครื่องที่เช่า (สุ่มด้วย `secrets.token_hex`) ตัวที่ส่งรหัสผิดจะถูกปฏิเสธ ซึ่งทดสอบแล้ว
- **การเฉลี่ย Gradient:** ทุกครั้งที่ปรับน้ำหนัก coordinator รับ Gradient bf16 จากทุก replica พร้อมกัน เฉลี่ยด้วย float32 แล้วปัดกลับเป็น bf16 และส่งค่าเฉลี่ยชุดเดียวกันกลับให้ทุกตัวพร้อมกัน
- **`code/worker.py`:** replica 1 ตัวคือโมเดล 1 ชุด แนวทาง A แบ่งส่วนภาษา 19/17 ชั้นบน GPU 2 ใบ (ค่าที่สมดุลที่สุดจากขั้นที่ 3) และปิด GC ส่วนแนวทาง B ใช้ GPU 1 ใบและเปิด GC
- **การแจกข้อมูลและ loss:** สุ่มลำดับ Training Set ด้วย seed 0 แล้วให้ replica ตัวที่ r ได้ใบที่ r, r+N, … ป้อนทีละใบ หาร loss ด้วยจำนวนใบที่สะสม แล้วปรับด้วย AdamW lr 0.0002 จาก Gradient เฉลี่ยที่ได้กลับมา
- **ส่วนที่คิด loss:** loss คิดเฉพาะ token ของ JSON คำตอบกับ `<|im_end|>` ปิดท้าย (ให้โมเดลเรียนรู้ว่าต้องหยุดตรงไหน) ส่วนพรอมต์และภาพถูกปิดด้วย -100
- **สิ่งที่บันทึก:** ทุกครั้งที่ปรับน้ำหนักบันทึกเวลาคำนวณ เวลาส่ง/รอ/รับ ขนาด MB ที่ส่ง VRAM สูงสุด และ GPU util (อ่านทุก 0.1 วินาที) ตอนจบส่ง sha256 ของน้ำหนัก LoRA ให้ coordinator เทียบกัน
- **`code/run_node1.sh`:** รันทั้ง 4 รอบต่อกันด้วย nohup จึงไม่หยุดถ้า SSH หลุด มีพารามิเตอร์ `--coord host:port`, `--train-limit` และ `--save-adapter` เตรียมไว้ใช้ในขั้นที่ 5–6

**ต้องแก้ 1 จุดก่อนรันได้:** เมื่อจำกัด GPU ให้ worker ด้วย `CUDA_VISIBLE_DEVICES` CUDA เปิดไม่ได้ (error 804) เพราะเครื่องนี้ใช้ driver 535 กับ image CUDA 12.8 สคริปต์รันจึงตั้ง `LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu` แบบเดียวกับสคริปต์ของขั้นที่ 3
