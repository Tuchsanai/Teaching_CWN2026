
## สกิลทำอะไรได้
สั่งครั้งเดียวแล้วทำครบวงจรแบบเดียวกับ LAB 5:
1. เช่า Node 1 แล้วเตรียมโมเดล Qwen3-VL-8B และ Dataset CORD-v2
2. ถ้าเลือกไว้ จะหาขีดจำกัด VRAM ก่อน
3. วัดความเร็วบน 1 Node
4. เช่า Node อื่นมาต่อเป็นคลัสเตอร์ แล้ววัดความเร็วคลัสเตอร์
5. เทรนจริงด้วย LoRA แนวทาง A และ/หรือ B
6. วัดผล Base เทียบ Fine-tuned บน Test Set โดยแบ่งงานไปทุก GPU
7. ลบทุกเครื่องและสรุปค่าใช้จ่ายจากบิลจริง
8. ออกตาราง Speedup · Efficiency · เงินต่อ Epoch พร้อมกราฟ 4 รูป

งานทุกอย่างที่แตะ Vast.ai ให้สกิล `vastai` ทำ ในสกิลใส่ข้อควรระวังที่เจอจริงใน LAB 5 ไว้ด้วย เช่น error 804 ของ driver 535 ที่ต้องตั้ง `LD_LIBRARY_PATH`, ต้องใช้ public IP คนละตัว, ถ้าดึงไฟล์จาก Node 1 แล้วหลุดให้ส่งผ่าน Node อื่น และถ้าเน็ตสะดุดให้วัดรอบนั้นใหม่

## ค่าที่ปรับได้ (ค่าเริ่มต้น)
| ค่า | ค่าเริ่มต้น |
|---|---|
| รุ่น GPU | RTX 3090 (เครื่องละ 2 ใบเสมอ) |
| จำนวน Node | 2 |
| เพดานราคา | $0.60/ชม. ต่อเครื่อง |
| แนวทาง | A และ B |
| Effective Batch | วัดความเร็วที่ 8 และ 32 · เทรนที่ 8 |
| จำนวนครั้งที่วัด | EB 8: 20 ครั้ง (ไม่นับ 3 ครั้งแรก) · EB 32: 8 ครั้ง (ไม่นับ 2 ครั้งแรก) |
| จำนวนใบที่เทรน | 400 ใบ · 1 Epoch |
| ป้ายเครื่อง | `vapp-lab5-n` แล้วต่อเลข 1, 2, … |
| โฟลเดอร์ผล | `lab5_cluster_vlm/results` (ถ้ามีผลเดิมอยู่จะใช้โฟลเดอร์ย่อยใหม่ ไม่เขียนทับ) |

ค่าอื่นที่ปรับได้: วัดผลหรือไม่ (ค่าเริ่มต้นคือวัด), VRAM probe (ทำเองเมื่อ GPU ไม่ใช่ 24 GB), เก็บเครื่องไว้ไม่ลบ, เกณฑ์เลือกเครื่อง, image, disk

ในสกิลยังมีขั้นตอน 10 ขั้น, เกณฑ์ตรวจผ่านที่มีตัวเลขอ้างอิงจาก LAB 5 และกติกาเรื่องเงิน: ลบทุก Node เสมอแม้งานล้มกลางทาง, งบอ้างอิง $2.44, เปิดเกิน 3 ชม. หรือคาดว่าเกิน $3 ต้องถามก่อน

## สิ่งที่ควรรู้
- **โค้ดบางไฟล์แก้ไว้นิดหน่อย** เพื่อให้รับค่าที่ปรับได้ข้างบน โดยค่าเริ่มต้นยังทำงานเหมือน LAB 5:
  - สคริปต์ `run_*.sh` ทั้ง 4 ไฟล์รับค่าผ่าน env เช่น `NODES` `RUNS` `STEPS` `APPROACHES` `LIMIT` `EB` `MODELS`
  - `eval.py` เพิ่ม `--models` เพื่อวัดเฉพาะ Base กับแนวทางที่เทรน
  - `report.py` `compare_nodes.py` `summarize_train.py` ข้ามส่วนที่ไม่มีผลดิบได้ และ `report.py` เพิ่ม `--label-prefix`
  - อีก 6 ไฟล์คัดลอกมาตรงตัว
- **ผลการทดสอบบนเครื่องนี้:**
  - ใช้ผลจริงของ LAB 5 รัน `report.py` และ `compare_nodes.py` ตัวใหม่ แล้วได้ `metrics.json` และตัวเลขทุกตัวเท่ากับตัวเดิม
  - กรณีรันแค่บางส่วน (แนวทาง B อย่างเดียว ป้ายเครื่องใหม่ ไม่มี VRAM probe) รันจนจบและได้กราฟครบ 4 รูป
  - ลองสคริปต์ shell กับ ssh จำลอง กระจาย replica ได้ถูกต้อง และข้ามรอบที่ Effective Batch หารจำนวน replica ไม่ลงตัว
- **ยังไม่ได้ทดสอบ:**
  - `eval.py run` กับภาพ `examples.jpg` ต้องใช้ GPU และ Dataset บนเครื่องเช่า จึงยังไม่ได้รัน
  - คลัสเตอร์ 3 Node ขึ้นไปสคริปต์รองรับ แต่ยังไม่เคยรันจริง สกิลเขียนกำกับไว้แล้ว
