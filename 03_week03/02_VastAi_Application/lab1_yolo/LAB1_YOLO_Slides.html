ภาคพื้นฐาน · ทฤษฎี

ทฤษฎี 1 · Object Detection ให้กรอบหลายกรอบจากรูปเดียว แต่ละกรอบมีคลาส Confidence และพิกัด

1Object Detection ตอบว่ามีอะไร อยู่ตรงไหน เป็นรายการกรอบ
2การจำแนกทั้งรูป (Classification) ตอบได้คำเดียวต่อรูป แต่งานความปลอดภัยต้องรู้ว่าคนไหนไม่สวมหมวกและมีกี่คน
3ใน LAB นี้ใช้ 8.5 ms ต่อรูปบน RTX 4090 และรูป no_hardhat_1 ได้ 33 กรอบในครั้งเดียว
ภาคพื้นฐาน · ทฤษฎี

ทฤษฎี 2 · Fine-tuning ไม่ต้องเริ่มจากศูนย์ จึงใช้ข้อมูลน้อยและเทรนเร็ว

1เริ่มจากโมเดลที่เทรนกับ Dataset ใหญ่มาแล้ว (Pre-trained บน COCO 80 คลาส) แล้ว เทรนต่อ ด้วยข้อมูลของเรา
2การเทรนจากศูนย์ต้องใช้ภาพจำนวนมากและเวลานาน ส่วนโมเดล Pre-trained รู้จักขอบ รูปร่าง และคนอยู่แล้ว
ภาคพื้นฐาน · ทฤษฎี

ทฤษฎี 2 · Fine-tuning เปลี่ยนส่วนทำนายคลาสจาก 80 คลาสของ COCO เป็น 10 คลาสของเรา

1ส่วนที่สกัดลักษณะของภาพถูกใช้ต่อ ส่วนที่ทำนายคลาสถูกเปลี่ยนเป็น 10 คลาส แล้วปรับ weight ทั้งโมเดล
2ใน LAB นี้ใช้ 2,605 ภาพ เทรน 508 วินาที mAP50 เพิ่มจาก 0.090 เป็น 0.782
ภาคพื้นฐาน · ทฤษฎี

ทฤษฎี 3 · ตัดสินผลด้วย Test Set ที่โมเดลไม่เคยเห็น เพราะภาพที่เคยเห็นให้คะแนนสูงเกินจริง

1Training Set 2,605 (93%) ภาพ ใช้ปรับ weight ของโมเดล
2Validation Set 114 (4%) ภาพ ใช้ดูระหว่างเทรน และเลือกโมเดลที่ดีที่สุด (best.pt)
3Test Set 82 (3%) ภาพ ใช้ตัดสินครั้งเดียวตอนจบ ใช้เทียบก่อนกับหลังเทรน
