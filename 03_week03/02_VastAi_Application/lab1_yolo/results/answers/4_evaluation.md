ขั้นที่ 4 รันจริงบนเครื่อง vapp-lab1 (RTX 4090) เสร็จแล้ว ผลอยู่ใน `lab1_yolo/results` ครบทุกอย่าง

**ผลบน Test Set (82 รูป ไม่ได้ใช้เทรน) วัดสองโมเดลด้วยวิธีเดียวกัน**

| ค่าที่วัด | ก่อนเทรน (yolo11s ของ COCO) | หลังเทรน (best.pt) |
|---|---|---|
| mAP50 | 0.090 | **0.782** |
| mAP50-95 | 0.066 | **0.504** |
| AP50 Hardhat | 0.000 | **0.940** |
| AP50 NO-Hardhat | 0.000 | **0.578** |
| AP50 Safety Vest | 0.000 | **0.888** |
| AP50 NO-Safety Vest | 0.000 | **0.839** |
| AP50 Person | 0.753 | **0.880** |
| เวลาต่อรูป | 8.56 ms | 8.54 ms |

- **ก่อนเทรน:** โมเดลได้คะแนนแค่ Person กับ vehicle (vehicle ได้ 0.149) เพราะ COCO ไม่มีคลาสหมวกหรือเสื้อสะท้อนแสง คลาสอื่นจึงได้ 0
- **หลังเทรน:** ทุกคลาสดีขึ้นมาก คลาสที่ยังอ่อนที่สุดคือ NO-Hardhat (0.578) ซึ่งมีกรอบใน Test Set แค่ 41 กรอบ
- **ความเร็วเท่ากัน:** สองโมเดลเป็นสถาปัตยกรรมเดียวกัน เวลาต่อรูปนับรวมเตรียมรูป ประมวลผล และจัดผลลัพธ์ ทีละรูป
- **ตรวจตัวเลขซ้ำ:** ผมรันตัววัดผลในตัวของ Ultralytics กับ Test Set ด้วย ได้ mAP50 0.787 และ mAP50-95 0.512 ใกล้กับสคริปต์ของเรา ส่วนที่ต่างเล็กน้อยมาจากการจัดขนาดรูปต่างกัน

**สิ่งที่ปรับระหว่างทำ**
- เครื่องที่เช่าไม่มี pandas จึงเปลี่ยนไปอ่านไฟล์ results.csv ด้วย csv ที่มากับ Python แทน
- ใน Test Set มีแค่ 4 รูปที่เฉลยมีทั้งคนสวมและไม่สวมหมวก รูปที่ 5 ของภาพเทียบก่อน/หลังจึงเลือกจากรูปที่โมเดลหลังเทรนเจอทั้งสองคลาส
- รูปตัวอย่างแบบ "ทุกคนสวมหมวก" ใช้เกณฑ์ว่าไม่พบ NO-Hardhat และจำนวนหมวกต้องไม่น้อยกว่าจำนวนคนที่โมเดลเจอ ถ้าใช้แค่เกณฑ์ไม่พบ NO-Hardhat รอบแรกได้รูปที่มี 27 คนแต่เจอหมวกแค่ 21 ใบ

**ไฟล์ที่ได้**
