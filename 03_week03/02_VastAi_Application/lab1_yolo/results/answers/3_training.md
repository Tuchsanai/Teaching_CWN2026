**โค้ด `lab1_yolo/code/train.py` ทำอะไร**
1. สร้างไฟล์ข้อมูล Dataset ใหม่ที่ใช้ path เต็ม เพราะ `data.yaml` จาก Roboflow ใช้ path แบบอ้างอิงตำแหน่ง (`../train/images`)
2. ตั้งให้พิมพ์บรรทัด `[progress]` หลังจบทุก Epoch: Epoch ที่เท่าไร · ค่า loss · mAP50 และ mAP50-95 บน Validation Set · เวลาที่ผ่านไป
3. ถ้ายังไม่มี `last.pt` ให้เริ่มจาก `yolo11s.pt` ที่เทรนบน COCO แล้วเทรน 50 Epoch ภาพ 640 batch 32 seed 0 ถ้ามี `last.pt` อยู่แล้วจะเทรนต่อจากจุดเดิม (รันคำสั่งเดิมซ้ำได้เลย)
4. จับเวลาที่ใช้เทรน แล้วบันทึกลง `train_info.json`

สคริปต์รันอยู่ใน tmux บนเครื่องที่เช่า จึงเทรนต่อได้แม้การเชื่อมต่อหลุด โมเดลที่ดีที่สุดอยู่ที่ `/workspace/runs/ppe_yolo11s/weights/best.pt` บนเครื่องนั้น

ไฟล์บันทึกการเทรนดึงกลับมาไว้ที่ `lab1_yolo/results/train/` แล้ว คือ `train_info.json` · `results.csv` · `args.yaml` · `train_progress.log`
