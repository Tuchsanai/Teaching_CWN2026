**1. เว็บและ AI server:** เว็บที่ http://localhost:3401 เปิดอยู่แล้ว (container `vapp-lab1-web-1`) จึงไม่ต้องสั่ง docker compose ใหม่ ส่วน `/api/health` ตอบว่า AI server พร้อมใช้งาน (`ready: true`) ใช้โมเดล `ppe-yolo11s`

**2. ส่งรูปให้เว็บตรวจ:** ส่งครบ 6 รูป ทีละรูป ไม่มีรูปไหนผิดพลาด
