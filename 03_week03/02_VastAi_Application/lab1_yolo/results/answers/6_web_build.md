เว็บ SiteSafe เปิดอยู่ที่ http://localhost:3401 แล้ว (docker compose ชื่อ project `vapp-lab1` มี 2 container คือ web กับ db) ลองส่งรูปตัวอย่างไปที่ AI server บน Vast.ai แล้วได้ผลกลับมาจริง

## โครงสร้างไฟล์ของเว็บแบบย่อ (`lab1_yolo/code/web`)
```
.env                  ← ไฟล์เดิม (ไม่ได้แก้หรือลบ) อยู่ใน .gitignore / .dockerignore
docker-compose.yml    ← web (Next.js, พอร์ต 3401) + db (PostgreSQL 16)
Dockerfile            ← build Next.js แบบ standalone
app/
  layout.tsx          ← แถบบน: โลโก้ เมนู และป้ายสถานะ AI server
  page.tsx            ← หน้าแรก (ตรวจภาพ)
  history/page.tsx    ← ตารางประวัติพร้อมยอดรวม
  history/[id]/page.tsx ← รายละเอียดการตรวจแต่ละครั้ง
  api/detect          ← รับรูป ส่งต่อไป /v1/detect พร้อม Bearer key แล้วบันทึกลง PostgreSQL
  api/health          ← ถาม /health ของ AI server
  api/image/[id]      ← ส่งรูปที่บันทึกไว้ในฐานข้อมูล
components/           ← Inspector, BoxedImage (วาดกรอบ), ResultPanel, HealthBadge
lib/                  ← db.ts (สร้างตารางให้เอง), ai.ts (อ่าน YOLO_* ใช้ได้เฉพาะฝั่ง server), types.ts
public/samples/       ← รูปตัวอย่าง 6 รูป (คัดลอกมาจาก results/samples)
```

## หน้าที่มี
- **หน้าแรก `/`**: อัปโหลดรูปได้ทั้งกดเลือกและลากมาวาง หรือกดรูปตัวอย่าง 6 รูป จะได้รูปพร้อมกรอบ (ป้ายชื่อกรอบเป็นภาษาไทยและมี % ความมั่นใจ) กับป้ายผล **ผ่าน / ไม่ผ่าน** โดยไม่ผ่านเมื่อพบ NO-Hardhat อย่างน้อย 1 กรอบ ใต้ป้ายผลแสดงจำนวนคน สวมหมวก ไม่สวมหมวก ไม่สวมเสื้อสะท้อนแสง เวลาที่โมเดลใช้ และเวลาส่งรูปไป-กลับ
- **ประวัติ `/history`**: ยอดรวม (ตรวจทั้งหมด / ผ่าน / ไม่ผ่าน) และตารางผลตรวจทุกครั้งจาก PostgreSQL
- **รายละเอียด `/history/<id>`**: รูปพร้อมกรอบ ตัวเลขชุดเดียวกับหน้าแรก และตารางกรอบทุกกรอบ (ประเภท ความมั่นใจ พิกัด x1 y1 x2 y2)
- **มุมขวาบนทุกหน้า**: จุดเขียวหรือแดงบอกว่า AI server พร้อมไหม ตรวจซ้ำทุก 15 วินาที

## ผลลองส่งรูป 1 รูป (`no_hardhat_1.jpg`)
| รายการ | ผล |
|---|---|
| ป้ายผล | **ไม่ผ่าน** (พบ NO-Hardhat 8 กรอบ) |
| จำนวนคน / สวมหมวก / ไม่สวมหมวก / ไม่สวมเสื้อสะท้อนแสง | 9 / 0 / 8 / 9 |
| จำนวนกรอบทั้งหมด | 33 (รูปขนาด 640×640) |
| เวลาที่โมเดลใช้ | 32.1 ms |
| เวลาส่งรูปไป-กลับ | 954.5 ms |
| บันทึกลงฐานข้อมูล | รายการ #1 หน้าประวัติ หน้ารายละเอียด และรูปเปิดได้ (HTTP 200) |

ลองกดรูปตัวอย่าง `all_hardhat_1` ในเบราว์เซอร์อีกรูป ได้ **ผ่าน** (คน 5 สวมหมวก 6 ไม่สวมหมวก 0) และป้ายมุมบนขึ้นว่า "AI server พร้อม" ตอนนี้จึงมีประวัติอยู่ 2 รายการ

ตรวจเรื่อง key แล้วไม่พบค่า key ทั้งใน HTML ของทุกหน้าและในไฟล์ JavaScript ที่ส่งไปให้เบราว์เซอร์ เพราะ key อยู่ใน container ฝั่ง server เท่านั้น

⚠️ **เครื่องบน Vast.ai ยังเปิดอยู่และยังคิดเงินอยู่** (AI server ยังตอบที่ `/health`) ถ้าใช้เสร็จแล้วอย่าลืมปิดเครื่อง
