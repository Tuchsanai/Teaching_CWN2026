ทฤษฎี 2 · Speedup 1.74 เท่า คิดเป็น Efficiency 87% ของ Ideal

1Speedup = เวลา 1 GPU ÷ เวลา N GPU หมายถึงเร็วขึ้นกี่เท่า
2Ideal คือ N เท่า และ Efficiency = Speedup ÷ N หมายถึงได้กี่ % ของ Ideal
3วัดเป็นวินาทีต่อ Epoch โดยไม่นับ Epoch แรกและ Epoch สุดท้าย
4ใน LAB นี้ 128.3 ÷ 73.9 = 1.74 เท่า และ 1.74 ÷ 2 = 87%
พื้นฐาน · ทฤษฎีที่ต้องรู้

ทฤษฎี 3 · 2 GPU ไม่เร็วขึ้น 2 เท่า เพราะการ Sync แบ่งให้ GPU ทำพร้อมกันไม่ได้

1ส่วนที่แบ่งทำพร้อมกันไม่ได้เป็น เพดานของ Speedup ตามหลักเดียวกับ Amdahl's law
2เวลาที่เพิ่ม 41 ms ต่อ step ราวครึ่งหนึ่งคือ All-reduce (21.4 ms) ที่เหลือคือเวลาที่ GPU ใบหนึ่งรออีกใบ
3CPU ไม่ใช่คอขวด 1 GPU ใช้ CPU เพียง 2.8 core และ 2 GPU ใช้ 5.3 core จาก 32 core ที่เครื่องให้ ส่วน GPU util เฉลี่ยเป็น 85.5% (1 GPU) และ 81.1% / 81.3% (2 GPU)
พื้นฐาน · ทฤษฎีที่ต้องรู้

Gradient ราว 80 MB ต้องข้าม GPU ทุก step ความเร็วจึงขึ้นกับทางเชื่อม

1เครื่องใน LAB นี้เป็น PHB ข้อมูลผ่าน PCIe 3.0 x8 ลงไปที่ CPU และ RAM แล้วจึงขึ้นไป GPU อีกใบ
2วัดได้ 3.9 GB/s และส่ง 80 MB ใช้เวลา 21.4 ms
3เครื่องที่มี NVLink มีทางตรงระหว่าง GPU จึงส่งได้เร็วกว่า
