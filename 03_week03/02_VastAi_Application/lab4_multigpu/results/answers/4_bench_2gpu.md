ผมเทรนรอบ 2 GPU บนเครื่อง vapp-lab4 เสร็จแล้ว เร็วขึ้น **1.74 เท่า** (จาก 128.3 เหลือ 73.9 วินาทีต่อ Epoch) mAP50 ไม่ลดลง

ใช้สคริปต์ `code/bench.py` ตัวเดิมโดยไม่แก้ เพราะสคริปต์รองรับ 2 GPU อยู่แล้ว ผมเทียบ checksum แล้ว ไฟล์ในเครื่องเรา ใน container และบนเครื่องเช่าตรงกันทุกไฟล์ จึงใช้ผลรอบ 1 GPU เดิมเทียบได้เลย ไม่ต้องรันใหม่ ค่าเหมือนเดิมทุกอย่าง: YOLO11m · 5 Epoch · imgsz 640 · batch 32 ต่อ GPU · seed 0 · workers 8

| ตัวชี้วัด | 1 GPU | 2 GPU |
|---|---|---|
| วินาทีต่อ Epoch (เฉลี่ย Epoch 2–4) | 128.32 | **73.87** |
| เร็วขึ้นกี่เท่า | 1.00× | **1.74×** (ได้ 87% ของ 2 เท่าที่ควรได้) |
| step ต่อ Epoch | 461 (batch 32) | 231 (batch รวม 64) |
| วินาทีต่อ step | 0.278 | 0.320 (ช้าลงราว 15% ต่อ step) |
| GPU util เฉลี่ย | 85.5% | 81.1% / 81.3% |
| CPU ที่ใช้ | 2.77 core | 5.32 core (เครื่องมี 64 thread) |
| เวลา all-reduce ข้อมูล 80 MB | ไม่มี | 21.4 ms (≈3.9 GB/s · ทาง PCIe ไม่มี NVLink) |
| mAP50 | 0.9619 | 0.9628 |
| mAP50-95 | 0.6377 | 0.6228 |
| เวลารันทั้งหมด | 726 s | 405 s ของการเทรน |

ที่ไม่ได้ 2 เท่าเต็ม เพราะแต่ละ step ช้าลงจาก 0.278 เป็น 0.320 วินาที ส่วนที่เพิ่มคือเวลารวม gradient ระหว่าง GPU ผ่าน PCIe และ GPU util ที่ลดลงเล็กน้อย

ระหว่างเทรนผมรายงานทุก 2–3 นาที และรันแบบ `setsid nohup` บนเครื่องเช่า ถ้าการเชื่อมต่อหลุด การเทรนก็ยังวิ่งต่อ
