เปิด AI server ตรวจภาพบน GPU ใบแรกของเครื่อง vapp-lab5 ได้แล้ว ทดสอบจากนอกเครื่องผ่านครบ: `/health` ตอบพร้อม, ส่ง 6 รูปพร้อม key ได้ผลครบ และส่งแบบไม่มี key ได้ 401 ตามที่ต้องการ

## โค้ดทำงานอย่างไร (`lab5_image_api/code/server.py`)
- รูปที่เข้ามาถูกแปลงเป็นภาพ 640×640 ทุกครั้ง (ย่อ/ขยายโดยรักษาสัดส่วนแล้วเติมขอบ) โมเดลจึงเจอภาพขนาดเดียวกันตลอด แล้วคำขอเข้าคิวรอ
- มีตัวทำงานตัวเดียวที่เรียกโมเดลบน GPU ทีละครั้ง ตั้งโหมดด้วย `MODE`: `single` ส่งเข้าโมเดลทีละรูป (batch = 1) ส่วน `microbatch` รวมคำขอที่รอในคิวได้สูงสุด 32 รูป และรอคำขอเพิ่มไม่เกิน 5 ms
- ตอนเปิด server พอร์ตเปิดทันที แต่ `/health` ตอบ 503 "warming" ระหว่างอุ่นโมเดลทุกขนาด batch ตั้งแต่ 1 ถึงค่าสูงสุดของโหมด อุ่นครบแล้วจึงตอบ 200 "ready"
- ตรวจ key ที่ส่งมาแบบ Bearer ถ้าไม่มีหรือผิดตอบ 401 · key เก็บในไฟล์ `.api_key` (เปิดอ่านได้เฉพาะ root) และส่งขึ้นเครื่องเป็นไฟล์ `.env` ไม่ได้พิมพ์ค่า key ออกมาที่ไหนเลย

## คำขอ 1 ครั้ง: ส่งอะไรไป ได้อะไรกลับ
**ส่งไป:** `POST /v1/detect` แบบ multipart แนบรูปในช่อง `file` พร้อม header `Authorization: Bearer <key>`

**ได้กลับ** (คำตอบจริงของ sample-3.jpg ตัดรายการวัตถุให้สั้นลง):
```json
{"detections": [
   {"class": "Person", "confidence": 0.8999, "box": [311.5, 2.2, 581.0, 315.2]},
   {"class": "NO-Hardhat", "confidence": 0.8208, "box": [351.0, 30.0, 411.0, 57.1]}, ...],
 "count": 7, "replica": "gpu0-single",
 "timing_ms": {"decode": 6.72, "queue": 0.07, "inference": 23.35},
 "batch_size": 1, "image": {"width": 640, "height": 640}}
```
| ช่อง | ความหมาย |
|---|---|
| `detections` | วัตถุที่เจอ: `class` ชื่อคลาส · `confidence` ความมั่นใจ (เกณฑ์ขั้นต่ำ 0.35) · `box` กรอบ [x1, y1, x2, y2] เป็นพิกเซลของรูปต้นฉบับ |
| `count` | จำนวนวัตถุทั้งหมดที่เจอ |
| `replica` | ชื่อ server ที่ตอบคำขอนี้ |
| `timing_ms.decode` | เวลาแปลงรูป: อ่าน JPEG แล้วทำเป็น 640×640 |
| `timing_ms.queue` | เวลาที่คำขอรอคิวก่อนได้เข้าโมเดล |
| `timing_ms.inference` | เวลาที่โมเดลใช้กับ batch รอบนั้น |
| `batch_size` | จำนวนรูปที่เข้าโมเดลพร้อมกันในรอบนั้น (โหมดนี้เป็น 1 เสมอ) |
| `image` | ขนาดรูปต้นฉบับ |

## ผลทดสอบจากนอกเครื่อง
- `GET /health` → 200 `ready`, โหมด single, อุ่นแล้ว batch 1–1, ใช้ GPU ใบแรก
- ส่ง 6 รูปพร้อม key → ได้ 200 ทั้ง 6 รูป
- ส่งแบบไม่มี key → 401 `missing API key` · ส่ง key ผิด (ทดสอบเพิ่ม) → 401 `invalid API key`

**เวลาที่โมเดลใช้ต่อรูป (batch = 1):** 46.0, 28.3, 23.4, 22.7, 23.2, 24.5 ms ถ้าไม่นับรูปแรก เฉลี่ยประมาณ 24 ms ต่อรูป (รวม 6 รูปเฉลี่ย 28 ms)
- แปลงรูปเฉลี่ยประมาณ 7 ms และรอคิวไม่ถึง 0.1 ms เพราะส่งทีละรูป
- เวลาตั้งแต่ส่งจนได้คำตอบเมื่อวัดจากนอกเครื่องอยู่ที่ราว 1.1 วินาที ส่วนใหญ่เป็นเวลาเดินทางของเครือข่ายและการเปิดการเชื่อมต่อใหม่ทุกคำขอ เวลาภายใน server รวมแล้วราว 30 ms

**โหมด Micro-batching เขียนไว้แล้วแต่ยังไม่ได้เปิดทดสอบ** ตั้ง `MODE=microbatch` ตอนเปิด server จะอุ่นโมเดล batch 1–32 ก่อนรับคำขอ

ไฟล์อยู่ใน container ที่ `/workspace/vastapp_lab/lab5_image_api/` · โค้ดอยู่ใน `code/` (server.py, run_single.sh, test_api.py, make_grid.py) · ผลอยู่ใน `results/` (test_single.json, dataset_samples.jpg)
