เปิด AI server บนเครื่อง vapp-lab1 แล้ว ทดสอบจากนอกเครื่องผ่านทั้ง 3 ข้อ

**ผลทดสอบ** (ยิงจากเครื่องนี้ไปที่ `http://203.0.113.10:41234`)

| ข้อ | สิ่งที่ทดสอบ | ผล |
|---|---|---|
| 1 | `/health` ไม่ใช้ key | ✅ HTTP 200 ได้ `ready: true` ชื่อโมเดล `ppe-yolo11s` และคลาสครบ 10 คลาส |
| 2 | `/v1/detect` ส่งรูปจาก Test Set พร้อม key | ✅ HTTP 200 รูปขนาด 640×640 ได้ 6 กรอบ ทุกกรอบมี confidence ตั้งแต่ 0.35 ขึ้นไป เช่น Hardhat 0.92, Person 0.86, NO-Mask 0.85 |
| 3 | `/v1/detect` ส่งโดยไม่มี key | ✅ HTTP 401 ถูกปฏิเสธ (ลองส่ง key ผิดก็ได้ 401 เหมือนกัน) |

**เวลาที่โมเดลใช้ต่อรูป (`inference_ms`)**
- รูปแรกใช้ประมาณ 63 ms
- รูปต่อ ๆ ไปใช้ประมาณ 13–23 ms ส่วนใหญ่อยู่ที่ราว 20 ms บน RTX 4090

**สิ่งที่ทำไป**
- **`lab1_yolo/code/serve.py`**: โหลด `best.pt` ค้างไว้บน GPU และอุ่นโมเดลไว้ก่อน เปิดที่พอร์ต 8080 ตอนเปิดครั้งแรก server สุ่ม API key เองแล้วเก็บไว้ในเครื่องที่เช่า (`/workspace/serve_api_key.txt`) ถ้าเปิดใหม่ก็ใช้ key เดิม
- **ทำงานต่อได้แม้การเชื่อมต่อหลุด**: ตัดการเชื่อมต่อ SSH ไปแล้ว server ยังทำงานอยู่ จากนั้นจึงทดสอบ 3 ข้อด้านบน
- **`lab1_yolo/code/web/.env`**: มี `YOLO_BASE_URL`, `YOLO_API_KEY` และ `YOLO_MODEL=ppe-yolo11s` ครบ ไม่ได้แสดงค่า key ที่ไหนเลย

⚠️ **เครื่องยังเปิดอยู่**: vapp-lab1 (instance <id>, RTX 4090) ยังทำงานอยู่ ค่าเช่าประมาณ $0.41/ชั่วโมง และยังคิดเงินต่อจนกว่าจะลบเครื่อง
