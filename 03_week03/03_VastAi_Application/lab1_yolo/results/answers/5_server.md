AI server เปิดแล้วบนเครื่อง vapp-lab1 และผ่านการทดสอบจากนอกเครื่องครบ 3 ข้อ ไฟล์ `.env` ของเว็บเขียนเสร็จแล้ว

**ทดสอบ AI server จากนอกเครื่อง** (ที่อยู่ `http://203.0.113.10:41234` คือพอร์ต 8080 ของเครื่องเช่า)

| ข้อ | การทดสอบ | ผล |
|---|---|---|
| 1 | server ตอบว่าพร้อม (`/health`) | ✅ HTTP 200 ได้ `status: ok` โมเดล ppe-yolo11s และรายชื่อ 10 คลาส |
| 2 | ส่งรูปจาก Test Set 1 รูปพร้อม key | ✅ HTTP 200 ได้กรอบ 4 กรอบ: Person, machinery, Hardhat, NO-Safety Vest |
| 3 | ส่งรูปโดยไม่มี key | ✅ ถูกปฏิเสธ HTTP 401 `invalid api key` |

**เวลาที่โมเดลใช้ต่อรูป** (ส่งรูปเดิม 3 ครั้ง)
- เวลาประมวลผลบน GPU ประมาณ **8 ms** ต่อรูป (7.8–8.2 ms)
- เวลาทั้งหมดบนเครื่องรวมเตรียมรูปประมาณ **11 ms** ครั้งแรกใช้ 36 ms เพราะเพิ่งเริ่ม
- เวลาส่งรูปไป-กลับผ่านเน็ตประมาณ **0.9 วินาที** เวลาส่วนใหญ่จึงหมดไปกับการส่งข้อมูลผ่านเน็ต ไม่ใช่การประมวลผลของโมเดล

**สิ่งที่ทำบนเครื่อง**
- server ทำงานใน tmux session ชื่อ `serve` จึงทำงานต่อได้แม้การเชื่อมต่อหลุด log อยู่ที่ `/workspace/serve.log`
- ก่อนเปิดได้ติดตั้ง fastapi, uvicorn และ python-multipart เพิ่ม เพราะเครื่องยังไม่มี
- โฟลเดอร์ `lab1_yolo` ใน container ไม่มี `serve.py` จึงคัดลอกจากโฟลเดอร์บทเรียนบนเครื่องนี้ขึ้นไปใช้แทน
- API key อยู่ในไฟล์ `/workspace/yolo_api_key.txt` บนเครื่องเช่า สคริปต์จะใช้ค่าเดิมทุกครั้งที่เปิด server ใหม่

**ไฟล์ `lab1_yolo/web/.env`**
- มี `YOLO_BASE_URL=http://203.0.113.10:41234`, `YOLO_API_KEY=<ไม่แสดง>` และ `YOLO_MODEL=ppe-yolo11s`
- ลองใช้ key ในไฟล์นี้ส่ง `sample-1.jpg` จากเครื่องนี้แล้ว ได้ HTTP 200
