## จุดที่ควรแก้ในสกิล
- คำสั่ง `bash -lc 'vastai ...'` หา `vastai` ไม่เจอ ผมต้องเรียกด้วย path เต็ม `/root/.local/share/vastai/current/bin/vastai` แทน
