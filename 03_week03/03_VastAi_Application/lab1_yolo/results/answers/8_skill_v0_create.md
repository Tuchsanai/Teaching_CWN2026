สร้างสกิล `yolo-ppe-train` เวอร์ชัน 0 และติดตั้งเป็นสกิลของโปรเจกต์แล้ว ส่วนที่เขียนนั้นสร้างจากพรอมต์ขั้น 1–7 สคริปต์ `train.py` `eval.py` `serve.py` และผลใน `results/` (รวมคำตอบของแต่ละขั้น) สกิลนี้ยังไม่ได้ลองรันจริง จะได้ลองในขั้นที่ 9

## สกิลทำอะไรได้
ทำงานของ LAB 1 ได้ครบในคำสั่งเดียว ทุกงานที่แตะ Vast.ai สกิลจะให้ไปใช้สกิล `vastai` ใน container `multi-account` ไม่ได้เขียนวิธีใช้ Vast.ai ซ้ำ
1. เช่าเครื่อง GPU ถ้าเครื่องขึ้น running แต่ SSH ไม่ติด จะลบแล้วเช่าเครื่องถัดไปทันที
2. เตรียม Dataset จาก Roboflow ส่ง key ทาง stdin เท่านั้น และใช้ opencv แบบ headless เพราะเครื่องไม่มีไลบรารีหน้าจอ
3. Training ใน tmux และรายงาน mAP50 ทุกประมาณ 2 นาที
4. Evaluation ก่อนเทรน vs หลังเทรนบน Test Set แล้วดึงผลกลับมาเก็บที่เครื่องนี้
5. เปิด AI server แล้วทดสอบ 3 ข้อ และเขียนไฟล์ `web/.env` (ขั้นนี้เลือกปิดได้)
6. เปิดเว็บ SiteSafe และทดสอบรูปตัวอย่าง 3 รูป (ขั้นนี้เลือกปิดได้)
7. ลบเครื่อง ปิดเว็บโดยเก็บประวัติไว้ และสรุปค่าใช้จ่ายจริง

**เกณฑ์ตรวจผ่าน:**
- mAP50 หลังเทรนต้องสูงกว่าก่อนเทรน
- เทรน 50 Epoch ขึ้นไปต้องได้ mAP50 ไม่ต่ำกว่า 0.70 ถ้าน้อยกว่า 50 Epoch ต้องไม่ต่ำกว่า 0.50 (ค่าอ้างอิงจาก LAB 1: ก่อนเทรน 0.090 หลังเทรน 0.782)
- ไม่มีเครื่องค้างในบัญชี และไม่มีค่า key ปรากฏในคำตอบหรือไฟล์ผล

**กติกาเรื่องเงิน:**
- ลบเครื่องเสมอ แม้ขั้นใดล้มกลางทาง
- ไม่เช่าเกินราคาที่ตั้งไว้ และเช่าได้ทีละ 1 เครื่องเท่านั้น
- แตะเฉพาะเครื่องที่มีป้ายของงานนี้
- จะเปิดเครื่องค้างไว้ได้ต่อเมื่อผู้ใช้สั่ง และต้องบอกในสรุปว่ายังคิดเงินอยู่ชั่วโมงละเท่าไร
