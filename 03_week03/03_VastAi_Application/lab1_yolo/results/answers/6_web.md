เปิดเว็บแล้ว ต่อกับ AI server บน Vast.ai ได้จริง ส่งทั้ง 3 รูปผ่านหมดโดยไม่มี error

**ขั้นที่ 1: เปิดเว็บ**
- สั่ง `docker compose up -d --build` ในโฟลเดอร์ `lab1_yolo/web` แล้ว container `vapp-lab1-db-1` (PostgreSQL, healthy) กับ `vapp-lab1-web-1` ขึ้นครบทั้งคู่
- http://localhost:3401 ตอบ HTTP 200
- เว็บอ่านที่อยู่และ key ของ AI server จาก `.env` แล้วต่อเข้าเครื่องบน Vast.ai ได้จริง ผลตอบกลับมาจากโมเดล `ppe-yolo11s` ไม่ใช่ mock เพราะไม่ได้เปิด mock

**ขั้นที่ 2: ทดสอบ** (ส่งทีละรูปไปที่ `/api/detect` ของเว็บ)

| รูป | ผล | จำนวนคนไม่สวมหมวก | เวลาที่โมเดลใช้ (ms) | เวลาส่งรูปไป-กลับ (ms) |

- โมเดลบน GPU ใช้เวลาแค่ราว 8–11 ms ต่อรูป เวลาไป-กลับที่เหลือเกือบทั้งหมดเป็นเวลาเดินทางผ่านเน็ตจากเครื่องนี้ไป Vast.ai และกลับ
- รูปแรกช้าสุด (ราว 0.9 วินาที) เพราะเป็นการเชื่อมต่อครั้งแรก รูปต่อ ๆ มาเร็วขึ้น
- ผลทั้ง 3 รายการบันทึกลงประวัติของเว็บแล้ว (id 1–3) ดูได้ที่หน้าเว็บ
- ไม่ได้แสดงค่า key ที่ไหนเลย
