ผมสร้างสกิล `yolo-ppe-train` เวอร์ชัน 0 และติดตั้งเป็นสกิลของโปรเจกต์แล้ว ตรวจแล้วว่าสคริปต์ทั้ง 5 ไฟล์ compile ผ่าน แต่สคริปต์ที่แก้ยังไม่ได้รันจริงบนเครื่อง GPU จะได้ทดสอบจริงในขั้นที่ 10

## สกิลทำอะไรได้
ทำซ้ำ LAB 1 ได้ในคำสั่งเดียว:
1. **เช่าเครื่อง** บน Vast.ai
2. **เตรียม Dataset** construction-site-safety รุ่น 28 พร้อมภาพตัวอย่าง 8 รูป
3. **เทรน** YOLO11s แบบรันแยกจากการเชื่อมต่อ SSH ถ้าเครื่องหลุดกลางทางก็เทรนต่อจากเดิมได้ และรายงานความคืบหน้าทุก 2 นาที
4. **วัดผล** ก่อน vs หลังเทรนบน Test Set ได้ `metrics.json` ภาพเทียบ 5 ภาพ กราฟ 2 รูป และรูปตัวอย่างสำหรับเว็บ 6 รูป
5. **(เลือกได้) เปิด AI server** `/v1/detect` พร้อมทดสอบ 3 ข้อ และเขียน `web/.env` ให้
6. **(เลือกได้) เปิดเว็บ SiteSafe** แล้วทดสอบกับรูปตัวอย่างทั้ง 6 รูป
7. **ลบเครื่อง** แล้วสรุปบิลจริง

ทุกงานที่แตะ Vast.ai สกิลนี้ส่งต่อให้สกิล `vastai` ทำ ไม่ได้เขียนวิธีใช้ซ้ำ

**เกณฑ์ตรวจผ่าน**อิงตัวเลขจริงของรอบนี้ เช่น mAP50 จาก 0.090 เป็น 0.782 และ Dataset มี 82 ภาพใน Test Set

**กติกาเรื่องเงิน:**
- ลบเครื่องเสมอ รวมถึงตอนที่งานล้มกลางทาง
- เช่าได้ครั้งละ 1 เครื่อง และแตะเฉพาะเครื่องป้ายของตัวเอง
- งบอ้างอิงรอบเต็มประมาณ 0.21 USD ถ้าเครื่องเปิดเกิน 1 ชั่วโมงต้องรายงานก่อนทำต่อ

## สิ่งที่ต่างจากโค้ดเดิม
ผมแก้สคริปต์เล็กน้อยเพื่อให้ค่าที่ปรับได้ใช้งานได้จริง:
- **`train.py`** รับจำนวน Epoch และค่าการเทรนอื่นผ่านตัวแปรสภาพแวดล้อม (เดิมตั้งตายตัวไว้ที่ 50 Epoch)
- **`eval.py`** อ่านจำนวน Epoch จากผลการเทรน แทนข้อความ "50 epochs" ที่เขียนตายตัวไว้
- **`serve.py`** ตั้งชื่อโมเดลและเกณฑ์ confidence ได้
- **`download_dataset.py`** รับ Roboflow key ทาง stdin ได้ด้วย key จึงไม่ต้องอยู่ในบรรทัดคำสั่ง
