## สรุปผลการเทรน

เทรนครบ 50 Epoch โดยเริ่มจาก yolo11s ที่เทรนบน COCO มาแล้ว และจบโดยไม่มีข้อผิดพลาด

| รายการ | ผล |
|---|---|
| เวลาที่ใช้เทรน | **418 วินาที (ประมาณ 7 นาที)** บน RTX 4090 |
| mAP50 บน Validation Set ที่ Epoch 10 | **0.661** |
| mAP50 บน Validation Set ที่ Epoch 25 | **0.767** |
| mAP50 บน Validation Set ที่ Epoch 50 | **0.819** |

- ระหว่างเทรนรายงานทุก 2 นาที ได้ค่า mAP50 ดังนี้: Epoch 2 = 0.493 → Epoch 18 = 0.748 → Epoch 35 = 0.805 → Epoch 50 = 0.819
- เมื่อเทรนจบ สคริปต์วัดโมเดลที่ดีที่สุด (best.pt) อีกรอบ ได้ mAP50 = 0.817 ใน log จะเห็นรอบนี้เป็น "Epoch 51/50"
- การเทรนรันใน tmux session `train` บนเครื่องที่เช่า จึงเทรนต่อได้แม้การเชื่อมต่อหลุด log อยู่ที่ `/workspace/train.log`
- ไฟล์โมเดลอยู่บนเครื่องที่เช่าที่ `/workspace/runs/ppe/weights/best.pt`
- โฟลเดอร์ `lab1_yolo` ใน container เดิมว่างอยู่ จึงคัดลอก `train.py` จากโฟลเดอร์ของบทบนเครื่องนี้เข้าไปก่อนเริ่มเทรน

**เครื่อง vapp-lab1 (RTX 4090, ประมาณ $0.41 ต่อชั่วโมง) ยังเปิดอยู่และยังคิดเงินอยู่** พร้อมสำหรับขั้นที่ 4 (Evaluation)
