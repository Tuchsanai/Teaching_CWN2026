AI server เปิดใช้งานได้แล้ว ส่งรูปเข้าไปแล้วได้กรอบกลับมา และ mAP50 บน Test Set ขึ้นจาก **0.090 เป็น 0.782** เครื่อง `vapp-v-lab1` ยังเปิดอยู่ตามสูตรเพื่อให้เว็บใช้ต่อ

**เครื่องที่สร้างและลบ**
- เครื่องแรกเป็น RTX 4090 ที่ Florida ราคา $0.451/ชม. แต่เปิดไม่ขึ้น Vast ตอบว่า GPU ไม่ว่าง ("Required resources are currently unavailable") จึงลบทิ้งทันที ยังไม่ถูกเก็บเงิน
- จึงเช่าเครื่องใหม่ที่ถูกที่สุดในรายการ ตอนนี้ใช้เครื่องนี้อยู่
