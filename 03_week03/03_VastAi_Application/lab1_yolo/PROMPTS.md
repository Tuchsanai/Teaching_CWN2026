# LAB 1 · พรอมต์ Copy & Paste

วางทีละพรอมต์ในช่องพิมพ์ของ Claude Code app (เปิดที่โฟลเดอร์ของบทนี้) · ทำตามลำดับขั้นที่ 1 → 7 ให้ครบในรอบเดียว

## ขั้นที่ 1 · เช่าเครื่อง GPU (~3 นาที)

```text
ทำงานใน container `multi-account` โฟลเดอร์ /workspace/vastapp_lab ด้วยสกิล vastai

เช่าเครื่อง GPU สำหรับเทรนโมเดล
1. เช่า RTX 4090 1 ใบ ราคารวมไม่เกิน $0.70 ต่อชั่วโมง ตั้งป้ายเครื่องว่า vapp-lab1
2. เลือกเครื่อง verified ที่เน็ตเร็วทั้งขาเข้าและขาออก (500 Mbps ขึ้นไป) มี CPU 12 cores ขึ้นไป แล้วเอาเครื่องที่ถูกที่สุด
3. ใช้ image PyTorch 2.8 ที่มี CUDA 12.8 disk 40 GB และเปิดพอร์ต 8080 ไว้ให้ AI server
4. รอจนเครื่องพร้อมและเข้าไปเห็น GPU จริง ถ้าเกิน 10 นาทียังไม่พร้อม ให้ลบแล้วเช่าเครื่องอื่น
กุญแจ SSH อยู่ที่ /workspace/vastai_lab/Devtool_SSH/devtoolSSH

สรุปเป็นตารางภาษาไทย: GPU · ราคาต่อชั่วโมง · ที่ตั้ง · CPU cores · เวลาที่รอจนเครื่องพร้อม แล้วบอกว่าเครื่องยังเปิดอยู่
```

## ขั้นที่ 5 · เปิด AI server (~3 นาที)

```text
ทำงานใน container `multi-account` โฟลเดอร์ /workspace/vastapp_lab ด้วยสกิล vastai
เครื่องที่ใช้คือเครื่องป้าย vapp-lab1 · กุญแจ SSH อยู่ที่ /workspace/vastai_lab/Devtool_SSH/devtoolSSH

เปิด AI server บนเครื่องที่เช่า ให้เว็บส่งรูปมาถามโมเดลที่เทรนได้
1. ใช้สคริปต์ lab1_yolo/serve.py ของโฟลเดอร์ปัจจุบัน เปิด AI server ที่พอร์ต 8080 ให้ทำงานต่อได้แม้การเชื่อมต่อหลุด (สคริปต์สร้าง API key ให้เอง)
2. ทดสอบจากนอกเครื่อง 3 ข้อ: server ตอบว่าพร้อม · ส่งรูปจาก Test Set 1 รูปพร้อม key แล้วได้กรอบกลับมา · ส่งแบบไม่มี key ต้องถูกปฏิเสธ
3. เขียนไฟล์ lab1_yolo/web/.env ของโฟลเดอร์ปัจจุบัน ให้มี YOLO_BASE_URL YOLO_API_KEY และ YOLO_MODEL=ppe-yolo11s เพื่อให้เว็บต่อ server นี้ได้

ห้ามแสดงค่า key · สรุปเป็นภาษาไทย: ผลทดสอบ 3 ข้อ และเวลาที่โมเดลใช้ต่อรูป แล้วบอกว่าเครื่องยังเปิดอยู่
```

## ขั้นที่ 6 · เปิดเว็บและทดสอบ (~2 นาที)

```text
เปิดเว็บตรวจความปลอดภัยหน้างานบนเครื่องนี้ (Docker Desktop) แล้วต่อกับ AI server บน Vast.ai
1. เปิดเว็บในโฟลเดอร์ lab1_yolo/web ด้วย docker compose แล้วรอจน http://localhost:3401 เปิดได้ (เว็บอ่านที่อยู่และ key ของ AI server จากไฟล์ .env ที่ขั้นก่อนเขียนไว้)
2. ทดสอบโดยส่งรูป sample-1.jpg sample-2.jpg sample-5.jpg ในโฟลเดอร์ lab1_yolo/web/public/samples ให้เว็บตรวจทีละรูป

สรุปเป็นตารางภาษาไทย: รูป · ผล (ผ่าน/ไม่ผ่าน) · จำนวนคนไม่สวมหมวก · เวลาที่โมเดลใช้ (ms) · เวลาส่งรูปไป-กลับ (ms) ห้ามแสดงค่า key แล้วบอกว่าเครื่องบน Vast.ai ยังเปิดอยู่
```

เปิด http://localhost:3401 ในเบราว์เซอร์ แล้วลองกดรูปตัวอย่างหรืออัปโหลดรูปเอง · ดูผลย้อนหลังที่หน้า "ประวัติ"
