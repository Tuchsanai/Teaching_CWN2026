## สรุปขั้นที่ 2: เปิดแชทบอท shop-bot บน GPU 1 ใบ บนเครื่อง vapp-lab6 แล้ว

แชทบอทเปิดอยู่และทดสอบผ่านแล้ว ทั้ง 2 คำถามที่ส่งพร้อม key ได้คำตอบแบบ streaming และการเรียกที่ไม่มี key ถูกปฏิเสธ

**เวอร์ชัน:** vLLM **0.34.0** (บน PyTorch 2.14.0 + CUDA 13.2) · NGINX และ C compiler (gcc, build-essential, python3-dev) ติดตั้งครบ

| ขั้นตอน | เวลา |
|---|---|
| ติดตั้ง NGINX และ C compiler | 15 วินาที |
| ติดตั้ง vLLM | 241 วินาที |
| **ติดตั้งรวม** | **256 วินาที (~4.3 นาที)** |
| ดาวน์โหลดโมเดล Qwen3-4B-Instruct-2507 (7.6 GB) | **67 วินาที** |
| เปิด server จนพร้อมรับคำถาม (vLLM + NGINX) | **145 วินาที** |

**สคริปต์ `cluster.sh`**
- ตัวต้นฉบับอยู่ใน container ที่ `/workspace/vastapp_lab/lab6_llm_chat/code/cluster.sh` และนำขึ้นเครื่องที่เช่าไว้ที่ `/workspace/lab6/cluster.sh`
- คำสั่งที่ใช้ได้: `start --gpus 1|2 --mode batch|single --lb least_conn|round_robin` · `lb` · `status` · `stop`
- `--mode batch` คือ Continuous Batching ตามค่าปกติของ vLLM (พร้อมกันสูงสุด 256 คำถาม) ส่วน `--mode single` ตอบทีละ 1 คำถาม
- NGINX รับผู้ใช้ที่พอร์ต 8000 ส่ง token ต่อทันทีแบบ streaming และทุกคำตอบมี header `X-Served-By` บอกว่าไป vLLM ตัวไหน
- สลับ least_conn ↔ round robin ได้โดยไม่ต้องเปิด vLLM ใหม่ ทดสอบแล้ว: NGINX โหลดค่าใหม่ ส่วน vLLM ยังเป็นตัวเดิม
- API key สคริปต์สุ่มเอง เก็บไว้บนเครื่องที่เช่าที่ `/workspace/lab6/secrets/api_key` (สิทธิ์ 600)
- vLLM แยกออกจากการเชื่อมต่อ SSH จึงทำงานต่อได้แม้การเชื่อมต่อหลุด หลังปิดการเชื่อมต่อที่ใช้สั่งเปิดแล้ว ระบบยังตอบได้ (health 200)

**ผลทดสอบ** (สั่งบนเครื่องที่เช่า ผ่าน NGINX พอร์ต 8000 ตอบไม่เกิน 150 token)

| คำถาม | ไป vLLM ตัว | token ขาเข้า / คำตอบ | เวลาถึงตัวอักษรแรก (TTFT) | เวลารวม | ความเร็ว |
|---|---|---|---|---|---|
| น้ำยาล้างจานแบบไหนอ่อนโยนต่อมือ เหมาะกับคนผิวแพ้ง่ายคะ | vllm-1 | 78 / 150 | 0.144 วินาที | 1.92 วินาที | 84.3 token/วินาที |
| ไม้ถูพื้นแบบสเปรย์กับแบบถังปั่น ต่างกันอย่างไร ควรเลือกแบบไหนดีครับ | vllm-1 | 90 / 150 | 0.026 วินาที | 1.79 วินาที | 84.9 token/วินาที |

- **คำตอบข้อ 1:** "ค่ะ สำหรับคนผิวแพ้ง่าย แนะนำน้ำยาล้างจานที่มีส่วนผสมอ่อนโยน… ปลอดภัยกับผิว ไม่ระคายเคือง และมีส่วนผสมจากธรรมชาติ เช่น น้ำมะพร้า" ถูกตัดตรงนี้เพราะครบ 150 token
- **คำตอบข้อ 2:** "สวัสดีครับ… 🔹 **แบบสเปรย์** ใช้สะดวก แค่สเปรย์สารลงบนพื้นแล้วถูด้วยไม้ถู ดีสำหรับพื้นที่เล็ก… ไม่ต้องใช้แรงปั่น แต่อาจไม่กระจายสาร" ถูกตัดเพราะครบ 150 token เช่นกัน
- **เรียกแบบไม่มี key:** ถูกปฏิเสธด้วย `HTTP 401 {"error":"invalid or missing API key"}`

ทั้ง 2 คำตอบยาวเกิน 150 token จึงถูกตัดกลางประโยค ในขั้นยิงโหลดถัดไปควรขอให้บอทตอบสั้นลง หรือเพิ่มเพดาน token

**ความปลอดภัย:** HF_TOKEN ส่งเข้าเครื่องผ่าน stdin เฉพาะตอนดาวน์โหลด ค้นทั้งเครื่องด้วยค่าจริงของ token แล้วไม่พบเหลืออยู่ที่ไหน · ไม่ได้แสดงค่า key หรือ token ในผลลัพธ์ใดเลย
