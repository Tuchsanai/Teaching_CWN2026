# ทดสอบแชทบอทอัตโนมัติ 26 เคส (Playwright)

เปิดเว็บแชทบอทจริงในเบราว์เซอร์ พิมพ์และกดปุ่มเหมือนลูกค้า แล้วตรวจคำตอบตามเงื่อนไขใน `cases.json`
(เคส 1-18 ถามข้อเดียว, เคส 19-26 ถามต่อเนื่องในแชทเดียวกัน) ทุกเคสได้วิดีโอ GIF และมีรายงานเทียบคำตอบที่ควรได้กับคำตอบจริง

## วิธีรัน (ใน Linux container)

เริ่มเว็บจากโฟลเดอร์ `../frontend` ให้เปิดที่ http://localhost:3300 ก่อน แล้วรันคำสั่งเดียว

```bash
bash run-all.sh
```

สคริปต์ทำ 6 ขั้น: ติดตั้ง Playwright + Chromium + ffmpeg (ครั้งแรกเท่านั้น) → ตรวจว่าเว็บเปิดอยู่ → ล้างตารางการจองและประวัติแชท → รัน 26 เคส → ทำ GIF ของแต่ละเคส → เขียนรายงาน
รันซ้ำได้ และจบด้วยสถานะสำเร็จแม้มีเคสไม่ผ่าน (ดูจำนวนที่ผ่านในบรรทัดสุดท้าย)

ปรับได้: `BASE_URL=http://localhost:3300` (ที่อยู่เว็บ) · `WORKERS=1` (จำนวนเคสที่รันพร้อมกัน ค่าเริ่มต้น 2) · `ANSWER_TIMEOUT_MS=180000` (เวลารอคำตอบ 1 ข้อความ)

## ผลลัพธ์ในโฟลเดอร์ `out/`

- `TEST_REPORT.md` — สรุปจำนวนที่ผ่าน ชื่อโมเดล และตารางทุกเคส (คำตอบที่ควรได้ เทียบ คำตอบจริง)
- `results.json` — ผลเดียวกันแบบข้อมูล (คำตอบจริงครบทุกข้อความ)
- `gifs/case<N>-<ชื่อ>.gif` — วิดีโอของแต่ละเคส (กว้าง 800 px ไม่เกิน 1.5 MB)
- `videos/`, `answers/` — วิดีโอเต็ม (.webm) และผลดิบรายเคส

## ไฟล์สำคัญ

- `cases.json` — 26 เคส: ลูกค้าทำอะไร, ต้องมีอะไรในคำตอบ, คำตอบที่ควรได้
- `tests/chatbot.spec.ts`, `tests/helpers.ts`, `tests/check.ts` — ตัวรันเคส, การพิมพ์/รอคำตอบ, การตรวจเงื่อนไข
- `make-media.mjs`, `make-report.mjs` — ทำ GIF และรายงาน

รันเฉพาะบางเคส: `npx playwright test -g case16` แล้ว `node make-media.mjs && node make-report.mjs` (GIF ทำจากภาพหน้าจอใน `out/frames/` ที่เทสต์เก็บไว้)
