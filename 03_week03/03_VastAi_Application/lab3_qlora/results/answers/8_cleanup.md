## ไฟล์ที่คัดลอกกลับมาไว้ใน `lab3_qlora`

- **จาก container:**
  - `code/`: `train.py`, `eval_val.py`, `serve.sh`
  - `results/`: `adapter/` (LoRA และ tokenizer), `loss_curve.png`, `train_log.json`, `val_eval.json`, `val_eval.log`
  - GIF และคำตอบของการทดสอบ E2E ไว้ที่ `results/e2e/base|ft/` และ `results/e2e/diff-gifs/`
- **จากเครื่องเช่า (ดึงมาก่อนลบเครื่อง):** `code/run.sh`, `results/progress.json`, `results/run_state.json` และ log ใน `results/logs/` (train, serve, setup, vllm_install, trainer_state)
  - ตรวจไฟล์เหล่านี้แล้ว ไม่พบ API key หรือ token หลุดอยู่
- **ไม่ได้คัดลอก:** `checkpoints/` บนเครื่องเช่า (ประมาณ 400 MB) เพราะ checkpoint สุดท้ายคือ adapter ที่คัดลอกมาแล้ว
- **ไม่ได้เขียนทับ:** ไฟล์ที่มีอยู่แล้วบนเครื่องนี้ เช่น `code/web/db/init.sql` ใช้ฉบับบนเครื่องนี้ต่อ
- **ไฟล์ใหม่:**
  - `results/close_record.json`: ข้อมูลของเครื่องที่จดไว้ก่อนลบ
  - `results/answers/8_close.md`: สรุปขั้นนี้ เขียนแบบเดียวกับไฟล์ 1–7
