## สกิลทำอะไรได้
สั่งทำ LAB 3 ซ้ำได้ในคำสั่งเดียว คือสอนโมเดลเล็ก Qwen3-4B ด้วย QLoRA ให้เป็นแชทบอทร้านนวด "สบายใจ" งานที่แตะ Vast.ai ทั้งหมดส่งต่อให้สกิล `vastai` โดยไม่แก้สกิลนั้น ลำดับงานมีดังนี้:
1. **(เลือกได้) สร้าง Dataset ใหม่:** สร้างคำถามลูกค้า แล้วเช่า RTX 5090 เปิดโมเดลครู 27B ให้ตอบ คัดเฉพาะคำตอบที่ถูก แล้วลบเครื่องครูทันที
2. **เทรน:** เช่า RTX 3090 แล้วเทรน QLoRA แบบเทรนต่อได้แม้การเชื่อมต่อหลุด และรายงานความคืบหน้าทุก 5 นาที
3. **วัดผล:** เปิด AI server 2 โมเดล (`qwen3-4b-base` และ `qwen3-4b-sabaijai`) แล้ววัด Base เทียบ Fine-tuned บน Validation Set
4. **(เลือกได้) ทดสอบผ่านเว็บ:** เปิดเว็บแชทบอทที่ http://localhost:3403 พร้อมหน้า `/compare` และรันชุดทดสอบ 26 เคส
5. **ปิดงาน:** ลบเครื่องทุกครั้ง ปิดเว็บ และสรุปค่าใช้จ่าย

ในสกิลมีเกณฑ์ตรวจผ่าน พร้อมค่าอ้างอิงจากรอบจริงไว้เทียบ เช่น Validation loss 1.004 → 0.307, คำตอบถูก 87.1% → 94.1%, ชุดทดสอบได้ 25/26 ทั้งสองโมเดล และค่าเครื่องประมาณ $0.36 กติกาเรื่องเงินมีดังนี้:
- จบงานหรือมีขั้นที่ล้มจนไปต่อไม่ได้ ต้องลบเครื่องเสมอ
- ห้ามเกินเพดานราคา และห้ามขยับเพดานเอง
- งานนี้เปิดเครื่องได้ครั้งละ 1 เครื่อง
- แตะได้เฉพาะเครื่องป้ายของงานนี้
- เครื่องไหนเปิดเกิน 2 ชั่วโมง ต้องรายงานผู้ใช้ก่อนทำต่อ

## ไฟล์ที่อยู่ในสกิล
- **`SKILL.md`:** มี name, description, ค่าที่ปรับได้, ขั้นตอนที่ 0–9, เกณฑ์ตรวจผ่าน, กติกาเรื่องเงิน และแบบสรุปตอนจบ
- **`scripts/`:** โค้ดที่รันจริงแล้ว คัดลอกจาก `lab3_qlora/code` ตอนใช้งานสกิลจะคัดลอกไปไว้เป็น `<lab>/code/` เพราะสคริปต์อ้างไฟล์กันแบบ path สัมพัทธ์
  - `make_questions.py` · `make_dataset.py` · `train.py` · `run_train.sh` · `serve.sh` · `eval_val.py`
  - `web/` (เว็บแชทบอท) และ `e2e/` (ชุดทดสอบ 26 เคส)
- **`references/ninfer_teacher.md`:** คู่มือเปิดโมเดลครูด้วย NInfer คัดลอกมาจากบทที่แล้ว ใช้เฉพาะตอนสร้าง Dataset ใหม่

ส่วนที่ต่างจากโค้ดใน LAB มี 3 จุด:
- **`train.py`:** เพิ่ม `--model` เพื่อให้เปลี่ยนโมเดลตั้งต้นได้
- **`run_train.sh`:** แก้มาจาก `run.sh` เดิม ซึ่งบรรทัดบันทึกเวลาเสีย ตอนนี้ส่งค่า `--epochs`, `--model` และ `--out_dir` ต่อให้ `train.py` ได้
- **ข้อมูลลับ:** ตรวจแล้ว ไม่มี key หรือ IP ติดมาในสกิล
