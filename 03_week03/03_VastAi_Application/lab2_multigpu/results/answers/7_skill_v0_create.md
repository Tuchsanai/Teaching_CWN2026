สร้างสกิล `multigpu-speedup` เวอร์ชัน 0 เสร็จแล้ว และติดตั้งเป็นสกิลของโปรเจกต์เรียบร้อย ยังไม่ได้ลองรันสกิลจริงบน Vast.ai ซึ่งจะทำในขั้นที่ 8

## สกิลทำอะไรได้
สั่งครั้งเดียวแล้วสกิลทำ LAB 2 ให้ครบทุกขั้นตามลำดับนี้
1. เช่าเครื่องที่มี GPU 2 ใบในเครื่องเดียว และจดว่า GPU ต่อกันแบบ NVLink หรือ PCIe
2. เตรียม Dataset hard-hat-workers และทำภาพตัวอย่าง โดยส่ง key ทาง stdin ไม่ทิ้งไว้บนเครื่องเช่า
3. ลองรันสั้น ๆ ก่อน ทั้ง 1 และ 2 GPU
4. เทรน YOLO11m ด้วย GPU 1 ใบ แล้วเทรนซ้ำด้วย 2 ใบโดยใช้ค่าเดิมทุกอย่าง ระหว่างนั้นวัดวินาทีต่อ Epoch และต่อ step, GPU util, CPU ที่ใช้จริง และเวลา all-reduce
5. ค้นราคาตลาดตอนนี้ แล้วคำนวณ speedup, efficiency และเงินต่อ Epoch พร้อมกราฟ 4 รูป
6. ลบเครื่องและสรุปค่าใช้จ่ายจริง

งานทุกอย่างที่แตะ Vast.ai สกิลส่งต่อให้สกิล `vastai` ทำ ไม่ได้เขียนวิธีใช้ซ้ำ ในสกิลมีเกณฑ์ตรวจผ่านและค่าอ้างอิงจากรอบจริงของ LAB 2 ไว้เทียบ เช่น 128.3 → 73.9 วินาทีต่อ Epoch (เร็วขึ้น 1.74 เท่า) และ all-reduce 21.4 ms ส่วนกติกาเรื่องเงินคือลบเครื่องเสมอ รวมถึงตอนที่งานล้มกลางทาง ห้ามเช่าเกินเพดานราคา เช่าได้ทีละเครื่อง และแตะเฉพาะเครื่องที่มีป้ายของงานนี้

## ค่าที่ปรับได้
| ค่า | ค่าเริ่มต้น |
|---|---|
| รุ่น GPU (`gpu`) | RTX 3090 |
| จำนวน GPU (`num_gpus`) | 2 (สูงสุด 2 ใบ ถ้าเลือก 1 จะวัดแค่เส้นฐาน 1 GPU) |
| เพดานราคา (`max_price`) | $0.60/ชม. |
| Epoch (`epochs`) | 5 (ต้องไม่น้อยกว่า 3 เพราะค่าเฉลี่ยไม่นับ Epoch แรกกับ Epoch สุดท้าย) |
| ป้ายเครื่อง (`label`) | `vapp-lab2` |

ค่าอื่นที่ปรับได้ด้วย ได้แก่ เกณฑ์เลือกเครื่อง, image, disk 60 GB, เวลารอเครื่องพร้อม 10 นาที, model/imgsz/batch/seed, โฟลเดอร์เก็บผล (`out_dir`) และ `keep_machine`
