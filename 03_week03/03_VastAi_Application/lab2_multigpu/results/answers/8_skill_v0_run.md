# สรุปผล: ใช้สกิล multigpu-speedup กับ RTX 3090 × 2 (3 Epoch ต่อรอบ)

2 GPU เร็วกว่า 1 GPU **1.79 เท่า** และ **ลบเครื่องแล้ว** ค่าใช้จ่ายจริง **$0.143** ผลเก็บไว้ที่ `lab2_multigpu/results/skill_v0_run/` ไม่ได้แตะผลเดิมใน `lab2_multigpu/results`

## เครื่องที่เช่า

| รายการ | ค่า |
|---|---|
| GPU | RTX 3090 × 2 ในเครื่องเดียว (24 GB ต่อใบ) |
| GPU ต่อกันแบบ | PHB (ผ่าน PCIe host bridge ไม่มี NVLink และไม่ข้าม CPU socket) |
| ราคา | $0.369/ชม. (ไม่เกิน $0.60) |
| ที่ตั้ง | Missouri, US |
| CPU | AMD Ryzen 7 3700X · 16 threads |

- ไม่ได้เลือกเครื่องที่ถูกที่สุด ($0.351, Quebec) เพราะความน่าเชื่อถือ (reliability) แค่ 0.60
- Dataset: Train 14,748 ภาพ (head 13,670 / helmet 41,450 กรอบ) · Valid 1,413 ภาพ · Test 706 ภาพ · 2 คลาส · ตรวจแล้วไม่มี key ค้างบนเครื่องเช่า

## 1 GPU เทียบ 2 GPU

| | 1 GPU | 2 GPU |
|---|---|---|
| **วินาทีต่อ Epoch** | **110.3** | **61.4** (ideal 55.1) |
| **Speedup** | 1.00× | **1.79×** · efficiency 89.8% |
| วินาทีต่อ step | 0.239 | 0.266 (+27 ms) |
| Step ต่อ Epoch | 461 | 231 (≈ ครึ่ง) |
| GPU util | 96.5% | 92.9% / 94.6% |
| CPU ที่ใช้ | 2.0 cores | 3.2 cores |
| All-reduce 80 MB | – | 22.5 ms |
| mAP50 (3 Epoch) | 0.950 | 0.944 |
| **เงินต่อ Epoch (ราคาตลาด)** | $0.00630 (เครื่อง 1 GPU $0.2056/ชม.) | **$0.00598** (เครื่อง 2 GPU $0.3506/ชม.) |
| **เงินต่อ Epoch (เครื่องที่เช่าจริง)** | $0.01130 | **$0.00629** |

ตอน 3 Epoch ค่าเฉลี่ยนับได้แค่ Epoch กลางอันเดียว เพราะไม่นับ Epoch แรกและสุดท้าย เวลาทั้ง 3 Epoch คือ 1 GPU 118 / 110 / 123 วินาที และ 2 GPU 71 / 61 / 69 วินาที ตัวเลข speedup จึงแกว่งได้มากกว่ารอบ 5 Epoch

## ตอบ 3 ข้อ

1. **เร็วขึ้นกี่เท่า:** 1.79 เท่า (110.3 → 61.4 วินาทีต่อ Epoch) คิดเป็น efficiency 89.8% สูงกว่าค่าอ้างอิงเดิมที่ได้ 1.74 เท่า
2. **แบบไหนคุ้มเงินที่สุดต่อ 1 Epoch:** เครื่อง 2 GPU ทั้งสองแบบ
   - ราคาตลาด: $0.00598 ต่อ Epoch เทียบกับ $0.00630 ของเครื่อง 1 GPU ถูกกว่าเล็กน้อยและเสร็จเร็วกว่าเกือบเท่าตัว
   - บนเครื่องที่เช่าจริง: ถ้าเปิดเครื่อง 2 ใบแต่ใช้แค่ใบเดียว จะเสียเงินเกือบสองเท่า ($0.0113 เทียบกับ $0.0063 ต่อ Epoch)
3. **ทำไมไม่เร็วขึ้น 2 เท่า:**
   - เวลาต่อ step เพิ่มจาก 239 เป็น 266 ms (+27 ms) เกือบทั้งหมดคือการรวม gradient ระหว่าง 2 GPU (all-reduce 80 MB ใช้ 22.5 ms)
   - GPU สองใบต่อกันผ่าน PCIe (PHB) ไม่มี NVLink จึงส่งข้อมูลได้แค่ราว 3.7 GB/s
   - GPU util ลดจาก 96.5% เหลือ 93–95% ส่วน CPU ใช้เพิ่มจาก 2.0 เป็น 3.2 cores ซึ่งยังเหลือเยอะ (16 threads) จึงไม่ใช่คอขวด
