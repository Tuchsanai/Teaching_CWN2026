เทรนรอบจริงด้วย GPU 1 ใบบนเครื่อง vapp-lab2 (RTX 3090 ×2) เสร็จแล้ว ใช้เวลารวมประมาณ 12 นาที

**ผลรอบ 1 GPU (เส้นฐาน)**

| ค่าที่วัด | 1 GPU |
|---|---|
| วินาทีต่อ Epoch (เฉลี่ย Epoch 2–4) | **128.3 วินาที** |
| วินาทีต่อ step (461 step ต่อ Epoch, batch 32) | **0.278 วินาที** (ประมาณ 115 ภาพต่อวินาที) |
| GPU util เฉลี่ย | **85.5%** |
| CPU ที่งานใช้จริง | **2.8 core** (เครื่องมี 64 thread) |
| mAP50 ตอนจบ (Validation Set) | **0.962** (mAP50-95 = 0.638) |

- **Epoch แรกและ Epoch สุดท้ายช้ากว่า:** แต่ละ Epoch ใช้ 146 / 128 / 129 / 128 / 149 วินาที Epoch แรกช้ากว่าเพราะเป็นช่วงเริ่มต้น ส่วน Epoch สุดท้ายรวมเวลาวัด Validation ไว้ด้วย จึงตัดสองรอบนี้ออกตามที่กำหนด
- **ใช้ CPU แค่ประมาณ 2.8 core:** ตอนนี้ CPU ยังไม่ใช่คอขวด

**รอบทดสอบสั้น (ภาพ 5%, 2 Epoch)**
- **1 GPU:** รันผ่าน
- **2 GPU:** รันผ่าน
- **all-reduce ขนาด 80 MB ระหว่าง GPU 2 ใบ:** ใช้เวลาประมาณ **21.4 มิลลิวินาที** (bus bandwidth ประมาณ 3.9 GB/s) GPU สองใบต่อกันผ่าน PCIe แบบ PHB ไม่มี NVLink
- **mAP50 ของรอบทดสอบสั้นเป็น 0:** เทรนแค่ 48 step ซึ่งยังอยู่ในช่วง warm-up ทั้งหมด จึงไม่มีความหมาย ผลรอบจริงได้ 0.962 ตามปกติ

**ทำงานต่อได้แม้การเชื่อมต่อหลุด:** รันงานบนเครื่องเช่าด้วย `setsid nohup` แล้วตัดการเชื่อมต่อ SSH ทิ้งระหว่างเทรน งานยังรันต่อจนจบ

**สคริปต์ `bench.py`**
- ก่อนเริ่มตรวจว่า GPU ว่าง (ไม่มีโปรเซสอื่นและไม่มีหน่วยความจำค้าง)
- เก็บ GPU util ทุกวินาทีจาก `nvidia-smi`
- นับ CPU จากเวลา CPU ที่โปรเซสหลักและโปรเซสลูกทั้งหมดใช้ หารด้วยเวลาจริงของช่วง Epoch 2–4
- อ่านเวลาของแต่ละ Epoch จาก `results.csv`
