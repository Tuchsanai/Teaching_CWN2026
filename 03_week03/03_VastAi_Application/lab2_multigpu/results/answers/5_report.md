## ตอบ 3 ข้อ

**1. เร็วขึ้นกี่เท่า:** 1.74 เท่า จาก 128.3 เหลือ 73.9 วินาทีต่อ Epoch ถ้าเร็วขึ้นตามจำนวน GPU จะเหลือ 64.2 วินาที จึงได้ efficiency 87% ความแม่นยำไม่ลดลง (mAP50 0.962 กับ 0.963)

**2. แบบไหนคุ้มเงินที่สุดต่อ 1 Epoch:** คำตอบขึ้นกับว่าเช่าเครื่องแบบไหน
- **ถ้าเช่าใหม่ในราคาตลาด เครื่อง 1 GPU ถูกที่สุด** ที่ $0.0068 ต่อ Epoch ถูกกว่าเครื่อง 2 GPU ที่ $0.0072 อยู่ประมาณ 5% เหตุผลคือเครื่อง 2 ใบแพงขึ้น 1.83 เท่า แต่เร็วขึ้นแค่ 1.74 เท่า ถ้ารีบอยากได้ผลเร็ว ควรเลือก 2 GPU เพราะจ่ายเพิ่มเพียงเล็กน้อยแต่ประหยัดเวลาได้ 42%
- **บนเครื่อง vapp-lab2 ที่เช่าอยู่ ควรใช้ทั้ง 2 ใบ** ที่ $0.0085 ต่อ Epoch ถ้าใช้ใบเดียวจะเป็น $0.0148 ต่อ Epoch เพราะยังต้องจ่ายค่าเครื่องเต็มราคา $0.414 ต่อชั่วโมง

**3. ทำไมไม่เร็วขึ้นตามจำนวน GPU** (ตัวเลขทั้งหมดวัดได้จริง)
- **เวลาต่อ step เพิ่มจาก 278 เป็น 320 ms (+41 ms):** แต่ละ GPU ยังประมวลผลภาพ 32 ภาพเท่าเดิม แต่ทุก step ต้องรอซิงก์กันก่อน
- **การรวม gradient (all-reduce) ขนาด 80 MB ใช้ 21.4 ms ต่อครั้ง หรือราว ½ ของเวลาที่เพิ่มมา:** GPU สองใบเชื่อมกันแบบ PHB คือผ่าน PCIe และ CPU โดยไม่มี NVLink ความเร็วจึงได้แค่ 3.9 GB/s ที่เหลือราว 20 ms คือเวลาที่ GPU ใบหนึ่งรออีกใบ
- **GPU util ลดลงจาก 85.5% เหลือ 81.1% และ 81.3%:** GPU ว่างนานขึ้นระหว่างรอซิงก์
- **CPU ไม่ใช่คอขวด:** รอบ 2 GPU ใช้ CPU เพียง 5.3 core จาก 64 thread (รอบ 1 GPU ใช้ 2.8 core)

**เครื่อง vapp-lab2 (instance <id>) ยังเปิดอยู่** สถานะ running และยังเสียเงิน $0.414 ต่อชั่วโมง ยังไม่ได้ลบ เพราะการลบเป็นขั้นถัดไปของ LAB
