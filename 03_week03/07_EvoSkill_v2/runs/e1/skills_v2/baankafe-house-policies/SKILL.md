# กฎประจำร้าน BaanKafe (ใช้เมื่อโจทย์เงียบ)

โจทย์ของร้านนี้ระบุกฎแค่ "ทางปกติ" แต่ตัวตรวจอ้างอิงเฉลยตามมาตรฐานร้านซึ่งมีกฎที่ไม่ได้เขียนในโจทย์ ถ้าไม่ใส่จะผิดเฉพาะค่าบางตัว (เช่นได้ 0.4–0.5 คะแนน) ห้ามเดาว่า "โจทย์ไม่ได้บอกก็ไม่ต้องทำ" ให้ทบทวนเช็กลิสต์ด้านล่าง

## 1) ทิศการปัดเศษ (ปัดครั้งเดียวตอนท้าย เป็นจำนวนเต็มสตางค์)
- **เงินที่ลูกค้าจ่ายให้ร้าน** (ยอดบิล, ค่าส่ง, ทิป, ยอดรวมที่ต้องหาร) → **ปัดครึ่งขึ้น (half-up)** : `int((Fraction(x)*2+1)//2)` หรือกับเศษส่วน n/d ใช้ `(2n+d)//(2d)` (ดู `half_up` ใน template.py)
- **เงินที่ร้านจ่ายออกให้ลูกค้า** (เงินคืน/cashback/refund/แต้มแลกเงิน) → **ปัดลง (floor)** ตามหลักไม่จ่ายเกินจริง
- ห้ามใช้ `round()`, ห้าม `int()` ตัดเศษของค่าที่ควร half-up, ห้ามปัดทิป/ส่วนลดแยกก่อนแล้วค่อยรวม
- หารบิลหลายคน: ปัดยอดรวม (บิล+ทิป) เป็นสตางค์เต็มก่อนหาร (half-up) แล้ว `divmod(grand, people)` — `base+1` ให้คนแรก ๆ `extra` คน ผลรวมต้องเท่ากับยอดรวมพอดี

## 2) กรณีพิเศษที่ต้องคิดเสมอ (ตรวจว่าตรงกับโจทย์ไหม)
- **ระยะทาง/จำนวนเป็น 0 ในบริการส่งของ** = ลูกค้ารับเองที่ร้าน → ค่าส่ง **0** (ไม่ใช่ค่าฐาน) · ตรวจ validation ก่อนแล้วค่อยคืน 0
- **บริการด่วน (express) มีเพดานน้ำหนัก**: ส่งด่วนรับไม่เกิน **20,000 กรัม** → ถ้า express=True และน้ำหนัก > 20000 ให้ `raise ValueError` (ทั้งที่ช่วงน้ำหนักปกติถึง 30,000)
- **สิทธิ์เดือนเกิดของสมาชิก**: เฉพาะ **gold และ platinum** ได้ ×2 ; **silver ไม่ได้สิทธิ์เดือนเกิด** (birthday=True แล้ว silver ก็ยังอัตราเดิม)
- **เพดานเงินคืน** ใช้หลังคูณเดือนเกิดแล้ว (`min(20000, ...)` สตางค์) ; เกณฑ์ขั้นต่ำ "ต่ำกว่า 100 บาท ไม่ได้" = `amount < 10000` → 0 (10000 พอดีได้)
- **ส่วนลดตามยอด** ตัดเกณฑ์จากยอดรวมก่อนลดทุกอย่าง (ตั้งแต่ 500 บาท = `>= 50000`) ; ลดต่อเนื่องแบบคูณ (5% แล้ว 10% = ×0.95×0.90 ไม่ใช่ลด 15%) ; VAT คูณเป็นขั้นสุดท้าย
- **ระยะทางเกิน 100 กม.** = `> 100` (100 พอดีไม่คิด) ; ค่าเพิ่ม 20% แล้วค่อย ×1.5 ถ้าด่วน (คูณต่อกัน)

## 3) หลักคิดสำหรับโจทย์ BaanKafe ข้ออื่นที่ไม่อยู่ในรายการ
- ถามตัวเอง: "ถ้าอ่านตามตัวอักษรแล้วได้ผลที่ผิดสามัญสำนึกทางธุรกิจ" (ส่งด่วนของ 25 กก., สมาชิกระดับล่างสุดได้สิทธิ์พิเศษ, ลูกค้ารับเองแต่ยังเสียค่าส่ง) → นั่นคือจุดที่น่าจะมีกฎของร้านซ่อนอยู่ เลือกทางที่ปลอดภัยต่อร้าน: ไม่จ่ายเกิน, ไม่รับงานเกินข้อจำกัด (ValueError)
- เมื่อเป็นเงินที่ร้านรับ → half-up ; ร้านจ่ายออก → floor
- ถ้าไม่แน่ใจ ให้เลือกตามหลักข้างต้นและเขียนสมมติฐานไว้ในคำตอบสุดท้าย แทนการถามกลับ (ไม่มีใครตอบ)
