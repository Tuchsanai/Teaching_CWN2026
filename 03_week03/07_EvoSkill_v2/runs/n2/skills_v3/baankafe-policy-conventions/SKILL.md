# นโยบายมาตรฐาน BaanKafe (ที่ brief มักไม่บอก)

ตัวตรวจอ้างอิง "มาตรฐานคิดเงินของร้าน" ซึ่งมีกฎแฝงที่ไม่อยู่ใน brief · rollout ที่ทำตามตัวอักษรของ brief อย่างเดียวพลาดกฎเหล่านี้ทุกครั้ง ให้ใช้กฎด้านล่างเป็นค่าเริ่มต้น และเขียนสมมติฐานไว้ใน comment + สรุปท้ายงาน

## 1. การปัดเศษ
- เงินที่ **ลูกค้าจ่ายให้ร้าน** (ยอดบิล ค่าส่ง ยอดรวมทิป) → ปัดครึ่งขึ้น (half-up) เป็นสตางค์เต็ม ทำครั้งเดียวตอนท้ายด้วย Fraction
- เงินที่ **ร้านจ่ายออกให้ลูกค้า** (เงินคืน cashback, คูปอง, แต้มแลกเงิน) → ปัดลง (floor) เพราะไม่จ่ายเกินสิทธิ์
- เพดาน/ขั้นต่ำ (เช่น สูงสุด 200 บาท) ใช้หลังคำนวณและปัดแล้ว เทียบเป็นสตางค์

## 2. สิทธิ์/ข้อยกเว้นตามระดับสมาชิก
- สิทธิ์โบนัสเดือนเกิด (ได้ 2 เท่า) ใช้กับ **gold และ platinum เท่านั้น** — silver ไม่ได้สิทธิ์แม้ `birthday=True`
- โดยทั่วไป: สิทธิพิเศษที่ "ผูกกับสมาชิก" ให้ตรวจว่าระดับล่างสุดมักไม่ได้สิทธิ์เสริมเหล่านั้น

## 3. ค่าส่ง
- `distance_km == 0` = ลูกค้ารับเองที่ร้าน → ค่าส่ง **0** (ก่อนคิดน้ำหนัก/ด่วน แต่หลังตรวจ input)
- ส่งด่วน (`express=True`) รับน้ำหนักไม่เกิน **20,000 กรัม** — เกินแล้ว `raise ValueError` (ตรวจก่อนคืน 0 ของข้อรับเอง)
- ส่วนเกินน้ำหนักคิดตามสัดส่วนกรัม (Fraction ไม่ปัดเป็นกิโลก่อน)
- ตัวคูณ (ระยะไกล +20%, ด่วน +50%) คูณต่อเนื่องกันโดยไม่ปัดระหว่างทาง

## 4. ส่วนลด/ภาษี
- เกณฑ์ลดเทียบ "ยอดรวมก่อนลด" ด้วย `>=` ตามคำว่า "ตั้งแต่" ลดต่อเนื่องทีละขั้นตามลำดับที่โจทย์เรียง VAT ท้ายสุด
- รายการสินค้า price = 0 ได้ (ผ่าน) แต่ qty ต้อง >= 1; list ว่าง → ยอด 0 (ไม่ error เว้นแต่โจทย์ห้าม)

## 5. หารบิล
- ยอดรวมทิป = `half_up(total*(100+tip)/100)` แล้วค่อยหารคน เศษสตางค์ให้คนแรก ๆ คนละ 1 ผลรวมลิสต์ต้องเท่ายอดรวม

## 6. เมื่อเจอโจทย์ใหม่ที่ไม่ตรงกฎข้างบน
ก่อนส่งงาน ไล่เช็คช่องว่างที่ brief ไม่พูดถึง แล้วเลือกตามหลักของร้าน (ระวังเกินจริง ไม่เติมกฎเกินความจำเป็น):
- ค่า 0 ของแต่ละพารามิเตอร์ (ระยะ 0, ยอด 0, จำนวนคน 1) มีความหมายพิเศษไหม? ถ้าความหมายตามธรรมชาติชัด (รับเอง = ฟรี) ให้ใช้
- ขอบบนของช่วงที่โจทย์ให้ (เช่น น้ำหนักสูงสุด 30,000) บริการพิเศษ (ด่วน) อาจรับน้อยกว่าช่วงปกติ → reject เกินเพดานบริการพิเศษ
- สิทธิพิเศษ (โบนัส) ใช้กับทุก tier ไหม หรือเฉพาะ tier สูง
- เงินเข้า-ออกร้าน → เลือกทิศการปัดตามข้อ 1
- ความสัมพันธ์ระหว่างกฎ (ลำดับ ปัด เพดาน) ให้ตีความตามตัวอักษรของ brief ก่อน นโยบายข้างบนเสริมเฉพาะจุดที่ brief เงียบ **ห้ามขัดกับสิ่งที่ brief เขียนชัด**
