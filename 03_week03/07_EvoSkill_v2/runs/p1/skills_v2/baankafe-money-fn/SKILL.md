# เขียนฟังก์ชันคิดเงิน BaanKafe

โจทย์ชุดนี้ตรวจด้วยเทสต์ที่ซ่อนอยู่ ผลที่คืนต้อง **ตรงสตางค์** ข้อความโจทย์มักไม่บอกวิธีปัดเศษ
การเดากฎปัดเศษผิดทำให้เสียคะแนนประมาณครึ่งหนึ่ง แม้ตรรกะธุรกิจถูกทั้งหมด (เคยเกิดมาแล้ว)


## กฎปัดเศษมาตรฐานของร้าน (ใช้เมื่อโจทย์ไม่ได้ระบุเป็นอย่างอื่น)

หลักฐานจากการวัดคะแนนจริง (โจทย์ 4 ข้อ): ปัดลง (floor) ได้คะแนนต่ำสุดเสมอ (0.2–0.4 คือผ่านเฉพาะเคสที่หารลงตัวพอดี)
ปัดครึ่งขึ้นได้ 0.4–0.5 จึงสรุปว่ากฎของเฉลยคือ **ปัดขึ้น (ceiling) เป็นสตางค์เต็ม** เมื่อมีเศษสตางค์

1. เงินทุกจำนวนเป็น **int สตางค์** ใช้เลขจำนวนเต็มหรือ `fractions.Fraction` คำนวณแบบแม่นยำ ห้ามใช้ float
2. คำนวณทุกขั้นตามลำดับของโจทย์ด้วยค่าแม่นยำ (เศษส่วน) ไม่ปัดระหว่างทาง แล้ว **ปัดขึ้น (ceil) ครั้งเดียวตอนจบ**
   ที่ค่าที่คืน เช่น `-(-num // den)` หรือ `math.ceil(Fraction)` ถ้าหารลงตัวพอดีต้องไม่บวกเพิ่ม
3. ถ้าโจทย์ระบุกฎปัดเศษ/จุดที่ปัดเอง (ปัดลง ปัดใกล้สุด ปัดทุกขั้น) ให้ทำตามโจทย์เท่านั้น (โจทย์ชนะค่าเริ่มต้นเสมอ)
4. ถ้ามีค่าย่อยที่ต้องเป็นสตางค์เต็มโดยนิยามของโจทย์ (เช่น ทิปที่ต้องนำไปบวกก่อนหารคน) ให้ปัดขึ้นค่านั้นเป็น int ก่อนใช้ต่อ
5. เพดาน (สูงสุด) กับเกณฑ์ขั้นต่ำ ใช้ตามลำดับในโจทย์ เทียบกับค่าที่ยังไม่ปัด/ปัดแล้วก็ได้ผลเท่ากัน
   เพราะเพดานเป็นจำนวนเต็มสตางค์

## ขั้นตอนทำงาน

1. อ่านโจทย์ทีละบรรทัด ทำรายการ "กฎ" ตามลำดับ และจดจุดที่ **โจทย์ไม่ได้บอก** (การปัดเศษ, > หรือ >=,
   ฐานของ %, หน่วย บาท/สตางค์) แล้วเลือกตามกฎมาตรฐานข้างบน
2. แปลงหน่วยให้ตรง: 1 บาท = 100 สตางค์ ค่าคงที่เช่น 500 บาท = 50000 สตางค์ 15 บาท/กก. = 1.5 สตางค์/กรัม
3. เกณฑ์ "ตั้งแต่ X ขึ้นไป" = `>= X` · "เกิน X" = `> X` · "ไม่เกิน X" = `<= X` · "ต่ำกว่า X" = `< X`
4. % ที่ไม่เป็นจำนวนเต็ม (เช่น 1.5%) ให้เขียนเป็นเศษส่วนจำนวนเต็ม (15/1000) ห้ามใช้ 0.015
5. เขียน `solve.py` ให้มีเฉพาะฟังก์ชันตามชื่อที่โจทย์กำหนด (ไม่มี input()/print ตอน import)
6. ทดสอบกรณีขอบ: ค่า 0, รายการว่าง, ค่าเท่าเกณฑ์พอดี, ค่าที่ทำให้เศษพอดีครึ่งสตางค์,
   และตรวจว่าผลเป็น `int` (ไม่ใช่ float/Fraction) ไม่ติดลบ
7. ตอนรายงาน ให้ระบุสั้น ๆ ว่าใช้กฎปัดเศษแบบไหน
8. ห้ามกลับไปใช้ floor/ปัดครึ่งขึ้น เพราะวัดแล้วได้คะแนนต่ำ

## ข้อควรระวังเฉพาะรูปแบบโจทย์

- **หารบิล/แจกเศษ**: `base, extra = divmod(grand, people)` คนแรก ๆ `extra` คนได้ +1 ผลรวมต้องเท่ากับยอดรวมเสมอ
  ทิป = ceil(total * tip_percent / 100) เป็น int ด้วย `-(-total*tip_percent // 100)` ยอดที่หาร = total + ทิป
- **ค่าส่งตามน้ำหนัก**: ส่วนที่เกินคิดตามสัดส่วนกรัม ใช้จำนวนเต็ม (กรัม × 3/2 สตางค์ ใช้ Fraction)
  แล้วคูณระยะทางและด่วนต่อด้วยเศษส่วนแม่นยำ ปัดขึ้นครั้งเดียวตอนจบ
- **ส่วนลด/VAT**: ส่วนลดคือคูณ (100-p)/100 ต่อเนื่องตามลำดับ ไม่ใช่เอา % มาบวกกัน
  ยอดรวม = sum(price*qty) เกณฑ์ส่วนลดดูที่ยอดรวมก่อนลด
- **เงินคืน/แต้ม**: อัตราเป็นส่วนในพัน; ตรวจเกณฑ์ขั้นต่ำก่อน → คูณอัตรา (และตัวคูณเดือนเกิด) แบบแม่นยำ → ปัดขึ้น → จำกัดเพดาน
- ค่า input ที่ไม่ถูกต้อง (tier แปลก ฯลฯ) ให้ปฏิเสธด้วย ValueError ถ้าโจทย์ไม่ได้บอกค่าเริ่มต้น

## แม่แบบ

```python
from fractions import Fraction
import math

def fee(amount):            # amount: int สตางค์
    a = Fraction(amount) * Fraction(95, 100) * Fraction(107, 100)
    return math.ceil(a)     # ปัดขึ้นครั้งเดียวตอนจบ
```
