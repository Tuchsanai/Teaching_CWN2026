# นโยบายร้าน BaanKafe (เฉลยอ้างอิงทำตามนี้)

เทสต์ลับอิงนโยบายเหล่านี้ แม้โจทย์ไม่ได้เขียน ให้ใส่ในโค้ดและ **ระบุไว้ในคอมเมนต์ + สรุปท้ายงาน**

## การปัดเศษ
- เงินที่ **ลูกค้าจ่าย** (ยอดบิล ค่าส่ง ยอดรวมทิป): ปัด **half-up** เป็นสตางค์ ครั้งเดียวตอนท้ายสุด จากค่า Fraction ที่ยังไม่ปัด
- เงินที่ **ร้านจ่ายออก** (เงินคืน cashback, แต้ม, ส่วนลดที่ร้านให้เป็นเงินสด): **ปัดลง (floor)** — นโยบาย C2
  - ลำดับ cashback: คำนวณอัตรา × (เดือนเกิด) เป็น Fraction → ปัดลง → จึงค่อยจำกัดเพดาน
- การหารเท่ากัน (หารบิล): ยอดรวมที่หารปัด half-up ก่อน แล้ว `divmod(grand, people)` — เศษกระจายคนแรก ๆ คนละ 1 สตางค์ ผลรวมต้องเท่ายอดรวมพอดี

## กรณีพิเศษที่รู้แล้ว
- **ค่าส่ง (shipping_fee):**
  - S1: `distance_km == 0` = ลูกค้ารับเองที่ร้าน → ค่าส่ง **0** (คืน 0 ก่อนคิดสูตรอื่น แต่ยังตรวจ input ทุกตัวก่อน)
  - S2: ส่งด่วน (`express=True`) รับน้ำหนัก **ไม่เกิน 20,000 กรัม**; เกินนั้น → `raise ValueError`
  - ส่วนเกิน 5,000 กรัม คิดตามสัดส่วนกรัม: `1500 สตางค์ × (g−5000) / 1000` เป็น Fraction ไม่ปัดก่อนคูณ 20% / 50%
  - ช่วงน้ำหนัก 1–30,000, distance ≥ 0 (int), express เป็น bool
- **เงินคืน (cashback):**
  - C1: tier **silver ไม่ได้สิทธิ์เดือนเกิด** (ไม่คูณ 2) เฉพาะ gold/platinum คูณ 2
  - ต่ำกว่า 10,000 สตางค์ (100 บาท) → 0; เพดาน 20,000 สตางค์ต่อบิลใช้หลังคูณเดือนเกิดและหลังปัดลง
  - tier ต้องเป็น "silver"/"gold"/"platinum" เท่านั้น (str) นอกนั้น ValueError
  - อัตราใช้ Fraction: 15/1000, 25/1000, 4/100
- **คิดเงินหน้าร้าน (cafe_bill):** ยอดรวม = Σ price×qty; ≥ 50,000 สตางค์ ลด 5% (เทียบยอดก่อนลด); member ลดอีก 10% (คูณต่อ); VAT 7% ขั้นสุดท้าย; ปัด half-up ครั้งเดียวตอนท้าย; price ≥ 0, qty ≥ 1, items list ว่างได้ → 0
- **หารบิล (split_bill):** total ≥ 0, people ≥ 1, tip 0–100 (int); grand = half_up(total×(100+tip)/100); ผลเป็น list ยาว people

## ฟังก์ชันใหม่ที่ไม่เคยเห็น — หลักคิดเมื่อโจทย์เงียบ
1. ค่าที่หมายถึง "ไม่มีบริการ/ไม่มีสิทธิ์" ในเชิงธุรกิจ (ระยะ 0 = รับเอง, tier ต่ำสุดไม่ได้โบนัส) → ให้ผลเป็น 0 หรือไม่ได้สิทธิ์ ไม่ใช่ error
2. ค่าที่เกินความสามารถของบริการ (น้ำหนักเกินสำหรับส่งด่วน, จำนวนเกินที่รับ) → ValueError
3. สิทธิ์พิเศษที่ให้กลุ่มเดียว/จำกัดกลุ่ม ให้ตรวจโจทย์ว่าบอกกลุ่มไหน ถ้าโจทย์เหมารวมแต่กลุ่มล่างสุดดูผิดธรรมชาติ ให้ยึดข้อ 1
4. เงินออกจากร้าน = ปัดลง, เงินเข้าร้าน = ปัด half-up
5. ลำดับการคูณ/ลด/VAT/เพดาน ตามลำดับในโจทย์เป๊ะ และเพดาน/ขั้นต่ำเทียบที่จุดที่โจทย์ระบุ
6. ทุกกฎที่เดาเอง ให้เขียนเป็นคอมเมนต์ในโค้ด และมีเทสต์รองรับใน test_solve.py
