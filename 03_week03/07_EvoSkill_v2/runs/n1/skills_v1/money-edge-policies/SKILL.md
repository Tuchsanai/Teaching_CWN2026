# กรณีที่โจทย์เงียบ: ตัดสินใจอย่างไร

เฉลยของร้านมักมี "นโยบายแฝง" ที่ brief ไม่ได้เขียนไว้ตรง ๆ แต่ตัวตรวจทดสอบ ให้ถามตัวเองทุกข้อตามรายการนี้ก่อนเขียนโค้ด แล้วเลือกตามหลักด้านล่าง และ **เขียนสมมติฐานไว้เป็น comment ใน solve.py + แจ้งผู้ใช้ในสรุป** (ไม่ต้องหยุดถามถ้าไม่มีใครตอบได้)

## เช็กลิสต์
1. **ค่าขอบของพารามิเตอร์ที่ "ตั้งแต่ 0"** (ระยะทาง 0, ยอด 0, รายการราคา 0): ต้องรับได้ ไม่ crash หาร 0; ถ้าระยะทาง 0 โจทย์ไม่ได้บอก ให้ใช้สูตรปกติตามที่โจทย์เขียนเท่านั้น อย่าสร้างกฎใหม่ที่โจทย์ไม่ได้กล่าว ยกเว้นความหมายตามธรรมชาติชัดเจน (เช่น รับเองที่ร้านไม่มีค่าส่ง) ซึ่งให้ระบุเป็นสมมติฐาน
2. **สิทธิ์ที่ผูกกับระดับสมาชิก** (tier × เดือนเกิด/โปร): ถ้าโจทย์ใช้ถ้อยคำกว้าง ("เดือนเกิดได้ 2 เท่า") ให้ใช้กับทุกระดับตามตัวอักษร
3. **ข้อจำกัดข้ามพารามิเตอร์** (ส่งด่วน × น้ำหนักมาก): ถ้าโจทย์ให้ช่วงของแต่ละพารามิเตอร์แยกกัน ให้ยอมรับทุกชุดภายในช่วงนั้น
4. **ลำดับ**: ส่วนลดคูณต่อกัน; ตัวคูณ "คูณต่อจากข้อก่อน" = คูณสะสม; VAT/ภาษีเป็นขั้นสุดท้าย
5. **การปัดเศษ**: ดู `money-function-solve` (จ่ายออก = ปัดลง, ลูกค้าจ่าย = half-up, ปัดครั้งเดียวท้ายสุด)
6. **เกณฑ์ขั้นต่ำ/เพดาน**: เทียบเกณฑ์ขั้นต่ำกับค่าดิบที่โจทย์ระบุ, ใช้เพดานหลังตัวคูณทั้งหมด

## หลักตัดสิน
- ถ้า brief กับเฉลยอาจต่างกัน ให้ยึดถ้อยคำของ brief ก่อน แล้วเลือกการตีความที่ "ปลอดภัยทางธุรกิจ" และสมเหตุสมผลตามธรรมชาติ
- ห้ามคาดเดาหลายกฎเกินจำเป็น — ทุกกฎที่เพิ่มเองมีโอกาสผิด
- ลองคำนวณตัวอย่างด้วยมือที่ค่าขอบ (พอดีเกณฑ์, ต่ำกว่า 1, สูงกว่า 1) แล้วเทียบกับโค้ด
