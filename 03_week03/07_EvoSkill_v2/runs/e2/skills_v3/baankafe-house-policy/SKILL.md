# กฎมาตรฐานร้าน BaanKafe ที่โจทย์ไม่ได้เขียน

ตัวตรวจอ้างอิง "มาตรฐานคิดเงินของร้าน" ซึ่งมีกฎแฝงที่ไม่อยู่ในโจทย์ · การทำตามตัวอักษรของโจทย์อย่างเดียวจะได้ไม่เต็ม (rollout ก่อนหน้าได้ ~0.4–0.55 ในข้อที่มีกฎแฝง) ให้ใช้หลักต่อไปนี้ตัดสินกรณีที่โจทย์เงียบ แล้วเขียนสรุปข้อสมมติไว้ท้ายคำตอบ

## กฎที่เคยพบ (ใช้เมื่อสถานการณ์ตรงกัน)
1. **ค่าส่ง ระยะทาง 0 กม. = ลูกค้ารับเองที่ร้าน → ค่าส่ง 0 สตางค์** (คืน 0 ทันที ไม่ใช่ราคาตามน้ำหนัก) แต่ยังต้องตรวจ input ให้ครบก่อน
2. **ส่งด่วนมีเพดานน้ำหนัก: ส่งด่วนรับไม่เกิน 20,000 กรัม** น้ำหนักมากกว่านี้ถ้า express=True → `ValueError` (ส่งธรรมดาน้ำหนักถึง 30,000 ได้) · **ลำดับสำคัญ: ตรวจชนิด/ช่วง และเพดานนี้ให้เสร็จก่อนทางลัด "รับเอง = 0"** ดังนั้น `(20001, 0, True)` ต้อง ValueError ไม่ใช่ 0 (กฎที่ปฏิเสธ input ต้องมาก่อนกฎที่คืนค่าลัดเสมอ)
3. **เงินคืนสมาชิก: ระดับ silver ไม่ได้สิทธิ์เดือนเกิด** (birthday ไม่เพิ่มอะไรให้ silver) · gold และ platinum ได้ 2 เท่า
4. **เงินคืน/แต้ม = เงินที่ร้านจ่ายออก → ปัดลง (floor)** ส่วนยอดที่ลูกค้าต้องจ่าย (บิล ค่าส่ง ยอดหาร) → ปัดครึ่งขึ้น
5. เพดานเงินคืนต่อบิล ตัดหลังคูณตัวคูณเดือนเกิดแล้ว และตัดหลังปัดลง (`min(เพดาน, floor(...))`)
6. ขั้นต่ำ "ต่ำกว่า 100 บาทไม่ได้เงินคืน" ดูที่ยอดซื้อเดิม คืน 0 (ไม่ใช่ error)
7. ส่วนลดเปอร์เซ็นต์หลายชั้นคูณต่อกันตามลำดับ (ไม่ใช่บวกเปอร์เซ็นต์) · เงื่อนไขขั้นต่ำของส่วนลดดูที่ยอดก่อนลด · VAT บวกท้ายสุด
8. ทิป/เปอร์เซ็นต์ของยอดสตางค์ที่หารไม่ลงตัว: คำนวณยอดรวมก่อน (half up) แล้วค่อยหารคน เศษสตางค์ให้คนแรก ๆ คนละ 1

## หลักคิดเมื่อเจอกรณีใหม่ที่โจทย์ไม่พูดถึง
ไล่ถามทีละ argument:
- **ค่าเสื่อม/ค่าศูนย์ของพารามิเตอร์** (ระยะ 0, จำนวน 0, ยอด 0) บริการนั้นยังมีความหมายไหม? ถ้าไม่ (เช่น ไม่ต้องขนส่ง) ผลควรเป็น 0 ไม่ใช่ราคาขั้นต่ำ
- **ตัวเลือกพิเศษ (ด่วน/พรีเมียม)** อาจมีข้อจำกัดความสามารถ (น้ำหนัก/ขนาด) → นอกขีดจำกัดให้ ValueError ไม่ใช่คิดราคาต่อ
- **สิทธิ์ตามระดับสมาชิก** ระดับต่ำสุดอาจไม่ได้สิทธิ์พิเศษบางอย่าง ตรวจว่าสิทธิ์พิเศษควรกระทบทุก tier หรือไม่
- **ใครจ่ายใคร**: ลูกค้าจ่ายร้าน → ปัดครึ่งขึ้น · ร้านจ่ายลูกค้า → ปัดลง
- **ค่านอกโดเมน** ที่โจทย์ระบุช่วงไว้ → ValueError เสมอ (ไม่ใช่คืน 0)
- ถ้าตัดสินใจไม่ได้จริง ๆ เลือกทางที่สอดคล้องกับกฎ 1–8 ข้างบนที่สุด และบอกข้อสมมติในคำตอบสุดท้าย (อย่าถามกลับ ให้ส่ง solve.py ที่สมบูรณ์เสมอ)

ให้ใช้ร่วมกับสกิล `baankafe-money-function` (ตรวจ input เข้มงวด + Fraction)
