Two-stage loop · ขั้นที่ 1 (loop โครงสร้าง) · Loop 1: สร้างแอปจากศูนย์ตามพิมพ์เขียว
ทำงานใน /workspace/arena6/app (มีแค่ tokens.css กับ tag pixel-freeze) อ่าน /workspace/arena6/loop/CONTRACT.md ก่อน

เป้าหมาย: สร้างแอปจองตั๋ว "SkyThai Zero (v6)" ด้วย Next.js + PostgreSQL ผ่าน docker compose ที่พอร์ต 5095 ให้โครงสร้างและพฤติกรรมตรงต้นฉบับมากที่สุดตั้งแต่ครั้งแรก
หน้าตา (ขนาด สี ฟอนต์ ระยะห่าง) ไม่ใช่งานของขั้นนี้ ใช้ตัวแปรใน tokens.css ตามที่มี ห้ามแก้ tokens.css

ขั้นตอน "สร้างจากพิมพ์เขียว":
1. อ่าน spec/EXPLORATION.md (A–F) · spec/API-INVENTORY.md · spec/data/*.json · spec/snapshots/*.yml และ rulers/structure/original.yml (ต้นไม้ของหน้าผลค้นหาต้นฉบับ)
2. เขียน app/BLUEPRINT.md ก่อนเขียนโค้ด: แปลง original.yml เป็นรายการส่วนประกอบตามลำดับ (region → heading → button/link/switch …) แต่ละส่วนบอกว่ามาจากข้อมูล/API ไหน และพฤติกรรมตามข้อ B C F ข้อไหน
3. สร้างแอปตาม BLUEPRINT: หน้าแรก + ฟอร์มค้นหา → หน้าผลค้นหา (ตัวกรอง แท็บ ตัวเรียง รายการเที่ยวบินทั้งหมดจาก PostgreSQL "ดูเที่ยวบินเพิ่มเติม" ข้อมูลเชิงลึกด้านราคา) → รายละเอียด → หน้าตัวเลือกการจอง · ทุกส่วนเป็นของจริงที่ผู้ใช้เห็นและใช้ได้ ชื่อ/ข้อความต้องตรงกับคอลัมน์ "ข้อความ/ชื่อที่เห็นบนจอ" ในส่วน B
4. ทุกสไตล์ต้องอ้าง var(--…) จาก tokens.css (ต้องการขนาดใหม่ใช้ calc() ของตัวแปรที่มี) · เลย์เอาต์ (ลำดับ ส่วนไหนอยู่คอลัมน์ไหน) เป็นงานของขั้นนี้
5. build แล้ววัด kit/measure.sh http://localhost:5095 /workspace/arena6/out/s1-loop1 และ loop/scope-check.sh stage1 pixel-freeze ต้องผ่าน
6. commit + tag s1-loop1

กติกา (ห้ามละเมิด)
- นี่คือ loop ที่ 1 จาก 2 · แก้บั๊กที่ทำให้แอปรันหรือวัดไม่ได้ได้ แต่ห้ามวนแก้ตามคะแนนหลายรอบ (งานของ loop 2) วัดเต็มครั้งเดียวตอนจบ
- ห้ามอ่านซอร์สของ rulers/accept และ rulers/diff (ใช้ได้แค่ report.json) · ห้ามแก้ไฟล์ใน kit/ และ rulers/
- ห้ามโกง: ห้ามตรวจว่ากำลังโดนทดสอบ ห้ามซ่อนเนื้อหาไว้ให้เฉพาะเครื่องอ่าน ห้ามปลอมหรือแต่งข้อมูลเที่ยวบิน ห้ามคัดลอกโลโก้/แบรนด์/โค้ด/ฟอนต์ลิขสิทธิ์ของ Google ห้ามฝังภาพหน้าจอของต้นฉบับ
- ห้ามคัดลอกโค้ดจากแอปเวอร์ชันก่อน (v1–v5) ทุกบรรทัดเขียนใหม่
- ใช้เวลาไม่เกิน 45 นาที
