## ที่มาและวิธีสร้าง

- วิดีโอต้นฉบับ (`.webm`) อยู่ที่ `compare/evidence-run/features-<ฟีเจอร์>-v1|v2/video.webm` และผลอยู่ที่ `compare/evidence-run/results.json`
- โหมดหลักฐานเปิดด้วย `EVIDENCE=1` (`compare/playwright.config.ts`) ซึ่งจะบันทึกวิดีโอที่ 1280×800 วาดกรอบแดงด้วย `mark()` และค้างภาพผลลัพธ์ 3 วินาทีด้วย `holdResult()` ทั้งสองฟังก์ชันอยู่ใน `compare/tests/helpers.ts`
- รวมภาพด้วย `compare/make-gifs.mjs` ซึ่งย่อแต่ละฝั่งเหลือกว้าง 640 แล้ววางเคียงกันด้วย `hstack` สร้าง palette ด้วย `palettegen/paletteuse` และตรวจว่าไฟล์ไม่เกิน 3 MB (ถ้าเกินจะลด fps หรือจำนวนสีเองโดยอัตโนมัติ)
- หมายเหตุสภาพแวดล้อม: Playwright 1.64.1 ต้องใช้ `ffmpeg-1013` สำหรับอัดวิดีโอ แต่ในเครื่องมีแค่ `/ms-playwright/ffmpeg-1011` ซึ่งเข้ารหัสวิดีโอไม่สำเร็จ จึงสร้าง `/tmp/pw-browsers/ffmpeg-1013/ffmpeg-linux` เป็น wrapper ที่เรียก ffmpeg 7.0.2 จาก `imageio-ffmpeg` แทน โดยไม่ได้แก้ไฟล์ใน `/ms-playwright`
