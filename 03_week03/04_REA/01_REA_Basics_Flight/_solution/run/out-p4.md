ผมสร้าง SkyThai Mini ใน `skythai-mini/` แล้ว และลองจองจริงผ่านเบราว์เซอร์ได้ 1 ครั้ง แต่ตอนนี้แอปยังเปิดที่พอร์ต 5081 ไม่ได้ เพราะพอร์ตนี้มี process อื่นใช้อยู่ แอปจึงรันอยู่ที่พอร์ตชั่วคราว 15081 แทน

**เรื่องพอร์ต 5081:** process ที่ใช้พอร์ตอยู่คือ `python3 -m http.server 5081` (PID 224206) ซึ่ง Claude อีก session ที่ทำงานใน `rea-flight-v2` เปิดค้างไว้ ตัวที่เปิดมันปิดไปแล้ว และโฟลเดอร์ที่มันเสิร์ฟก็ไม่มีอยู่จริง ทุกหน้าจึงตอบ 404 ผมไม่ได้เป็นคนเปิด เลยไม่ได้ปิดให้เอง ส่วน `docker-compose.yml` ตั้งไว้ที่ 5081 ตามโจทย์แล้ว

**เรื่องวันที่:** วันนี้คือ 1 พ.ย. 2569 วันที่ 15 ของเดือนหน้าจึงเป็น 15 ธ.ค. แต่ snapshot เก็บราคาไว้สำหรับวันเดินทาง 15 พ.ย. 2569 ผมไม่ได้แต่งข้อมูลเดือนธันวาคมขึ้นมาเอง หน้าเว็บจึงแสดงวันที่ตามข้อมูลที่มี และมีหมายเหตุบอกความต่างนี้ไว้ ถ้าจะได้ราคาวันที่ 15 ธ.ค. ต้องให้ REA เก็บข้อมูลใหม่

**วิธีเปิดแอป**
- **ตอนนี้:** เปิด http://localhost:15081 (ตรวจสุขภาพได้ที่ http://localhost:15081/api/health)
- **ให้ใช้พอร์ต 5081:**
  ```bash
  kill 224206    # ปิด http.server ที่ค้างอยู่ (ตรวจก่อนว่าไม่ได้ใช้แล้ว)
  cd /workspace/rea-flight/skythai-mini && docker compose up -d --build
  ```
  จากนั้นเปิด http://localhost:5081
- **หยุดแอป:** `docker compose down` ถ้าจะล้างฐานข้อมูลด้วย ใช้ `docker compose down -v`
