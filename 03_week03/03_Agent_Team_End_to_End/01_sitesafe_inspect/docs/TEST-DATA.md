## 10. gateway และคิว (API key, คิวเต็ม, Worker ล่ม · 7 แถว)

ใช้ gateway จริงบนเครื่อง GPU · Q-3 ถึง Q-6 ตั้ง `MAX_QUEUE_DEPTH=5` และหยุด Worker ไว้ก่อน เพื่อให้จำนวนงานค้างคงที่ · กติกา: งานค้าง ≥ `MAX_QUEUE_DEPTH` → ปฏิเสธ

| Q-4 | งานค้าง 5 | ส่งงานใหม่ 1 งาน | 5 ≥ 5 จริง → ปฏิเสธ · งานค้างยังเป็น 5 | `429` `QUEUE_FULL` มี header `Retry-After` · `GET /v1/jobs/{job_id}` ของงานนี้ตอบ `404` | คิวเต็ม เท่ากับ |
