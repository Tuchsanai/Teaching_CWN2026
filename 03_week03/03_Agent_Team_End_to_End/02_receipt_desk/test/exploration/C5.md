## ข้อสังเกต/ฟีเจอร์ที่พบ

- กรณีขอบ "120 นาทีพอดีไม่ค้าง" ทดสอบไม่ได้จริงหลังรีเซ็ต เพราะเวลาเดินไปแล้ว — ต้องเรียก reset แล้ววัดใน 0 วินาที หรือใช้ unit test ที่ล็อกนาฬิกา
- คอลัมน์ "รอมาแล้ว (นาที)" ปัดลง (floor) — ใบที่อายุ 120.6 นาทีแสดง 120 แต่อยู่ในรายการค้าง ผู้ใช้อาจสับสนว่า "120 ไม่ควรค้าง" (ดูจาก API 15:09:37 ใบ a แสดง minutesWaiting=120 แต่ overdue=true) ควรแสดงทศนิยมหรือนาทีปัดขึ้น
- W11 `?overdue=false` คืนทั้งหมด 330 ใบ (ดูเหมือนไม่ได้กรอง "ไม่ค้าง") — ไม่ได้ระบุใน Requirement จึงไม่นับเป็นข้อผิดพลาด
- CSV ใส่ BOM และใช้ `confirmed_at` เป็น UTC (Z) ส่วนหน้าเว็บแสดงเวลาไทย — การนับเดือนใช้ `receipt_date` ถูกต้อง แม้ S-02 ยืนยันเวลา 2026-10-31T17:32Z (= 1 พ.ย. 00:32 ไทย)
- merchant ในข้อมูลตั้งต้นทุกใบเป็น "ร้านตัวอย่าง"
- ยอดตรวจนับมีทั้งระดับสำนักงานและ `?batchId=`
