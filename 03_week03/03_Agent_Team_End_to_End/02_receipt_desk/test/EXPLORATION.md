## 1. ฟีเจอร์ที่พบ

- **เข้าสู่ระบบ 4 บทบาท** เมนูเปลี่ยนตามบทบาท ลูกค้าเห็นแค่ `/portal` ผู้ไม่เข้าสู่ระบบถูกพาไป `/login` และ API ตอบ `401`
- **อัปโหลดชุด** (`/upload`) เลือกร้าน · ติ๊กงานด่วน (เฉพาะหัวหน้า) · แสดงตัวนับ "ใบงานปกติที่ค้างในคิว x / 400" และ "งานด่วนที่ใช้ไปวันนี้ x / 5"
  - ไฟล์ที่ไม่ผ่านถูกแสดงทีละไฟล์ (ลำดับ · ชื่อ · เหตุผล) และบอก "รับแล้ว 0 ใบ"
- **ชุดใบเสร็จ** (`/batches`) มียอดตรวจนับทั้งสำนักงาน (รับเข้า · รวมทุกสถานะ · ผลต่าง) และหน้าชุดที่บอกสถานะทีละใบพร้อมปุ่มงานด่วน
- **รายการใบ** (`/receipts`) กรองสถานะ · ลูกค้า · เฉพาะใบติดธง
- **หน้าตรวจใบ** แก้ทุกช่อง เพิ่ม/ลบรายการ เห็นผลรวมรายการ เลือกหมวด ติ๊ก "เทียบยอดรวมกับรูปแล้ว" ยืนยัน และดูประวัติ (ค่าเดิม · ค่าที่แก้ · ผู้แก้ · เวลา)
- **อ่านไม่ได้** (`/unreadable`) บอกจำนวนครั้งที่อ่านและเหตุผล ให้พิมพ์ 5 ช่องเองแล้วยืนยัน
- **ค้างเกินกำหนด** (`/overdue`) เรียงใบที่รอนานที่สุด บอกจำนวนนาที
- **สรุปรายเดือน** (`/reports`) ดูตัวอย่างและออก CSV (UTF-8) ต่อร้านต่อเดือน
- **เวลาตรวจ · GPU** (`/insights`) เวลาตรวจเฉลี่ยต่อใบ และตารางเทียบ GPU 1 กับ 2 ใบ (ยังไม่มีข้อมูล)
- **หน้าลูกค้า** (`/portal`) ส่งใบเอง · เห็นใบของร้านทันทีพร้อมสถานะ "รับแล้ว รอสำนักงานตรวจ" · สรุปเดือนแยกหมวด
- **ข้อความระบบเต็ม** "ตอนนี้ระบบเต็ม กรุณาลองใหม่ในอีก N นาที" พร้อม header `Retry-After`

## 3. จุดที่เว็บไม่ตรง Requirement (หรือยังสรุปไม่ได้)

1. **ชื่อร้านและวันที่ไม่ถูกอ่าน (FR-03)** ใบเสร็จจริงทุกใบที่ส่งเข้า GPU ได้ชื่อร้าน `UNKNOWN` และวันที่ `1900-01-01` อ่านได้จริงเพียงรายการ ราคา และยอดรวม (3 จาก 5 ช่อง) ถ้าพนักงานไม่แก้วันที่ ใบที่ยืนยันจะถูกนับเข้าเดือน 1900-01 ตาม BR-14 (C1 · C2 · C3)
2. **ธง "ยอดไม่ตรงรายการ" ไม่ถูกคิดใหม่หลังแก้ค่า (BR-05 · FR-09 · FR-12)** แก้ราคาให้ต่าง 1.01 บาทแล้วไม่ติดธง และยืนยันใบที่ยอดรวม 0.01 แต่รายการรวม 28,000.00 ได้โดยไม่มีคำเตือน (C2-07, C2-11)
3. **"เปิดดูรายละเอียดก่อนยืนยัน" ตรวจหลวม (FR-12)** ใบติดธงที่ยังไม่เปิดถูกปฏิเสธ `409 review_not_opened` ถูกต้อง แต่แค่เรียก `GET /api/receipts/{id}` ก็นับว่าเปิดแล้ว (C2)
4. **ติ๊กด่วนตอนอัปโหลดแล้วผิดกฎ ทั้งชุดถูกปฏิเสธ** ไม่ใช่ "ชุดยังเป็นงานปกติ" ตามที่ TEST-DATA เขียน ต้องถามลูกค้าว่าต้องการแบบใด (C3)
5. **ข้อความ error ไม่ตรงความจริง** ใบที่รูปเสียแสดง "ไม่พบไฟล์รูปของใบนี้" ทั้งที่ API ส่งรูปได้ · ประวัติของใบอ่านไม่ได้ไม่แสดงการลองซ้ำ 3 ครั้ง (NFR-10) (C1)
6. **รหัส error นอกตาราง DESIGN 9.2** `total_not_checked` · `review_not_opened` · `bad_request` และ 429 ของเว็บไม่มี `workers_alive` (C2 · C4)
7. **รูปของใบตั้งต้นตอบ `404 image_missing` ต่างจาก `404 not_found`** ถ้าตรวจไฟล์ก่อนตรวจร้าน อาจบอกได้ว่าใบของร้านอื่นมีอยู่ ยังทดสอบด้วย id จริงของ S-08 ไม่ได้ (C6)
8. **ลองไม่ได้ในรอบนี้:** BR-01 ชุด 99/100 ใบ · BR-04 เส้น 0.89/0.90 · BR-08 พอดี 10 ใบ · BR-09 ข้ามเที่ยงคืน · BR-10 ลำดับ 4:1 (เกิดฝั่ง GPU) · BR-11 พอดี 400 · BR-13 พอดี 120 นาที · FR-30 ยังไม่มีข้อมูล GPU
