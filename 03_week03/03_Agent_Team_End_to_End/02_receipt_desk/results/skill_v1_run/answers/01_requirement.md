| จุดขัดกัน | ทางที่เลือก |
|---|---|
| "อย่าเดา" vs "ไม่ต้องตรวจทุกช่อง" (L23/L29) | ธงเฉพาะช่องที่ไม่แน่ใจ · Silent Error = 0 · Flag Rate ≤ 25% |
| งานด่วนแซงคิว vs ปกติไม่ค้างข้ามวัน (L35/L41) | สลับ ด่วน 4 : ปกติ 1 + ปกติรอ ≥ 60 นาทีหยิบก่อน + ด่วน ≤ 20 ใบ/วัน |
