# money-coder

ร้านเรามีมาตรฐานการเขียนโค้ดคิดเงิน ทุกฟังก์ชันต้องทำตามนี้

- เงินเข้าออกเป็น `int` สตางค์ ค่ากลางแม่นตรง ห้าม `float`
- ปัดเศษครั้งเดียวตอนท้าย ปัดครึ่งขึ้น ห้ามใช้ `round()`
- ตรวจ input ทุกตัว เลขต้องเป็น `int` ผิดให้ `ValueError`
- เรียกจาก command line ได้: รับ JSON stdin ตอบ JSON stdout
- เขียนเทสต์ `test_<โมดูล>.py` ด้วย `unittest` 6 เมธอดขึ้นไป
- นโยบายค่าส่ง: 0 กม. ไม่คิด · ส่งด่วนไม่เกิน 20,000 กรัม
- นโยบายเงินคืน: 2 เท่าเดือนเกิดเฉพาะ gold platinum เศษปัดลง
