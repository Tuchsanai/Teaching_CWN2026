# money-coder

ร้านเรามีมาตรฐานการเขียนโค้ดคิดเงิน ทุกฟังก์ชันต้องทำตามนี้

- ค่าเงินที่ฟังก์ชันรับเข้าและคืนออกเป็น `int` หน่วยสตางค์เสมอ (1 บาท = 100 สตางค์ · จำนวนเงินที่โจทย์เขียนเป็นบาทให้แปลงเป็นสตางค์ในโค้ด) · ค่าระหว่างคำนวณที่ไม่ลงตัวเป็นสตางค์ให้เก็บเป็นค่าแม่นตรง คือคู่จำนวนเต็ม ตัวเศษ/ตัวส่วน หรือ `fractions.Fraction` · ห้ามมี `float` ในโค้ดคิดเงินทุกรูปแบบ: ไม่เขียนค่าคงที่ทศนิยม (อัตรา 12.5% เขียนเป็นจำนวนเต็ม 125 ส่วน 1000) ไม่ใช้ `/` ระหว่าง `int` กับ `int` และไม่เรียก `float()`
- ปัดเศษสตางค์ครั้งเดียว คือตอนแปลงยอดสุดท้ายเป็นจำนวนเต็มสตางค์ก่อนคืนค่า · ทุกขั้นก่อนหน้านั้น (ส่วนลด ภาษี ค่าธรรมเนียม ตัวคูณ การบวกหรือหักยอด และการเทียบกับเพดานหรือขั้นต่ำ) ให้คิดต่อจากค่าแม่นตรงที่ยังไม่ปัด ห้ามปัดทีละขั้น และห้ามปัดยอดย่อยแต่ละตัวก่อนนำมาบวกลบกัน · ทิศการปัดคือปัดครึ่งขึ้น: เศษตั้งแต่ครึ่งสตางค์ปัดขึ้น ต่ำกว่าครึ่งปัดลง คิดด้วยจำนวนเต็ม `(2 * ตัวเศษ + ตัวส่วน) // (2 * ตัวส่วน)` ห้ามใช้ `round()` (ปัดครึ่งเข้าหาเลขคู่) และห้ามตัดเศษทิ้ง · ถ้าฟังก์ชันคืนหลายยอดที่แบ่งจากยอดเดียว ให้ปัดยอดที่จะแบ่งตามกติกานี้ก่อน แล้วแบ่งด้วย `divmod` โดยผลบวกของทุกส่วนต้องเท่ากับยอดนั้นพอดี · ใช้ทิศการปัดอื่นเฉพาะเมื่อโจทย์หรือนโยบายของร้านในสกิลนี้ระบุไว้
- ตรวจ input ทุกตัวก่อนคำนวณ: ตัวเลขต้องเป็น `int` เท่านั้น (ไม่รับ `float` `bool` `str` `None` เว้นแต่โจทย์บอกชัดว่ารับทศนิยม) ค่าจริง/เท็จต้องเป็น `bool` และทุกค่าต้องอยู่ในช่วงที่โจทย์กำหนด · ผิดทุกกรณีให้ `raise ValueError` เท่านั้น ห้ามใช้ `TypeError` หรือ exception ชนิดอื่น
- ต้องเรียกใช้จาก command line ได้: `python3 <ไฟล์>.py` อ่าน JSON object 1 ก้อนจาก stdin (key = ชื่อพารามิเตอร์ของฟังก์ชัน) แล้วพิมพ์ JSON 1 บรรทัดทาง stdout · สำเร็จ: `{"ok": true, "result": <ค่าที่ฟังก์ชันคืน>}` exit code 0 · ผิดทุกกรณี (JSON อ่านไม่ได้ ขาด key หรือ input ไม่ผ่านการตรวจ): `{"ok": false, "error": "<ข้อความ>"}` exit code 2 และห้ามมี traceback
- เขียนเทสต์มาด้วยทุกครั้งในไฟล์ `test_<โมดูล>.py` (โค้ดอยู่ใน `solve.py` → `test_solve.py`) ด้วย `unittest.TestCase` (ห้ามใช้ pytest) อย่างน้อย 6 เมธอด `test_*` และต้องผ่านเมื่อรัน `python3 -m unittest -q test_<โมดูล>`
- นโยบายค่าส่งของร้าน (ใช้กับฟังก์ชันคิดค่าส่งเท่านั้น): ระยะทาง 0 กม. คือลูกค้ารับเองที่ร้าน ไม่คิดค่าส่ง · ส่งด่วนรับน้ำหนักไม่เกิน 20,000 กรัม ถ้าเลือกส่งด่วนแล้วน้ำหนักเกินกว่านี้ถือเป็นข้อมูลผิด ให้ปฏิเสธแบบเดียวกับ input ที่ไม่ผ่านการตรวจ
- นโยบายเงินคืนสมาชิกของร้าน (ใช้กับฟังก์ชันคิดเงินคืนสมาชิกเท่านั้น): สิทธิ์เงินคืน 2 เท่าในเดือนเกิดให้เฉพาะสมาชิกระดับ gold และ platinum ระดับอื่นได้อัตราปกติของตัวเอง · เงินคืนเป็นเงินที่ร้านจ่ายออก เศษสตางค์ของเงินคืนให้ปัดลงเสมอ ไม่ปัดครึ่งขึ้น (ยอดเงินชนิดอื่นยังปัดตามมาตรฐานเดิม)
