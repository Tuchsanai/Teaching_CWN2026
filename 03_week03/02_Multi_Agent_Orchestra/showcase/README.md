**อัดจากระบบจริงทั้งหมด:** stack `bmai` (http://localhost:3500) ใช้ GPU 3 ใบบน Vast.ai
- Qwen บน RTX 5090
- Whisper บน RTX 4090
- VoxCPM2 + reranker บน RTX 4090 อีกใบ

**วิธีอัด:**
- ใช้ Playwright headless ที่วาด WebGL ด้วย GPU ของเครื่อง (ANGLE D3D11) ฉาก 3D จึงลื่น 60 fps
- เสียงคำถามมาจากไฟล์ `e2e/voice-fixtures/V01–V03.wav` ที่ป้อนเข้าไมค์ปลอม (เทคนิคเดียวกับ `e2e/fixtures/fake-mic.ts`)
- เสียงตอบเป็นไฟล์ WAV จริงที่ VoxCPM2 สร้าง ดึงจาก `/api/tts/<id>` แล้ววางลงวิดีโอตรงเวลาที่หน้าเว็บเริ่มเล่น
- ช่วงที่รอ AI ประมวลผลถูกเร่งให้เร็วขึ้น (มีป้าย `>> x2` บนจอ)
- ช่วงเลื่อนหน้าแรกและหน้าแดชบอร์ดเร่งเล็กน้อย (×1.3–1.5)
- ช่วงที่มีเสียงทุกช่วงเล่นที่ความเร็วจริง
