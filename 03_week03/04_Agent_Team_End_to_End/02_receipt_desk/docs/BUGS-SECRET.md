กติกาของการทำบั๊ก

- บั๊กทั้ง 3 จุดอยู่ในโมดูลกฎโมดูลเดียวของเว็บ อ่านค่า `BUG_MODE` ตอนเริ่มโปรแกรม
- กฎข้ออื่นอีก 11 ข้อต้องถูกเหมือนเดิมแม้ `BUG_MODE=1`
- ห้ามมีคำบอกใบ้ชื่อกฎในชื่อตัวแปร ข้อความบนหน้าเว็บ คำตอบของ API `/api/health` log หรือข้อความ commit
