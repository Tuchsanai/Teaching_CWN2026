### จุดที่เว็บไม่ตรง Requirement (สำคัญที่สุด)
1. **P1 · โมเดลอ่านชื่อร้านและวันที่ไม่ได้** ทุกใบได้ชื่อร้าน `UNKNOWN` และวันที่ `1900-01-01` จึงได้จริงแค่ 3 จาก 5 ช่องตาม FR-03 ถ้าพนักงานลืมแก้วันที่ ใบนั้นจะถูกนับผิดเดือน
2. **P1 · ธง "ยอดไม่ตรงรายการ" (BR-05) ไม่ถูกคิดใหม่หลังแก้ค่า** subagent ยืนยันใบที่มียอดรวม 0.01 บาทได้ ทั้งที่ผลรวมรายการเป็น 28,000 บาท และไม่มีธงเตือนเลย
3. **P2**
   - ระบบนับว่าพนักงาน "เปิดดูใบติดธงแล้ว" ทันทีที่มีการเรียก GET API ทั้งที่ยังไม่ได้เปิดหน้าตรวจจริง
   - เมื่อติ๊กงานด่วนตอนอัปโหลดแล้วผิดกฎ ทั้งชุดถูกปฏิเสธ แทนที่จะรับไว้เป็นงานปกติ
   - เปิดรูปของใบที่ไม่มีไฟล์รูปได้ `image_missing` แต่ใบที่หาไม่เจอได้ `not_found` ต้องลองซ้ำด้วย id จริงของ S-08 (ร้านอื่น) ว่ารหัสที่ต่างกันนี้บอกได้ไหมว่าใบนั้นมีอยู่
   - หน้าเทียบ GPU 1 กับ 2 เครื่องยังว่าง
   - เส้นแบ่งพอดีหลายข้อลองไม่ได้ในโหมด gateway ต้องรันซ้ำในโหมด mock
4. **P3** ข้อความ error ไม่ตรงกับสาเหตุจริง · ปุ่มถูกปิดโดยไม่บอกเหตุผล · นาทีที่ค้างถูกปัดลง · หน้าลูกค้าไม่แบ่งหน้า · มีรหัส error ที่ไม่อยู่ในตารางของ DESIGN
