## What-if: วางแผน receiptdesk เพิ่มอีก 2 แบบ (วางแผนเท่านั้น ไม่ได้รันจริง)

ใช้ `blocks.json` ของแผน receiptdesk ชุดเดิม 14 บล็อก โดยไม่แก้บล็อกใดเลย (ค่า md5 ก่อนและหลังตรงกัน) แล้วสั่ง `dagplan.py dag` และ `dagplan.py plan` ใน container `multi-account`
- **receiptdesk-2**: `plan --max-agents 2 --accounts yolo1,yolo2,yolo3,cyolo1`
- **receiptdesk-nocodex**: `plan --max-agents 4 --accounts yolo1,yolo2,yolo3`

ภาพ Gantt ของ 2 แผนใหม่อยู่ที่ `./plan/whatif/gantt-receiptdesk-2.png` และ `./plan/whatif/gantt-receiptdesk-nocodex.png` ส่วน PLAN.md ของแต่ละแผนอยู่ในโฟลเดอร์เดียวกัน หัวภาพทั้งสองเขียนว่า "receiptdesk" เพราะดึงมาจากชื่อใน blocks.json ให้ดูจากชื่อไฟล์แทน

### เทียบ 3 แผน
- **เวลารวม:** แผนเดิมใช้ 63.5 นาทีและวางได้ครบ 14 บล็อก
  - receiptdesk-2 ได้ 68.1 นาที แต่ตัวเลขนี้นับแค่ 8 บล็อกที่วางได้ ระบบยังไม่เสร็จ เพราะ B14 (รวมระบบ + ทดสอบ) ไม่ได้เริ่ม
  - receiptdesk-nocodex วางไม่ได้เลยสักบล็อก จึงไม่มีเวลาให้เทียบ
- **Critical Path:** ทั้ง 3 แผนใช้ไฟล์บล็อกชุดเดียวกัน จึงเป็นเส้นเดียวกันคือ B01 → B02 → B04 → B11 → B14 (9.6M tok)
  - receiptdesk-2 ทำได้ถึง B11 (เสร็จนาทีที่ 68.1) แล้วไม่มีทางไปต่อถึง B14
  - receiptdesk-nocodex ติดตั้งแต่ B01
- **บัญชีที่งานหนักที่สุด:**
  - แผนเดิมคือ yolo2: ถือ slot อยู่ 61.3 นาที ได้ 5 บล็อก รวม 9.6M tok
  - receiptdesk-2 ก็คือ yolo2 เช่นกัน: 47.5 นาที ได้ 3 บล็อก (B10, B03, B04) ขณะที่ yolo1 ไม่ได้งานเลย
  - receiptdesk-nocodex ไม่มีบัญชีไหนได้งาน
- **บล็อกที่วางไม่ได้หรือถูกลดคุณภาพ:**
  - **receiptdesk-2:** B06 (debate) ใช้ 3 agent และ B12 (best_of n=2) ก็ใช้ 3 agent ซึ่งเกินเพดาน 2 จึงวางไม่ได้ทั้งคู่ ทำให้ B07, B08 และ B09 ที่รอ B06 ติดตามไปด้วย และ B14 ก็ติดเช่นกัน สรุปวางได้ 8/14 บล็อก
    - ช่วงนาที 7.9–20.6 มี agent ทำงานแค่ 2 ตัว และ B03 ต้องรอจนนาทีที่ 20.6
  - **receiptdesk-nocodex:** งานที่ต้องใช้ Codex ไม่มีใครรับ ได้แก่ B01, B02, B05, B07 (cyolo) และ B13 (image) ส่วน B03 (review) ต้องมีผู้ตรวจที่ใช้ CLI คนละตัว และ B06 (debate) ต้องเป็น Claude ปะทะ Codex จึงทำไม่ได้เหมือนกัน
    - ที่หนักที่สุดคือ B01 (โครงโปรเจกต์) เป็นบล็อกแรกที่ทุกบล็อกต้องรอ เมื่อวาง B01 ไม่ได้ อีก 13 บล็อกจึงติดทั้งหมด (วางได้ 0/14)
    - ถ้าแก้บล็อกได้ B12 (best_of) ใช้ Claude 3 บัญชีได้ แต่ตัวเลือกจะมาจากโมเดลเดียวกันหมด คุณภาพจึงลดลง ข้อนี้เป็นการคาดเอง ไม่ได้มาจากผลของ planner

### คำแนะนำ
**ควรรันแผนเดิม receiptdesk (4 agent: yolo1–3 + cyolo1)** เพราะเป็นแผนเดียวที่วางได้ครบ 14 บล็อก และเสร็จเร็วที่สุดที่ประมาณ 63.5 นาที
- receiptdesk-2 ช้ากว่าแม้ทำได้แค่ 8 บล็อก และไม่มีขั้นรวมระบบ + ทดสอบ (B14)
- receiptdesk-nocodex เริ่มไม่ได้เลยถ้ายังไม่แก้บล็อก ทีมนี้ต้องมี Codex อย่างน้อย 1 บัญชี และต้องให้ agent ทำงานพร้อมกันได้อย่างน้อย 3 ตัว เพื่อให้ debate/best_of ทำงานได้
