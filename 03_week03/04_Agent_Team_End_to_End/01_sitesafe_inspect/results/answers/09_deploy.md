**สิ่งที่ทำต่างจาก README ของทีมโดยไม่แก้โค้ด**
- เครื่อง GPU เป็น container ใช้ docker ซ้อนไม่ได้ จึงเปิด RabbitMQ, gateway, Worker เป็น process ใน tmux (หลุดการเชื่อมต่อแล้วยังรันอยู่)
- gateway เปิด HTTPS ด้วยใบรับรองที่สร้างเอง เพราะเว็บโหมดจริงไม่รับ `http://` (ข้อที่ TEST.md ของทีมค้างไว้)
- API key ใหม่อยู่ใน `./.env` ของโฟลเดอร์นี้และบนเครื่อง GPU เท่านั้น ค้นใน log ทุกส่วนแล้วไม่พบค่า key

**ผลทดสอบ** (ตัวเลขทั้งหมดอยู่ใน `results/deploy/MEASUREMENTS.md`)
- 5 รูปจาก Test Set ผ่านเว็บ: เสร็จครบใน 9.1 วินาที (รอผลต่อรูป 2.4–8.9 วินาที) ผลในฐานข้อมูลตรงกับที่ gateway ตอบ 5/5 ทั้ง H, V, รุ่นโมเดล, Threshold และกรอบทุกกรอบ
- GPU ใช้เวลาในโมเดลเฉลี่ย 22 ms ต่อรูป (มัธยฐาน 18.5 ms) เวลาที่เหลือเกือบทั้งหมดคือเว็บส่งรูปไปเครื่อง GPU ทีละรูป คำขอละ 1.0–1.5 วินาที
- คิว 20 งาน: หยุด Worker (SIGKILL) ตอนเสร็จ 6 งานและงานที่ 7 กำลังตรวจ ปิดไว้ 20 วินาที เปิดใหม่แล้วเสร็จครบ 20 งานใน 6 วินาที ไม่มีงานหายหรือผลซ้ำ งานที่ค้างตอนหยุดถูกส่งซ้ำ 1 ครั้งแล้วเสร็จ
