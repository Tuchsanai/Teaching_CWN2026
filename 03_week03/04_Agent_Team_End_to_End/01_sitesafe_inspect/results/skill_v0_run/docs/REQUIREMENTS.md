## Business Rules (BR) — ตัวเลข + ค่าเส้นแบ่ง

| ID | กฎ | ต่ำกว่า | เท่ากับ | สูงกว่า |
|---|---|---|---|---|
| BR-01 | คนไม่ใส่หมวก ≥ 1 คน → ไม่ผ่าน | 0 คน → ไม่ไม่ผ่านจากหมวก | 1 คน → ไม่ผ่าน | 2 คน → ไม่ผ่าน |
| BR-02 | คนไม่ใส่เสื้อ 0 → ผ่าน · 1–2 → เตือน · ≥ 3 ("เกิน 2") → ไม่ผ่าน (A-02) | 2 คน → เตือน | (เส้น "เกิน 2") 3 คน → ไม่ผ่าน · 1 คน → เตือน · 0 → ผ่าน | 4 คน → ไม่ผ่าน |
| BR-03 | สถานะรูป = ผลที่รุนแรงที่สุดของ BR-01 กับ BR-02 (ไม่ผ่าน > เตือน > ผ่าน) | หมวก 0 + เสื้อ 0 → ผ่าน | หมวก 0 + เสื้อ 1 → เตือน | หมวก 1 + เสื้อ 1 → ไม่ผ่าน |
| BR-04 | อัตราผ่าน = (รูปทั้งหมด − รูปไม่ผ่าน) ÷ รูปทั้งหมด × 100 ทศนิยม 1 ตำแหน่ง · 0 รูป = "–" (A-03) | 0 รูป → "–" | 10 รูป ไม่ผ่าน 1 → 90.0% | 10 รูป ไม่ผ่าน 0 → 100.0% |
| BR-05 | อัตราผ่าน < 90.0% → สีแดง | 89.9% → แดง | 90.0% → ไม่แดง | 90.1% → ไม่แดง |
| BR-06 | รับเฉพาะ JPG/PNG ตาม magic bytes (นามสกุลไม่พอ) | `.gif` → ปฏิเสธ | `.jpg` เนื้อใน JPEG → รับ | `.jpg` เนื้อใน PDF → ปฏิเสธ |
| BR-07 | อัปโหลดได้ 1–60 รูปต่อครั้ง (A-07) | 0 รูป → ปฏิเสธ | 60 รูป → รับ | 61 รูป → ปฏิเสธทั้งชุด |
| BR-08 | ขนาดไฟล์ ≤ 12 MB (12,582,912 ไบต์) (A-06) | 12,582,911 → รับ | 12,582,912 → รับ | 12,582,913 → ปฏิเสธ |
| BR-09 | คิว gateway รับงานค้างได้ ≤ 500 งาน เกิน → 429 | 499 → รับ | 500 → รับ | 501 → 429 |
| BR-10 | เหตุผลการแก้ผล 5–200 ตัวอักษร (ตัดช่องว่างหัวท้าย) | 4 → ปฏิเสธ | 5 / 200 → รับ | 201 → ปฏิเสธ |

## Non-Functional Requirements (NFR)

| ID | เรื่อง | เกณฑ์ |
|---|---|---|
| NFR-01 | เกณฑ์โมเดล (Acceptance Gate) | บน Test Set ที่มีรูป Positive (มี no_helmet) ≥ 100 และ Negative ≥ 100: Image-level Recall(no_helmet) ≥ 0.80 และ Precision ≥ 0.80 · Threshold เลือกบน Validation แล้วล็อกก่อนวัด · Test Set ไม่พอ = "ยังตัดสินไม่ได้" |
| NFR-02 | SLO ความเร็ว | ด่วน: p95 ≤ 30 วินาทีต่อรูป (อัปโหลดเสร็จ → ผลบนหน้าเว็บ) · ชุด 50 รูป: เสร็จครบ ≤ 5 นาที |
| NFR-03 | ความจุ | ช่วงเช้า 3 ไซต์ × 50 รูป = 150 รูปพร้อมกัน ระบบไม่ล่ม (ไม่มี 5xx) เสร็จครบ ≤ 15 นาที |
| NFR-04 | ข้อมูลห้ามหาย | หยุด Worker กลางทางแล้วเปิดใหม่: งาน 20/20 ได้ผล ไม่หาย ไม่ซ้ำ |
| NFR-05 | ความเป็นส่วนตัว | ไม่มี URL รูปสาธารณะ · gateway ต้อง HTTPS + API key · key/รหัสผ่านไม่อยู่ใน log หรือ repo |
| NFR-06 | การตรวจสอบย้อนหลัง | ประวัติแก้ผลแก้/ลบไม่ได้ผ่าน API ใด ๆ |
| NFR-07 | ค่าใช้จ่าย | GPU 1 ใบ ≤ $0.30/ชม. |
| NFR-08 | ทดสอบได้ | `AI_MODE=mock` ใช้ mock-gateway · `POST /api/test/reset` (เปิดเฉพาะ `TEST_MODE=1`) · `data-testid` ทุกปุ่ม/ตัวเลข |
