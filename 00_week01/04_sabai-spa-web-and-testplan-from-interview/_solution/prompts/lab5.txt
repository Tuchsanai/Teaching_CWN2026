พรอมต์นั้นต้องสั่งให้ครบทุกข้อนี้
1. ทำตาม DESIGN.md: Next.js (App Router, TypeScript) ต่อ PostgreSQL 16 ด้วยไลบรารี pg เขียน SQL ตรง ๆ (ไม่ใช้ ORM)
2. Docker แยก 2 โปรเจกต์ คุยกันผ่าน network ชื่อ sabai-net
   - db/ : container sabai-db (postgres:16-alpine) · volume sabai-pgdata · พอร์ต 5433:5432 · healthcheck pg_isready
           db/init/01-schema.sql ตาม ERD (ข้อมูลใน TEST-DATA ที่ ERD ยังไม่มีตาราง ให้เพิ่มตารางได้) · db/init/02-seed.sql ตาม TEST-DATA.md ทุกค่า
   - web/: container sabai-web พอร์ต 3000 · DATABASE_URL ชี้ไปที่ sabai-db:5432 · output standalone · HOSTNAME=0.0.0.0 · TZ=Asia/Bangkok
           healthcheck ด้วย node เรียก /api/health ตอบ {"ok":true,"db":true} (ต่อฐานข้อมูลไม่ได้ให้ตอบ db:false) · ห้ามต่อฐานข้อมูลตอน build
   - เปิด db ก่อน รอ healthy แล้วค่อยเปิด web
3. ใช้ได้บน Windows และ macOS: ไม่มีไฟล์ .sh ที่ต้องรัน · .gitattributes ให้เป็น LF
   ถ้ามี container อื่นใช้พอร์ต 3000 หรือ 5433 อยู่ ให้บอกชื่อแล้ว docker stop ก่อน

   ทุกหน้าที่พูดถึงคนต้องเห็นหน้าคนจริง: นักบำบัดทุกคนตามรหัส เจ้าของร้าน น้องบัว ทีมงาน · ลูกค้าตัวอย่างในรีวิว
   รูปไหนจำเป็นแต่ไม่มีใน brand-kit และเครื่องมี Codex CLI ให้สั่ง codex exec สร้างภาพถ่ายสมจริงเพิ่ม ถ้าไม่มีก็ใช้ภาพใกล้เคียงจาก brand-kit
   เขียน web/ASSETS.md: ไฟล์ | ใช้ที่หน้าไหน | ที่มา

   - header โปร่งใสบน hero แล้วทึบเมื่อเลื่อน · ปุ่ม "จองคิว" ลอยบนมือถือ · การ์ดมีเงานุ่ม เส้นทองบาง ลายไทยจาง ๆ · transition นุ่มทุกหน้า · ฟอนต์ไทยผ่าน @fontsource (ไม่พึ่งอินเทอร์เน็ตตอนรัน)

6. ฟีเจอร์ครบตาม REQUIREMENTS.md · ตัวเลขทุกตัวตรงตาม BR และ TEST-DATA.md · มีหน้าสมัครสมาชิก · มีหน้า /admin ให้เจ้าของร้านกด "ใช้บริการเสร็จ" (ให้แต้ม ตัดครั้งคอร์ส)
7. "AI" ทุกตัวเป็นกฎตายตัว ไม่เรียก API ภายนอก · วิเคราะห์ผิวคำนวณในเบราว์เซอร์ ไม่อัปโหลดรูป
   เพลงเปิดด้วยปุ่มเท่านั้น · ส่ง Gift Card ทาง LINE/email เป็นการจำลอง (แสดงข้อความที่ "ส่ง")
8. สำหรับทดสอบ: data-testid ทุกปุ่ม ช่องกรอก ผลลัพธ์ และข้อความ error · <html data-ready="true" data-bug-mode="0|1">
   POST /api/test/reset (เปิดเมื่อ ALLOW_TEST_RESET=1) ล้างข้อมูลกลับเป็น seed และรับ {"now":"<วันเวลา ISO>"} เพื่อล็อก "วันนี้" ของเว็บ
   (ไม่ส่ง now = ใช้วันล็อกใน TEST-DATA.md)

    ช่วง B สั่ง subagent ทุกตัวในข้อความเดียว (ไม่ใช้โหมดเบื้องหลัง) รอจนครบ · หน้าเว็บกับ API ทำพร้อมกันได้เพราะยึด API-CONTRACT.md · แต่ละตัวแก้ได้เฉพาะไฟล์ของตัวเอง ห้ามแก้ไฟล์กลาง ถ้าสัญญาขาดให้จดใน web/CONTRACT-NOTES/<ชื่อ>.md · ห้ามรัน docker · ห้ามทำ BUG_MODE
       ฝั่ง API 5 ตัว: A1 รอบว่าง จองคิว ยกเลิก · A2 คิดราคาและแต้ม (lib กลางตัวเดียว + unit test ค่าขอบจาก TEST-DATA) · A3 สมัคร เข้าสู่ระบบ บัญชี ระดับ ประวัติ · A4 คอร์ส Wallet รอบเอว Gift Card หลังร้าน · A5 บริการ สมุนไพร นักบำบัด รีวิว รถรับส่ง แชต แบบทดสอบ อารมณ์ reset
