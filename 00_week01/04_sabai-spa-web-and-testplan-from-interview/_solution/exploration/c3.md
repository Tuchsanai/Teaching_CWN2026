## D ความเสี่ยง

1. **ลำดับการกดทำให้เสียโอกาสใช้ส่วนลด (ปานกลาง):** ลูกค้าเกิดเดือนนี้กด "แลกสูงสุด" ก่อนติ๊กเดือนเกิด จะเจอข้อความเท็จว่าส่วนลดอื่นมากกว่า ปุ่มแลกสูงสุดไม่ทำงาน ตัวเลขค้าง เขาอาจเลิกใช้สิทธิ์ 20% ไม่เกิดเงินผิดเพราะปุ่มยืนยันถูกปิด
2. **ทางตันเมื่อ session หมด (ปานกลาง):** หน้าสรุปยังโชว์ราคา Platinum และบอกให้กรอกชื่อเบอร์ที่ไม่มีช่องให้กรอก
3. **API จองรับคำขอที่ไม่มี `expectedPayAtShop` (ต่ำถึงปานกลาง):** ผู้เรียก API ตรงจองได้โดยไม่ยืนยันราคา ราคายังคิดฝั่งเซิร์ฟเวอร์ถูกต้อง
4. **รหัสบัตรพิมพ์เล็กไม่ผ่าน (ต่ำถึงปานกลาง):** ลูกค้าที่พิมพ์เองจากบัตรหรือ LINE อาจคิดว่าบัตรใช้ไม่ได้
5. **ข้อความแต้มทำให้เข้าใจผิด (ต่ำ):** "ต้องมีอย่างน้อย 100 แต้ม" ขึ้นกับคนที่มี 250 แต้ม และ "ยอดนี้ยังแลกแต้มไม่ได้" ขึ้นกับคนที่มี 1,700 แต้ม
6. **ขอบเขตที่ยังเปิด:** ส่วนใหญ่ตรวจราคาด้วย API ไม่ได้เปิดหน้าสรุปทุกแถว · หน้า `/admin` ไม่ได้เปิดดู · ไม่ได้ลองภาษา en/zh (เป็นของ C6) · แต้มที่ได้จริงและยอดสะสมหลังกดเสร็จเป็นของปิดท้าย เห็นแค่ preview · การจองทดสอบทั้งหมดถูกยกเลิกแล้ว แต่ยังเหลือแถว CANCELLED ในวันของ C3 (17 มิ.ย., 6–8 ก.ค.)

ไม่ได้ทดสอบ / ส่งต่อ:
- E93 U01: บัญชีไม่อยู่ในสิทธิ์ของ C3 (ทำทดแทนด้วย U02)
- E153–E156 BR-32: ส่งต่อปิดท้าย
- E92 แต้มจริงหลังกดเสร็จ: ส่งต่อปิดท้าย
- การใช้สิทธิ์เดือนเกิดจริง: charter ห้าม จึงไม่ได้ยืนยันว่าหักสิทธิ์และคืนสิทธิ์ถูกต้อง

## E คำถามถึงทีม

### ถามร้าน
1. รหัส Gift Card ควรพิมพ์เล็กได้ไหม เช่น `gift-2199`
2. ถ้าแลกแต้มเต็มเพดานแล้วเลือกเดือนเกิด ควรลดแต้มให้อัตโนมัติ หรือให้ลูกค้าลดเอง
3. ยืนยัน A-32: แลกแต้มจนค่าบริการเหลือ ฿0 ได้จริงไหม (U11 แลก 1,600 แต้ม จ่าย ฿0 และได้ 0 แต้ม)
4. ยืนยัน A-09 / Q26: บัตรจ่ายค่าบริการก่อนค่ารถ ทำให้คุณฝนได้ 14 แต้มไม่ใช่ 17 แต้ม ใช่ไหม

### ถามคนสร้างเว็บ
1. `expectedPayAtShop` ตั้งใจให้ไม่บังคับใน `POST /api/bookings` ไหม
2. ทำไม `birthday-result` ขึ้น "เพราะส่วนลดอื่นมากกว่า" ตอนที่ quote ล้มเหลวด้วย `points-exceed-service` และเพดานแต้มคิดจาก quote ที่สำเร็จล่าสุดใช่ไหม
3. ตั้งใจให้ข้อความ `points-not-enough` ใช้กรณีขอเกินยอดที่มีด้วยไหม ควรแยกข้อความหรือเปล่า
4. เมื่อ session หมดระหว่างจอง หน้าเว็บควรทำอย่างไร ตอนนี้ไม่ตรวจว่าเปลี่ยนจากสมาชิกเป็นแขก
5. U05 ที่ใช้สิทธิ์แล้วยังกดตัวเลือกเดือนเกิดได้ (`disabled=false`) ตั้งใจไหม
6. รีโหลดแล้วค่าหายทั้งหมดเป็นพฤติกรรมที่ตั้งใจไหม
