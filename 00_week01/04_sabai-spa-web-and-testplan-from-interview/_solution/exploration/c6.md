## D ความเสี่ยง

1. **FR-76 ภาพจำลองก่อน/หลังเปิดอยู่ทั้งที่ร้านยังไม่ยืนยัน** ลูกค้าเห็นผลก่อน/หลังซึ่งอาจเข้าข่ายโฆษณาเกินจริง
2. **รูปร่างกายของคุณนิดาเปิดได้โดยไม่ล็อกอิน** ที่ `/placeholder/nida-*-body.jpg` ตอนนี้เป็นไฟล์ชั่วคราว แต่ถ้ารูปจริงใช้วิธีเดียวกันจะขัด NFR-12 และเรื่องรูปส่วนตัว (ลอง GET ตรงเท่านั้น ไม่ได้เปิดดูเนื้อหารูป)
3. **เส้นทาง `/api/*` ที่ไม่มีจริงตอบ 200 เป็น HTML หน้าแรก** (เช่น `/api/nope`, `/api/quiz/5`, `/api/users/<id>`) ขณะที่ `/th/nope-xyz` ตอบ 404 · สคริปต์ที่เช็กแค่ status จะเข้าใจผิดว่าสำเร็จ และ `r.json()` จะพัง · แม้ HTML มีคำว่า nida แต่เป็นรีวิวหน้าแรก (`home-review-nida`) ไม่ใช่ข้อมูลบัญชีรั่ว
4. **รีวิวหน้าแรกมี test id `home-review-nida`** ถ้าเป็นชื่อลูกค้าจริงต้องได้รับอนุญาต ยังไม่ได้ตรวจข้อความเต็ม
5. **แชตบอกรอบผิดช้า** พิมพ์ 10:15 แล้วถามจำนวนคนต่อ จึงบอก "ไม่มีรอบเวลานี้" ลูกค้าเสียขั้นตอน และข้อความที่ไม่มีตัวอักษรภาษาตอบเป็นอังกฤษบนหน้าไทย
6. **แชตไม่แสดง P01 ในรายการจอง** ลูกค้า Bangkok Relax อาจคิดว่าจองผ่านแชตไม่ได้
7. API ที่ไม่ส่ง `x-locale` ตอบภาษาอังกฤษบนหน้าไทย ตรวจเฉพาะกรณี fetch ตรง ไม่ได้เห็นบนหน้าจอลูกค้า
8. เสียงเป็น `spa-ambient-placeholder.wav` และมีป้าย "เสียงชั่วคราว" ค้างบนเว็บ
9. ตรวจ NFR-07 จาก `innerText` ของขั้นที่เดินผ่าน ยังไม่ครอบคลุมข้อความ error, แชต และบัญชี U06

### ถามร้าน

1. ภาพจำลองก่อน/หลังที่ `/skin` อนุมัติให้เปิดหรือยัง (FR-76, A-23) ถ้ายังควรปิดก่อนขึ้นจริงไหม
2. รูป `cust-*` รีวิวลูกค้าตัวอย่าง และคำรับรองบนหน้าแรก/รีวิว ได้รับอนุญาตจากลูกค้าไหม หรือควรเอาออก (ไม่ได้ตรวจรูปทีละใบในรอบนี้)
3. ตารางอารมณ์ (FR-68), 4 คำถามของแบบทดสอบ (FR-70) และกฎความสว่างผิว (FR-75) ร้านตรวจแล้วหรือยัง
4. อนุญาตให้จองผ่านแชตจริงไหม (A-21) และต้องรวม Bangkok Relax ไหม
5. ใช้เพลงจริงเพลงไหนแทนเสียงชั่วคราว
6. คำแปลอังกฤษและจีน โดยเฉพาะชื่อสมุนไพร ใครจะตรวจ (A-38)

### ถามคนสร้างเว็บ

1. `FEATURE_SKIN_PREVIEW` ทำไมค่าเริ่มต้นเป็น 1 ทั้งที่ FR-76 บอกยังไม่เปิดใช้
2. รูป before/after ของลูกค้าจะเสิร์ฟจาก path สาธารณะต่อไปไหม หรือจะมีการตรวจสิทธิ์
3. `/api/*` ที่ไม่มีจริงควรตอบ 404 JSON ตามรูปแบบ `{"error":{...}}` ใช่ไหม
4. แชตควรตรวจรอบเวลาทันทีหลังพิมพ์เวลาได้ไหม และควรใช้ `x-locale` เมื่อเดาภาษาไม่ได้ไหม
5. NFR-13 ต้องดูฐานข้อมูล ผู้สอนจะให้ใครตรวจ
