# Requirements · สบายใจ สปา (Sabai Jai Wellness Spa)

ที่มา: `USER-STORIES.md`, `interview/INTERVIEW.md` รอบที่ 1 และ `interview/OWNER-ANSWERS.md` รอบที่ 2

**วิธีอ่าน**

- **FR** = ระบบต้องทำอะไรได้ · **BR** = กฎของร้านที่มีตัวเลข · **NFR** = ต้องดีแค่ไหน และวัดอย่างไร
- **[D]** = ร้านพูดเอง โดยบอกตำแหน่งไว้ท้ายป้าย เช่น `[D] §4 ราคา` คือหัวข้อใน `OWNER-ANSWERS` · `[D] บ.12` คือบรรทัด 12 ใน `INTERVIEW`
- **⚠️ สมมติ A-xx** = ร้านยังไม่ได้ตอบ หรือทีมกำหนดเอง ดูรายละเอียดในตารางสมมติฐานท้ายไฟล์
- เรื่องที่ลูกค้าขอแต่ร้านยังไม่ได้ยืนยัน นับเป็น ⚠️ ไม่นับเป็น [D]
- รหัสบริการ S01–S07, P01, K01 มาจาก §1 · นักบำบัด T01–T06 มาจาก §2 · โรงแรม H01–H06 มาจาก §3
- "เหลือ 24:00" หมายถึงเหลือ 24 ชั่วโมง 0 นาที · ✓ = ทำได้ · ✗ = ทำไม่ได้
