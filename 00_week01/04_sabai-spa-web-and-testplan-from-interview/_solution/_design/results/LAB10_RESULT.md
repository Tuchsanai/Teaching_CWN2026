## ข้อสังเกต 👀

- 👀 **"ทำไมจับได้" สำคัญกว่า "จับอะไร"** — ตอนเขียนตาราง 8.1 แล้วถามว่า "ถ้าส่วนลดหลุดเข้าแพ็กเกจ TC ไหนล้ม" จึงเห็นว่า PRICE-06 เดิมใช้ U08 (Silver 0%) ซึ่ง**ไม่มีส่วนลดให้หลุด** TC จะผ่านแม้เว็บผิด — ตาราง 8.1 ทำหน้าที่ตรวจ oracle ของแผนเอง ไม่ใช่แค่สรุป
- 👀 **ผลที่คาดหวังแบบ "หน้าจอเปลี่ยน" ไม่พอ** — แผนเดิมแทบไม่มีข้อไหนบอกว่าต้องรีโหลดแล้วดูซ้ำ หน้าเว็บที่แสดงค่าจากหน่วยความจำ (ไม่ได้บันทึก) จะผ่านทุก TC สถานะ
- 👀 ถ้ารันแผนนี้กับเว็บปัจจุบัน **Chromium ไม่ผ่านเกณฑ์ Exit แน่นอน**: EXPLORATION บันทึกไว้แล้วว่า BOOK-05 (กดซ้ำได้ 2 นัด C46, **P1**), GC-04 (F22), TRN-03 (F24), SEC-04 (C49) ล้ม → อย่างดีที่สุด 38/42 = 90.5% และ P1 ไม่ครบ → ล้มทั้ง EX-1 และ EX-2
- 👀 "≥ 95% คิดเป็นจำนวนข้อ" ต้องปัดขึ้น: 39.9 → 40 ข้อ (ถ้าปัดลงเป็น 39 จะปล่อยให้ล้ม 3 ข้อ = 92.9%)
- 👀 WebKit รอบหน้ารันแต่ P1 → เกณฑ์ 95% ไม่มีผลจริง (P1 ต้องผ่าน 100% อยู่แล้ว) — เขียนบอกไว้ในตาราง 6.2 ไม่ให้คนอ่านสงสัย
- 👀 TC ที่ยิง API อย่างเดียว (6 ข้อ) ไม่ขึ้นกับเบราว์เซอร์ — ต้องเขียนกติกาว่านับให้ทุกเบราว์เซอร์ ไม่งั้นแต่ละคนจะนับตัวหารไม่เท่ากัน
- 👀 FR-35 (Must, ไม่มีช่องอัปโหลดรูปหน้า) ไม่อยู่ในรายการฟีเจอร์ส่วน B เลยเพราะเป็น "สิ่งที่ต้องไม่มี" — traceability จาก FR → TC เป็นวิธีเดียวที่เจอ (matrix จากฟีเจอร์จะไม่เห็น)

## ข้อเสนอแก้พรอมต์

1. "ผ่านเกณฑ์เมื่อ … ≥ 95% (คิดเป็นจำนวนข้อด้วย)" ไม่บอกวิธีปัดและไม่บอกว่า "ไม่ได้รัน" นับยังไง → เสนอ "…(คิดเป็นจำนวนข้อ ปัดขึ้น · TC ที่ไม่ได้รันนับเป็นไม่ผ่าน)"
2. "ตัดสินแยกทีละเบราว์เซอร์" แต่ TEST-PLAN หัวข้อ 2 มีแค่ Chromium และบาง TC ยิง API อย่างเดียว → เสนอเพิ่ม "…ระบุว่า TC ที่ไม่ผ่านเบราว์เซอร์นับอย่างไร"
3. "Coverage matrix … ช่องที่ควรมีแต่ว่างให้ทำ ⚠️" — ไม่บอกว่าให้ทำ matrix ก่อนหรือหลังแก้ ทำให้ช่องที่เติมแล้วหายไปจากภาพ → เสนอ "ทำ matrix หลังแก้ และทำเครื่องหมาย ✚ ช่องที่เติมจากการรีวิว"
4. "ตรวจทีละข้อ: ผลที่คาดหวังตรวจได้ไหม" — เสนอเพิ่ม "**และข้อมูลที่เลือกทำให้คำตอบผิดได้ตัวเลขต่างจากคำตอบถูกไหม**" (จับ oracle อ่อนแบบ PRICE-06 ได้ตรงกว่าการรอให้เจอจากตาราง 8.1)
5. "แก้ใน TEST-PLAN.md ให้เลย" — ไม่บอกว่าเพิ่ม TC ใหม่ได้ไหม (กระทบตัวเลขเกณฑ์ Exit ที่เขียนไปแล้ว) → เสนอ "เพิ่ม TC ได้ แล้วอัปเดตตัวเลขในหัวข้อ 6 ให้ตรง"
