## ข้อสังเกต 👀 / ปัญหาที่เจอ

- 👀 บั๊กที่ฝังทั้ง 3 **หน้าจอ = API = ฐานข้อมูล ผิดตรงกัน** ไม่มี error ไม่มี 409 → ตรวจ "หลังรีโหลด" อย่างเดียวไม่พอ ต้องมีตัวเลขที่คิดเองล่วงหน้า
- 👀 รอบที่หายไป "ไม่แสดงอะไรเลย" — ผู้ใช้ (และ [O]) จะคิดว่าห้องเต็ม · API ตอบ SLOT_INVALID ไม่ใช่ SLOT_TAKEN
- 👀 [A] จับได้ครบในบั๊กที่ฝัง เพราะ SPEC เขียนตอนเว็บถูกแล้วบั๊กเปิดด้วย flag — ในโลกจริงถ้า AI เข้าใจกฎผิด SPEC จะผิดไปด้วย · และ [A] พลาดเรื่องที่ SPEC ไม่ได้พูด (TRN-03, SEC-04)
- 👀 [O] จากหน้าจอ **ตอนเว็บถูก** (normal-mode/) เป็น regression oracle ที่ดี จับได้ครบ — แต่ไม่ได้บอกว่าอะไร "ถูก"
- 👀 TC-BOOK-07 ล้มแบบ **timeout 90 วิ** (รอคลิกปุ่มที่ไม่มี) แทน expect.soft → ขั้นราคา ฿2,520 ไม่ได้ตรวจต่อ และรอบ GIF ช้าถึง 4.2 นาที · test ไม่ผิดแต่ควร `expect.soft(slot).toBeVisible()` ก่อนคลิก (ไม่ได้แก้ เพราะพรอมต์ห้ามแตะ test ให้ผ่าน)
- 👀 PRICE-04 ใบเสนอราคามี `pointsToEarn 39` (ควร 35) = บั๊ก 3 โผล่ด้วย แต่ test ไม่ได้ assert → ตัวเลขข้างเคียงบนจอเดียวกันควรตรวจด้วย
- ปัญหา: `docker compose up -d` ใน web/ พร้อม `$env:BUG_MODE` recreate container ให้เอง ไม่ต้อง `--force-recreate` · ไม่มี container petshop ชนพอร์ต
- ปัญหา: รอบ `npm run test:gif` เขียนทับ artifacts/screenshot ของรอบ 3 เบราว์เซอร์ (outputDir เดียวกัน) แต่ summary.json รวมผลทุก project ให้ถูกต้อง
- ปัญหา: probe SEC-04 รอบแรกใช้ request context เดิมหลัง logout → cookie ถูกลบ ได้ 401 (ผิดวิธี) · แก้โดยเก็บค่า cookie ก่อน logout แล้วส่ง header เอง → 200 ตรงกับ test
- "ภาพวงแดง" ใน GIF คือจุดคลิก ไม่ใช่วงรอบจุดที่ผิด → ต้องดูภาพ test-failed-1.png + ข้อความ error ประกอบ
