## F คำถาม

### ถามร้าน

1. ลูกค้าเลือกวันอดีต ควรให้โทรร้านหรือบอกแค่ว่าเลือกไม่ได้
2. แขกทำรหัสจองหาย ให้โทรร้านอย่างเดียวใช่ไหม
3. เลือกนักบำบัดแล้วบริการไม่ตรง ให้เปลี่ยนเป็น "ใครก็ได้" หรือให้เลือกใหม่
4. ห้องคู่เต็ม อยากให้บอก "ห้องคู่ไม่ว่างรอบนี้" แทนรอบหายเงียบไหม · ขอจองแยก 2 คนได้ไหม
5. กลุ่มควรเลี่ยงคนทำบริการพิเศษ เช่น S04 ไหม หรือยึดคะแนนสูงสุด
6. Bangkok Relax 2 คนต้องใช้ Couple Suite และ 3 คนไม่ใช้ เป็นกติกาจริงไหม (D-01, A-34)
7. รหัส Gift Card ควรพิมพ์เล็กได้ไหม
8. แลกแต้มเต็มเพดานแล้วเลือกเดือนเกิด ควรลดแต้มให้เองหรือให้ลูกค้าลด
9. ยืนยัน A-32 (แลกแต้มจนเหลือ ฿0) และ A-09 / Q26 (บัตรจ่ายค่าบริการก่อนค่ารถ)
10. คนขับดูจุดรับจากไหน ต้องการเห็นโรงแรม ระยะ จำนวนรถในตารางไหม
11. พิมพ์ระยะเอง ต้องการที่อยู่เพิ่มไหม ใครตรวจ ระยะจริงต่างกันเก็บเงินหน้างานไหม
12. เกิน 15.1 กม. ให้โทรคุยหรือไม่รับเลย
13. "ใช้ได้ 365 วัน" นับวันจองหรือวันนัด (D-06, E208)
14. คอร์สเหลือ 0 จากการกันไว้ ควรขึ้นว่าอะไร (A-48)
15. ซื้อบัตรส่ง LINE/email ต้องบังคับกรอกผู้รับไหม
16. รับได้ไหมที่ใครถือรหัสบัตรก็ใช้ได้
17. ต้องการเตือนก่อนคอร์สหมดอายุไหม
18. รูปก่อน/หลังจริงและความยินยอมจะได้เมื่อไร (A-45, TD-10)
19. ภาพจำลองที่ `/skin` อนุมัติหรือยัง (FR-76, A-23)
20. รูป `cust-*` และคำรับรองลูกค้าได้รับอนุญาตไหม
21. ตารางอารมณ์ คำถามแบบทดสอบ กฎความสว่างผิว ร้านตรวจแล้วหรือยัง
22. อนุญาตจองผ่านแชตไหม (A-21) และต้องรวม Bangkok Relax ไหม
23. ใช้เพลงจริงเพลงไหน · ใครตรวจคำแปล (A-38)

### ถามคนสร้างเว็บ

1. `same-day-call` กับวันอดีตตั้งใจไหม หรือควรเป็น `date-out-of-range`
2. "ใครก็ได้" ควร retry คนว่างถัดไปเมื่อชน EXCLUDE ไหม
3. `/api/quote` ควรตรวจรอบไหม
4. `booking-step3-back` ไม่อยู่ใน SPEC ข้อ 8 ตั้งใจไหม
5. รีโหลดหน้าสรุปและหน้ายืนยันควรเก็บสถานะไหม
6. session หมดกลางทางตั้งใจให้เกิดอะไร ตอนนี้ขึ้น `guest-info-required` แต่ไม่มีฟอร์ม
7. Platinum เสมอกลุ่มที่ 10% ตั้งใจให้ป้ายเป็น TIER ไหม
8. deep link `therapist` และ `party` ค่าผิด ควรแจ้งไหม หรือเปลี่ยนตัวอย่างใน SPEC
9. `expectedPayAtShop` ตั้งใจไม่บังคับไหม
10. `birthday-result` ขึ้น "ส่วนลดอื่นมากกว่า" ตอน quote ล้มเหลว เป็นบั๊กไหม
11. ควรแยกข้อความ `points-not-enough` กรณีขอเกินยอดไหม
12. U05 ที่ใช้สิทธิ์แล้วยังติ๊กเดือนเกิดได้ ตั้งใจไหม
13. ลิงก์ "จองคิวพร้อมรถรับส่ง" ควรส่งค่าต่อไหม
14. ตอนระยะถูกปฏิเสธควรซ่อนยอดเก่าไหม
15. API รับทั้ง `hotelId` และ `distanceKm` แล้วเงียบ เหมาะไหม
16. ค่า `.5`, `5.`, `-0`, `+5` ตั้งใจปฏิเสธไหม
17. จำนวนคนผิดในเครื่องคำนวณควรบอกช่องไหม
18. P01 4 คนควรใช้รหัสอื่นแทน `not-enough-therapists` ไหม
19. `/booking?service=K01` ไม่มีคอร์ส ควรแสดง `course-required` หรือพาไปซื้อไหม
20. ช่องมูลค่าบัตรควรรับ `1,000` ไหม และตัวอย่างไม่ควรโชว์ "฿abc"
21. "ราคาเต็ม 1 คน ฿0" ของคอร์ส และปุ่มแลกแต้มตอนค่าบริการ ฿0 ตั้งใจไหม
22. `wallet-course-*` ใช้ลำดับ ไม่ใช่รหัสคอร์ส ตั้งใจไหม
23. `FEATURE_SKIN_PREVIEW` ทำไมค่าเริ่มต้นเป็น 1
24. รูป before/after จะเสิร์ฟจาก path สาธารณะต่อไปไหม
25. `/api/*` ที่ไม่มีจริงควรตอบ 404 JSON ใช่ไหม
26. แชตควรตรวจรอบทันทีและใช้ `x-locale` เมื่อเดาภาษาไม่ได้ไหม

28. ตารางหลังร้าน API ส่งโรงแรมและระยะแล้ว ทำไมหน้าจอไม่แสดง
