# brand-kit · รูปร้านสบายใจ สปา

รูปทั้งหมดในโฟลเดอร์นี้ **สร้างด้วย image gen เป็นภาพจำลอง** บุคคลในภาพไม่มีตัวตนจริง ใช้เพื่อการเรียนการสอนเท่านั้น ในเรื่องราวของบทเรียน นี่คือรูปที่คุณจันทร์ส่งให้ทีมทำเว็บ

| โฟลเดอร์ | มีอะไร |
|---|---|
| `people/` | `owner-chan` คุณจันทร์ · `staff-t01-sri` พี่ศรี · `staff-t02-malee` พี่มาลี · `staff-t03-phum` พี่ภูมิ · `staff-t04-fah` น้องฟ้า · `staff-t05-tiw` พี่ทิว · `staff-t06-kaew` น้องแก้ว · `staff-bua` น้องบัว · `cust-*` ลูกค้าที่ให้สัมภาษณ์ |
| `shop/` | `hero-*` ภาพใหญ่ 3 ภาพ · ทางเข้า ล็อบบี้ Couple Suite ห้องนวดเท้า ห้องอบสมุนไพร ศาลา ชั้นสมุนไพร · `owner-*` คุณจันทร์ · `team-group` ทีมงาน · `pano-couple` ภาพกว้างสำหรับทัวร์ 360° |
| `services/` | รูปบริการตามรหัสเมนู `svc-s01` ถึง `svc-s07`, `svc-p01`, `svc-k01` |
| `herbs/` | รูปสมุนไพรแต่ละตัว |
| `giftcard/` | ลาย Gift Card 3 แบบ `gc-orchid` `gc-lotus` `gc-gold` (ตรงกลางเว้นไว้สำหรับวางข้อความ) |
| `misc/` | `mood-*` รูปอารมณ์ · `skin-sample` ใบหน้าตัวอย่างสำหรับวิเคราะห์ผิว · `login-side` `empty-state` `review-bg` |
