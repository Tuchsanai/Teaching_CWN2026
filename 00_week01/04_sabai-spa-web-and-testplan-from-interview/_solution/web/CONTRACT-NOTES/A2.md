# A2 · สมมติฐานที่สัญญาไม่ได้ระบุ

## ราคาและแต้ม

1. `discountAmount` = `fullPrice − ยอดหลัง %` เพื่อให้เป็นบาทเต็มและบรรทัดรวมกันตรง · ราคาสมมติ ฿999 ลด 5% (E156) จึงได้ `discountAmount = 50` ไม่ใช่ 49.95
2. ลำดับตรวจแต้มใน `quote()`: แขก `points-login-required` → ติดลบ `validation` → ขอน้อยกว่า 100 หรือมีน้อยกว่า 100 `points-not-enough` → ไม่ลงตัว 100 `points-not-multiple` → ขอเกินที่มี `points-not-enough` → ส่วนลดเกินยอดหลัง % `points-exceed-service`
3. `points.maxRedeemable` มีหน่วยเป็นแต้ม (`maxSets × 100`) ไม่ใช่บาท
4. เพิ่ม helper `maxRedeemSets` ใน `rules.ts` · ฟังก์ชันอื่นคงชื่อและ signature เดิม

## เดือนเกิด

5. `birthdayEligibility` ถือ `birthDate = null` เป็น reason `guest` เพราะ input ไม่มีช่องบอกว่าเป็นแขก · ตรวจเรียง: guest → service-not-eligible → not-birthday-month → already-used
6. `birthday.reason` บอกผลการตรวจสิทธิ์เสมอแม้ลูกค้าไม่ได้กดเลือก · `applied` จึงเป็นตัวบอกว่าใช้จริงในราคานี้หรือไม่

## ระยะ

7. `parseDistanceKm` ตัดช่องว่างหัวท้ายก่อนตรวจ · รับเฉพาะ `ตัวเลข` หรือ `ตัวเลข.ตัวเลข 1 ตำแหน่ง` · `.5` `5.` `1e1` `+5` เป็น `distance-invalid`
8. `distanceKm` ที่เป็นข้อความว่างหรือช่องว่าง ถือว่าไม่ได้ส่ง → `distance-required`
9. `internal.distanceKm` จัดรูปเป็นทศนิยม 1 ตำแหน่งเสมอ เช่นพิมพ์ `12` ได้ `12.0`

## คอร์สและบัตร

10. ส่ง `coursePurchaseId` กับบริการที่ไม่ใช่ K01 → `course-not-found` (ค้นด้วย `service_id` ของบริการที่ส่งมา) · แขกหรือหลายคนยังได้ `course-login-required` / `course-one-person` ก่อน
11. อายุคอร์สและบัตรคำนวณจาก `purchased_on` ผ่าน `courseValidOn` / `giftCardValidOn` · `expires_on` ใช้แสดงผลเท่านั้น · A4 ต้องตั้ง `expires_on` ให้ตรงกับกฎเดียวกัน
12. `courseValidOn` และ `giftCardValidOn` ตรวจเฉพาะเพดานวันสุดท้าย · วันก่อนวันซื้อถือว่าใช้ได้ เพราะการล็อกนาฬิกาย้อนไปก่อนวันซื้อต้องไม่ทำให้ขึ้นว่าหมดอายุ
13. `giftCardCode` ตัดช่องว่างหัวท้าย และเทียบรหัสตรงตัว (แยกตัวพิมพ์) · ข้อความว่างถือว่าไม่ใช้บัตร

## ลำดับตรวจและผู้เรียก

14. ลำดับใน `loadAndQuote`: จำนวนคน → บริการ → course-required / login / one-person → วันที่ → จำนวนนักบำบัด → รูปแบบเวลา → ผู้จอง → คอร์ส → ระยะหรือโรงแรม → บัตร → `quote()` (แต้ม แล้วระยะเกิน 15.0) · คำขอที่ผิดหลายข้อพร้อมกันจะตอบข้อแรกตามลำดับนี้
15. `maxParty` นับจาก `therapist_services` ตรง ๆ แทนการเรียก `getService` ของ A5 เพื่อไม่ต้องอ่านข้อมูลเกินจำเป็นใน transaction · K01 นับได้ 2 แต่ถูก `course-one-person` กันไว้ก่อน จึงเท่ากับ 1 ตาม type
16. `time` ที่รูปแบบผิดตอบ `validation` · การตรวจรอบ :00/:30 และเวลาปิดเป็นของ A1 (`invalid-slot`) ไม่อยู่ใน `loadAndQuote`
17. `userId` ที่ไม่มีแถวใน `users` (cookie ค้างหลัง reset) ตอบ 401 `unauthorized`
18. `/api/quote` ตัด `internal` ออกจาก response · OWNER ส่งเป็น `userId = null` ที่ route นี้แล้ว · A1 และ A5 ต้องส่ง `null` เองเมื่อผู้เรียกเป็น OWNER
19. `pointsToRedeem` ที่ไม่ใช่ number ตอบ `validation` · ไม่ส่งหรือ `null` เท่ากับ 0
