# F5 · สมมติฐานที่สัญญาไม่ได้ระบุ

1. **OWNER กับ `?next=`** · OWNER ไป `/{locale}/admin` เสมอ แม้มี `next` · ลูกค้าไป `next` หรือ `/{locale}/account`
2. **ลำดับ `router.push` กับ `router.refresh`** · ใช้ `push` ก่อนแล้วค่อย `refresh` ต่างจากลำดับในงานที่สั่ง เพราะใน Next ตัวที่ติดตั้ง (`app-router-instance.js`) navigation จะ discard action ที่ค้างอยู่ ถ้า `refresh` ก่อน header จึงอาจไม่เปลี่ยนสถานะเข้าสู่ระบบ
3. **ยืนยันก่อนยกเลิก** · ไม่ใช้ `window.confirm` เพราะ dialog ของเบราว์เซอร์แปลตามภาษาเว็บไม่ได้ · กด `account-cancel-<bookingCode>` แล้วขึ้นแผงในการ์ด กด `account-cancel-confirm-<bookingCode>` เพื่อยกเลิก หรือ `account-cancel-keep-<bookingCode>` เพื่อเก็บนัด
4. **ชื่อลูกค้าในโหมด 中文** · `MeResponse.fullName` เป็นข้อความที่ลูกค้ากรอกและไม่มีคำแปล · ถ้ามีตัวอักษรไทย จะไม่แสดงแถวชื่อในโหมด 中文 (NFR-07) · ชื่อที่ไม่มีตัวอักษรไทยแสดงตามปกติ
5. **ไม่เข้าสู่ระบบ** · หน้า `/account` และ `/account/history` ตรวจ cookie ฝั่งเซิร์ฟเวอร์ก่อน แล้วตรวจ 401 จาก API อีกชั้น · redirect เป็น `/{locale}/login?next=/{locale}/account` (ไม่ encode `/` ตามรูปแบบในสัญญาข้อ 5)
6. **`?next=`** · รับเฉพาะ path ภายในเว็บ ค่าอย่าง `//evil.test` `/\evil.test` `https://…` ถูกเมิน · หน้าสมัครรับ `next` ด้วย เพื่อไม่ให้หายเมื่อกดจาก login ไปสมัคร
7. **OWNER ที่หน้า `/account`** · ไม่มีระดับและแต้มจึงไม่แสดง `account-tier` `account-spend` `account-points` · แสดง `account-owner-note` กับ `account-admin` แทน และซ่อนนัด ประวัติ และ Wallet
8. **`canCancel = false`** · รายการนี้มีเฉพาะ CONFIRMED จึงถือเป็นกรณีเหลือไม่ถึง 24 ชม. เสมอ
