ทดสอบรายงานกับผลรันจริงแล้ว 3 กรณี:
- **ไม่มีไฟล์:** เตือน และรายงานเขียนว่ายังไม่สมบูรณ์
- **`[]`:** รายงานเขียนว่า "ตรวจแล้ว ไม่พบ"
- **ใส่ REC-01 ที่ผลพลิก:** รายงานคำนวณได้ 38/40 → "ยังไม่ปล่อย" และติดป้ายว่าคำตัดสินพลิก

ข้อมูล REC-01 ที่ใช้ทดสอบมาจากที่ agent บอกไว้ว่าถ้าตีความอีกแบบจะล้ม ผมยังไม่ได้ลองกับเว็บจริงเอง
