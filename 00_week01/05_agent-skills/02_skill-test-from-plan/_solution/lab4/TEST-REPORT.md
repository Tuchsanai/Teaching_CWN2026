### BUG-001 · TC-AUTH-02

**ทำไมเป็น "เว็บผิด" ไม่ใช่ "test ผิด":** TC-AUTH-03 ใช้ selector error-confirm เดียวกันแล้วเจอ error "รหัสผ่านไม่ตรงกัน" (selector ถูก) และภาพตอนล้มเห็นชัดว่าใต้ช่องยืนยันรหัสผ่านไม่มีข้อความ รันซ้ำ 3 รอบ (agent 2 + รอบรวม) ผลเดิม

**ขั้นตอนทำซ้ำ:** 1) เปิด /register → 2) ไม่กรอกอะไรเลย กด "สมัครสมาชิก" → 3) ดูใต้ช่อง "ยืนยันรหัสผ่าน"

**ผลที่คาดหวัง:** error ทุกช่อง (ชื่อ อีเมล รหัสผ่าน ยืนยันรหัสผ่าน เงื่อนไข)

**ผลจริง:** ชื่อ อีเมล รหัสผ่าน และเงื่อนไขขึ้น error ส่วนช่องยืนยันรหัสผ่านว่างเปล่า ไม่มี error

### BUG-002 · TC-REC-01

**ทำไมเป็น "เว็บผิด" ไม่ใช่ "test ผิด":** ตีความตามตัวอักษร "อาหารแมว" = อาหาร (เม็ด/เปียก) ไม่รวมขนม · หน้าเว็บเองตั้งหัวข้อว่า "อาหารที่เหมาะกับน้อง" · ถ้านับขนมเป็นอาหาร ข้อนี้ผ่าน

**ขั้นตอนทำซ้ำ:** 1) เปิด /finder → 2) เลือกแมว → ลูกแมว → แพ้ไก่ (ประเภทอาหารเว้นเป็นค่าเริ่มต้น) → 3) ดูผลอันดับ 2

**ผลที่คาดหวัง:** อาหารแมวไม่มีไก่ อันดับ 1 ลูกแมวแซลมอน

**ผลจริง:** อันดับ 1 ลูกแมว สูตรแซลมอน ✔ · ไม่มีไก่ทุกรายการ ✔ · แต่อันดับ 2 เป็นขนม (type=treat) ไม่ใช่อาหาร

### BUG-003 · TC-REC-03

**ทำไมเป็น "เว็บผิด" ไม่ใช่ "test ผิด":** สาเหตุเดียวกับ BUG-002 · ถ้านับขนมเป็นอาหาร ข้อนี้ผ่าน

**ขั้นตอนทำซ้ำ:** 1) เปิดหน้า ลูกแมว สูตรแซลมอน, แมวโต เป็ดเกรนฟรี, เพาช์ทูน่าในเยลลี่ → 2) กลับหน้าแรก ดูส่วน "แนะนำสำหรับคุณ"

**ผลที่คาดหวัง:** "แนะนำสำหรับคุณ" เป็นอาหารแมวทั้งหมด

**ผลจริง:** 4 รายการเป็นสินค้าแมวทั้งหมด แต่ 1 รายการเป็นขนม (type=treat)
