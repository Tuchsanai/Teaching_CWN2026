## ข้อที่ต้องถามคุณ
1. **"อาหารแมว" ในแผนรวมขนมแมวด้วยไหม** (TC-REC-01, TC-REC-03) ข้อนี้สำคัญที่สุด
   - test ใช้ความหมายตรงตัว คือ "อาหาร" ไม่รวม "ขนม" ผลคือล้ม
   - ลองกับเว็บจริงแล้ว ถ้านับขนมเป็นอาหาร ทั้งสองข้อผ่าน
   - **คำตัดสินจะพลิกเป็น "ปล่อยได้"**: P1 ผ่าน 15/15 และอัตราผ่าน 39/40 = 97.5% เหลือส่วนเผื่อ 1 ข้อ ถ้าล้มเพิ่มอีกข้อจะต่ำกว่า 95%
2. **ช่องยืนยันรหัสผ่านที่ว่างต้องขึ้น error ของตัวเองไหม** (TC-AUTH-02) ถ้าไม่ต้อง ข้อนี้ผ่าน แต่คำตัดสินไม่เปลี่ยน
3. **ปุ่ม/เมนู "อาหารแมว" และ "อาหารสุนัข" พาไปหน้าที่มีของเล่นและอุปกรณ์ปนอยู่ ถูกไหม** (TC-HOME-02, TC-MOB-01) ตอนนี้ผ่านเพราะนับสินค้าทุกชนิดได้ 14 รายการ ถ้านับเฉพาะอาหารจะล้ม (อาหารรวมขนมมี 10 รายการ) และจะขัดกับคำตอบข้อ 1 ถ้าคุณตอบว่า "อาหาร = ทุกอย่าง"
4. **ใส่ PAW10 ไว้แล้วกรอกโค้ดผิดหรือหมดอายุทับ คูปองเดิมควรยังอยู่ไหม** (TC-CPN-02) ลองกับเว็บแล้ว PAW10 หลุด และยอดเด้งจาก ฿761 เป็น ฿840 ถ้าคูปองเดิมควรอยู่ นี่คือบั๊กเรื่องเงินที่ต้องเพิ่ม test
5. **ปุ่ม + ควรกดไม่ได้เมื่อจำนวนถึงสต็อกไหม** (TC-PRD-03) ตอนนี้ปุ่มยังกดได้ แต่จำนวนหยุดที่ 3 ถูกต้อง
6. **หลังกดล้างตัวกรอง ช่องค้นหาต้องว่างด้วยไหม** (TC-CAT-05) ตอนนี้ผลกลับมา 28 รายการ แต่ช่องค้นหายังค้างคำค้นเก่าไว้
7. **฿770 ใน TC-CPN-01 คือยอดที่รวมค่าส่ง ฿50 แล้วใช่ไหม** (799 − 79 = 720 ไม่ใช่ 770) ลองอีกความหมายไม่ได้ เพราะเว็บไม่แสดงยอดก่อนบวกค่าส่งแยก
8. ยืนยันว่า "ทำจากแซลมอน" ดูจากวัตถุดิบหลัก ไม่ใช่จากชื่อ (TC-CAT-01) และ "ราคา" ที่ใช้เรียงคือราคาเริ่มต้นบนการ์ด (TC-CAT-03) ถ้าตีความอีกแบบ สองข้อนี้จะล้ม แต่แบบที่เลือกน่าจะถูกอยู่แล้ว

## จุดที่ตัดสินใจเองรอบนี้
- **ใช้ Playwright แบบไม่เปิดหน้าจอทั้งหมด** ไม่ใช้ Chrome ของคุณ และไม่ได้เปิดจอดู agent
- **กันข้อมูลชนกันตอนรันพร้อมกัน**

  - สมัครสมาชิกด้วยอีเมลไม่ซ้ำ
