### BUG-001 · TC-AUTH-02

**ทำไมเป็น "เว็บผิด" ไม่ใช่ "test ผิด":** TC-AUTH-03 ใช้ selector error-confirm เดียวกันแล้วเจอ error "รหัสผ่านไม่ตรงกัน" (selector ถูก) และภาพตอนล้มเห็นชัดว่าใต้ช่องยืนยันรหัสผ่านไม่มีข้อความ รันซ้ำ 3 รอบ (agent 2 + รอบรวม) ผลเดิม · เจ้าของแผนยืนยัน (2 พ.ย. 2569) ว่าช่องยืนยันรหัสผ่านที่ว่างต้องขึ้น error ของตัวเอง

**ขั้นตอนทำซ้ำ:** 1) เปิด /register → 2) ไม่กรอกอะไรเลย กด "สมัครสมาชิก" → 3) ดูใต้ช่อง "ยืนยันรหัสผ่าน"

**ผลที่คาดหวัง:** error ทุกช่อง (ชื่อ อีเมล รหัสผ่าน ยืนยันรหัสผ่าน เงื่อนไข)

**ผลจริง:** ชื่อ อีเมล รหัสผ่าน และเงื่อนไขขึ้น error ส่วนช่องยืนยันรหัสผ่านว่างเปล่า ไม่มี error
