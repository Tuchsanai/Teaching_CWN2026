- ตีความผลที่คาดหวังในแผนเมื่อเขียนได้หลายแบบ

## ผลการทดสอบ skill
- **ใช้กับเว็บนี้:** สร้าง e2e ใหม่จาก skill ในโฟลเดอร์ทดลอง ใส่ test 40 ข้อเดิม แล้วรัน ได้ผลเท่าเดิม ผ่าน 39 ล้ม 1 (TC-AUTH-02) GIF, index, รายงาน และ dashboard ออกถูกต้อง สรุปว่า "ปล่อยได้" ตรงกับรอบจริง
- **ไม่ผูกกับเว็บนี้:** ลองกับแผนสมมติของเว็บอื่น (คนละ URL, หัวตารางภาษาอังกฤษ, รหัส test คนละแบบ, เกณฑ์ 90%) อ่านได้ถูก และข้ามหัวข้อ "Answer key" เอง
- **แก้ระหว่างทดสอบ 3 จุด:**
  - ใช้ path เต็มของแผนเมื่อแผนอยู่ไกลจาก e2e
  - เก็บ path ใน URL ไว้ เช่น `/app` ไม่ให้หาย
  - อ่านเกณฑ์ภาษาอังกฤษ "All P1 pass" ได้ตรง ๆ
  - และตัดข้อความ error ที่ไม่จำเป็นของ ffprobe ออก
- **จุดที่ยังไม่ได้ทดสอบ:** ยังไม่ได้ลองเปิดแชตใหม่จริงเพื่อดูว่าคำว่า "ทดสอบเว็บตามแผน" เรียก skill ขึ้นมาเอง ตามปกติ Claude Code โหลด skill ในโฟลเดอร์ `.claude/skills` ตอนเปิด session
