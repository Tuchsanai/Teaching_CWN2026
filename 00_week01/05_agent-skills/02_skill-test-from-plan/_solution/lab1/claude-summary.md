## จุดที่ README ไม่ได้บอก แต่ผมต้องตัดสินใจเอง
1. **ใช้แทน Chrome:** พรอมต์ LAB 5 ให้เปิด `agents.html` ใน Chrome ผมใช้ Chromium headless ถ่ายภาพหน้านี้ทุก 5 วินาทีแทน ได้ 67 ภาพ เก็บไว้ที่ `e2e/test-report/agents-shots/`
2. **ทำให้ `agents.html` อัปเดตเองได้:** เปิดไฟล์จากเครื่องตรง ๆ หน้าเว็บอ่าน `agents.log` เองไม่ได้ จึงเขียนสคริปต์ที่สร้างหน้านี้ใหม่จาก log ทุก 1 วินาที ส่วนหน้าเว็บรีเฟรชทุก 2 วินาทีตามที่สั่ง
3. **ทำงานพร้อมกันได้แค่ 6 ไม่ใช่ 8:** agent เปิดทีละตัวห่างกันประมาณ 15 วินาที และโมดูลเล็ก (หน้าแรกใช้ 32 วินาที) เสร็จก่อนตัวท้าย ๆ จะเริ่ม ผมรายงานตามที่ log วัดได้จริง ไม่ได้ใส่ตัวเลข 8 ตาม README
4. **กัน agent ล้างข้อมูลกันเอง:** การล้างข้อมูล (`/api/test/reset`) ล้างทั้งเซิร์ฟเวอร์ ถ้า agent สั่งระหว่างที่ตัวอื่นรันอยู่จะลบข้อมูลของกัน ผมจึงให้ล้างครั้งเดียวก่อนรันรวม ระหว่างที่ agent รันของตัวเองตั้ง `PP_SKIP_RESET=1` ไว้ และให้แต่ละ agent เก็บผลในโฟลเดอร์ของตัวเอง ไม่งั้นจะลบไฟล์ผลของกัน
5. **กันสต็อกชนกัน:** กำหนดให้ test ซื้อของแต่ละข้อใช้สินค้าคนละตัว ไม่ให้ใครซื้อสินค้าที่ test ตะกร้าใช้ หรือไก่ฟรีซดราย/สูตรลดก้อนขน ที่ test หน้าสินค้าตรวจสต็อก
6. **ทำให้ GIF ยาวพอ:** เดินช้าลง 350 ms ต่อขั้น และค้างหน้าจอตอนจบ ให้วิดีโอยาวอย่างน้อยประมาณ 6.5 วินาที ส่วน test API ไม่มีหน้าเว็บให้ดู จึงให้แสดง method / status / body บนหน้าจอเป็นหลักฐาน
7. **ตีความแผนเอง:**
   - "error ทุกช่อง" = ทุกช่องต้องมี error ของตัวเอง
   - "อาหารแมว" ใน TC-REC-01 และ 03 นับขนมแมวด้วย (ทุกอย่างที่เป็นของแมว) ถ้าแผนหมายถึงอาหารหลักเท่านั้น TC-REC-01 จะล้ม
