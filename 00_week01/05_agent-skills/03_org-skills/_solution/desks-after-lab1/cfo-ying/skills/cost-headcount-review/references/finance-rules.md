# กติกาการเงินที่ใช้ในรายงาน (สรุปจาก company-kit)

> ต้นทาง: `company-kit/margin-rules.md` v2026.1 (ผู้ดูแล `fin-joy`, มีผล 2026-01-01) และ `company-kit/price-list.csv`
> ถ้าเครื่องนั้นมีไฟล์ต้นทางและเวอร์ชันใหม่กว่า ให้ใช้ไฟล์ต้นทาง

## 1 · สูตร
```
กำไรขั้นต้น (บาท)  = รายได้ × gross margin %          (จาก KPI รายเดือน)
ต้นทุนตรง (บาท)    = รายได้ − กำไรขั้นต้น
Gross margin %    = (ราคาขาย − ต้นทุน) / ราคาขาย × 100   (คิดหลังหักส่วนลดเสมอ)
มูลค่า margin ที่หาย = รายได้เดือนนี้ × (pts ที่ลดลง / 100)
```
- ทุกราคา **ไม่รวม VAT** (VAT 7% ไม่ใช่รายได้)
- งาน fixed-price ต้องมี risk buffer 10% ของ man-day อยู่ในแผน — ดีลที่ไม่มี buffer = เสี่ยงเกินแผน

## 2 · เกณฑ์
| ตัวเลข | ค่า |
|---|---|
| เป้า gross margin เฉลี่ยทั้งบริษัทปี 2026 | **30%** |
| margin ดีล ≥ 25% | ผ่าน (หัวหน้าทีมขายอนุมัติ) |
| margin ดีล 15% – < 25% | ต้องให้ MD อนุมัติพร้อมเหตุผลเชิงกลยุทธ์ |
| margin ดีล < 15% | ปฏิเสธ ห้ามขอยกเว้น |
| ส่วนลด > 10% | MD เท่านั้น และ margin หลังลดต้อง ≥ 15% |

## 3 · ราคาและต้นทุนต่อ man-day (price-list 2026)
ใช้ประมาณมูลค่า man-day ที่เกินแผน และจุดคุ้มเงินเดือนของตำแหน่งใหม่

| code | บทบาท | ราคาขาย/วัน | ต้นทุน/วัน |
|---|---|---:|---:|
| MD-SA | Solution Architect | 18,000 | 11,000 |
| MD-PM | Project Manager | 16,000 | 10,000 |
| MD-DEV-SR | Senior Developer / Tech Lead | 15,000 | 9,500 |
| MD-DEV | Developer | 11,000 | 7,000 |
| MD-UX | UX/UI Designer | 12,000 | 7,500 |
| MD-QA | QA Engineer | 9,000 | 5,800 |
| MD-DEVOPS | DevOps Engineer | 14,000 | 9,000 |
| MD-ML | ML Engineer / Data Scientist | 17,000 | 11,000 |

- ไม่รู้ว่า man-day ที่เกินเป็นบทบาทไหน → ใช้ช่วงของบทบาทที่เป็นไปได้ (เช่น Dev 7,000 ถึง Senior 9,500) แล้วบอกว่าเป็นค่าประมาณ

## 4 · งวดเงินที่ถือว่าปกติ (อ้างอิงดีลที่ผ่านเกณฑ์)
- 30% เซ็นสัญญา / 40% ผ่าน UAT / 30% go-live · เครดิตเทอม 30 วัน · MA + hosting เก็บล่วงหน้ารายปี
- ค่าปรับล่าช้าปกติมีเพดาน (เช่น 0.1%/วัน เพดาน 5%)

## 5 · การแสดงผล
- **ต้นทุนและ margin ใช้ภายในเท่านั้น** ห้ามอยู่ในเอกสารที่ส่งลูกค้า → รายงานนี้ติดป้าย "เอกสารภายใน" เสมอ
