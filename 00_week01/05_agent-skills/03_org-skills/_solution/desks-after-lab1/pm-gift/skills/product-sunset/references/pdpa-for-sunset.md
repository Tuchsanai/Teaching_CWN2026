# PDPA ที่ต้องใช้ตอนเลิกให้บริการ (สรุปจาก company-kit)

> ต้นทาง: `company-kit/customer-data-policy.md` v1.4 (ผู้ดูแล `plat-may` · อ้างอิง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล 2562) · ถ้าไม่แน่ใจเรื่องไหนใช้ skill `customer-data-policy` หรือถาม `plat-may`

## 1. ห้ามใส่ในแผนและประกาศ (เอกสารที่อาจออกนอกบริษัท)

1. เลขบัตรประชาชนของใครก็ตาม
2. **เบอร์มือถือส่วนตัว** — ทั้งลูกค้าปลายทางและพนักงานของลูกค้าองค์กร → ใช้ตำแหน่ง อีเมลบริษัท เบอร์สำนักงานแทน
3. เลขบัญชี / เลขบัตรของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง → ใช้รหัสเคสถ้าต้องอ้างถึง
- ถ้าไม่จำเป็นต้องอ้างถึง **ตัดทิ้ง** ดีกว่าปิดบัง · ถ้าจำเป็นต้องปิดบัง: มือถือ `081-XXX-4567`, เลขบัตร `1-XXXX-XXXXX-XX-3`, บัญชี `XXX-X-X6789-X`, อีเมล `s*****@gmail.com`
- เบอร์มือถือที่ลูกค้าให้มา → เก็บใน CRM ภายในเท่านั้น

## 2. ข้อมูลอ่อนไหว (มาตรา 26)

ศาสนา สุขภาพ ประวัติอาชญากรรม ข้อมูลชีวภาพ → ถ้าระบบเก่าเก็บไว้ (เช่น ช่องหมายเหตุนัดของโรงพยาบาล)
- ไฟล์ส่งออกต้องส่งผ่านช่องทางเข้ารหัส
- ตอนย้ายเวอร์ชัน ถามลูกค้าว่าจำเป็นต้องย้ายข้อมูลนั้นไหม (เก็บเท่าที่จำเป็น)
- ปรึกษา `plat-may` ก่อนเปิดส่งออก

## 3. การลบและเก็บรักษา

- สำเนาข้อมูลลูกค้าปลายทางที่เราได้รับระหว่างโครงการ: ลบภายใน 90 วันหลังส่งมอบ (กติกาทั่วไป) — ตอนเลิกให้บริการใช้กติกาที่เข้มกว่า คือ **ลบภายใน 30 วันหลังปิด รวม backup และ log**
- สัญญา TOR proposal เก็บ 5 ปีหลังจบสัญญา · ใบแจ้งหนี้ 5 ปี → **ไม่ต้องลบ** เอกสารพวกนี้ตอนเลิกให้บริการ
- ข้อมูลติดต่อลูกค้าองค์กร: เก็บตลอดความสัมพันธ์ + 2 ปี

## 4. ถ้าเกิดเหตุ

ส่งไฟล์ส่งออกผิดคน หรือแชร์ผิด → แจ้ง `plat-may` **ภายใน 1 ชั่วโมง** (ช่อง `#ask-pdpa` / dpo@novatech.example) ห้ามแก้เงียบ ๆ เอง
