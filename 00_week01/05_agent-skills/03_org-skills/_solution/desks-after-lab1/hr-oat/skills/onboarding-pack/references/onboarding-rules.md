## 3. ไทม์ไลน์

- **D−5** (วันทำการ): ส่งคำขอบัญชี/อุปกรณ์/แพ็ก Claude Code, แจ้ง buddy, เพิ่มเข้าปฏิทินทีม
- **D−1** (วันทำการ): ทดสอบบัญชีเข้าได้, Claude Code + แพ็กติดตั้งเสร็จ, โน้ตบุ๊กวางที่โต๊ะ
- **D1**: ต้อนรับ 09:30 ล็อบบี้ชั้น 12 → อบรม → ทานข้าวกับทีม → buddy พาตั้งเครื่อง
- **D5**: หัวหน้าคุย 15 นาที "สัปดาห์แรกเป็นยังไง"
- **D30 / D60 / D90**: คุยกับหัวหน้า · **D119** ประเมินผ่านทดลองงาน
- Dn = D1 + (n−1) วัน ถ้าตกเสาร์-อาทิตย์เลื่อนเป็นศุกร์ก่อนหน้า (การเลื่อนนี้เป็นแนวปฏิบัติของ `hr-oat` ไม่ได้เขียนในต้นฉบับ)

## 4. ปัญหาที่เคยเกิด (ต้องกันทุกครั้ง)

- **ส.ค. 2026**: Dev ใหม่ไม่ได้ติดแพ็ก dev วันแรก → ขึ้นโปรเจกต์เอง ใช้ access token 60 นาทีแบบไม่หมุน ซ้ำบั๊กปี 2025 → ใส่ "ตรวจว่ามีแพ็กแผนก" ในเช็กลิสต์ D−1 และตอน buddy ตั้งเครื่องวันแรก
- **มิ.ย. 2026**: บัญชี Gitea มาช้า 3 วัน เพราะส่งคำขอวันศุกร์ก่อนเริ่มงาน → ห้ามส่งคำขอช้ากว่า D−5 ถ้าช้าแล้วให้ขอยืนยันรับเรื่องภายในวันถัดไป
