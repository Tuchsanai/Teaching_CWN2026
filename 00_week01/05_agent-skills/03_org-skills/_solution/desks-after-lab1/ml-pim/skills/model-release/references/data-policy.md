# ข้อมูลลูกค้าในงานปล่อยโมเดล (สรุปจาก customer-data-policy v1.4)

> ต้นฉบับ: `company-kit/customer-data-policy.md` ผู้ดูแล `plat-may` · ถ้าไม่แน่ใจ ใช้ skill `customer-data-policy` หรือถามช่อง `#ask-pdpa`

- ข้อมูลเทรน/ประเมินต้อง **ไม่ระบุตัวตน** และใช้ได้ตามสัญญา (เช่น MA) · ห้ามคัดลอกข้อมูลจริงลงเครื่องตัวเอง ใช้ bucket ข้อมูลของทีม
- release notes / รายงานถึงลูกค้า: ใช้รหัสสาขา ตัวเลขรวม ได้ · ห้ามชื่อ เบอร์มือถือ เลขบัญชี เลขบัตร ของลูกค้าปลายทาง · ห้ามเบอร์มือถือส่วนตัวของพนักงานลูกค้า (ใช้เบอร์สำนักงาน/on-call กลาง)
- ตัวอย่างข้อมูลในรายงาน (เช่น แถวที่ทำนายผิด) ต้องเป็นระดับสาขา-ชั่วโมง ไม่ใช่ระดับคน
- สำเนาข้อมูลลูกค้าปลายทางที่ได้ระหว่างโครงการ: ลบภายใน 90 วันหลังส่งมอบ
- ใช้ข้อมูลลูกค้า A เป็นต้นแบบให้ลูกค้า B: ส่งให้ B ได้แค่ผลวิธีการ/metric รวม ห้ามส่งข้อมูลดิบของ A
- สงสัยว่ารั่ว → แจ้ง `plat-may` ภายใน 1 ชั่วโมง
