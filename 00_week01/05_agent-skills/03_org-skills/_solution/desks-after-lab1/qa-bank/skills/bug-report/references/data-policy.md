# ข้อมูลส่วนบุคคลในรายงานบั๊ก (สรุปจาก company-kit/customer-data-policy.md v1.4 · ผู้ดูแล plat-may)

ถ้ามี skill `customer-data-policy` ติดตั้งอยู่ ให้ใช้ตัวนั้นเป็นหลัก ไฟล์นี้คือสรุปขั้นต่ำสำหรับรายงานบั๊ก

## ห้ามมีในรายงานบั๊ก / log ที่แนบ
- เลขบัตรประชาชน, เลขหนังสือเดินทาง
- เบอร์มือถือส่วนตัว (ทั้งลูกค้าปลายทางและพนักงานลูกค้าองค์กร)
- เลขบัญชี, เลขบัตรเครดิต/เดบิต, เลขสัญญาสินเชื่อ, CIF
- ชื่อ-นามสกุลลูกค้าปลายทาง → ใช้รหัสเคส เช่น `CASE-2026-0815`
- ข้อมูลทดสอบต้องเป็น synthetic เท่านั้น (เช่น `qa-user-07`) ห้ามคัดลอก DB จริงมาเครื่อง

## ถ้าจำเป็นต้องอ้างถึง ให้ปิดบัง (ถ้าไม่จำเป็น ตัดทิ้งดีกว่า)
| ข้อมูล | แบบปิดบัง |
|---|---|
| เบอร์มือถือ | `081-XXX-4567` |
| เลขบัตรประชาชน | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | `XXX-X-X6789-X` |
| บัตรเครดิต | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | `s*****@gmail.com` |

- screenshot / video ที่มีข้อมูลข้างต้น ต้องเบลอก่อนแนบ (ระบุในรายงานว่าเบลอแล้ว)
- เจอข้อมูลจริงใน log → ปิดบังในรายงาน และแจ้ง DevOps ให้ redact ที่ระดับ logger (เขียนลง "ข้อสังเกตของ QA")
- สงสัยข้อมูลรั่ว → แจ้ง plat-may (`#ask-pdpa`, dpo@novatech.example) ภายใน 1 ชั่วโมง
