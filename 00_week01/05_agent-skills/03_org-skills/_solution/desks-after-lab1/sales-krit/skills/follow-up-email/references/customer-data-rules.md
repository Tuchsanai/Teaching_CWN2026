# กติกาข้อมูลลูกค้าในอีเมล

สรุปจาก `company-kit/customer-data-policy.md` v1.4 (ผู้ดูแล plat-may, อิง PDPA 2562) เฉพาะส่วนที่ใช้กับอีเมลถึงลูกค้า
ฉบับเต็มและคำถามที่ไม่แน่ใจ → skill `customer-data-policy` หรือ `#ask-pdpa` / dpo@novatech.example

## ห้ามใส่แบบเต็มในอีเมลถึงลูกค้า (ข้อ 2)

1. เลขบัตรประชาชน ของใครก็ตาม
2. **เบอร์มือถือส่วนตัว** — ทั้งลูกค้าปลายทาง และ**พนักงานของลูกค้าองค์กร** (ใช้อีเมลบริษัท/เบอร์สำนักงานแทน)
3. เลขบัญชี / เลขบัตร ของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง → ใช้รหัสเคส เช่น `CASE-2026-0815`

เบอร์มือถือที่ลูกค้าให้ในที่ประชุมหรือใน TOR → **เก็บใน CRM เท่านั้น** แม้ลูกค้าบอก "โทรหาผมได้เลย"

## ถ้าจำเป็นต้องอ้างถึง (ข้อ 3) — แต่ตัดทิ้งดีกว่าเสมอ

| ข้อมูล | แบบปิดบัง |
|---|---|
| เบอร์มือถือ | `081-XXX-4567` |
| เลขบัตรประชาชน | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | `XXX-X-X6789-X` |
| เลขบัตรเครดิต | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | `s*****@gmail.com` |

screenshot ที่แนบต้องเบลอข้อมูลข้างต้นก่อน

## ข้อมูลภายในที่ไม่ใช่ PDPA แต่ไม่ควรอยู่ในอีเมลลูกค้า

- ราคา/ต้นทุน/margin ที่ยังไม่ผ่านบัญชี · ราคาที่ลูกค้าเดิมจ่าย
- ชื่อหรือข้อมูลคู่แข่ง · "ความรู้สึกหลังประชุม" ในบันทึกภายใน

## ส่งผิดคน / แนบผิดไฟล์

แจ้ง plat-may **ภายใน 1 ชั่วโมง** ห้ามแก้เงียบ ๆ เอง
