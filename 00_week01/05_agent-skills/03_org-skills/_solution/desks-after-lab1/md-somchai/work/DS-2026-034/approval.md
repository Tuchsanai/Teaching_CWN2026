| ลูกค้า | โรงพยาบาลเมืองใหม่ (เอกชน 250 เตียง, ลูกค้าใหม่, มีข้อมูลสุขภาพ = ข้อมูลอ่อนไหว PDPA ม.26) |

| Margin | ตามสรุปดีล **18.0%** · ถ้าเติม buffer 10% ตามกฎ **11.8%** · ถ้าคืน QA 35 วันด้วย **9.5%** |

## เหตุผล (≤ 5 บรรทัด)
1. margin 18% เกิดจากไม่ใส่ risk buffer 10% ที่ `margin-rules` บังคับสำหรับงาน fixed-price และตัด QA ออก — ถ้าคิดตามกฎ margin จริงคือ 11.8% (< 15% = ปฏิเสธ ห้ามขอยกเว้น)
2. แผน 3 เดือนสำหรับงานที่ปกติใช้ 5–6 เดือน: ไม่มี buffer, UAT 1.5 สัปดาห์ (< 3), HIS ยังไม่มีเอกสาร API
3. ชำระเงิน 10/30/60 (งวดสุดท้าย 60% และจ่ายหลัง go-live 90 วัน) เครดิต 90 วัน → ผิดเกณฑ์ทั้งสองข้อ
4. ค่าปรับ 0.2%/วัน ไม่มีเพดาน = unlimited liability · ยังไม่มี DPA ทั้งที่เป็นข้อมูลสุขภาพ
5. Tech lead (ปอนด์) จะถือ 3 โปรเจกต์ช่วง ม.ค.–ก.พ. 2027 (เกิน 2) · "อีก 3 รพ. ในเครือ" ยังไม่มีหลักฐานเป็นลายลักษณ์อักษร
