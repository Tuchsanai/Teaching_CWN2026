# เกณฑ์ของวิทย์: ดีลไหนเร่ง ดีลไหนปล่อย

## 1. สถานะดีล (เลือก 1)

| สถานะ | ใช้เมื่อ |
|---|---|
| 🚀 **เร่ง** | margin ≥ 25% (หรือยังไม่คิดราคาแต่มูลค่าสูง/ตรงผลิตภัณฑ์เรา) + ความเสี่ยงหลักมีทางแก้ + เส้นตายใกล้ → เคลียร์สิ่งกีดขวางให้ทีมวันนี้ |
| 🟡 **ประคอง** | ลูกค้าสนใจจริงแต่มีตัวชี้ขาดที่ยังไม่เกิด (สาธิต, งบตึง, รอเอกสาร) → บอกตัวชี้ขาดและวัน |
| 🔴 **ตีกลับ** | ผิดกติกา (ไม่มี buffer, ส่วนลดเกินอำนาจ, margin < 15%) หรือความเสี่ยงซ้อน ≥ 3 ข้อ → บอกทางแก้ (แบ่งระยะ / ลดขอบเขต / เงื่อนไขสัญญา) |
| ⚫ **ปล่อย** | ตีกลับแล้วลูกค้าไม่รับทางแก้, หรือ margin < 15% หลังแก้, หรือดึงคนจากดีลที่ใหญ่กว่า |

## 2. สัญญาณเสี่ยงหลุด / เสี่ยงขาดทุน (นับข้อ)

- เวลาส่งมอบสั้นกว่างานแบบเดียวกันปกติ หรือ UAT < 3 สัปดาห์
- ตัด QA / ตัด buffer "เพื่อให้ราคาลง"
- ส่วนลด > 10% เพื่อชนะคู่แข่ง
- เงินก้อนใหญ่เก็บหลัง go-live นาน (เช่น 60% หลัง 90 วัน) หรือเครดิตเทอม > 30 วัน
- ค่าปรับล่าช้าไม่มีเพดาน
- integration กับระบบที่ยังไม่เห็นเอกสาร API
- คนหลัก (tech lead, SA) ถือ ≥ 3 โปรเจกต์ช่วงเดียวกัน / ตำแหน่งที่ต้องใช้ยังไม่ได้คน
- ข้อมูลอ่อนไหวแต่ยังไม่มี DPA
- ยังไม่มีใบคิดราคา แต่เหลือ < 10 วันถึงวันยื่น
- เซลส์รับปากลูกค้าโดยยังไม่มีหลักฐาน (เช่น "ผ่าน pen test ทุกครั้ง")
- ไม่มีนัดสาธิต/ประชุมถัดไปก่อนวันยื่น
- win rate เดือนก่อนต่ำกว่าเป้า → ระวังการซื้อดีลด้วยราคา

## 3. เช็กลิสต์ไขว้ Sales × Product (ทำทุกครั้ง)

1. ลูกค้าในดีลเป็นลูกค้าผลิตภัณฑ์อยู่แล้วไหม (เทียบรายชื่อลูกค้า v1/v2) — ถ้าใช่: วันหมด MA, สนใจย้ายไหม, มีข้อมูลอ่อนไหวไหม, นโยบายห้ามปิดระบบก่อน MA หมด
2. ฟีเจอร์ที่ TOR **บังคับ** อยู่ลำดับไหนใน backlog ของ Product — ของที่ TOR บังคับแต่ Product จัดท้าย = ต้องคุย
3. ตัวเลขใน TOR ตรงกับที่ลูกค้ารายอื่นขอไหม (เช่น เก็บ log 1 ปี vs 2 ปี) — ใช้ค่าที่เข้มกว่า
4. ฟีเจอร์ที่ห้ามขาย (ขัดหลักความเป็นธรรม/กฎ ธปท.) มีเซลส์ไปรับปากไหม
5. ตัวเลขความแม่นยำ/ประสิทธิภาพที่จะใส่ proposal — มาจากการทดลองที่เทียบกันได้ไหม, มี monitoring/ถอยรุ่นตามที่ TOR ขอไหม
6. ราคาบริการภายนอกที่ฟีเจอร์ใหม่ต้องใช้ (LINE OA ฯลฯ) ยืนยันกับบัญชีแล้วหรือยัง
7. ดีลหลายใบใช้คน/ทีมเดียวกันช่วงเดียวกันไหม

ผลของเช็กลิสต์ → ตาราง "เรื่องที่ Sales × Product ต้องคุย" ทุกข้อมี "ทำไมต้องคุย" (มีหลักฐานจากไฟล์) และ "ขอผลลัพธ์อะไร"
