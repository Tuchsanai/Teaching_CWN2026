# กติกาดีลที่ต้องรู้ตอนทบทวน (สรุปจาก margin-rules v2026.1 + price-list + customer-data-policy v1.4)

## สูตร (ไม่รวม VAT, หลังหักส่วนลดเสมอ)
```
ราคาขาย = Σ(จำนวน × ราคาต่อหน่วย) − ส่วนลด
margin % = (ราคาขาย − ต้นทุน) / ราคาขาย × 100
VAT = ราคาขาย × 0.07
```
- งาน fixed-price ต้องบวก **buffer 10% ของ man-day** ทุกบทบาท — สรุปดีลที่ไม่มี buffer = ผิดกติกา
- ของภายนอกที่ไม่อยู่ใน price list = ต้นทุนจริง + อย่างน้อย 20%

## เกณฑ์อนุมัติ
| margin | ผล | ใคร |
|---|---|---|
| ≥ 25% | ผ่าน | หัวหน้าทีมขาย |
| 15 – < 25% | ต้อง MD + เหตุผลเชิงกลยุทธ์ | MD |
| < 15% | ตีกลับ ห้ามขอยกเว้น | — |

| ส่วนลด (จากราคา price list) | ใครให้ได้ |
|---|---|
| ≤ 5% | เซลส์ |
| 5 – 10% | หัวหน้าทีมขาย |
| > 10% | MD เท่านั้น และ margin หลังลดต้อง ≥ 15% |
- ห้ามลดราคา MA และ cloud hosting · เป้า margin บริษัทปี 2026 = 30%
