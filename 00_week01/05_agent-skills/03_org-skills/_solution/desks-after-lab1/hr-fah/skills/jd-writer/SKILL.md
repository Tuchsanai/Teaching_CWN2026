# jd-writer — ประกาศรับสมัคร 1 ตำแหน่ง ที่ได้คนตรงงาน

ทำเรื่องเดียว: เอาข้อมูลตำแหน่ง 1 ตำแหน่ง → เขียนประกาศ 1 ฉบับ + ใบตรวจ ไม่ทำชุดต้อนรับพนักงานใหม่ (นั่นคือ `onboarding-pack`) และไม่ตัดสินว่าควรเปิดอัตราไหม

ความรู้ที่ต้องใช้อยู่ใน skill แล้ว ไม่ต้องเปิด company-kit:
- `references/jd-rules.md` — โครง 6 หัวข้อ, จำนวนข้อ, กติกาห้าม, น้ำเสียงแบรนด์ (สรุปจาก `jd-template.md` + `brand-guide.md`)
- `references/benefits.md` — สวัสดิการ, ทดลองงาน, ขั้นตอนสัมภาษณ์, on-call, ที่อยู่ออฟฟิศ (สรุปจาก `hr-benefits-faq.md` ปี 2026)
- `references/example-jd.md` — ประกาศที่ผ่านแล้ว (NVT-JOB-2026-021) ใช้เทียบความยาวและน้ำเสียง

ถ้าเครื่องนี้มี `company-kit/` ที่ใหม่กว่า (ดูวันที่หัวไฟล์) ให้ใช้ของ company-kit แทน

## ขั้นตอน

1. **เก็บข้อมูลตำแหน่ง** — ต้องมีครบ: ชื่อตำแหน่ง, ทีม/โปรเจกต์, รหัส NVT-JOB, ช่วงเงินเดือน, ประสบการณ์, stack/ทักษะ, งานหลัก, ทีม+หัวหน้า, รูปแบบงาน, วันเริ่มงาน, ช่องทางสมัคร
   - หาจาก: ข้อความผู้ใช้ → ไฟล์คำขออัตรากำลังที่ให้มา → ตาราง "ตำแหน่งที่เปิดอยู่" ใน `company-kit/jd-template.md` (ถ้ามี)
   - **ขาดช่วงเงินเดือน = หยุดถาม** ห้ามเดาตัวเลข · ช่องอื่นที่ขาดให้ถามรวมครั้งเดียว
2. **เขียนประโยคเปิด** 1–2 ประโยค: ปัญหาจริงของผู้ใช้ปลายทาง (มีตัวเลขยิ่งดี) → เรากำลังสร้างอะไร → มองหาคนแบบไหน
3. **เขียน 6 หัวข้อตามลำดับ** ใน `references/jd-rules.md` — งานต้องเป็นงานจริงของโปรเจกต์ (ไม่ใช่ "พัฒนาซอฟต์แวร์ตามที่ได้รับมอบหมาย"), สวัสดิการเลือก 4–6 ข้อที่ตรงกับสายงาน (เช่น Dev ได้ MacBook Pro) จาก `references/benefits.md`
4. **ตรวจข้อมูลลูกค้า** (ตาม `customer-data-policy`) — ห้ามชื่อธนาคาร/ลูกค้า ชื่อผู้ติดต่อ งบดีล หรือรายละเอียดใน TOR ที่ยังไม่ประกาศ ใช้ "ลูกค้าธนาคาร" แทน
5. **ตรวจรายการใน jd-rules.md ข้อ "เช็กก่อนส่ง"** ทุกข้อ แก้จนผ่าน
6. **บันทึก** ที่ `work/<รหัสตำแหน่ง>-<slug>.md` (ประกาศ) และ `work/<รหัสตำแหน่ง>-check.md` (ตารางผลตรวจ + จุดที่ HR ต้องตัดสินใจ)

## ผลลัพธ์ที่ส่งกลับ
- path ของ 2 ไฟล์
- จุดที่ต้องให้คนตัดสิน (เช่น ตัวเลขจาก TOR ที่อาจทำให้เดาชื่อลูกค้าได้, on-call ใช้กับตำแหน่งนี้ไหม, ข้อมูลที่ขาด)
- ขั้นถัดไป: เมื่อได้คนแล้ว ส่งต่อ `onboarding-pack` (hr-oat) อย่างน้อย 5 วันทำการก่อนวันเริ่มงาน
