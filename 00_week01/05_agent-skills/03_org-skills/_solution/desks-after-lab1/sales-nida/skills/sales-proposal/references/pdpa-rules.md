# ข้อมูลส่วนบุคคลใน proposal (สรุปจาก customer-data-policy v1.4 · เจ้าของ plat-may)

ห้ามใส่แบบเต็มในเอกสารที่ส่งออกนอกบริษัท:
1. เลขบัตรประชาชนของใครก็ตาม
2. **เบอร์มือถือของบุคคล** — รวมถึงผู้ประสานงานฝั่งลูกค้าที่ TOR ให้มา → ใช้อีเมลบริษัท / เบอร์สำนักงานแทน
3. เลขบัญชี / เลขบัตร ของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง (ใช้รหัสเคส)

- ไม่จำเป็นต้องอ้าง → **ตัดทิ้ง** ดีกว่าปิดบัง · จำเป็นจริงใช้รูปแบบ `081-XXX-4567`, `1-XXXX-XXXXX-XX-3`
- เบอร์มือถือจาก TOR/ที่ประชุม เก็บใน CRM เท่านั้น
- ในเนื้อหาโซลูชัน: ระบุว่าเลขบัตรประชาชนไม่เก็บแบบข้อความธรรมดา, ข้อมูลเทรนเป็นข้อมูลไม่ระบุตัวตน, ลบสำเนาข้อมูลลูกค้าปลายทางภายใน 90 วันหลังส่งมอบ
- TOR/proposal เก็บ 5 ปีหลังจบสัญญาในไดรฟ์ฝ่ายขาย
- ไม่แน่ใจ → ถาม plat-may (#ask-pdpa, dpo@novatech.example) · ส่งผิด → แจ้งภายใน 1 ชั่วโมง
