## รูปแบบที่ใช้ซ้ำได้
- บทสรุป: ปัญหาเป็นตัวเลข ("สายเข้า 2,400 สาย/เดือน", "รอคิว 45 นาที") → ข้อเสนอ → เป้าหมาย % ในกี่เดือน → ระยะเวลา + มูลค่า
- ความปลอดภัยที่ธนาคารถามทุกครั้ง: TLS 1.2+, AES-256 at rest, audit log (ระยะเก็บตาม TOR), สิทธิ์ตามบทบาท + SSO ของธนาคาร, WAF, pentest ก่อนเปิด, เข้ารหัส/แฮชข้อมูลระบุตัวตน
- เชื่อมระบบเดิม "ผ่าน API ไม่แก้ระบบเดิม" — ลดความกังวลฝ่าย IT ธนาคาร
- UX: ทดสอบกับผู้ใช้จริงตั้งแต่เดือนแรก, ขั้นตอนไม่เกิน 4 ขั้น, ตัวอักษรใหญ่สำหรับผู้สูงอายุ
- แผน: pentest เดือนก่อน UAT, UAT 3 สัปดาห์, นำร่องก่อนขยาย, hypercare 2 สัปดาห์
- ทีมมาตรฐาน: SA 1, PM 1, Senior Dev 1, Dev 2, UX 1, QA 1, DevOps 1 (+ ML 1 ถ้ามีงานพยากรณ์)
