# กติกาคิดราคา (สรุปจาก margin-rules v2026.1 · เจ้าของ fin-joy)

ราคา/ต้นทุน: `price-list.csv` ในโฟลเดอร์นี้ (สำเนาจาก company-kit — ถ้าต้นฉบับเปลี่ยนให้คัดลอกใหม่) ทุกตัวไม่รวม VAT
ของนอกตาราง: ต้นทุนจริงจากผู้ขาย + อย่างน้อย 20% พร้อมหมายเหตุ

```
ราคาขายรวม = Σ(จำนวน × unit_price) − ส่วนลด
ต้นทุนรวม  = Σ(จำนวน × cost)
margin %   = (ราคาขายรวม − ต้นทุนรวม) / ราคาขายรวม × 100   ← คิดหลังส่วนลดเสมอ
VAT        = รวมก่อน VAT × 0.07 (ปัด 2 ตำแหน่ง)
```
- งาน fixed-price: บวก buffer 10% ใน man-day ทุกบทบาท (ไม่แยกบรรทัด)

| margin | ผล |
|---|---|
| ≥ 25% | ผ่าน — หัวหน้าทีมขายอนุมัติ |
| 15 – <25% | MD อนุมัติ (`deal-approval`) + เหตุผลเชิงกลยุทธ์ |
| < 15% | reject ห้ามส่ง ห้ามขอยกเว้น |

| ส่วนลด (จากราคาเต็ม) | ใครให้ได้ |
|---|---|
| ≤ 5% | เซลส์เจ้าของดีล |
| >5 – 10% | หัวหน้าทีมขาย |
| > 10% | MD เท่านั้น และ margin หลังลด ≥ 15% |

- ห้ามลด MA และ cloud hosting · ส่วนลดเป็นบรรทัด "ส่วนลดพิเศษ" แยก ห้ามแอบลดในราคาต่อหน่วย
- เอกสารลูกค้าแสดง `รวมก่อน VAT` → `VAT 7%` → `รวมทั้งสิ้น` · **ห้ามแสดงต้นทุน/margin**
- เป้า margin เฉลี่ยบริษัทปี 2026 = 30%
