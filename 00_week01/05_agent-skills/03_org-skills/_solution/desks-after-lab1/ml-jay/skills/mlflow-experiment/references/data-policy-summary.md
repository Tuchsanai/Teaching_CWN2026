# กติกาข้อมูลที่เกี่ยวกับงานทดลอง ML (สรุปจาก Customer Data Policy v1.4)

> ฉบับเต็มดูแลโดย `plat-may` (skill `customer-data-policy`) · สงสัยให้ถามใน `#ask-pdpa`

- ใช้เฉพาะข้อมูล **ไม่ระบุตัวตน** และต้องมีสิทธิ์ใช้ตามสัญญา (เช่น ข้อมูลเกษตรไทยใช้ได้ตามสัญญา MA)
- ห้ามคัดลอกฐานข้อมูลจริงของลูกค้ามาไว้ที่เครื่องตัวเอง ให้ใช้ bucket ของทีม · การเข้าถึงข้อมูลจริงใน production ต้องขอผ่าน ticket
- รายงาน/ทะเบียน run/artifact **ห้ามมี** เลขบัตรประชาชน, เบอร์มือถือ, เลขบัญชี/เลขบัตร, ชื่อลูกค้าปลายทาง, CIF — ให้อ้างอิงแค่ระดับสาขา/ชั่วโมงเท่านั้น
- feature ห้ามดึงข้อมูลส่วนบุคคล (เช่น CIF, ระดับลูกค้ารายคน) ถ้าไม่จำเป็นจริง ข้อมูลอ่อนไหว (สุขภาพ ศาสนา ฯลฯ) ห้ามใช้
- สำเนาข้อมูลลูกค้าปลายทางที่ได้รับระหว่างโครงการต้อง **ลบภายใน 90 วันหลังส่งมอบ** — ระบุ data_version ให้ตามลบได้
- ถ้าสงสัยว่าข้อมูลรั่ว → แจ้ง `plat-may` ภายใน 1 ชั่วโมง
