# ข้อมูลลูกค้าในใบแจ้งหนี้ (สรุปจาก company-kit/customer-data-policy.md v1.4)

> เจ้าของต้นฉบับ: เมย์ อรุณรัตน์ (`plat-may`) · ถ้ามี skill `customer-data-policy` ในเครื่อง ใช้ตัวนั้นตัดสินกรณีกำกวม · สรุปเมื่อ 2026-11-03

## ลูกค้า 2 ระดับ
- **ลูกค้าองค์กร** = บริษัท/ธนาคารที่จ้างเรา + พนักงานที่ติดต่อเรา → ใส่ชื่อ ตำแหน่ง อีเมลบริษัท ได้
- **ลูกค้าปลายทาง** = ประชาชนที่ใช้ระบบที่เราสร้าง (เช่น ลูกค้าของธนาคาร) → **ห้ามมีอะไรของเขาเลย**

## ห้ามแบบเต็มในเอกสารที่ส่งออก (รวมใบแจ้งหนี้)
1. เลขบัตรประชาชนของใครก็ตาม
2. เบอร์มือถือส่วนตัว — ทั้งลูกค้าปลายทางและพนักงานลูกค้าองค์กร (ใช้เบอร์สำนักงาน/อีเมลบริษัทแทน)
3. เลขบัญชี / เลขบัตรของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง → ใช้รหัสเคส เช่น `CASE-2026-0815`

ข้อมูลส่วนบุคคลอื่นที่ต้องระวัง: อีเมลส่วนตัว, ที่อยู่บ้าน, เลขที่สัญญาสินเชื่อ/CIF ของบุคคล, ประวัติธุรกรรม, ข้อมูลสุขภาพ/ศาสนา (อ่อนไหว)

## ในใบแจ้งหนี้: ตัดทิ้งก่อน mask ทีหลัง
ใบแจ้งหนี้แทบไม่มีเหตุต้องอ้างข้อมูลบุคคล → **ตัดทิ้ง** ถ้าจำเป็นจริงค่อย mask:

| ข้อมูล | แบบปิดบัง |
|---|---|
| เบอร์มือถือ | `081-XXX-4567` |
| เลขบัตรประชาชน | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | `XXX-X-X6789-X` |
| เลขบัตรเครดิต | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | `s*****@gmail.com` |

## แสดงได้ (อย่าตัดผิด)
- เลขประจำตัวผู้เสียภาษีของนิติบุคคล (13 หลัก ขึ้นต้น 0) ทั้งผู้ขายและผู้ซื้อ
- บัญชีรับเงินของบริษัทโนวาเทค
- ชื่อ + ตำแหน่ง + อีเมลบริษัท ของผู้ติดต่อฝั่งลูกค้าองค์กร
