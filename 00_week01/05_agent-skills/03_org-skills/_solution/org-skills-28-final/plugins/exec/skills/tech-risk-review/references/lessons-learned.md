# จุดที่เคยพัง (สรุปจาก company-kit ณ พ.ย. 2026)

ถ้างานใหม่มีรูปแบบเดียวกับข้อใดข้อหนึ่ง → ขึ้นระดับอย่างน้อย 🟠 และระบุว่าซ้ำกับข้อไหน

| # | เหตุการณ์ | รูปแบบที่ต้องจับให้ได้ | สิ่งที่ต้องมีเพื่อกัน |
|---|---|---|---|
| L1 | **Payment ShopDee ล่ม 47 นาที (2026-09-18, Sev1)** cert ที่ upload มือหมดอายุ ไม่มี alert, uptime check ยิงแค่หน้า www, ลูกค้ารู้ก่อนเรา 9 นาที, order ค้าง 214 รายการ (9 รายการตัดเงินแล้ว) | cert ที่ทำมือ (OV ของลูกค้า, **client cert mTLS ของธนาคาร**), reminder อยู่ในปฏิทินส่วนตัวของคน, health check ไม่ครอบคลุม flow ที่ทำเงิน | ทะเบียน cert กลาง + alert < 21 วันทุกโดเมน + synthetic check flow หลักทุก 5 นาที + เจ้าของเป็นบทบาท ไม่ใช่ตัวคน |
| L2 | **Token หลุดกลางการชำระเงิน (ShopDee 2025)** access 60 นาที refresh ไม่หมุน, callback ผูกกับ session ทำให้ลูกค้าจ่ายซ้ำ ต้องคืนเงิน 37 รายการ | flow ที่ผู้ใช้ออกไประบบภายนอกแล้วกลับมา (gateway, OTP, LIFF) | access 15 นาที + rotate + refresh ก่อน redirect, callback ผูกกับ order_id, E2E ที่ใช้ token อายุสั้น |
| L3 | **Webhook ซ้ำ (BaanRai 2026)** gateway ส่งซ้ำ 3 ครั้งทำให้แต้มเพิ่มซ้ำ | รับ event จากภายนอก | ตาราง event_id UNIQUE, ตรวจ HMAC, ตอบ 200 เร็วแล้วโยนงานเข้าคิว |
| L4 | **บั๊ก timezone ใน slot (kaset-appointment-web release/2026.11)** runner TZ=UTC ทำให้ 15:00 ไทยกลายเป็น 22:00 → ระบบตอบ 409 "เต็ม" ทั้งที่ว่าง เกิดหลัง refactor ไป date-fns-tz และเครื่อง dev (TZ Bangkok) จองผ่านปกติ | ระบบจอง/นัดหมายที่มีช่วงเวลา, reuse โค้ด booking ไปโปรเจกต์ใหม่ | CI รันทั้ง TZ=UTC และ Asia/Bangkok, เก็บเวลาเป็น UTC แล้วแปลงที่ขอบระบบที่เดียว |
| L5 | **DentDee เกินแผน 18 man-day** ทำให้ margin ต.ค. ตกเหลือ 27.1% (เป้า 30%) และมีโปรเจกต์ on-time แค่ 7/10 | ประเมิน effort จากความรู้สึก, งานแบบที่ "เคยทำแล้ว" | แตก effort รายโมดูล + เผื่อเวลา + ให้ tech lead เซ็นรับ |
| L6 | **ML พยากรณ์คิว (r01–r03)** เปลี่ยน data version พร้อมกับ feature ทำให้เทียบไม่แฟร์, ไม่ fix seed, โมเดลอยู่ใน notebook บนเครื่อง DS สัญญาจ้าง, ไม่มี monitoring, พยากรณ์ต่ำกว่าจริง 20–30% ช่วงเที่ยงในย่านออฟฟิศ | ML ที่มีเกณฑ์ความแม่นยำในสัญญา, ความรู้อยู่ในคนคนเดียว | MLflow + seed + เทียบบน data version เดียวกัน + shadow mode + เกณฑ์ถอยกลับไป baseline |
| L7 | **Reminder หายไปกับบัญชีของคนที่ลาออก (มี.ค. 2026)** | ความรู้หรือการแจ้งเตือนที่ผูกกับตัวคน | เก็บในระบบกลาง |
