# MD อยากเห็นอะไรก่อน (ความรู้ของ exec-ploy + กติกาจาก company-kit)

## ลำดับที่ MD อ่าน
1. **มีอะไรต้องตัดสินและต้องตอบเมื่อไร** → หน้า 2 บรรทัด "ต้องตัดสินใจ" และหน้า 7
2. **กำไร ไม่ใช่แค่รายได้** — รายได้โตแต่ margin ลด ให้คำนวณกำไรขั้นต้นเป็นบาท (รายได้ × margin) ด้วย
   ถ้ากำไรเป็นเงินไม่โต ให้บอกตรง ๆ ในหัวสไลด์
3. **เงินเข้าจริงหรือยัง** — ถ้า note บอกว่ารายได้รวมงวดที่ยังไม่ออกใบแจ้งหนี้ ให้เขียนไว้ใต้ตัวเลข
4. **ทำไมตัวเลขต่ำกว่าเป้า** — ใช้เหตุผลจากคอลัมน์ note ของ CSV เท่านั้น ไม่แต่งเหตุผลเอง
5. **เรื่องค้างจากเดือนก่อน** — เช่น action item จาก incident ที่มีวันครบกำหนดใกล้ ๆ

## นิยาม KPI (monthly-kpi.csv)
- `revenue` บาท ไม่รวม VAT · `gross_margin` % · `pipeline_value` บาท
- `win_rate` = won / (won + lost) ภายในเดือน
- `projects_on_time` = ไม่เลื่อน milestone เกิน 1 สัปดาห์ → แสดงเป็น x/y และ %
- `customer_nps` สำรวจรายไตรมาส ใช้ค่าล่าสุด
- metric ที่ "น้อยดีกว่า": incidents_sev1/2, attrition, deals_lost
- เป้า margin เฉลี่ยทั้งบริษัทปี 2026 = 30%

## เกณฑ์ดีล
ใช้ skill `core:pricing-rules` เพื่อบอกว่าดีลเข้าเกณฑ์ไหน ไม่ใช่ตัดสินแทน

ถ้าใบสรุปดีล fixed-price บอกว่าไม่มี buffer ให้ยกขึ้นเป็นข้อเท็จจริงในหน้า 7
