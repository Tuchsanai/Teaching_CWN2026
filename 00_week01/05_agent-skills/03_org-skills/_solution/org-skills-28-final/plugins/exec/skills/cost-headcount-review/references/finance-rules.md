# กติกาการเงินที่ใช้ในรายงาน (สรุปจาก company-kit)

> สูตร margin เกณฑ์ และตารางราคาอยู่ใน skill `core:pricing-rules` ไฟล์นี้เก็บเฉพาะสิ่งที่รายงานนี้ใช้

## 1 · สูตร
```
กำไรขั้นต้น (บาท)  = รายได้ × gross margin %          (จาก KPI รายเดือน)
ต้นทุนตรง (บาท)    = รายได้ − กำไรขั้นต้น
มูลค่า margin ที่หาย = รายได้เดือนนี้ × (pts ที่ลดลง / 100)
```
- ทุกราคา **ไม่รวม VAT** (VAT 7% ไม่ใช่รายได้)
- ดีล fixed-price ที่ไม่มี risk buffer ในแผน = เสี่ยงเกินแผน

## 2 · เกณฑ์
เกณฑ์ margin และส่วนลดใช้ skill `core:pricing-rules` ข้อ 3–4

## 3 · ราคาและต้นทุนต่อ man-day
ใช้ประมาณมูลค่า man-day ที่เกินแผน และจุดคุ้มเงินเดือนของตำแหน่งใหม่ โดยอ่านจาก `references/price-list.csv` ของ skill `core:pricing-rules`

- ไม่รู้ว่า man-day ที่เกินเป็นบทบาทไหน → ใช้ช่วงของบทบาทที่เป็นไปได้ (เช่น Dev 7,000 ถึง Senior 9,500) แล้วบอกว่าเป็นค่าประมาณ

## 4 · งวดเงินที่ถือว่าปกติ (อ้างอิงดีลที่ผ่านเกณฑ์)
- 30% เซ็นสัญญา / 40% ผ่าน UAT / 30% go-live · เครดิตเทอม 30 วัน · MA + hosting เก็บล่วงหน้ารายปี
- ค่าปรับล่าช้าปกติมีเพดาน (เช่น 0.1%/วัน เพดาน 5%)

## 5 · การแสดงผล
- **ต้นทุนและ margin ใช้ภายในเท่านั้น** ห้ามอยู่ในเอกสารที่ส่งลูกค้า → รายงานนี้ติดป้าย "เอกสารภายใน" เสมอ
