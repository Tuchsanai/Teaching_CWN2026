# skill-finder: หา skill และดูผลกระทบ

แหล่งเดียวที่ใช้ตอบคือ `references/catalog.md` ในโฟลเดอร์ของ skill นี้ ซึ่งสร้างจากหัวไฟล์ของทุก skill ด้วย `scripts/build-catalog.py` ของคลัง ห้ามตอบจากความจำ

## ขั้นตอน

1. อ่าน `references/catalog.md`
2. ตอบตามคำถาม
   - **มี skill สำหรับเรื่องนี้ไหม:** เทียบงานกับหัวข้อ "ทำอะไร" แล้วเสนอไม่เกิน 3 ตัว พร้อมชื่อเรียกใช้แบบ `plugin:skill` ถ้าไม่มีให้บอกตรง ๆ ว่าไม่มี
   - **ใครดูแล:** ตอบทั้งเจ้าของ skill และผู้ดูแล plugin (CODEOWNER ผู้รีวิว PR)
   - **แก้ตัวนี้กระทบใคร:** ใช้ตาราง "แก้ตัวไหนกระทบใคร" แล้วไล่ผลกระทบต่อทีละชั้น จาก skill ที่กระทบตรงไปยัง skill ที่ `uses` หรือ `follows` skill นั้น แยกตอบเป็น 3 กลุ่ม คือ skill ที่กระทบตรง, skill ที่กระทบต่อเนื่อง, และ skill ที่รับงานต่อจาก (`next`) พร้อมผู้ดูแลที่ต้องแจ้ง
3. ถ้า skill ที่แนะนำอยู่ใน plugin ของแผนกอื่น ให้บอกด้วยว่าผู้ใช้อาจยังไม่ได้ติดตั้ง และต้องติดต่อใคร

## ความหมายของหัวไฟล์

| ช่อง | ความหมาย |
|---|---|
| `layer` | `core` ทุกคนต้องใช้ · `department` งานของแผนกเดียว · `shared` งานข้ามแผนก |
| `uses` | skill ที่เรียกใช้ระหว่างทำงาน |
| `next` | งานถัดไปหลังจบ skill นี้ |
| `follows` | นโยบายที่ต้องทำตาม |
