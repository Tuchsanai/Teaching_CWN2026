# ภาคผนวก PDPA (บังคับทุกครั้งเมื่อลูกค้าเป็นธนาคารหรือสถาบันการเงิน)

> เจ้าของกฎ: MD (`deal-rules` v2026.3 ข้อ 2 แถว 5 และข้อ 3) · ไฟล์นี้เป็นต้นฉบับเดียวของข้อความภาคผนวก skill อื่นให้ชี้มาที่นี่ ไม่เก็บสำเนา

กติกาของ MD มีผลตั้งแต่ 1 ก.ค. 2026 ถ้าลูกค้าเป็นธนาคารหรือสถาบันการเงินแล้ว proposal ไม่มีภาคผนวกนี้ หรือมีไม่ครบ 3 ข้อ MD จะตีกลับทันทีโดยไม่พิจารณาข้ออื่นต่อ และกำหนดยื่นที่กระชั้นไม่ใช่เหตุยกเว้น

ใส่ไว้ท้าย proposal ต่อจากหัวข้อ 9 ใช้ชื่อหัวข้อตามนี้ และมี 3 ข้อพอดี

```markdown
## ภาคผนวก PDPA

1. **DPA:** โนวาเทคเป็นผู้ประมวลผลข้อมูลส่วนบุคคล ลูกค้าเป็นผู้ควบคุมข้อมูลส่วนบุคคล และโนวาเทคประมวลผลตามคำสั่งของลูกค้าเท่านั้น
2. **Data residency:** ข้อมูลส่วนบุคคลทั้งหมดเก็บใน data center ในประเทศไทยเท่านั้น รวม backup และ log
3. **Breach notification:** โนวาเทคแจ้งเหตุละเมิดข้อมูลส่วนบุคคลให้ลูกค้าทราบภายใน 72 ชั่วโมงนับจากที่ทราบเหตุ
```

- เนื้อหาในหัวข้อ 4 ใช้แทนภาคผนวกไม่ได้ แม้จะพูดถึงข้อตกลงประมวลผล hosting หรือ audit log แล้วก็ตาม
- ถ้าโซลูชันทำตามข้อใดไม่ได้ หรือยังยืนยันไม่ได้ว่าทำตามได้ ห้ามตัดหรือแก้ข้อความเอง ให้แจ้ง `plat-may` และ MD ให้ตัดสินร่วมกัน จดไว้ใน internal-notes และห้ามยื่นจนกว่าจะได้ข้อสรุป
