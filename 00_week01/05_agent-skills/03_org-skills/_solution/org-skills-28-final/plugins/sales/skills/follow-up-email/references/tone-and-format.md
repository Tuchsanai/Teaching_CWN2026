# น้ำเสียงและรูปแบบ

วิธีเขียนอีเมลของกฤต

## น้ำเสียงบริษัท
ใช้ skill `core:brand-guide` ข้อ 3

## โครงอีเมลแบบกฤต

```
เรื่อง: <หัวข้อ> — <สิ่งที่ขอ> — <ชื่อโครงการ>

เรียน คุณ<ชื่อ>

<ขอบคุณ 1 ประโยค + อ้างวันที่คุยกัน>

**<สิ่งที่ขอให้ลูกค้าทำ 1 อย่าง> ภายใน <วัน วันที่>**   ← ตัวหนา
<ตัวเลือกให้เลือก ถ้ามี (ไม่เกิน 3)>

<ตาราง "สิ่งที่เราจะส่ง | ภายใน" ถ้ามีคำมั่นหลายข้อ>

ขอแสดงความนับถือ
<ชื่อ> · <ฝ่าย> โนวาเทค
```

- ยาวไม่เกิน ~150 คำ (ไม่นับตาราง)
- 1 ฉบับ = 1 สิ่งที่ขอ · ให้ตัวเลือกแทนคำถามปลายเปิด ("เลือก 17/18/19" ดีกว่า "สะดวกวันไหน")
- เขียนวันพร้อมชื่อวัน ("ศุกร์ 6 พ.ย.") และเช็กว่าตรงปฏิทิน
- ผู้ตัดสินใจอยู่ "ถึง" · ผู้ใช้งานจริง/ทีมเราอยู่ "สำเนา"

## เช็กก่อนส่ง

- [ ] ไม่มีเบอร์มือถือ / เลขบัตร / เลขบัญชี (ดู `customer-data-rules.md`)
- [ ] ไม่มีราคาที่ยังไม่ผ่านบัญชี, ข้อมูลคู่แข่ง, ความรู้สึกภายใน
- [ ] ไม่มีคำโอ้อวด ไม่มีอีโมจิ คำเทคนิคมีวงเล็บอธิบายครั้งแรก
- [ ] มีสิ่งที่ขอ 1 อย่าง + วันกำหนด ตัวหนา
- [ ] วันที่ทุกวันตรงกับบันทึกประชุมและชื่อวันถูก
- [ ] ทุกคำมั่นมีหลักฐาน หรือถูกยกไป "ต้องตัดสินใจ"
- [ ] ช่องทาง/ผู้รับตรงกับที่ลูกค้าขอ
