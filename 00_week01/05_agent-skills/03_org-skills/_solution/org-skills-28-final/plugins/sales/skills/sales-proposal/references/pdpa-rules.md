# ข้อมูลส่วนบุคคลใน proposal

กติกาทั้งหมดอยู่ใน skill `core:customer-data-policy` ไฟล์นี้เก็บเฉพาะสิ่งที่ proposal ต้องเขียน

- ในเนื้อหาโซลูชัน: ระบุว่าเลขบัตรประชาชนไม่เก็บแบบข้อความธรรมดา, ข้อมูลเทรนเป็นข้อมูลไม่ระบุตัวตน, ลบสำเนาข้อมูลลูกค้าปลายทางภายใน 90 วันหลังส่งมอบ

## ภาคผนวก PDPA (บังคับทุกครั้งเมื่อลูกค้าเป็นธนาคารหรือสถาบันการเงิน)

proposal ต้องมีหัวข้อ "ภาคผนวก PDPA" ต่อจากหัวข้อ 9 มี 3 ข้อพอดี (DPA, Data residency, Breach notification) ถ้าไม่มีภาคผนวกนี้ หรือมีไม่ครบ 3 ข้อ MD จะตีกลับทันที

กติกาและข้อความมาตรฐานอยู่ใน `references/bank-pdpa-annex.md` ของ skill `core:customer-data-policy` ที่เดียว ให้คัดลอกจากไฟล์นั้น ไฟล์นี้ไม่เก็บสำเนา และเส้นทางเมื่อโซลูชันทำตามข้อใดไม่ได้หรือยังยืนยันไม่ได้ก็อยู่ในไฟล์นั้นเช่นกัน
