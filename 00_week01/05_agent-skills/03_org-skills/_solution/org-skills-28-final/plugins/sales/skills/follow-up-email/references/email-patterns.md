# 3 แบบอีเมลที่ใช้บ่อย

## 1. หลังประชุม — "เขียนอีเมลตามลูกค้าหลังประชุม"

ส่งภายใน 1–2 วันทำการหลังประชุม
- ขอบคุณ + ประโยคที่ลูกค้าใช้บ่อย (แสดงว่าเข้าใจปัญหา) 1 ประโยค
- **สิ่งที่ขอ 1 อย่าง** (มักเป็นยืนยันนัดถัดไป) ตัวหนา + ตัวเลือก + วันตอบ
- ตาราง "สิ่งที่เราจะส่ง | ภายใน" จาก follow-up ในบันทึกประชุม — คัดเฉพาะที่ลูกค้าต้องรู้ ไม่บอกว่าใครในทีมทำ
- เรื่องที่ลูกค้าขอช่องทางแยก → ส่งอีกฉบับ

## 2. ลูกค้าเงียบ — "ลูกค้าเงียบไป 2 อาทิตย์ ช่วยตามหน่อย"

- ไม่ตำหนิ ไม่ถาม "ได้รับเมลไหม" — อ้างฉบับก่อน (วันที่ + เรื่อง) สั้น ๆ
- ให้**เหตุผลที่ต้องตอบตอนนี้** ที่เป็นจริง เช่น วันยื่นข้อเสนอ วันปิดรอบงบ ช่วงที่ทีมว่าง
- ทำให้ตอบง่ายที่สุด: คำถามใช่/ไม่ใช่ หรือเลือก 1 จาก 2–3
- เสนอทางเลือกที่เล็กลง (คุย 15 นาทีทางโทรศัพท์/ออนไลน์ แทนประชุมใหญ่)
- ถ้าตามครั้งที่ 3 แล้วยังเงียบ → ถามตรง ๆ สุภาพ ว่าโครงการยังอยู่ในแผนไหม และบอกว่าจะไม่ตามอีกจนกว่าเขาพร้อม

## 3. สรุปนัดหมายถัดไป — "ร่างเมลสรุปนัดหมายถัดไป"

- บรรทัดแรก: วัน เวลา สถานที่/ลิงก์ ระยะเวลา (ตัวหนา)
- ผู้เข้าร่วมทั้ง 2 ฝั่ง + วาระ ไม่เกิน 3 ข้อ
- สิ่งที่ขอให้ลูกค้าเตรียม (ถ้ามี) + วันที่ต้องได้
- ขอให้ตอบยืนยัน หรือแจ้งถ้าต้องเลื่อน
