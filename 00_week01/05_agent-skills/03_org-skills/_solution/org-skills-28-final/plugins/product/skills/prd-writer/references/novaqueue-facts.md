## สถาปัตยกรรม (สำหรับ NFR ใน PRD — รายละเอียดให้ SA)

- modular monolith, โมดูลตามโดเมน: `booking`, `branch`, `notification`, `report`
- งาน async (ส่ง SMS/LINE, รายงาน) → BullMQ บน Redis, idempotent, retry exponential ≤ 5 ครั้ง, dead-letter + แจ้งเตือน
- ชื่อ event `<domain>.<event>` อดีตกาล เช่น `booking.created`, `notification.failed`
- PostgreSQL หลัก, ข้อมูลอ่อนไหว (เบอร์, เลขบัตร) เข้ารหัสระดับคอลัมน์ · ลูกค้าธนาคาร: cloud ภูมิภาคไทยเท่านั้น
