# แม่แบบประกาศเลิกให้บริการ (ถึงลูกค้า)

> รูปแบบและน้ำเสียงใช้ skill `core:brand-guide` ข้อ 3 และ 5

## กติกาที่ต้องทำตาม

- แบรนด์ทั้งหมดตาม skill `core:brand-guide` · วันที่บนหัวเอกสาร: หน่วยงานไทยใช้ พ.ศ.
- ห้ามสัญญาเกินข้อเสนอมาตรฐาน (ดู `sunset-rules.md` ข้อ 2) · ผู้ติดต่อใช้อีเมลบริษัท/เบอร์สำนักงานเท่านั้น

## โครง

```markdown
<!-- ร่างภายใน · ห้ามส่งจนกว่า MD อนุมัติ · เติม {{...}} รายลูกค้า · ลบหัว [เฉพาะ ...] ก่อนส่ง -->

**โนวาเทค**
เลขที่ NVT-EOL-<ปี>-{{ลำดับ}} · วันที่ <วันประกาศ>
เรื่อง แจ้งการสิ้นสุดการให้บริการ <ผลิตภัณฑ์ เวอร์ชัน> และข้อเสนอย้ายไปยัง <เวอร์ชันใหม่>
เรียน {{ตำแหน่งผู้รับ}} {{ชื่อหน่วยงาน}}

## 1. สรุป        ← วันสิ้นสุดบริการ + ข้อเสนอค่าย้ายฟรีพร้อมวันสุดท้าย (ประโยคเดียว)
## 2. เหตุผล       ← เหตุผลด้านความปลอดภัย/การดูแล ไม่โทษลูกค้า
## 3. กำหนดการสำคัญ ← ตาราง: ใช้งานปกติถึงเมื่อไร, เปิดส่งออกข้อมูล, วันสุดท้ายค่าย้ายฟรี, วันสิ้นสุด, ลบข้อมูลภายใน + หนังสือยืนยัน
## 4. ข้อเสนอการย้าย ← ข้อเสนอมาตรฐาน 3 ข้อ + ย่อหน้า [เฉพาะ <ลูกค้า>] ตามเงื่อนไข (DPA ธนาคาร, MA หมดก่อน, จัดซื้อราชการ)
## 5. สิ่งที่ขอให้ท่านดำเนินการ ← แจ้งผู้ประสานงานภายใน <วันที่> + เลือกย้าย/ส่งออก
## 6. ติดต่อ      ← PM + Sales (อีเมลบริษัท/เบอร์สำนักงาน)

ขอแสดงความนับถือ · ลงนาม
---
โนวาเทค · ข้อมูลลับเฉพาะลูกค้า · หน้า N
```
