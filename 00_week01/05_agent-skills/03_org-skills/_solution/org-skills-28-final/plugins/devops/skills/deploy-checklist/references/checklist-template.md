## 0. บทบาท (Deploy lead / Verifier / Comms + หัวหน้า dev ที่ติดต่อได้)
## 1. เตรียมล่วงหน้า (1.1–1.8 + ตาราง cert TLS ทุกโดเมน)
## 2. วัน deploy ก่อนกด (bridge, dashboard, snapshot <ชื่อ>, image tag เดิม, cron/batch ที่ต้องปิด *ระบุชื่อ job*)
## 3. Deploy (maintenance, migrate + เทียบเวลา dry-run, rolling + /readyz)
## 4. Smoke test (flow จริงของระบบ + regression ของบั๊กรอบนี้ + webhook + ตัวเลข)
## 5. แผน rollback (เกณฑ์ที่ต้อง rollback และ "ข้อมูลผิด" ในระบบนี้หมายถึงอะไร → flag → image เดิม → restore ที่ต้องมี 2 คนตกลงร่วมกัน → แจ้งลูกค้าภายใน 30 นาที)
## 6. หลัง deploy (แจ้งว่าเสร็จ, เปิด job คืน, on-call, tag/CHANGELOG)

ส่วนที่ต้องมี:
- เรื่อง
