# วิธีที่ price_calc.py คิด (เฉพาะ skill นี้)

- ตัวอย่างตรวจ script: SA 10 + Dev 40 + QA 15 man-day ไม่ใช่ fixed-price ต้องได้ตรงกับตัวอย่างใน `core:pricing-rules` ข้อ 6
