# ข้อมูลลูกค้าในใบแจ้งหนี้

กติกาและวิธี mask อยู่ใน skill `core:customer-data-policy` รวมกติกาเฉพาะใบแจ้งหนี้ใน `references/doc-type-rules.md` ของ skill นั้น ไฟล์นี้เก็บเฉพาะสิ่งที่ต้องจำตอนตรวจใบ

- ใบแจ้งหนี้แทบไม่มีเหตุต้องอ้างข้อมูลบุคคล → **ตัดทิ้ง** ถ้าจำเป็นจริงค่อย mask
- ลูกค้าปลายทาง: **ห้ามมีอะไรของเขาเลย**
- แสดงได้ (อย่าตัดผิด): เลขผู้เสียภาษีนิติบุคคลทั้งผู้ขายและผู้ซื้อ, บัญชีรับเงินของบริษัทโนวาเทค, ชื่อ + ตำแหน่ง + อีเมลบริษัทของผู้ติดต่อฝั่งลูกค้าองค์กร
