> ถ้าต้นฉบับมี version ใหม่กว่า v2026.2 ให้ยึดต้นฉบับ

## 1. งวดมาตรฐาน

| งวด | เกิดเมื่อ | สัดส่วน | เอกสารแนบที่ต้องมีก่อนออก |
|---|---|---|---|
| 1 | ลงนามสัญญา | 30% | สำเนาสัญญาหน้าที่มีลายเซ็น |
| 2 | ผ่าน UAT | 40% | ใบตรวจรับ UAT ที่ลูกค้าลงนาม |
| 3 | go-live | 30% | ใบตรวจรับงานขึ้นระบบจริง |
| MA / hosting / license | ล่วงหน้ารายปี | 100% ของปี | — |

- สัญญาลูกค้ากำหนดต่าง → ยึดสัญญา + เขียนเลขข้อสัญญาในหมายเหตุ
- ออกได้ **หลัง** ได้เอกสารแนบครบเท่านั้น

## 2. สูตร

```
ยอดงวด (ก่อน VAT) = มูลค่าสัญญาก่อน VAT × สัดส่วนงวด
VAT 7%            = ยอดงวด × 0.07   (ปัดเศษ 2 ตำแหน่ง)
รวมทั้งสิ้น        = ยอดงวด + VAT
```
- จำนวนเงินตัวอักษรตรงกับ "รวมทั้งสิ้น" (ลงท้าย "บาทถ้วน" หรือ "…สตางค์")
- ผลรวมทุกงวด = มูลค่าสัญญาพอดี (งวดสุดท้ายรับเศษ)
- ภาษีหัก ณ ที่จ่าย 3% ลูกค้าหักเอง — ไม่หักในใบ แต่เขียนหมายเหตุ
- แสดง 3 บรรทัดเสมอ: รวมก่อน VAT → VAT 7% → รวมทั้งสิ้น · ห้ามแสดงต้นทุน/margin

## 3. เลขที่และวันที่

- `INV-<ปี ค.ศ.>-<ลำดับ 4 หลัก>` เช่น `INV-2026-0142` เรียงไม่ข้าม
- วันครบกำหนด = วันที่ออก + เครดิตเทอมในสัญญา (ค่าเริ่มต้น 30 วัน)

## 4. ช่องที่ต้องมีครบ (8 ช่อง)

1. ผู้ขาย: บริษัท โนวาเทค จำกัด (สำนักงานใหญ่) เลขประจำตัวผู้เสียภาษี 0105561012345 · 88 อาคารโนวาทาวเวอร์ ชั้น 12 ถ.พระราม 9 แขวงห้วยขวาง เขตห้วยขวาง กรุงเทพฯ 10310
2. ผู้ซื้อ: ชื่อนิติบุคคลเต็ม, สาขา/สำนักงานใหญ่, เลขผู้เสียภาษี, ที่อยู่ตาม ภ.พ.20
3. เลขที่สัญญา / PO ของลูกค้า
4. ผู้ติดต่อฝั่งลูกค้า: **ชื่อ + ตำแหน่ง + อีเมลบริษัทเท่านั้น** (ห้ามเบอร์มือถือ)
5. รายการ: ชื่อโครงการ, งวดที่, เงื่อนไขงวด, สัดส่วน
6. ยอดก่อน VAT / VAT 7% / รวมทั้งสิ้น / จำนวนเงินตัวอักษร
7. บัญชีรับเงินบริษัท: ธนาคารสยามรุ่งเรือง สาขาพระราม 9 ชื่อบัญชี บริษัท โนวาเทค จำกัด เลขที่ 714-2-08835-1 (บัญชีบริษัท แสดงได้)
8. ผู้จัดทำ + ผู้ตรวจ (ผู้อนุมัติ: หัวหน้าบัญชี `fin-joy`)

## 5. ห้ามมีในใบแจ้งหนี้

- เบอร์มือถือส่วนตัวของใครก็ตาม, ชื่อหรือข้อมูลของลูกค้าปลายทาง (ประชาชนที่ใช้ระบบ), เลขบัตรประชาชน
- รายละเอียดเคสภายในของลูกค้า — ถ้าจำเป็นให้อ้างรหัสเคส/รหัส ticket

## 6. เช็กลิสต์ผู้ตรวจ

- [ ] งวดและสัดส่วนตรงสัญญา · มีเอกสารแนบครบ
- [ ] คำนวณ VAT และรวมทั้งสิ้นใหม่เอง ตรงทุกหลัก
- [ ] จำนวนเงินตัวอักษรตรงกับตัวเลข
- [ ] ไม่มีข้อมูลต้องห้ามตามข้อ 5
- [ ] เลขที่เรียงต่อจากใบล่าสุด, วันครบกำหนดถูก

## ตัวอย่างที่เคยเจอ (INV-2026-0142, 3 พ.ย. 2026)

ร่าง auto-fill: VAT พิมพ์ 51,080 แทน 51,800 (สลับหลัก) → รวมและตัวอักษรผิดตาม · หมายเหตุดึงข้อความจากบันทึก UAT มาทั้งชื่อลูกค้าของธนาคาร + เบอร์มือถือ + เรื่องเคส
