# กติกาข้อมูลเฉพาะงานทดลอง ML

ข้อมูลส่วนบุคคลใช้ skill `core:customer-data-policy` ไฟล์นี้เก็บเฉพาะสิ่งที่ใช้กับงานทดลอง

- ใช้เฉพาะข้อมูล **ไม่ระบุตัวตน** และต้องมีสิทธิ์ใช้ตามสัญญา (เช่น ข้อมูลเกษตรไทยใช้ได้ตามสัญญา MA)
- ใช้ bucket ของทีม ไม่คัดลอกข้อมูลจริงมาไว้ที่เครื่องตัวเอง
- รายงาน/ทะเบียน run/artifact อ้างอิงแค่ระดับสาขา/ชั่วโมงเท่านั้น และห้ามมี CIF
- feature ห้ามดึงข้อมูลส่วนบุคคล (เช่น CIF, ระดับลูกค้ารายคน) ถ้าไม่จำเป็นจริง ข้อมูลอ่อนไหว (สุขภาพ ศาสนา ฯลฯ) ห้ามใช้
- สำเนาข้อมูลลูกค้าปลายทางต้องลบตามกำหนด — ระบุ data_version ให้ตามลบได้
