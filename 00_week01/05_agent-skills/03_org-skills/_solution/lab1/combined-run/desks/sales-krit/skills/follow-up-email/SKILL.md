# อีเมลติดตามลูกค้า (follow-up-email)

เป้าหมายเดียว: **ลูกค้าตอบกลับ** — อีเมลสั้น สุภาพ และขอให้ลูกค้าทำ **1 อย่าง** ภายในวันที่ระบุ

## อินพุต

- บันทึกประชุม (ผู้เข้าประชุม, สิ่งที่คุย, ตาราง follow-ups, ข้อมูลติดต่อ) — ถ้าไม่มี ถามผู้ใช้: คุยกับใคร เมื่อไร รับปากอะไรไว้
- TOR / เอกสารดีล (ถ้ามี) — ใช้เช็กวันยื่นข้อเสนอ เป้าหมายของลูกค้า และคำศัพท์ที่ลูกค้าใช้
- โหมด "ลูกค้าเงียบ": วันที่ส่งเมลครั้งก่อน + เรื่องที่ค้าง

## ขั้นตอน

1. **หาขั้นต่อไปที่ดีที่สุด 1 ข้อ** (มักอยู่ในโน้ต "ขั้นต่อไป") → ทำเป็นหัวเรื่องและย่อหน้าที่ 2 พร้อมตัวเลือกให้ลูกค้าเลือก (เช่น วัน 2–3 วัน) และเส้นตายตอบกลับ
2. **เลือกผู้รับ:** ถึง = ผู้ตัดสินใจ · สำเนา = ผู้ใช้งาน/ผู้เกี่ยวข้องฝั่งลูกค้า + ทีมเราที่เข้าประชุม · ใครที่ขอให้ติดต่อทางอีเมลเท่านั้น ให้ใส่สำเนาและเรียกชื่อในย่อหน้าที่เกี่ยวกับเขา
3. **ร่างตามโครง** ใน `references/email-template.md` (หัวเรื่อง → ขอบคุณ+โจทย์ลูกค้า 1 ประโยค → ขั้นต่อไป → ตาราง "สิ่งที่เราจะส่ง" → สิ่งที่ขอจากลูกค้า → ปิด)
4. **ตรวจตาม `references/data-rules.md` และ `references/writing-rules.md`** ทุกข้อ โดยเฉพาะ:
   - ไม่มีเบอร์มือถือ/ข้อมูลส่วนตัวในเนื้อเมล แม้ลูกค้าจะบอกให้โทร
   - ไม่ยืนยันคำพูดในที่ประชุมที่ไม่มีหลักฐานรองรับ (เช่น "ผ่านทุกครั้ง") — รับปากแค่ "จะส่งหลักฐาน"
   - ไม่ให้ตัวเลขราคา/ส่วนลดที่บัญชียังไม่ทำ
   - วันที่ทุกวันมีชื่อวันและตรงกับปฏิทินจริง
5. **บันทึกผล** ลง `work/<YYYY-MM-DD>-<deal>-follow-up-email.md` ประกอบด้วย: อีเมล + "เช็กก่อนส่ง" (สิ่งที่ผู้ใช้ต้องยืนยันเอง) + "สิ่งที่ตั้งใจตัดออก" พร้อมเหตุผล

## ห้าม

- ห้ามส่งอีเมลเอง ส่งแค่ร่าง ให้เจ้าของดีลอ่านและกดส่ง
- ห้ามคัดลอกโน้ตภายใน (ความรู้สึกหลังประชุม คู่แข่ง margin) ลงอีเมล
- ห้ามเดาข้อมูลที่ไม่มี (ลายเซ็น เบอร์สำนักงาน ความว่างของทีม) — ใส่ `[...เติมก่อนส่ง]` และจดในเช็กลิสต์
