# ตัวอย่าง: deal-002 ธนาคารเอเชียไทยสากล (Card Dispute Portal)

## อินพุตโดยย่อ (จากบันทึกประชุม 28 ต.ค. 2026 + TOR ATI-IT-2026-052)

- ผู้ตัดสินใจ: คุณธีรพงษ์ (ผอ.ปฏิบัติการบัตรเครดิต) · ผู้ใช้งาน: คุณปวีณา · IT Security: คุณศิริพร (ขอให้ติดต่อเรื่อง security ทางอีเมลเท่านั้น)
- ประโยคที่ลูกค้าพูดบ่อย: "ทำให้ทีมผมเลิกโทรตามเอกสารได้ไหม" · เป้าหมาย TOR: เริ่มตรวจสอบภายใน 2 วันทำการ
- ขั้นต่อไปที่ดีที่สุด: นัดสาธิตหน้าจอเจ้าหน้าที่ (คิว + SLA timer) ก่อนวันยื่นข้อเสนอ 20 พ.ย. — ลูกค้าว่าง 17/18/19 พ.ย. บ่าย ต้องยืนยันภายใน 6 พ.ย.
- รับปากไว้: ผลงานอ้างอิง 1 หน้า (6 พ.ย.), ราคาช่วง + รายการตัดได้ (10 พ.ย.), คำตอบ CardLink (10 พ.ย.), security questionnaire คืนพร้อม proposal (20 พ.ย.)

## ผลลัพธ์ (ย่อ)

- **เรื่อง:** สรุปประชุม 28 ต.ค. และขอเลือกวันสาธิตหน้าจอเจ้าหน้าที่ (17–19 พ.ย.) — Card Dispute Portal
- **ถึง** คุณธีรพงษ์ · **สำเนา** คุณปวีณา, คุณศิริพร, นิดา, ไอศวรรย์
- ย่อหน้า 1: ขอบคุณ + โจทย์ "ทำให้ทีมเลิกโทรตามเอกสาร" + 2 วันทำการ
- ย่อหน้า 2: ขอเลือก 1 วัน (อ. 17 / พ. 18 / พฤ. 19 พ.ย. 14:00–15:00) ตอบภายใน ศ. 6 พ.ย. เพื่อให้ทันก่อน 20 พ.ย.
- ตาราง 4 แถว "สิ่งที่เราจะส่ง" พร้อมวันที่
- "คุณศิริพร: รบกวนส่งไฟล์แบบสอบถามความปลอดภัยมาที่อีเมลนี้" (ขอ 1 อย่างต่อคน)
