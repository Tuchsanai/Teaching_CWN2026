# โครงอีเมลติดตาม

ยาวรวมไม่เกิน ~1 หน้าจอมือถือ · ย่อหน้าละ 1–3 บรรทัด

```
ถึง: <ผู้ตัดสินใจ>
สำเนา: <ผู้ใช้งาน/ผู้เกี่ยวข้องฝั่งลูกค้า>, <ทีมเราที่เข้าประชุม>
เรื่อง: <สรุปประชุม <วันที่>> และ <ขั้นต่อไปที่ขอ> — <ชื่อโครงการ>

เรียน คุณ<ชื่อผู้ตัดสินใจ>

ขอบคุณที่สละเวลาประชุมกับเราเมื่อ<วัน วันที่> ครับ/ค่ะ เรารับโจทย์หลักไว้ว่า "<ประโยคที่ลูกค้าพูดบ่อย>" <+ เป้าหมายที่วัดได้จาก TOR>

**<ขั้นต่อไป 1 ข้อ>** — <ทำอะไร ให้ใคร นานเท่าไร>
- <ตัวเลือก 1 พร้อมชื่อวัน>
- <ตัวเลือก 2>
รบกวนตอบกลับ **ภายใน<วันที่>** เพื่อ<เหตุผลที่โยงกับเส้นตายของลูกค้าเอง>

**สิ่งที่เราจะส่งให้ตามที่รับปากไว้**
| เรื่อง | ส่งภายใน |
|---|---|
| ... | <วัน วันที่> |

**คุณ<ชื่อ>:** <สิ่งที่ขอจากคนนี้ 1 อย่าง>

หากมีข้อสงสัยเพิ่มเติม ติดต่อ<ผม/ดิฉัน>ทางอีเมลนี้ได้ตลอดครับ/ค่ะ

ขอแสดงความนับถือ
<ชื่อ> · <ตำแหน่ง> · โนวาเทค
<อีเมล / เบอร์สำนักงาน>
```

## โหมด "ลูกค้าเงียบไป" (ไม่มีการประชุมใหม่)

- หัวเรื่อง: `ติดตาม: <เรื่องที่ค้าง> — <ชื่อโครงการ>`
- ย่อหน้าแรกอ้างอีเมลครั้งก่อน 1 ประโยค (วันที่ + เรื่อง) ไม่ตำหนิว่าลูกค้าไม่ตอบ
- ให้ทางเลือกที่ง่ายกว่าเดิม (ตอบแค่ "ได้/ไม่ได้", เลือกวัน, หรือ "ให้ติดต่อใครแทน")
- เพิ่มคุณค่าใหม่ 1 อย่างถ้ามี (เอกสารที่สัญญาไว้, คำตอบคำถามเดิม)
- ถ้าใกล้เส้นตายของลูกค้า (เช่น วันยื่นข้อเสนอ) บอกวันนั้นตรง ๆ
