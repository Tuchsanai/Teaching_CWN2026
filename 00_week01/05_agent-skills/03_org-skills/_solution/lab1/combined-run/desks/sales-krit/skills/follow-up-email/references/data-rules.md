# ข้อมูลลูกค้าในอีเมล (สรุปจาก company-kit/customer-data-policy.md v1.4)

> เจ้าของนโยบาย: เมย์ อรุณรัตน์ (`plat-may`) · ไม่แน่ใจ ถามช่อง `#ask-pdpa` หรือ dpo@novatech.example
> ส่งผิดคน/แนบไฟล์ผิด → แจ้ง `plat-may` **ภายใน 1 ชั่วโมง** ห้ามแก้เงียบ ๆ เอง

## ห้ามใส่แบบเต็มในอีเมลถึงลูกค้า

1. เลขบัตรประชาชน ของใครก็ตาม
2. **เบอร์มือถือส่วนตัว** — ทั้งลูกค้าปลายทาง และ *พนักงานของลูกค้าองค์กร* (แม้เขาจะบอกในที่ประชุมว่า "โทรมือถือได้เลย") → ใช้อีเมลบริษัท/เบอร์สำนักงานแทน
3. เลขบัญชี / เลขบัตร ของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง (ใช้รหัสเคส เช่น `CASE-2026-0815`)

เบอร์มือถือที่ได้จากที่ประชุมหรือ TOR → เก็บใน CRM ภายในเท่านั้น ไม่คัดลอกลงอีเมล/เอกสาร

**ใช้ได้:** ชื่อ ตำแหน่ง และอีเมลบริษัทของพนักงานลูกค้าองค์กรที่ติดต่อกับเรา (ผู้รับอีเมลเอง)

## ถ้าจำเป็นต้องอ้างถึง ให้ปิดบัง (แต่ตัดทิ้งดีกว่า)

| ข้อมูล | แบบปิดบัง |
|---|---|
| เบอร์มือถือ | `081-XXX-4567` |
| เลขบัตรประชาชน | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | `XXX-X-X6789-X` |
| เลขบัตรเครดิต | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | `s*****@gmail.com` |

ภาพหน้าจอที่มีข้อมูลข้างต้นต้องเบลอก่อนแนบ

## ข้อมูลภายในที่ไม่ใช่ PDPA แต่ห้ามหลุดเหมือนกัน

- โน้ต "ความรู้สึกหลังประชุม", ชื่อ/ข้อมูลคู่แข่ง, margin, ต้นทุน
- มูลค่าสัญญาของลูกค้ารายอื่น — ถ้าลูกค้าขอผลงานอ้างอิง ให้ส่งเป็นเอกสารสรุปแยก และเช็กก่อนว่าอ้างชื่อลูกค้าเก่าได้
