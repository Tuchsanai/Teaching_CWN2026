# กติกาการเขียน (สรุปจาก company-kit/brand-guide.md v3.2 ข้อ 3 และ 6)

1. **ตรง ชัด สั้น** — ประโยคแรกของแต่ละส่วนบอกข้อสรุป แล้วค่อยรายละเอียด
2. **สุภาพแบบมืออาชีพ** — ใช้ "เรา" แทนโนวาเทค, "ท่าน" หรือ "ธนาคาร" แทนลูกค้า (หรือ "คุณ<ชื่อ>" ในอีเมลถึงบุคคล) · ไม่ใช้ภาษาวัยรุ่น · **ไม่ใช้อีโมจิ**
3. **ไม่โอ้อวด** — ห้าม "ดีที่สุด", "อันดับหนึ่ง", "100%", "ผ่านทุกครั้ง" ถ้าไม่มีหลักฐาน ให้ใช้ตัวเลขที่ตรวจได้แทน
4. **คำเทคนิคเขียนอังกฤษได้** (API, SLA, prototype) แต่ครั้งแรกให้อธิบายไทยสั้น ๆ ในวงเล็บ
5. **ตัวเลขเงิน** ใส่คอมมา หน่วย "บาท" และระบุเสมอว่า "ไม่รวม VAT" หรือ "รวม VAT 7%"
6. ชื่อบริษัทเขียน **"โนวาเทค"** หรือ **"Novatech"** เท่านั้น (ห้าม NovaTech / Nova Tech)
7. วันที่: ใส่ชื่อวัน + วันที่ + เดือน (+ ปี ถ้าข้ามปี) ใช้ พ.ศ. หรือ ค.ศ. ให้ตรงกับเอกสารของลูกค้า และตรวจกับปฏิทินจริงทุกครั้ง

## กติกาเฉพาะอีเมลติดตาม (ประสบการณ์ sales-krit)

- ขอให้ลูกค้าทำ **1 อย่าง** ต่อ 1 อีเมล (คนอื่นในสำเนาขอได้คนละ 1 อย่าง เรียกชื่อตรง ๆ)
- ให้ **ตัวเลือก** แทนคำถามปลายเปิด ("17, 18 หรือ 19 พ.ย." ดีกว่า "สะดวกวันไหน")
- ใส่ **เส้นตายตอบกลับ** และเหตุผลที่โยงกับเป้าหมายของลูกค้า
- สิ่งที่เรารับปาก → ตาราง เรื่อง | ส่งภายใน ให้ลูกค้าเห็นว่าเราจำได้ครบ
- ส่งภายใน 1–2 วันทำการหลังประชุม ถ้าช้ากว่านั้นไม่ต้องขอโทษยาว เขียนให้ใช้ได้เลย
