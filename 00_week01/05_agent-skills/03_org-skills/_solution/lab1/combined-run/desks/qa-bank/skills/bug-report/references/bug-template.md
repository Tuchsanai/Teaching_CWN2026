## Severity
| ระดับ | ความหมายทั่วไป | ระบบจองคิว |
|---|---|---|
| Sev1 | ระบบใช้ไม่ได้ | จองไม่ได้ทุกสาขาทุกเวลา |
| Sev2 | ฟีเจอร์หลักพัง ไม่มีทางเลี่ยง | จองไม่ได้บางช่วงเวลา/บางสาขา ที่ควรจองได้ |
| Sev3 | มีทางเลี่ยง | แสดงจำนวนที่ว่างผิด แต่จองได้ถูก |
| Sev4 | เล็กน้อย/หน้าตา | ข้อความ/สีผิด |

## Priority
| ระดับ | ความหมาย |
|---|---|
| P1 | ต้องแก้ก่อน release ถัดไป (ใช้เมื่อมีวัน deploy/ส่งมอบลูกค้าผูกอยู่) |
| P2 | แก้ใน sprint นี้ |
| P3 | แก้เมื่อว่าง |
