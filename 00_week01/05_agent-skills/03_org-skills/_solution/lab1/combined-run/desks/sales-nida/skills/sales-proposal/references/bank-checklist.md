# Checklist ลูกค้าธนาคาร + ข้อมูลส่วนบุคคล

> จากประสบการณ์ดีลธนาคารที่ชนะ และ `company-kit/customer-data-policy.md` v1.4 (ผู้ดูแล `plat-may`) · สรุปเมื่อ 2026-11-04

## 1. สิ่งที่กรรมการธนาคารตรวจ (ต้องมีคำตอบใน proposal)

**ความปลอดภัย**
- [ ] อ้างแนวนโยบาย IT risk ของ ธปท. และ PDPA พร้อมบอกว่าเราส่งมอบเอกสารอะไร
- [ ] เข้ารหัสขณะส่ง (TLS 1.2+) และขณะเก็บ (AES-256) · เชื่อมระบบธนาคารด้วย mTLS ถ้า TOR ระบุ
- [ ] เลขบัตรประชาชน / CIF เก็บอย่างไร (hash แบบมี key หรือเข้ารหัส, ไม่อยู่ใน log)
- [ ] audit log: เก็บอะไร นานเท่าไร (ตามตัวเลขใน TOR ไม่ใช่ค่าเดิมของเรา)
- [ ] penetration test: ใครทดสอบ ใครจ่าย เราแก้ระดับไหนก่อนเปิดใช้
- [ ] NDA, ข้อมูลทดสอบแบบสังเคราะห์, การเข้าถึงข้อมูลจริงต้องผ่านการอนุมัติ
- [ ] SSO กับระบบยืนยันตัวตนของธนาคาร (AD / Entra ID) สำหรับพนักงาน

**SLA / ความต่อเนื่อง**
- [ ] uptime ตรงหรือดีกว่า TOR
- [ ] เวลาตอบรับ Sev 1 ตรง TOR และ **ช่วงเวลาให้บริการตรงกับ MA ที่คิดราคา** (8x5 = MA-STD, 24x7 = MA-PREM)
- [ ] HA ของฐานข้อมูล (CL-M ขึ้นไป), WAF, monitoring
- [ ] แผนนำร่อง → ขยาย, hypercare, อบรม

**อื่น ๆ ที่ TOR ธนาคารมักขอ**
- [ ] ผลงานกับสถาบันการเงินตามจำนวนที่ TOR กำหนด
- [ ] ราคาแยกรายการ · อยู่ในวงเงิน · ระบุสิ่งที่ไม่รวม · ยืนราคา
- [ ] ถ้ามี ML: เกณฑ์ความแม่นยำ, วิธีวัด, การติดตามหลังใช้งาน, การถอยกลับรุ่นเดิม, shadow mode

## 2. ข้อมูลส่วนบุคคล (ห้ามในเอกสารที่ส่งออกนอกบริษัท)

| ห้ามแบบเต็ม | ทำแทน |
|---|---|
| เบอร์มือถือของใครก็ตาม (รวมพนักงานลูกค้าใน TOR) | ตัดทิ้ง ใช้อีเมลบริษัท/เบอร์สำนักงาน · ถ้าจำเป็นจริง `081-XXX-4567` |
| เลขบัตรประชาชน | ตัดทิ้ง / `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี / เลขบัตรของลูกค้าปลายทาง | ตัดทิ้ง / `XXX-X-X6789-X` |
| ชื่อ-นามสกุลลูกค้าปลายทาง | รหัสเคส เช่น `CASE-2026-0815` |

- ชื่อ + ตำแหน่งของพนักงานลูกค้าองค์กร (ผู้ประสานงาน) ใส่ได้
- ถ้าไม่จำเป็นต้องอ้างถึง ตัดทิ้งดีกว่าปิดบัง
- เบอร์มือถือที่ได้จาก TOR/ประชุม → เก็บใน CRM ภายในเท่านั้น
- สงสัย ถาม `plat-may` (#ask-pdpa) · ถ้าส่งผิด แจ้งภายใน 1 ชั่วโมง

## 3. ตรวจสุดท้ายก่อนส่ง

- [ ] ฉบับลูกค้าไม่มีคำว่า ต้นทุน / cost / margin / buffer
- [ ] ตัวเลขราคาในบทสรุป = ตารางราคา · VAT = ×0.07 ปัด 2 ตำแหน่ง
- [ ] ทุกข้อในตารางเทียบ TOR มีคำตอบ
- [ ] ไม่มีคำโอ้อวด, ไม่มีอีโมจิ, ชื่อ "โนวาเทค" สะกดถูก
- [ ] ตัวเลขผลงานตรวจสอบได้ · อ้างชื่อลูกค้าเก่าเมื่อได้รับอนุญาต
