# สรุปกฎกำไรและการลดราคา v2026.1 (มีผล 2026-01-01)

> สรุปจาก `company-kit/margin-rules.md` (ผู้ดูแล: fin-joy) · ถ้าต้นฉบับมีเวอร์ชันใหม่กว่า ให้ยึดต้นฉบับ

## แหล่งราคา
- ราคาขาย/ต้นทุนทุกบรรทัดจาก `price-list.csv` เท่านั้น (`unit_price_thb`, `cost_thb`) ราคาทั้งหมด **ไม่รวม VAT**
- ของนอกตาราง: ต้นทุนจริงจากใบเสนอราคาผู้ขาย + บวกอย่างน้อย 20% + เขียนหมายเหตุ

## สูตร
```
ราคาขายรวม (ไม่รวม VAT) = Σ(จำนวน × unit_price_thb) − ส่วนลด
ต้นทุนรวม              = Σ(จำนวน × cost_thb)
กำไรขั้นต้น            = ราคาขายรวม − ต้นทุนรวม
Gross margin %         = กำไรขั้นต้น / ราคาขายรวม × 100   (หลังหักส่วนลดเสมอ)
```
- งาน fixed-price: บวก **risk buffer 10%** ใน man-day ทุกบทบาท (รวมในจำนวน ไม่แยกบรรทัด)

## เกณฑ์ margin
| Gross margin | ผล | ผู้อนุมัติ |
|---|---|---|
| ≥ 25% | ผ่าน | หัวหน้าทีมขาย `sales-nida` |
| 15% – < 25% | ต้อง MD พร้อมเหตุผลเชิงกลยุทธ์ | `md-somchai` |
| < 15% | **reject** ไม่ส่งลูกค้า ห้ามขอยกเว้น | — |

เป้า margin เฉลี่ยบริษัทปี 2026 = 30%

## ส่วนลด (% ของราคาตาม price-list)
| ส่วนลด | ใครให้ได้ |
|---|---|
| ≤ 5% | เซลส์เจ้าของดีล |
| > 5% – 10% | หัวหน้าทีมขาย |
| > 10% | MD เท่านั้น และ margin หลังลดต้อง ≥ 15% |
- ห้ามลด MA และ cloud hosting
- ส่วนลดเป็นบรรทัดแยก "ส่วนลดพิเศษ" ห้ามแอบลดในราคาต่อหน่วย

## VAT / การแสดงผล
- แสดง 3 บรรทัดเสมอ: `รวมก่อน VAT` → `VAT 7%` → `รวมทั้งสิ้น` · VAT = ก่อน VAT × 0.07 ปัด 2 ตำแหน่ง
- **ห้ามแสดงต้นทุนและ margin ในเอกสารที่ส่งลูกค้า**
