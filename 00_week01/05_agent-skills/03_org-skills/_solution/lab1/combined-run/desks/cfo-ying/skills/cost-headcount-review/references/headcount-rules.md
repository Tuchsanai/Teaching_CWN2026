# วิธีตัดสิน "ควรรับคนเพิ่มไหม"

> สรุปจากวิธีคิดของ cfo-ying + ข้อมูลตำแหน่งใน `company-kit/jd-template.md` (ผู้ดูแล `hr-fah`)

## ตัดสินทีละตำแหน่ง ด้วย 4 คำถาม

1. **ผูกกับรายได้ไหม** — ตำแหน่งนี้รองรับโปรเจกต์/ดีลไหน มูลค่าเท่าไหร่ กี่เดือน
2. **ดีลเซ็นแล้วหรือยัง** — ถ้ายังอยู่ใน pipeline ให้ดู win rate ล่าสุด · ดีลยังไม่เซ็น → สรรหาได้ แต่ **ออก offer เมื่อเซ็น**
3. **คุ้มไหม** — กำไรขั้นต้นต่อเดือนของดีล (รายได้/เดือน × margin) ต้องมากกว่าเงินเดือนสูงสุดของคนที่รับ · ที่ margin m% ต้องมีรายได้เพิ่ม 100/m บาทต่อค่าคน 1 บาท
4. **ทันไหม** — วันเริ่มงานที่ต้องการ vs เวลาสรรหา (ขั้นตอนสมัครของบริษัท 3 รอบ ไม่เกิน 3 สัปดาห์) + ระยะแจ้งออกจากที่เก่า

## ผลลัพธ์ที่ใช้

| ผล | เมื่อไร |
|---|---|
| รับเลย | ดีลเซ็นแล้ว + คุ้ม + ทีมตึง (on-time ลด / งานเกินแผน) |
| สรรหาได้ ออก offer เมื่อดีลเซ็น | ผูกกับดีลใหญ่ที่ยังไม่เซ็น แต่เวลาสรรหาไม่พอถ้ารอ |
| ชะลอ | ยังไม่ผูกกับรายได้ หรือไม่มีข้อมูลเงินเดือน |
| ไม่รับ | margin ต่ำกว่า 25% ต่อเนื่อง และไม่มีรายได้ใหม่รองรับ |

สัญญาณเสริม: กำไรขั้นต้นต่อหัวลดลงหลังรับคน = คนใหม่ยังไม่สร้างรายได้ · on-time % ลด = ทีมตึง
