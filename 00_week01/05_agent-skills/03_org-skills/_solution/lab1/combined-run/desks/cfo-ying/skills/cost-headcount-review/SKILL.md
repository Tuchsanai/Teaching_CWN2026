# cost-headcount-review

สรุปตัวเลขเดือนที่แล้ว 1 หน้าให้ MD ตอบ 3 คำถาม: **กำไรเท่าไหร่ · เงินพอไหม · ควรรับคนเพิ่มไหม**
ความรู้บริษัทที่ต้องใช้สรุปไว้ใน `references/` แล้ว ไม่ต้องเปิด company-kit ก็ทำได้

## Input

- ไฟล์ KPI รายเดือน (CSV: `metric,unit,<YYYY-MM>...,target_monthly,note`) — ที่โนวาเทคคือ `company-kit/monthly-kpi.csv` · ถ้าไม่มี ให้ขอผู้ใช้
- (ถ้ามี) ตำแหน่งว่างที่ขออนุมัติพร้อมช่วงเงินเดือน — ที่โนวาเทคอยู่ใน `company-kit/jd-template.md`
- (ถ้ามี) ยอดเงินสด ลูกหนี้ รายจ่ายเงินเดือน จากบัญชี

## ขั้นตอน

1. **คำนวณ** — รัน `python scripts/kpi_calc.py <kpi.csv> [เดือนนี้] [เดือนก่อน]` ได้ตาราง markdown: กำไรขั้นต้น, ต้นทุนขาย, ต่อหัว, on-time % (สูตรอยู่ใน `references/kpi-and-margin.md`) · ถ้ารันไม่ได้ ให้คิดมือด้วยสูตรเดียวกัน
2. **อ่าน note ทุกแถว** ของ CSV — มักบอกว่ารายได้ไหนยังไม่เป็นเงินสด (เช่น วางบิลเดือนถัดไป) หรือสาเหตุ margin ตก
3. **กำไร** — เทียบ margin กับเกณฑ์ใน `references/kpi-and-margin.md` (เป้า 30%, เส้น 25% / 15%) และคิดว่า margin ที่ขาดเป้าเท่ากับเงินกี่บาท
4. **เงินพอไหม** — แยก "รายได้ตามบัญชี" กับ "เงินที่เข้าแล้ว" · ถ้าไม่มียอดเงินสด/ลูกหนี้ ให้ตอบระดับสัญญาณและระบุว่าต้องขอข้อมูลอะไร ห้ามเดา
5. **ควรรับคนเพิ่มไหม** — ตัดสิน **ทีละตำแหน่ง** ตาม `references/headcount-rules.md`: ผูกกับรายได้ไหม ดีลเซ็นแล้วหรือยัง กำไรขั้นต้นของดีลคุ้มเงินเดือนไหม
6. **เขียนรายงาน** ตาม `references/output-format.md` เก็บที่ `work/<YYYY-MM>-cost-headcount-review.md` และเก็บผลคำนวณที่ `work/<YYYY-MM>-kpi-calc.md`

## กติกา

- ตัวเลขทุกตัวต้องมาจากไฟล์หรือคำนวณจากไฟล์ — บอกสูตรเมื่อเป็นตัวเลขที่คิดเอง
- เอกสารนี้ **ภายในเท่านั้น** (มีต้นทุน/margin) ห้ามส่งลูกค้า
- คำตอบสั้นอยู่บนสุด MD ต้องอ่านจบใน 30 วินาที แล้วจบด้วย "สิ่งที่ขอให้ MD ตัดสิน" และ "ข้อมูลที่ยังขาด"
- ถ้าตัดสินให้รับคน ส่งต่อ HR ทำประกาศด้วย `jd-writer` · ถ้าต้องขึ้นสไลด์ประชุม ส่งต่อ `exec-deck`
