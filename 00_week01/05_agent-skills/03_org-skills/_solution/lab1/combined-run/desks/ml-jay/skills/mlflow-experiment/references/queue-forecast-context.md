## ความเสี่ยงที่ทีมรู้
- under-forecast −20 ถึง −30% ช่วง 11:00–13:00 สาขาย่านออฟฟิศ (จัดคนไม่พอ)
- สาขาเปิดใหม่ < 8 สัปดาห์ไม่มี lag → fallback ค่าเฉลี่ยสาขาขนาดเดียวกัน
- ข้อเสนอของ DS (ยังไม่ตัดสิน → เรื่องของ `model-release`): ปล่อย r03 แทน v1 ที่เกษตรไทย, shadow mode 1–2 สัปดาห์, rollback ถ้า MAPE รายสัปดาห์ > 22% สองสัปดาห์ติด หรือ under-forecast เที่ยง > 30%
