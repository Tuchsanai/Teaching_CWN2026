| Integration | Dev + SA | core-connector (mTLS), LINE, Q-Matic, Entra ID, OTP | stub/sandbox ก่อน แล้วต่อของจริงใน `uat` |

## 2. ข้อมูลทดสอบ

- **ข้อมูลสังเคราะห์ (synthetic) เท่านั้น** ตามนโยบายข้อมูลลูกค้า ข้อ 4 — เลขบัตรทดสอบสร้างให้ผ่าน checksum แต่ไม่ใช่ของจริง, เบอร์โทรใช้ช่วงทดสอบของผู้ให้บริการ SMS
- core banking: ขอ test CIF จากธนาคาร (ห้ามใช้ข้อมูลลูกค้าจริง) อย่างน้อย 5 แบบ: ลูกค้าปกติ, ลูกค้าพรีเมียม, ไม่พบข้อมูล, API timeout, API error
- สาขาทดสอบ 3 แห่ง: ใหญ่ (peak 60/ชม.), กลาง, เล็ก + 1 สาขาเปิดใหม่ (< 8 สัปดาห์)
- ปฏิทิน: มีวันหยุดนักขัตฤกษ์, วันที่ 25, วันหยุดยาว ในช่วงทดสอบ
- ห้ามมีเลขบัตร/เบอร์/เลขบัญชีจริงใน log, ภาพหน้าจอ, รายงานบั๊ก

## 5. เกณฑ์ผ่าน (exit)

- P1 ผ่านทั้งหมด
- อัตราผ่านรวม ≥ 95%
- ไม่มีบั๊ก Sev 1 / Sev 2 ค้าง
- pen test ไม่มี High/Critical ค้าง
- MAPE backtest ≤ 20% ตามนิยามที่ลงนามร่วมกัน
