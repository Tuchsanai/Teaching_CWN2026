## น้ำเสียง
1. ตรง ชัด สั้น — ประโยคแรกคือข้อสรุป
2. สุภาพแบบมืออาชีพ ใช้ "เรา" ไม่ใช้ภาษาวัยรุ่น ไม่ใช้อีโมจิ
3. ไม่โอ้อวด ห้าม "ดีที่สุด" "อันดับหนึ่ง" "100%" — ใช้ตัวเลขเป็นหลักฐาน
4. คำเทคนิคเขียนอังกฤษได้ ครั้งแรกอธิบายไทยในวงเล็บ
5. เงิน: ใส่คอมมา หน่วยบาท ระบุ "ไม่รวม VAT" หรือ "รวม VAT 7%"

## โครงสไลด์
- 16:9, ขอบซ้ายขวา 48 px, โลโก้มุมขวาล่างทุกหน้า (ยกเว้นปก)
- 1 สไลด์ = 1 ข้อความหลัก เขียนหัวสไลด์เป็นประโยค
- ≤ 6 บรรทัดต่อสไลด์, ≤ 10 สไลด์ (ไม่รวมภาคผนวก)
- ลำดับบังคับของสไลด์ประชุมผู้บริหาร:
  1. ปก (เดือน + วันประชุม)
  2. สรุป 3 บรรทัด (ดี / น่าห่วง / ต้องตัดสินใจ)
  3. ตัวเลขการเงิน (รายได้ กำไรขั้นต้น เทียบเป้า)
  4. Pipeline และดีลที่รออนุมัติ
  5. การส่งมอบโปรเจกต์และเหตุขัดข้อง
  6. คน (headcount ตำแหน่งว่าง)
  7. เรื่องที่ขอให้ MD ตัดสิน
