# เช็กข้อมูลลูกค้า (ข้อ 7)

> สรุปเฉพาะส่วนที่ใช้ตอนอนุมัติดีล จาก `company-kit/customer-data-policy.md` v1.4 (ผู้ดูแล `plat-may`) · รายละเอียดเต็มดู skill `customer-data-policy`

## ห้ามมีแบบเต็มในเอกสารที่ส่งออกนอกบริษัท (proposal, ใบเสนอราคา, อีเมล, สไลด์)
1. เลขบัตรประชาชนของใครก็ตาม
2. เบอร์มือถือส่วนตัว ทั้งของลูกค้าปลายทางและพนักงานลูกค้าองค์กร (ใช้เบอร์สำนักงานหรืออีเมลบริษัทแทน)
3. เลขบัญชีหรือเลขบัตรของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง (ใช้รหัสเคสแทน)

ถ้าไม่จำเป็นต้องอ้างถึง ให้ตัดทิ้ง ถ้าจำเป็นให้ปิดบัง เช่น `081-XXX-4567`, `1-XXXX-XXXXX-XX-3`

## ข้อมูลอ่อนไหว (PDPA ม.26)
สุขภาพ ศาสนา ประวัติอาชญากรรม ข้อมูลชีวภาพ → ห้ามเก็บถ้าไม่จำเป็นจริง
ดีลที่ระบบต้องเก็บข้อมูลแบบนี้ (เช่น โรงพยาบาล) ควรมี DPA, data residency ในไทย และ breach notification ในสัญญา (ดุลยพินิจ MD ถ้าไม่ใช่ลูกค้าธนาคาร)

## ของภายในที่ห้ามหลุดไปเอกสารลูกค้า
ต้นทุน, margin, ผลพิจารณาของ MD

ไม่แน่ใจหรือสงสัยว่าข้อมูลรั่ว → แจ้ง `plat-may` (`#ask-pdpa`) ภายใน 1 ชั่วโมง
