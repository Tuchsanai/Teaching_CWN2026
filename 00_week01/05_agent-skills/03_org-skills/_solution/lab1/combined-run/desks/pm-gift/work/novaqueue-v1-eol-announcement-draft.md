## 1. สรุป

เราจะเลิกให้บริการ **NovaQueue v1 หลังวันที่ 30 กันยายน 2570** (วันให้บริการวันสุดท้าย) และขอเสนอให้ท่านย้ายไป **NovaQueue v2** โดย **ไม่มีค่าย้ายระบบ** หากลงนามสัญญาภายในวันที่ 1 มีนาคม 2570

## 2. เหตุผล

NovaQueue v1 ติดตั้งบน server ของท่าน (on-prem) และทำงานบนซอฟต์แวร์พื้นฐาน (Java 8) ที่ผู้ผลิตหยุดออกแพตช์ความปลอดภัยแล้ว เราจึงไม่สามารถดูแลความปลอดภัยของระบบได้ในระยะยาว ฟีเจอร์ใหม่ทั้งหมดพัฒนาบน NovaQueue v2 ซึ่งให้บริการแบบ cloud SaaS (บริการผ่านอินเทอร์เน็ต) บน data center ในประเทศไทย ตั้งแต่ มิถุนายน 2568

## 4. ข้อเสนอสำหรับลูกค้า NovaQueue v1

1. **ไม่มีค่าย้ายระบบ** หากลงนามสัญญา NovaQueue v2 ภายใน 1 มีนาคม 2570
2. **ส่วนลด 20% สำหรับค่าบริการ NovaQueue v2 ปีแรก**
3. ย้ายข้อมูลได้ครบ ยกเว้นรายงานที่ท่านปรับแต่งเอง ซึ่งต้องสร้างใหม่บน v2 โดยทีมของเรายินดีช่วยออกแบบ

ราคาและเงื่อนไขอยู่ในใบเสนอราคาที่แนบ (ราคาไม่รวม VAT)

## 5. ข้อมูลของท่าน

- ข้อมูลในระบบเป็นของท่าน ท่านส่งออกได้ตั้งแต่ 1 เมษายน 2570 จนถึงวันปิดระบบ
- หากท่านไม่ย้ายไป v2 โปรดส่งออกข้อมูลที่ต้องการเก็บไว้ก่อน 30 กันยายน 2570 หลังวันดังกล่าวจะกู้คืนไม่ได้
- ไฟล์ส่งออกจะส่งผ่านช่องทางที่เข้ารหัสเท่านั้น

## 6. ขั้นตอนถัดไป
