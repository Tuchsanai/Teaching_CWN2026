# ข้อมูลที่ห้ามอยู่ในใบแจ้งหนี้ (สรุปจาก invoicing-rules ข้อ 5 + company-kit/customer-data-policy.md v1.4)

> ผู้ดูแลนโยบาย: เมย์ อรุณรัตน์ (`plat-may`) ทีมกลาง · skill เต็ม: `customer-data-policy`

## ลูกค้า 2 ระดับ
- **ลูกค้าองค์กร** = บริษัท/ธนาคารที่จ้างเรา + พนักงานของเขาที่ติดต่อกับเรา → ใส่ได้: ชื่อ ตำแหน่ง อีเมลบริษัท
- **ลูกค้าปลายทาง** = ประชาชนที่ใช้ระบบที่เราสร้าง (เช่น ลูกค้าของธนาคาร) → ห้ามมีข้อมูลใด ๆ ในใบแจ้งหนี้

## ห้ามมี
1. เบอร์มือถือส่วนตัวของใครก็ตาม (รวมพนักงานลูกค้าองค์กร — ใช้อีเมลบริษัทแทน)
2. ชื่อ-นามสกุล หรือข้อมูลของลูกค้าปลายทาง
3. เลขบัตรประชาชน
4. เลขบัญชี / เลขบัตรเครดิต-เดบิต / เลขสัญญาสินเชื่อ / CIF ของบุคคล
5. รายละเอียดเคสภายในของลูกค้า — ถ้าจำเป็นต้องอ้างอิงใช้รหัสเคส/ticket (เช่น `CASE-2026-0815`)

ใช้ได้: บัญชีรับเงินของ **บริษัทโนวาเทค** (เป็นบัญชีนิติบุคคล), เลขผู้เสียภาษีของนิติบุคคล, เลขสัญญา/PO ระหว่างบริษัท

## วิธีจัดการ
- ในใบแจ้งหนี้ (เอกสารภายนอก): **ตัดทิ้ง** ดีกว่าปิดบัง
- เวลาอ้างถึงในรายงานผลตรวจ ให้ปิดบัง เช่น เบอร์ `081-XXX-4567`, เลขบัตร `1-XXXX-XXXXX-XX-3`, เลขบัญชี `XXX-X-X6789-X`, อีเมลส่วนตัว `s*****@gmail.com`
- ร่างที่มีข้อมูลต้องห้ามแต่ยังไม่ส่งออก → แก้แล้วบันทึกในผลตรวจ
- ถ้าส่งออกไปแล้ว (ส่งเมล/แชร์ไฟล์) → แจ้ง plat-may **ภายใน 1 ชั่วโมง** (#ask-pdpa หรือ dpo@novatech.example) ห้ามแก้เงียบ ๆ
