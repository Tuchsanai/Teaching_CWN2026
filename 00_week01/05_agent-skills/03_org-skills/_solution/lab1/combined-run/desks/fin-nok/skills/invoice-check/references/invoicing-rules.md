> ผู้ดูแลต้นฉบับ: จอย พัฒนสิน (`fin-joy`) · ถ้าต้นฉบับออกเวอร์ชันใหม่ ให้อัปเดตไฟล์นี้และ version ของ skill

## งวดชำระมาตรฐาน

| งวด | เกิดเมื่อ | สัดส่วน | เอกสารแนบ |
|---|---|---|---|
| 1 | ลงนามสัญญา | 30% | สำเนาสัญญาหน้าที่มีลายเซ็น |
| 2 | ผ่าน UAT | 40% | ใบตรวจรับ UAT ที่ลูกค้าลงนาม |
| 3 | go-live | 30% | ใบตรวจรับงานขึ้นระบบจริง |
| MA / hosting / license | ล่วงหน้ารายปี | 100% ของปี | — |

- สัญญาลูกค้ากำหนดต่าง → ยึดสัญญา และต้องมีเลขข้อสัญญาในหมายเหตุ
- ออกใบแจ้งหนี้ได้ **หลัง** ได้เอกสารแนบครบเท่านั้น

## สูตร
```
ยอดงวด (ก่อน VAT) = มูลค่าสัญญาก่อน VAT × สัดส่วนงวด
VAT 7%            = ยอดงวด × 0.07   (ปัดเศษ 2 ตำแหน่ง)
รวมทั้งสิ้น        = ยอดงวด + VAT
```
- จำนวนเงินตัวอักษรต้องตรง "รวมทั้งสิ้น"
- ผลรวมทุกงวด = มูลค่าสัญญาพอดี (งวดสุดท้ายรับเศษ)
- ภาษีหัก ณ ที่จ่าย 3% ลูกค้าหักเอง → ไม่หักในใบ แต่ต้องมีหมายเหตุ

## เลขที่ / วันที่
- `INV-<ปี ค.ศ.>-<ลำดับ 4 หลัก>` เรียงไม่ข้าม
- วันครบกำหนด = วันที่ออก + เครดิตเทอมในสัญญา (ค่าเริ่มต้น 30 วัน)

## ช่องที่ต้องมีครบ 8 ช่อง
1. ผู้ขาย (ต้องตรงทุกตัวอักษร): **บริษัท โนวาเทค จำกัด (สำนักงานใหญ่) เลขประจำตัวผู้เสียภาษี 0105561012345 · 88 อาคารโนวาทาวเวอร์ ชั้น 12 ถ.พระราม 9 แขวงห้วยขวาง เขตห้วยขวาง กรุงเทพฯ 10310**
2. ผู้ซื้อ: ชื่อนิติบุคคลเต็ม, สาขา/สำนักงานใหญ่, เลขผู้เสียภาษี, ที่อยู่ตาม ภพ.20
3. เลขที่สัญญา / PO ของลูกค้า
4. ผู้ติดต่อฝั่งลูกค้า: ชื่อ + ตำแหน่ง + อีเมลบริษัทเท่านั้น (ห้ามเบอร์มือถือ)
5. รายการ: ชื่อโครงการ, งวดที่, เงื่อนไขงวด, สัดส่วน
6. ยอดก่อน VAT / VAT 7% / รวมทั้งสิ้น / จำนวนเงินตัวอักษร
7. บัญชีรับเงินบริษัท (แสดงได้): **ธนาคารสยามรุ่งเรือง สาขาพระราม 9 ชื่อบัญชี บริษัท โนวาเทค จำกัด เลขที่ 714-2-08835-1**
8. ผู้จัดทำ + ผู้ตรวจ (ผู้อนุมัติ: หัวหน้าบัญชี fin-joy)
