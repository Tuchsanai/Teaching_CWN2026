## ผลิตภัณฑ์

ระบบจองคิวและนัดหมายสาขา ขายแบบค่าบริการรายปี ทีม Product ดูแลตั้งแต่เปิดตัวจนเลิกให้บริการ

| เวอร์ชัน | รูปแบบ | สถานะ | ผลต่อ PRD |
|---|---|---|---|
| v1 | on-prem (Java 8 หมดแพตช์) | 🟡 ดูแลอย่างเดียว | **ห้ามเพิ่มฟีเจอร์** — ลูกค้า v1 ที่อยากได้ต้องย้ายไป v2 (ประสานเจ้าของ skill `product-sunset`) |
| v2 | cloud SaaS ภูมิภาคไทย | 🟢 ขายและพัฒนาต่อ | ฟีเจอร์ใหม่ทั้งหมดทำที่นี่ |
