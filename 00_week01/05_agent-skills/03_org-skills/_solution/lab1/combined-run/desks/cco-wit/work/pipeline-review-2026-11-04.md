## 3. รายดีล

### 🟢 DS-2026-031 ไทยโลจิสติกส์ครบวงจร · Fleet Tracking → เร่ง
- **ทำไมเร่ง:** GM 31.0% (เกินเป้า 30%), ส่วนลด 8.3% ไม่เกิน 10% (หัวหน้าทีมขายอนุมัติแล้ว), ลูกค้าเดิมทำ MA 2 ปี, มี buffer 10%, UAT 3 สัปดาห์, ค่าปรับมีเพดาน 5%, จ่าย 30/40/30 เครดิต 30 วัน, ไม่มีข้อมูลส่วนบุคคลคนขับ
- **ความเสี่ยงที่เหลือ:** API GPS box จำกัด 10 req/s (มีทางแก้ใน spec แล้ว) · ทีมชุดเดิมต้องว่างจริง ม.ค.–พ.ค. 2027
- **ทำต่อ:** ปิดเรื่องอนุมัติให้ทันส่งใบเสนอราคา 5 พ.ย. (ลูกค้าเข้าบอร์ด 12 พ.ย.) · `sales-krit` ส่ง + follow-up หลังบอร์ด

### 🟢 deal-001 ธนาคารนครหลวงพัฒนา · จองคิวสาขา + พยากรณ์คิว → เร่ง + ส่งต่อ
- **ทำไมเร่ง:** ตรงกับผลิตภัณฑ์ของเราเอง (NovaQueue v2 = จองคิว/นัดหมายสาขาบน cloud ในไทย) · 120 สาขา ต่อยอดฐาน v2 (ตอนนี้ 486 สาขา) · ลูกค้าธนาคาร 2 รายของ NovaQueue เคยบอกว่าถ้ามีเตือนผ่าน LINE จะเพิ่มอีก 60 สาขา (feedback F-11)
- **ช่องว่างระหว่าง TOR กับของที่มี:**
  - TOR ต้องการจอง/แจ้งเตือนผ่าน **LINE OA (LIFF)** → NovaQueue v2 ยังไม่มี (เป็น feedback อันดับต้น F-01/F-03/F-06)
  - ต้องมี **ML พยากรณ์คิว 7 วัน MAPE ≤ 20%** + ติดตามความแม่นยำ + rollback → ต้องใช้ทีม ML แต่ตำแหน่ง ML Engineer ยังว่าง
  - **Audit log 2 ปี** (TOR) ขณะที่ feedback เดิมจากฝ่ายไอทีธนาคารนี้ขอ 1 ปีเก็บในไทย → ต้องยืนยันว่า v2 รองรับ 2 ปี
  - mTLS กับ Core banking, SSO Entra ID, เชื่อมตู้ Q-Matic, pen test โดยผู้ทดสอบที่ธนาคารกำหนด, SLA 99.5% / Sev1 30 นาที
  - วงเงิน 4.8 ลบ. **รวม** ค่าพัฒนา + hosting ปีแรก + MA ปีแรก → ต้องคิดราคาให้ GM ≥ 25% ภายใต้เพดานนี้
- **ส่งต่อ (ภายใน 6 พ.ย.):**
  - `sa-ton` → TOR เป็น spec + แยกส่วนที่ใช้ NovaQueue v2 ได้ vs ต้องทำเพิ่ม (`req-to-spec`)
  - `pm-beam` → ตัดสินว่า "เตือนผ่าน LINE" จะเข้า roadmap v2 ก่อน ม.ค. 2027 ได้ไหม (ถ้าได้ = ทั้งชนะดีลนี้และตอบ feedback ลูกค้าเดิม)
  - ทีม ML (สายเทคโนโลยี ผ่าน `cto-nat`) → ประเมินความเป็นไปได้ MAPE ≤ 20% และคนที่จะทำ
  - `fin-joy` → คิดราคา + GM (`pricing-calc`) แล้วเข้า MD (`deal-approval`) ก่อน 11 พ.ย.
  - `sales-nida` → เตรียมผลงานสถาบันการเงิน 2 โครงการตามข้อ 7 ของ TOR
- **เงื่อนไขไปต่อ:** ถ้าคิดราคาแล้ว GM < 25% หรือหาคน Senior Full-stack/ML ไม่ทัน ม.ค. 2027 → กลับมาคุยกันก่อนยื่น

### 🟡 deal-002 ธนาคารเอเชียไทยสากล · Card Dispute Portal → ประคอง
- **ทำไมยังไม่เร่ง:** วงเงิน 2.2 ลบ. รวม hosting + MA สำหรับงานสร้างใหม่ 4 เดือน (ก.พ.–พ.ค. 2027) ที่ต้อง **PCI DSS** (token จาก CardLink, ห้ามเก็บเลขบัตรเต็ม), เชื่อม CardLink, SSO AD, pen test → margin น่าจะบาง · ไม่เกี่ยวกับผลิตภัณฑ์ของเรา · ช่วงเวลาชนกับ deal-001 (ม.ค.–มิ.ย.) และ DS-031 (ม.ค.–พ.ค.)
- **ทำไมยังไม่ปล่อย:** ลูกค้าธนาคารรายใหม่ ได้ผลงานด้านบัตรเครดิต และกำหนดยื่นยังมีเวลา (20 พ.ย.)
- **ทำต่อ:** `sa-ton` / `sa-ice` ประมาณ man-day แบบเร็ว + `fin-joy` เช็ก GM ที่ราคา 2.2 ลบ. → **ตัดสิน bid / no-bid ภายใน 11 พ.ย.** ถ้า GM < 25% หรือต้องดึงทีมเดียวกับ deal-001 → no-bid

### 🔴 DS-2026-034 โรงพยาบาลเมืองใหม่ · พอร์ทัลผู้ป่วย → ตีกลับ
- **ทำไมตีกลับ (ร่างนี้ไม่ผ่าน):**
  1. GM **18.0%** (ต่ำกว่า 25% ต้อง MD) และส่วนลด **28.2%** ของค่าพัฒนา (เกิน 10% ต้อง MD) — ขณะที่ GM บริษัทต่ำกว่าเป้าอยู่แล้ว
  2. ตัด QA 35 → 23 man-day "เพื่อให้ราคาลง" กับระบบที่มีข้อมูลสุขภาพ
  3. Timeline 3 เดือน ขณะที่งานลักษณะนี้ใช้ 5–6 เดือน · ไม่มี buffer 10% · UAT เหลือ 1.5 สัปดาห์
  4. เชื่อม HIS แต่ผู้ผลิตยังไม่ส่งเอกสาร API (ความเสี่ยงสูงสุด)
  5. ค่าปรับ 0.2%/วัน **ไม่มีเพดาน**
  6. งวดจ่าย 10/30/**60% หลัง go-live 90 วัน** + เครดิต 90 วัน → เงินก้อนใหญ่เข้าหลังเริ่มงานราว 8 เดือน
  7. ข้อมูลสุขภาพ (ข้อมูลอ่อนไหว PDPA ม.26) แต่ **ยังไม่มี DPA** ในร่าง
  8. Tech lead (ปอนด์) จะถือ 3 โปรเจกต์ ม.ค.–ก.พ. 2027 รวมโปรเจกต์จองคิวธนาคาร (deal-001) ถ้าได้
- **ไม่ได้ทิ้งลูกค้า — ให้เซลส์กลับไปทำร่างใหม่ที่:**
  - **ใช้ NovaQueue v2 ทำส่วนนัดหมาย** แทนเขียนใหม่ — โรงพยาบาลนี้เป็นลูกค้า NovaQueue v1 อยู่แล้ว (6 สาขา, MA หมด **31 ธ.ค. 2026**, สนใจ v2) → ตัดขอบเขต ลดเวลา และใช้ข้อเสนอย้าย v1→v2 มาตรฐาน (ย้ายฟรีถ้าเซ็นภายใน 90 วันหลังประกาศ, ลดค่าบริการปีแรก 20%)
  - แบ่งเฟส: เฟส 1 นัดหมาย + LINE OA ทันเปิดอาคาร 1 มี.ค. · เฟส 2 ผลแล็บ/ใบเสร็จหลังได้ API ของ HIS
  - คืน QA และ buffer · ค่าปรับมีเพดาน (≤ 5%) · งวดจ่ายใกล้ 30/40/30 · DPA อยู่ในสัญญา
  - เป้า GM ≥ 25% / ส่วนลด ≤ 10% → ถ้าทำไม่ได้จริงค่อยเข้า MD พร้อมเหตุผลเชิงกลยุทธ์ (โอกาส 3 รพ. ในเครือ) เป็นตัวเลข
- **ตอบเซลส์วันนี้ (4 พ.ย.):** ไม่ส่งร่างนี้เข้า MD · นัด `sales-nida` + `pm-beam` + `sa-ton` คุยร่างใหม่ภายในสัปดาห์นี้
