## 2. ผลิตภัณฑ์ NovaQueue (เจ้าของ `pm-beam`)

- ระบบ **จองคิวและนัดหมายสาขา** ของโนวาเทคเอง ขายเป็นค่าบริการรายปี
- **v1** on-prem (Java 8 หมดแพตช์) — ดูแลอย่างเดียว ไม่เพิ่มฟีเจอร์ · 5 ลูกค้า, 212 สาขา · MA รวม ~905,000 บาท/ปี
- **v2** cloud SaaS ในไทย — ขายและพัฒนาต่อ ฟีเจอร์ใหม่ทำบน v2 เท่านั้น · 14 ลูกค้า, 486 สาขา
- feedback อันดับต้น (Q3/2026): เตือนก่อนถึงคิว / เตือนผ่าน LINE แทน SMS / เห็นคิวปัจจุบัน · ลูกค้าธนาคาร 2 รายจะเพิ่ม 60 สาขาถ้ามีเตือนผ่าน LINE · ธนาคารขอ audit log เก็บในไทย
- **ห้ามรับปาก "VIP ข้ามคิว"** ให้ลูกค้าธนาคาร — ขัดหลักความเป็นธรรมที่ลูกค้าธนาคารให้ไว้กับ ธปท. ต้องถาม MD
- เมื่อดีลรับจ้างใด "เป็นระบบจองคิว/นัดหมาย" → ถามเสมอว่าใช้ NovaQueue v2 แทนเขียนใหม่ได้ไหม และลูกค้ารายนั้นอยู่ในรายชื่อลูกค้า v1/v2 หรือไม่ (ดู `novaqueue-v1-customers.csv`: วันหมด MA, ใช้งานจริง 30 วัน, สนใจ v2)

## 3. นโยบายวงจรชีวิตผลิตภัณฑ์ (ส่วนที่กระทบการขาย)

- เลิกให้บริการเวอร์ชันใด ต้อง **MD อนุมัติ** ถ้า MA ที่หายรวม > 500,000 บาท หรือมีลูกค้าธนาคาร/สถาบันการเงิน
- ประกาศล่วงหน้า **≥ 180 วัน** · ห้ามปิดก่อนวันหมด MA ของลูกค้าที่ยังไม่ย้าย · **ห้ามบอกวันปิดกับลูกค้ารายใดก่อนอนุมัติ**
- ข้อเสนอย้าย v1 → v2 มาตรฐาน: ค่าย้ายฟรีถ้าเซ็นภายใน 90 วันหลังประกาศ · ค่าบริการ v2 ปีแรกลด 20% · รายงานที่ลูกค้าปรับเองต้องทำใหม่
