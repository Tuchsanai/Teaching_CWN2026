# สรุปนโยบายข้อมูลลูกค้า โนวาเทค v1.4

> สรุปจาก `company-kit/customer-data-policy.md` (ผู้ดูแล `plat-may`, ปรับปรุง 2026-03-10) · อ้าง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
> ถ้านโยบายต้นฉบับออกเวอร์ชันใหม่ ให้อัปเดตไฟล์นี้และ version ของ skill

## 1. ข้อมูลส่วนบุคคล (ระบุตัวบุคคลได้ ทางตรงหรือทางอ้อม)

- ชื่อ-นามสกุล, เลขบัตรประชาชน, เลขหนังสือเดินทาง
- เบอร์มือถือส่วนตัว, อีเมลส่วนตัว, ที่อยู่บ้าน
- เลขบัญชีธนาคาร, เลขบัตรเครดิต/เดบิต, เลขที่สัญญาสินเชื่อ, CIF
- ภาพใบหน้า, IP address, ตำแหน่ง GPS, ประวัติธุรกรรม
- **ข้อมูลอ่อนไหว** (มาตรา 26): ศาสนา สุขภาพ ประวัติอาชญากรรม ข้อมูลชีวภาพ — ห้ามเก็บถ้าไม่จำเป็นจริง

ลูกค้า 2 ระดับ
- **ลูกค้าองค์กร** = บริษัท/ธนาคารที่จ้างเรา + พนักงานของเขาที่ติดต่อกับเรา
- **ลูกค้าปลายทาง** = ประชาชนที่ใช้ระบบที่เราสร้าง (เช่น ลูกค้าของธนาคาร)

## 2. ห้ามเด็ดขาดในเอกสารที่ส่งออกนอกบริษัท (แบบเต็ม)

ใช้กับ proposal, ใบแจ้งหนี้, อีเมลถึงลูกค้า, สไลด์, รายงาน, ประกาศ, ไฟล์ที่แชร์คนนอก

| # | ข้อมูล | ของใคร |
|---|---|---|
| 1 | เลขบัตรประชาชน | ใครก็ตาม |
| 2 | เบอร์มือถือส่วนตัว | ลูกค้าปลายทาง **และ** พนักงานลูกค้าองค์กร (ใช้เบอร์สำนักงาน/อีเมลบริษัทแทน) |
| 3 | เลขบัญชี / เลขบัตร | ลูกค้าปลายทาง |
| 4 | ชื่อ-นามสกุล | ลูกค้าปลายทาง (ใช้รหัสเคส เช่น `CASE-2026-0815` แทน) |

เบอร์มือถือที่ได้จากที่ประชุมหรือ TOR → เก็บใน CRM ภายในเท่านั้น ไม่คัดลอกลงเอกสาร

## 3. วิธีปิดบัง (masking)

| ข้อมูล | ห้าม | ใช้ได้ |
|---|---|---|
| เบอร์มือถือ | 081-234-4567 | `081-XXX-4567` |
| เลขบัตรประชาชน | 1-1037-01234-56-3 | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | 123-4-56789-0 | `XXX-X-X6789-X` |
| เลขบัตรเครดิต | 4111 1111 1111 1234 | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | somying.jai@gmail.com | `s*****@gmail.com` |

- ไม่จำเป็นต้องอ้างถึง → **ตัดทิ้ง** ดีกว่าปิดบัง
- screenshot ที่มีข้อมูลข้างต้น ต้องเบลอก่อนแนบ

## 4. ข้อมูลทดสอบ / log

- ข้อมูลทดสอบต้องเป็น synthetic เท่านั้น ห้ามคัดลอกฐานข้อมูลจริงมาเครื่องตัวเอง
- log และรายงานบั๊กห้ามมีเลขบัตร/เบอร์/เลขบัญชีจริง — เจอใน log ให้แจ้ง DevOps ปิดบังที่ระดับ logger
- เข้าถึงข้อมูลจริงใน production ต้องขอผ่าน ticket + ผู้อนุมัติฝั่งลูกค้า

## 5. การเก็บรักษา

| ข้อมูล | นานเท่าไร | ที่ไหน |
|---|---|---|
| TOR, proposal, สัญญา | 5 ปีหลังจบสัญญา | ไดรฟ์ฝ่ายขาย (Sales + MD) |
| ข้อมูลติดต่อลูกค้าองค์กร | ช่วงมีความสัมพันธ์ + 2 ปี | CRM |
| สำเนาข้อมูลลูกค้าปลายทางระหว่างโครงการ | ลบภายใน 90 วันหลังส่งมอบ | — |
| ใบแจ้งหนี้, เอกสารบัญชี | 5 ปี | ระบบบัญชี |
