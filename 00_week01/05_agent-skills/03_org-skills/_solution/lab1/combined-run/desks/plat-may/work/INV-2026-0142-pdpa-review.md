## 4. นอกขอบเขต PDPA แต่พบระหว่างตรวจ (ส่งต่อ `fin-nok` / `invoice-check`)

- **VAT ผิด**: 740,000.00 × 7% = **51,800.00** แต่เอกสารเขียน 51,080.00
  - รวมทั้งสิ้นที่ถูกต้อง = **791,800.00** (เอกสารเขียน 791,080.00)
  - จำนวนเงินตัวอักษรต้องแก้เป็น "เจ็ดแสนเก้าหมื่นหนึ่งพันแปดร้อยบาทถ้วน"
- ส่วนที่ตรวจแล้วตรง: ยอดงวด 1,850,000 × 40% = 740,000.00 · งวด 30/40/30 รวมเท่ามูลค่าสัญญา · ครบกำหนด 3 ธ.ค. 2026 = ออก + 30 วัน
