# กติกาบริษัทที่ postmortem ต้องใช้ (สรุปจาก company-kit)

> สรุปไว้ให้ skill ใช้ได้โดยไม่ต้องเข้าถึง company-kit · ต้นทาง: `deploy-runbook.md` (ผู้ดูแล `ops-art`, ปรับปรุง 2026-10-01), `customer-data-policy.md` v1.4 (ผู้ดูแล `plat-may`), `incident-2026-09.md`, `monthly-kpi.csv` · ถ้าต้นทางเปลี่ยน ให้อัปเดตไฟล์นี้และขึ้น version ของ skill

## 1. ระดับเหตุและ SLA

- **Sev 1** = ฟังก์ชันหลักของลูกค้าใช้ไม่ได้ (เช่น ลูกค้าปลายทางจ่ายเงินไม่ได้) · SLA กับลูกค้า (ตัวอย่างช้อปดีมาร์ท): **ตอบรับภายใน 30 นาที**
- นับจำนวนเหตุ Sev 1 / Sev 2 รายเดือนใน KPI บริษัท (`incidents_sev1` เป้า = 0) — postmortem ต้องระบุ Sev ให้ชัด เพราะผู้บริหารนำไปนับ
- ใน postmortem ให้แยก "SLA ผ่านไหม" ออกจาก "ใครรู้ก่อน" — ผ่าน SLA แต่ลูกค้ารู้ก่อนเรา ยังถือเป็นจุดอ่อนด้านการตรวจจับ

## 2. กำหนดส่ง

- เหตุหลัง deploy: เขียน postmortem **ภายใน 3 วันทำการ** (runbook ข้อ 6.3)
- ถ้าลูกค้าขอรายงานพร้อมกำหนด ให้ใช้กำหนดที่เร็วกว่า และใส่ไว้ใน "คำถามที่ยังเปิด" ถ้ายังไม่ส่ง

## 3. Runbook ที่เกี่ยวข้อง (deploy-runbook)

- 0 — บทบาทตอนทำงาน: Deploy lead, Verifier, Comms → ใช้ชื่อบทบาทเหล่านี้ในเอกสาร (ไม่ใช้ชื่อคน)
- 1.7 — เช็ก TLS cert ทุกโดเมนที่เกี่ยวข้องเหลือ > 21 วัน (เพิ่มหลัง incident 2026-09)
- 4.2–4.3 — smoke test ต้องรวม flow จ่ายเงินด้วยบัตรทดสอบ และ webhook ภายนอกเข้าได้
- 5 — rollback ทันทีถ้า: smoke test ไม่ผ่านและแก้ไม่ได้ใน 15 นาที · error rate > 5% นาน 5 นาที · ข้อมูลเงินเพี้ยนแม้รายการเดียว · แจ้งลูกค้าภายใน 30 นาทีหลังถอย
- เมื่อ action item ทำให้ต้องเพิ่มขั้นใน runbook ให้ส่งต่อเจ้าของ runbook (`ops-art`, skill `deploy-checklist`)

## 4. ข้อมูลลูกค้า (customer-data-policy) — สำคัญเมื่อส่ง postmortem ให้ลูกค้า

ห้ามมีแบบเต็มในเอกสารที่ออกนอกบริษัท:
1. เลขบัตรประชาชน
2. เบอร์มือถือส่วนตัว (ทั้งลูกค้าปลายทางและพนักงานลูกค้า) — ใช้เบอร์สำนักงาน/on-call กลาง
3. เลขบัญชี / เลขบัตร ของลูกค้าปลายทาง
4. ชื่อ-นามสกุลลูกค้าปลายทาง — ใช้รหัสเคส/เลข order แทน

- ไม่จำเป็นต้องอ้าง → ตัดทิ้งดีกว่าปิดบัง · ถ้าต้องอ้าง ใช้รูปแบบ `081-XXX-4567`, `4111 XXXX XXXX 1234`
- screenshot ที่มีข้อมูลข้างต้นต้องเบลอ
- สงสัยข้อมูลรั่วระหว่างเหตุ → แจ้ง `plat-may` ภายใน 1 ชั่วโมง และใส่ใน timeline
