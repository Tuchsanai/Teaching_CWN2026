## ลำดับความสำคัญ action item

| ลำดับ | ความหมาย |
|---|---|
| P1 | ทำทันที — ถ้าไม่ทำ เหตุเดิมเกิดซ้ำได้ในเร็ว ๆ นี้ |
| P2 | ภายใน 1 เดือน — ลดเวลาตรวจจับ/แก้ไข |
| P3 | ภายในไตรมาส — แก้เชิงโครงสร้าง/กระบวนการข้ามทีม |

## ประเภท action item ที่ควรมีให้ครบ

- **ป้องกัน** (ไม่ให้ trigger เกิด) · **ตรวจจับ** (รู้ก่อนลูกค้า) · **บรรเทา** (ถ้าเกิด กระทบน้อยลง/แก้เร็วขึ้น) · **กระบวนการ** (runbook, offboarding, ทะเบียน)
