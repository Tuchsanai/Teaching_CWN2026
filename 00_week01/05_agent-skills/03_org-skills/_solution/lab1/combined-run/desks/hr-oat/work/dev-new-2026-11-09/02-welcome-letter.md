## สิ่งที่เตรียมไว้ให้คุณ

- **MacBook Pro 14"** + จอ 27" ที่โต๊ะ + บัตรเข้าอาคาร
- บัญชีอีเมลบริษัท, chat, Google Drive, HR system, **Gitea** (ทีม Dev)
- **Claude Code** พร้อมแพ็ก skill ของบริษัท `core` + `dev` (มี `coding-standard` และ `project-scaffold` ช่วยให้เขียนโค้ดตรงมาตรฐานทีมตั้งแต่วันแรก)
- สิทธิ์ repo โปรเจกต์และ staging
- **Buddy** จากทีม Dev ดูแลคุณ 30 วันแรก

## สัปดาห์แรก

- อ่าน `coding-rules.md` (กติกาโค้ด 10 ข้อของทีม) และ `project-scaffold-notes.md`
- ขึ้นโปรเจกต์ตัวอย่างระบบสมาชิกด้วยแพ็ก dev แล้วให้ buddy รีวิว
- แก้บั๊กเล็ก 1 ticket และส่ง PR แรก
- ศุกร์ 13 พ.ย. คุยกับพี่ปอนด์ (tech lead) 15 นาที "สัปดาห์แรกเป็นยังไง"
