# onboarding-pack — ชุดต้อนรับพนักงานใหม่ 1 คน

ความรู้ของบริษัทอยู่ใน `references/` (สรุปจาก company-kit) อ่านก่อนเริ่มทุกครั้ง:
- `references/onboarding-rules.md` — ของที่ทุกคนได้, ของเพิ่มตามแผนก, เช็กลิสต์ตามเวลา, ปัญหาที่เคยเกิด
- `references/benefits-summary.md` — สวัสดิการ ทดลองงาน FAQ ที่ใส่ในจดหมายต้อนรับ

## ข้อมูลที่ต้องได้ก่อนเริ่ม
1. **แผนก** และ **วันเริ่มงาน (D1)** — ถ้าผู้ใช้พูดแค่ "วันจันทร์" ให้คำนวณเป็นวันที่จริงจากวันนี้ แล้วเขียนวันที่ + วันในสัปดาห์ให้ชัด
2. ชื่อพนักงานใหม่ / user (ถ้าไม่บอก ให้ดูการ์ดใน `people/` ว่ามีคนใหม่ของแผนกนั้นไหม แล้ว **ระบุว่าเป็นการสันนิษฐาน**)
3. หัวหน้าแผนก และผู้ที่เป็น buddy ได้ (แผนกเดียวกัน อยู่ ≥ 1 ปี ไม่ใช่หัวหน้า)

## ขั้นตอน
1. **เช็กเส้นตาย D−5** = 5 วันทำการก่อน D1 (ไม่นับ ส.–อา.) เทียบกับวันนี้ ถ้าเลยแล้ว: ขึ้นคำเตือนบนสุด, เปลี่ยนคำขอเป็น "ด่วน", เสนอแผนสำรอง
2. รวมรายการ = **ของที่ทุกคนได้** + **ของเพิ่มตามแผนก** (จาก `onboarding-rules.md`) — ใส่ผู้รับผิดชอบทุกบรรทัด
3. แพ็ก Claude Code = `core` + แพ็กแผนกตัวเอง **เท่านั้น** และต้องมีขั้น D−1 "ทดสอบว่าติดตั้งแล้วจริง"
4. คำนวณวันนัด D5 / D30 / D60 / D90 / D119 (นับ D1 = วันเริ่มงาน, Dn = D1 + n−1 วัน) ตรงเสาร์-อาทิตย์ให้เลื่อนเป็นวันทำการก่อนหน้าและบอกไว้
5. เขียนผลงาน 3 ไฟล์ในโฟลเดอร์ `work/<user-หรือแผนก>-<YYYY-MM-DD>/`
   - `01-hr-checklist.md` — ตาราง D−5 / D−1 / D1 / สัปดาห์แรก / นัดติดตาม พร้อมช่อง [ ] และความเสี่ยง
   - `02-welcome-letter.md` — ถึงพนักงานใหม่: ที่ไหน กี่โมง ตารางวันแรก เอกสารที่จะเซ็น ของที่ได้ งานสัปดาห์แรก สวัสดิการที่เกี่ยวกับตำแหน่ง
   - `03-request-messages.md` — ข้อความพร้อมส่งถึงทีมกลาง, ธุรการ, หัวหน้าแผนก, ผู้อบรม PDPA
6. ปิดท้ายด้วยรายการ "ต้องยืนยัน/ตัดสินใจ" ที่ข้อมูลอ้างอิงไม่ได้บอก

## กติกา
- **ห้ามแต่งข้อมูลที่ไม่มีใน references** (เช่น เอกสารส่วนตัวที่ต้องนำมา, พักร้อนคิดตามสัดส่วนหรือไม่) — ให้เขียนว่า "ต้องยืนยัน"
- ข้อมูลส่วนตัวพนักงานใหม่ (เลขบัตร เบอร์มือถือ เลขบัญชี) **ห้ามใส่** ในไฟล์ใด ๆ — ตามนโยบาย `customer-data-policy`
- จดหมายต้อนรับใช้น้ำเสียงเป็นกันเอง สุภาพ ภาษาไทย ใส่เฉพาะสวัสดิการที่เกี่ยวกับตำแหน่งนั้น (เช่น รุ่นโน้ตบุ๊ก, on-call)
- ถ้า references เก่ากว่า company-kit ปัจจุบัน (ดูวันที่ปรับปรุงหัวไฟล์) ให้เตือนผู้ใช้
