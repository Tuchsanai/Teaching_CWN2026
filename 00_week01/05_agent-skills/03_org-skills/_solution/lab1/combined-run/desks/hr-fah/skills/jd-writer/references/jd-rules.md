# กติกาประกาศรับสมัคร (สรุปจาก company-kit/jd-template.md)

## กติกาบังคับ

- ยาวไม่เกิน 1 หน้า A4
- ห้ามระบุ เพศ อายุ ศาสนา สถานภาพ
- ห้ามคำ "rockstar", "ninja", "ทนแรงกดดันสูง" (และคำโอ้อวดใน brand-voice.md)
- ระบุช่วงเงินเดือนเสมอ

## โครง (เรียงตามนี้ทุกประกาศ)

```
# <ชื่อตำแหน่ง> — <ทีม/โปรเจกต์>
<บรรทัดข้อมูลสั้น: รหัสตำแหน่ง · จำนวน · วันเริ่มงาน · รูปแบบงาน/ที่ตั้ง>
<ประโยคเปิด 1–2 ประโยค: งานนี้แก้ปัญหาอะไรให้ใคร>

## สิ่งที่คุณจะได้ทำ        (4–6 ข้อ ขึ้นต้นด้วยกริยา เป็นงานจริงของโปรเจกต์)
## สิ่งที่เรามองหา          (ต้องมี 4–6 ข้อ)
## จะดีมากถ้ามี             (2–4 ข้อ — ปิดท้ายว่า "ไม่มีครบทุกข้อก็สมัครได้")
## ทีมและวิธีทำงาน          (2–3 บรรทัด: ทีมกี่คน ใครเป็นหัวหน้า ใช้เครื่องมืออะไร)
## สิ่งที่คุณจะได้รับ        (เงินเดือน + 4–6 สวัสดิการเด่น)
## ขั้นตอนสมัคร             (3 รอบ ไม่เกิน 3 สัปดาห์ + ช่องทางสมัคร)
```

## ตัวอย่างประโยคเปิดที่ดี

> "ลูกค้าธนาคารกว่า 120 สาขาต้องรอคิวเฉลี่ย 38 นาที เรากำลังสร้างระบบที่ให้เขาจองล่วงหน้าและให้สาขารู้ล่วงหน้าว่าวันไหนคนจะล้น — และเรากำลังมองหาคนที่อยากเป็นแกนหลักของงานนี้"

## ตัวอย่างที่ห้ามใช้

(ผิด: เร่งเร้า, ภาษาวัยรุ่น, "ทนแรงกดดัน", ระบุอายุ)

## ข้อมูลลูกค้าในประกาศ (สรุปจาก customer-data-policy.md)

- ประกาศ = เอกสารภายนอก ห้ามเบอร์มือถือ, เลขบัตร, ชื่อ-นามสกุลลูกค้าปลายทาง
- ข้อมูลใน TOR (ชื่อผู้ประสานงาน เบอร์ เลข TOR) ห้ามคัดลอกลงประกาศ
- ชื่อลูกค้าองค์กร: ไม่ใส่จนกว่าจะเซ็นสัญญาและลูกค้ายินยอม — ใช้ "ธนาคาร" / "ลูกค้าธนาคาร 120 สาขา" แทน
- ไม่แน่ใจ → ถาม plat-may (`#ask-pdpa`, dpo@novatech.example)

- [ ] ไม่มีข้อมูลลูกค้าที่ห้าม
