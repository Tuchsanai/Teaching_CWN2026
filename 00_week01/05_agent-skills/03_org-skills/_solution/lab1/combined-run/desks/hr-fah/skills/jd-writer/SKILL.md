# jd-writer — เขียนประกาศรับสมัครโนวาเทค

ทำเรื่องเดียว: เปลี่ยนข้อมูลตำแหน่งว่าง 1 ตำแหน่ง ให้เป็นประกาศรับสมัคร 1 หน้า A4 + ใบตรวจ
ความรู้ที่ต้องใช้อยู่ใน `references/` ครบแล้ว ไม่ต้องเปิด company-kit

## ข้อมูลที่ต้องมีก่อนเขียน

ชื่อตำแหน่ง · ทีม/โปรเจกต์ · รหัสตำแหน่ง · จำนวน + วันเริ่มงาน · ช่วงเงินเดือน · ประสบการณ์ · stack/ทักษะ · งานหลัก · จะดีถ้ามี · ทีม (กี่คน ใครหัวหน้า) · รูปแบบงาน · ช่องทางสมัคร

- ถ้าผู้ใช้ให้ไฟล์ตำแหน่ง / TOR / แบบฟอร์มขอคน ให้ดึงจากไฟล์นั้น
- ถ้าขาด **ช่วงเงินเดือน** ห้ามเดา — ถามก่อน (กติกาบังคับระบุเสมอ)
- ช่องอื่นที่ขาด: เขียนเท่าที่มี แล้วจดไว้ในใบตรวจหัวข้อ "จุดที่ตัดสินใจเอง"

## ขั้นตอน

1. อ่าน `references/jd-rules.md` (โครง 6 หัวข้อ + ข้อห้าม) และ `references/brand-voice.md`
2. ประโยคเปิด 1–2 ประโยค: ปัญหาจริงของผู้ใช้ปลายทาง (มีตัวเลข) → สิ่งที่เรากำลังสร้าง → เชิญคนที่อยากเป็นแกนหลัก
3. เขียน 6 หัวข้อตามลำดับใน `jd-rules.md` — งานที่จะได้ทำต้องเป็นงานจริงของโปรเจกต์ ขึ้นต้นด้วยกริยา
4. หัวข้อ "สิ่งที่คุณจะได้รับ": เงินเดือน + เลือกสวัสดิการเด่น 4–6 ข้อจาก `references/benefits-2026.md` ให้เข้ากับตำแหน่ง (เช่น สาย tech เน้น MacBook Pro / งบเรียนรู้)
5. ขั้นตอนสมัคร: ใช้กระบวนการ 3 รอบจาก `benefits-2026.md` + ช่องทางสมัครของตำแหน่ง
6. ตรวจข้อมูลลูกค้า: ห้ามชื่อลูกค้า/เลข TOR ถ้าดีลยังไม่เซ็นหรือลูกค้าไม่อนุญาต, ห้ามเบอร์มือถือ/ชื่อผู้ประสานงานลูกค้า (ถ้าไม่แน่ใจ ส่งต่อ skill `customer-data-policy`)
7. ไล่ checklist ท้าย `jd-rules.md` ทุกข้อ
8. บันทึก 2 ไฟล์ใน `work/` ของผู้ใช้:
   - `work/jd-<ตำแหน่ง>-<โปรเจกต์>.md` — ประกาศพร้อมโพสต์
   - `work/jd-<ตำแหน่ง>-<โปรเจกต์>-check.md` — ตารางผลตรวจ + "จุดที่ตัดสินใจเอง" ให้ HR BP ยืนยัน

ดูตัวอย่างผลงานที่ผ่านแล้วใน `references/example-senior-fullstack.md`
