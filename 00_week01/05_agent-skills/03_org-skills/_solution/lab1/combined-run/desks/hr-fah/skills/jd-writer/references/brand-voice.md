# น้ำเสียงแบรนด์สำหรับประกาศรับสมัคร (สรุปจาก company-kit/brand-guide.md v3.2)

1. **ตรง ชัด สั้น** — ประโยคแรกของทุกหัวข้อบอกข้อสรุป แล้วค่อยให้รายละเอียด
2. **สุภาพแบบมืออาชีพ** — ใช้ "เรา" แทนโนวาเทค ไม่ใช้ภาษาวัยรุ่น **ไม่ใช้อีโมจิ** ในเอกสารภายนอก
3. **ไม่โอ้อวด** — ห้าม "ดีที่สุด", "อันดับหนึ่ง", "100%" ใช้หลักฐานแทน (เช่น "โบนัสปี 2025 เฉลี่ย 1.8 เดือน")
4. **คำเทคนิคเขียนอังกฤษได้** (API, LINE OA, mTLS) แต่ครั้งแรกให้อธิบายไทยสั้น ๆ ในวงเล็บ
5. ตัวเลขเงินใส่คอมมาและหน่วย "บาท" (กติกา VAT ใช้กับราคาขาย ไม่ใช้กับเงินเดือน)

## ชื่อบริษัท

- เขียน "โนวาเทค" (ไทย) หรือ "Novatech" (อังกฤษ) — ห้าม "NovaTech", "Nova Tech"

## ถ้าทำเป็นไฟล์จัดหน้า (PDF/Word/โพสต์ภาพ)

- ฟอนต์ IBM Plex Sans Thai: หัวเรื่อง SemiBold 20 pt, เนื้อหา Regular 11 pt (ห้าม TH Sarabun)
- สี: หัวเรื่อง Nova Navy `#0B2545`, ลิงก์ Nova Teal `#13A89E`, ตัวอักษร Ink `#1F2933`
- ห้ามแดงสด `#FF0000` และ gradient
