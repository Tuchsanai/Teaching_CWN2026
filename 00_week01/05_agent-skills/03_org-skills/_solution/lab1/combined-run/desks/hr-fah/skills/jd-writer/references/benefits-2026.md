## สวัสดิการ (เลือก 4–6 ข้อเด่นให้เข้ากับตำแหน่ง)

| เรื่อง | ใช้เขียนในประกาศ |

| เวลาทำงาน | จันทร์–ศุกร์ เข้างานยืดหยุ่น 08:00–10:00 น. วันละ 8 ชม. |
| Hybrid | เข้าออฟฟิศ 2 วัน/สัปดาห์ (อังคาร + พฤหัส) ที่เหลือ WFH ได้ |

| วันเกิด | หยุดได้ 1 วันในเดือนเกิด |

## ทดลองงาน

119 วัน มี buddy 1 คน นัดคุยกับหัวหน้าทุก 30 วัน · ได้สวัสดิการทุกอย่างตั้งแต่วันแรก ยกเว้นโบนัส (คิดตามสัดส่วน)

## ข้อเท็จจริงที่ควรบอกผู้สมัครตามตำแหน่ง

- ไปทำงานที่ลูกค้า: โปรเจกต์ธนาคารอาจไปประชุม/UAT 2–6 วันต่อโปรเจกต์ (เบิกค่าเดินทางได้)
- on-call: เฉพาะ DevOps และ Dev ที่ดูแลระบบหลังขึ้นจริง ผลัดละ 1 สัปดาห์ ~1 ครั้ง/เดือน ค่า on-call 3,000 บาท/สัปดาห์ + ค่าตอบแทนเมื่อถูกเรียกนอกเวลา
- ทำงานต่างจังหวัด: ได้ถ้าหัวหน้าอนุมัติ ต้องเข้าวันทีมอย่างน้อย 2 สัปดาห์ครั้ง
- ภาษา: ไทยเป็นหลัก เอกสารเทคนิคและโค้ดเป็นอังกฤษ

## ขั้นตอนสมัคร (ใช้ทุกประกาศ)

3 รอบ รวมไม่เกิน 3 สัปดาห์
1. คุยกับ HR 30 นาที
2. คุยเทคนิค/งานกับหัวหน้าทีม 90 นาที (โจทย์จริงขนาดเล็ก ไม่มีการบ้านกลับบ้าน)
3. คุยกับ MD 30 นาที
