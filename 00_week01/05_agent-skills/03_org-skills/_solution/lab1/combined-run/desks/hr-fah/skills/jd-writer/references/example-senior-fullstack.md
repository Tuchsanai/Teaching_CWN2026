## ประกาศที่ผ่านแล้ว

## Senior Full-stack Developer — โปรเจกต์ระบบจองคิวสาขาธนาคาร

รหัสตำแหน่ง NVT-JOB-2026-021 · 1 อัตรา · เริ่มงานได้ภายใน 4 ม.ค. 2027 · Hybrid กรุงเทพฯ (พระราม 9)

ลูกค้าธนาคารกว่า 120 สาขาต้องรอคิวเฉลี่ย 38 นาที เรากำลังสร้างระบบที่ให้เขาจองคิวล่วงหน้า และให้สาขารู้ล่วงหน้าว่าวันไหนคนจะล้น — เรากำลังมองหาคนที่อยากเป็นแกนหลักของงานนี้

### สิ่งที่คุณจะได้ทำ

- ออกแบบและพัฒนา booking engine (ระบบจัดการการจองคิว) พร้อม slot lock (การล็อกช่วงเวลาไม่ให้จองซ้ำ) ด้วย Redis
- สร้างหน้าจองคิวทั้งบนเว็บ (Next.js) และใน LINE ผ่าน LIFF (หน้าเว็บที่เปิดในแอป LINE)
- เชื่อมต่อ core banking API (ระบบหลักของธนาคาร) ผ่าน mTLS (การยืนยันตัวตนด้วยใบรับรองทั้งสองฝั่ง)
- ทำให้ระบบรองรับ 120 สาขาใช้งานพร้อมกัน ด้วยคิวงานเบื้องหลัง BullMQ และชุดทดสอบอัตโนมัติด้วย Playwright
- ร่วมกับทีม ML นำผลพยากรณ์ปริมาณคิว 7 วันขึ้น dashboard ของผู้จัดการสาขา

### สิ่งที่เรามองหา

- ประสบการณ์พัฒนาซอฟต์แวร์ 5 ปีขึ้นไป และเคยพัฒนาหรือดูแลระบบที่มีผู้ใช้จริงหลักหมื่นคนขึ้นไป
- เขียน TypeScript และ Node.js ได้คล่องในงานจริง
- เคยทำเว็บด้วย Next.js (App Router)
- ออกแบบฐานข้อมูล PostgreSQL และใช้ Redis ในงานที่มีผู้ใช้พร้อมกันจำนวนมาก
- เคยใช้ระบบคิวงาน (เช่น BullMQ) และเขียน end-to-end test (การทดสอบทั้งระบบ) เช่น Playwright
- อ่านเอกสารเทคนิคภาษาอังกฤษได้ และสื่อสารงานกับทีมเป็นภาษาไทยได้

### จะดีมากถ้ามี

- เคยทำงานกับธนาคารหรือ fintech
- รู้ PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล) หรือมาตรฐานความปลอดภัยของธนาคาร
- เคยทำงานกับ LINE OA (บัญชี LINE ทางการขององค์กร)
- เคยเป็น mentor ให้นักพัฒนาในทีม

ไม่มีครบทุกข้อก็สมัครได้

### ทีมและวิธีทำงาน

ทีมโปรเจกต์ 7 คน: Dev 4 · QA 1 · DevOps 1 · ML 1 นำโดย ปอนด์ เจริญกิจ (tech lead) · ทำงานแบบ Hybrid เข้าออฟฟิศอังคารและพฤหัส ที่เหลือ WFH ได้ · ใช้ Claude Code พร้อมแพ็ก skill ของบริษัท · ช่วงทดสอบกับผู้ใช้ (UAT) จะไปทำงานที่ธนาคารประมาณ 4 วัน (เบิกค่าเดินทางได้) · หลังขึ้นระบบจริงมีผลัด on-call (เวรรับเหตุ) ประมาณเดือนละ 1 สัปดาห์ ได้ค่า on-call 3,000 บาท/สัปดาห์

### สิ่งที่คุณจะได้รับ

- เงินเดือน 75,000 – 105,000 บาท/เดือน ตามประสบการณ์ · ปรับเงินเดือนปีละครั้ง และโบนัสตามผลงาน (ปี 2025 เฉลี่ย 1.8 เดือน)
- เวลาเข้างานยืดหยุ่น 08:00–10:00 น. · พักร้อน 12 วัน/ปีตั้งแต่ปีแรก + วันหยุดวันเกิด
- ประกันสุขภาพกลุ่ม IPD สูงสุด 100,000 บาท/ครั้ง OPD 2,000 บาท/ครั้ง และทันตกรรม
- กองทุนสำรองเลี้ยงชีพ บริษัทสมทบ 5%
- งบพัฒนาตัวเอง 20,000 บาท/ปี + วันเรียนรู้ 3 วัน/ปี
- MacBook Pro 14" + จอ 27" ที่ออฟฟิศ + ค่าอินเทอร์เน็ต WFH 500 บาท/เดือน

ได้สวัสดิการทุกอย่างตั้งแต่วันแรก (ทดลองงาน 119 วัน มี buddy ดูแล)
