# แม่แบบเกณฑ์ผ่าน shadow และเกณฑ์ถอยกลับ

ตัวเลขด้านล่างเป็น **ค่าเริ่มต้นที่ใช้กับ r03 พยากรณ์คิว** ปรับตาม TOR/โมเดลจริง แต่ต้องคงโครง: มีตัวเลข · มีช่วงเวลา · มีคนตัดสิน · เทียบโมเดลเดิม

## นิยามที่ต้องเขียนไว้ในแผนทุกครั้ง
- metric หลัก (เช่น MAPE) คิดบนอะไร (ชั่วโมงที่เปิดทำการ, หน่วยที่รวม)
- bias = (Σพยากรณ์ − Σจริง) / Σจริง · ติดลบ = พยากรณ์ต่ำ (อันตรายกว่าในงานจัดคน)
- segment ที่เป็นจุดอ่อน (เช่น ช่วงเที่ยงสาขาออฟฟิศ, payday, สัปดาห์มีวันหยุด, หน่วยใหม่ที่ใช้ fallback)

## เกณฑ์ผ่าน shadow → go-live (ครบทุกข้อ)
| # | เกณฑ์ (ค่าเริ่มต้น) |
|---|---|
| S1 | metric รายสัปดาห์ ≤ เกณฑ์ TOR (20%) ทุกสัปดาห์ และดีกว่าโมเดลเดิมทุกสัปดาห์ |
| S2 | segment ที่เป็นจุดขาย (payday) ≤ TOR + 2 และดีกว่าโมเดลเดิม |
| S3 | segment จุดอ่อน: bias ไม่แย่กว่า −30% และไม่แย่กว่าโมเดลเดิม |
| S4 | batch สำเร็จทุกคืน ไม่มีค่าติดลบ/ว่าง/NaN |
| S5 | UAT sign-off + แจ้งลูกค้าตามกติกา |

## Rollback 3 ระดับ
**A — ทันที (deploy lead / on-call ตัดสินเอง)**: batch ล้มหรือพยากรณ์ไม่ครบก่อนเวลาที่ผู้ใช้ต้องใช้ (เช่น 06:00) แก้ไม่ได้ใน 30 นาที · ค่าผิดรูปแม้ 1 รายการ (ติดลบ, ว่าง, NaN, > 3× ค่าสูงสุดในอดีต) · หน้าจอผู้ใช้พังหลังสลับ

**B — ความแม่นยำ (เจ้าของโมเดลเสนอ หัวหน้าทีม ML อนุมัติ ใน 1 วันทำการ)**:
- metric รายสัปดาห์ > TOR + 2 จุด **สองสัปดาห์ติด**
- segment จุดอ่อนแย่กว่าเกณฑ์ทั้งสัปดาห์ **และ** แย่กว่าโมเดลเดิม
- แพ้โมเดลเดิมที่รันคู่ในสัปดาห์เดียวกัน
- segment จุดขาย > TOR + 5 และแย่กว่าโมเดลเดิม

**C — เฝ้าระวัง (ไม่ถอย สืบสาเหตุ)**: metric อยู่ระหว่าง TOR ถึง TOR + 2 สัปดาห์เดียว · ข้อมูลขาด > 5% / ซ้ำ > 2% (แก้ข้อมูล ไม่ถอยโมเดล) · ผู้ใช้ร้องเรียน ≥ 3 หน่วย/สัปดาห์ · หน่วย fallback แย่กว่า 30%

## วิธีถอยกลับสำหรับโมเดล
1. สลับ flag/config เลือกโมเดล → โมเดลเดิม (ต้องรันคู่ไว้ตลอด hypercare ถึงจะทำได้ทันที)
2. image tag เดิม
3. restore DB เฉพาะเมื่อ schema เปลี่ยนจนโค้ดเก่าใช้ไม่ได้ (ต้องตกลงร่วม)
4. แจ้งลูกค้าภายใน 30 นาที → ระดับ A/B เขียน postmortem ภายใน 3 วันทำการ แล้วเริ่มแผนใหม่ตั้งแต่ shadow

## เหตุผลที่ต้องเทียบโมเดลเดิมเสมอ
ถ้าโมเดลเดิมก็พลาดใน segment เดียวกัน การถอยกลับไม่ช่วยอะไร — จึงต้องรู้ตัวเลขของโมเดลเดิมใน segment นั้นตั้งแต่ gate
