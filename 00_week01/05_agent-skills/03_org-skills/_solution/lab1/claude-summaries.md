5. **DPA ของลูกค้าที่ไม่ใช่ธนาคาร:** กฎภาคผนวก PDPA บังคับเฉพาะธนาคาร ผมเลยนับ DPA ที่ขาดไปเป็นความเสี่ยงสัญญาในข้อ 4 แทน
