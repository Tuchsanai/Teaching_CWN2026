# ข้อมูลลูกค้าในงานปล่อยโมเดล

ข้อมูลส่วนบุคคลใช้ skill `core:customer-data-policy` ไฟล์นี้เก็บเฉพาะสิ่งที่ใช้กับงานปล่อยโมเดล

- ข้อมูลเทรน/ประเมินต้อง **ไม่ระบุตัวตน** และใช้ได้ตามสัญญา (เช่น MA) · ใช้ bucket ข้อมูลของทีม
- release notes / รายงานถึงลูกค้า: ใช้รหัสสาขา ตัวเลขรวม ได้
- ตัวอย่างข้อมูลในรายงาน (เช่น แถวที่ทำนายผิด) ต้องเป็นระดับสาขา-ชั่วโมง ไม่ใช่ระดับคน
- ใช้ข้อมูลลูกค้า A เป็นต้นแบบให้ลูกค้า B: ส่งให้ B ได้แค่ผลวิธีการ/metric รวม ห้ามส่งข้อมูลดิบของ A
