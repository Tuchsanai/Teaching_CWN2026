# กติกาประกาศรับสมัครโนวาเทค

> สรุปจาก `company-kit/jd-template.md` (ผู้ดูแล hr-fah) · ณ 3 พ.ย. 2026

## โครง (เรียงตามนี้ทุกประกาศ)

```
# <ชื่อตำแหน่ง> — <ทีม/โปรเจกต์>
<ประโยคเปิด 1–2 ประโยค: งานนี้แก้ปัญหาอะไรให้ใคร>

## สิ่งที่คุณจะได้ทำ      4–6 ข้อ ขึ้นต้นด้วยกริยา เป็นงานจริงของโปรเจกต์
## สิ่งที่เรามองหา        ต้องมี 4–6 ข้อ
## จะดีมากถ้ามี           2–4 ข้อ + "ไม่ครบทุกข้อก็สมัครได้"
## ทีมและวิธีทำงาน        2–3 บรรทัด: ทีมกี่คน ใครเป็นหัวหน้า เครื่องมือ รูปแบบงาน
## สิ่งที่คุณจะได้รับ      เงินเดือน + 4–6 สวัสดิการเด่น (จาก benefits.md)
## ขั้นตอนสมัคร           3 รอบ ไม่เกิน 3 สัปดาห์ + วันเริ่มงาน + ช่องทางสมัคร
```

## ห้าม
- ยาวเกิน 1 หน้า A4 (markdown ไม่เกินประมาณ 50 บรรทัด รวมบรรทัดว่าง)
- ระบุ เพศ อายุ ศาสนา สถานภาพ (รวมคำแฝง เช่น "คนรุ่นใหม่", "ไฟแรง", "โสด")
- คำว่า "rockstar", "ninja", "ทนแรงกดดันสูง", "สายเทพ", "รับด่วน!!"
- ไม่ใส่ช่วงเงินเดือน (ต้องมีทุกประกาศ เป็นตัวเลขมีคอมมา + "บาท/เดือน")
- ชื่อลูกค้า / ข้อมูลดีล
