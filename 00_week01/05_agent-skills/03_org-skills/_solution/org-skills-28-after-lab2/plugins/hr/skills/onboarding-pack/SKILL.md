# onboarding-pack

ทำชุดต้อนรับพนักงานใหม่ 1 คน = ไฟล์ภายใน HR 1 ไฟล์ + จดหมายต้อนรับ 1 ไฟล์ ความรู้ที่ต้องใช้อยู่ใน `references/` ครบแล้ว ไม่ต้องเปิด company-kit

## ขั้นตอน

1. **เก็บข้อมูลจากคำสั่ง**: แผนก, วันเริ่มงาน (ถ้าพูดว่า "วันจันทร์" = จันทร์ถัดไปจากวันนี้), ชื่อ, ตำแหน่ง ไม่รู้ข้อไหนให้ใส่ `[...]` แล้วทำต่อ ไม่ต้องหยุดถาม
2. **คำนวณวัน**: `python scripts/onboarding_dates.py <วันเริ่ม YYYY-MM-DD> [วันนี้]` (ตั้ง `PYTHONIOENCODING=utf-8` บน Windows) ถ้าเลย D−5 แล้ว ให้ขึ้นบรรทัดแรกของสรุปว่า "ช้าไป N วันทำการ" และติดป้ายด่วนทุกคำขอ
3. **ประกอบชุด** จาก `references/onboarding-rules.md`: ของที่ทุกคนได้ (ข้อ 1) + ของแผนกนั้น (ข้อ 2) — แพ็ก Claude Code = `core` + แผนกตัวเองเท่านั้น
4. **เขียนไฟล์ภายใน** ตาม `references/pack-template.md` เก็บที่ `work/<วันเริ่ม>-<แผนก>-onboarding-pack.md`
5. **เขียนจดหมายต้อนรับ** จาก `references/benefits-summary.md` เก็บที่ `work/welcome-letter-<แผนก>-<วันเริ่ม>.md` น้ำเสียงตาม skill `core:brand-guide`
6. **ตรวจก่อนส่ง** (ด้านล่าง) แล้วสรุปให้ผู้ใช้: วันสำคัญ, คำขอที่ต้องส่งวันนี้, ช่อง `[...]` ที่ยังต้องเติม

## ตรวจก่อนส่ง

- [ ] ข้อ "ปัญหาที่เคยเกิด" ใน onboarding-rules ถูกกันไว้ครบ (แพ็กแผนกก่อนวันแรก, Gitea ไม่ส่งคำขอวันศุกร์ก่อนเริ่มงาน)
- [ ] buddy = คนแผนกเดียวกัน อายุงาน ≥ 1 ปี **ไม่ใช่หัวหน้า** — ถ้าไม่รู้อายุงาน ให้เขียน "เสนอ … รอยืนยัน"
- [ ] อุปกรณ์ตรงสายงาน (MacBook Pro 14" สำหรับ Dev/QA/DevOps/ML, Air สำหรับสายอื่น)
- [ ] วันนัดไม่ตกเสาร์-อาทิตย์ และเตือนให้เช็กวันหยุดนักขัตฤกษ์
- [ ] ไม่มีเลขบัตรประชาชน, เบอร์มือถือ, อีเมลส่วนตัว, เลขบัญชี ของพนักงานใหม่ในไฟล์ (เก็บใน HR system เท่านั้น) — ตาม `customer-data-policy`
- [ ] ไม่แต่งชื่อคน repo หรือ ticket ที่ไม่มีในข้อมูล ใช้ `[...]`

## ไฟล์ใน skill

- `references/onboarding-rules.md` — กติกาชุดต้อนรับ: ของทุกคน, ของแต่ละแผนก, ไทม์ไลน์, ปัญหาที่เคยเกิด, ผู้ติดต่อ
- `references/benefits-summary.md` — สวัสดิการ/ทดลองงาน/ที่ตั้ง สำหรับจดหมายต้อนรับ
- `references/pack-template.md` — โครงไฟล์ชุดต้อนรับ
- `scripts/onboarding_dates.py` — คำนวณ D−5 … D119 และเตือนเมื่อช้า
