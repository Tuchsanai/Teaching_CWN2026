# กติกาดีลเฉพาะตอนทบทวน pipeline

สูตร เกณฑ์อนุมัติ สิทธิ์ส่วนลด และตารางราคาอยู่ใน skill `core:pricing-rules` · ข้อมูลส่วนบุคคลอยู่ใน skill `core:customer-data-policy` ไฟล์นี้เก็บเฉพาะสิ่งที่ใช้ตอนทบทวน

## ราคา
- สรุปดีล fixed-price ที่ไม่มี buffer 10% = ผิดกติกา
- ถ้า TOR ขอตอบ Sev 1 นอกเวลาทำการ (เช่น ภายใน 30 นาที) → ต้องคิด MA-PREM ไม่ใช่ MA-STD
- ราคาบริการภายนอก (เช่น LINE OA) ก่อนใช้ขายให้ `fin-joy` ยืนยัน

## PDPA ในรายงานนี้
- อ้าง feedback ด้วยรหัส (F-xx)
- ข้อมูลสุขภาพ (ม.26) ในดีล → ต้องมี DPA ในสัญญา ถ้ายังไม่มีให้เป็นความเสี่ยง
