# หาต้นเหตุแบบไม่โทษคน

## ถาม "ทำไม" ทีละชั้น (ปกติ 4–6 ชั้น)
หยุดเมื่อคำตอบเป็น **กระบวนการ/ระบบที่เราแก้ได้** ไม่ใช่ "คน X ลืม"
- ❌ "dev ไม่ได้ต่อ cert" → ✅ "การต่อ cert ขึ้นกับการเตือนในปฏิทินส่วนตัว ไม่มีทะเบียนกลางและไม่มี alert"
- ❌ "ใครเป็นคน upload" → ✅ "ข้อยกเว้นจาก automation ไม่มีขั้นตอนบันทึกเจ้าของ"

## แยก 3 คำถามเสมอ
1. **ทำไมพัง** (trigger + ต้นเหตุหลัก)
2. **ทำไมเราไม่รู้ก่อน** (monitor/alert ขาดอะไร เทียบมาตรฐาน alert ใน company-rules ข้อ 3)
3. **ทำไมผลกระทบใหญ่ขนาดนั้น** (ปัจจัยเสริม: single point of failure, ไม่มี reconcile, ช่วงเวลาพีค)

## รูปแบบที่เจอบ่อย (ให้ลองเช็ก)
- ความรู้ผูกกับคน / บัญชีส่วนตัว (คนลาออก ลาพัก)
- ข้อยกเว้นที่หลุดจาก automation (cert มือ, config มือ, cron บนเครื่องคน)
- monitor ยิงแค่หน้าแรก ไม่ยิง flow ที่ทำเงิน
- runbook/checklist ไม่มีขั้นนั้น
- TODO ในแชตที่ไม่มีเจ้าของ
