# แม่แบบ PRD (คัดลอกแล้วเติม)

```markdown
# PRD-NQ-<YYYY-MM> · <ชื่อฟีเจอร์> (NovaQueue v2)

| | |
|---|---|
| เจ้าของ | <ชื่อ> (`<user>`) |
| สถานะ | ร่าง v0.1 · <วันที่> · รอรีวิว SA / QA / บัญชี |
| ผลิตภัณฑ์ | NovaQueue **v2 เท่านั้น** |
| ขั้นวงจรชีวิต | ไอเดีย → เบต้า → GA |
| ที่มา | <ไฟล์ feedback / ตัวเลข / TOR> |

## 1. ปัญหาของลูกค้า + หลักฐาน
<1–2 ประโยค ปัญหาจากมุมลูกค้า>
| หลักฐาน | ค่า |   ← F-xx + จำนวนครั้ง, ตัวเลขระบบตามเดือน, ต้นทุน (แสดงสูตร), ดีล/TOR

## 2. ตัวชี้วัดความสำเร็จ
| ตัวชี้วัด | ค่าปัจจุบัน | เป้า (ข้อเสนอ) |   ← บอกว่าวัดที่ไหน เมื่อไร

## 3. ขอบเขต
**ทำในรอบนี้** 1. ...
**ไม่ทำในรอบนี้** - ... → <ไป PRD ไหน / รอใคร>

## 4. User story + เกณฑ์ตรวจรับ
**US-01** ในฐานะ <ใคร> ฉันอยาก <ทำอะไร> เพื่อ <ได้อะไร>
- AC-01.1 Given ... When ... Then ... (มีค่าวัดได้: วินาที, ครั้ง, KB, ช่วงค่า)
**ข้อกำหนดที่ไม่ใช่ฟังก์ชัน** — คิว/retry, ชื่อ event, region, การเข้ารหัส, ห้ามข้อมูลส่วนบุคคลใน URL/log

## 5. ผลกระทบต่อเวอร์ชันอื่น
- v2: ... · v1: ไม่ทำ (เสนอย้าย) · ดีลที่เกี่ยวข้อง: ...

## 6. ต้นทุนและสิ่งที่ต้องยืนยัน
| รายการ | ตัวเลข | สถานะ (⚠️ ใครยืนยัน) |

## 7. คำถามเปิด (ต้องตัดสินก่อน GA)

## 8. ถัดไป
- SA (`req-to-spec`) · QA (`test-from-plan`) · บัญชี (`pricing-calc`)
```
