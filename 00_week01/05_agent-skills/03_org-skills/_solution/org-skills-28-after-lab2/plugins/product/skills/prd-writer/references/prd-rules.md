# กติกา PRD + PDPA (สรุปจาก company-kit)

> ต้นฉบับ: `company-kit/product/product-lifecycle-policy.md` v2026.2 ข้อ 1 (เจ้าของ pm-beam, อนุมัติ MD, มีผล 2026-08-01)
> และ `company-kit/customer-data-policy.md` v1.4 (ผู้ดูแล plat-may) · สรุปเมื่อ 2026-11-04

## PRD ทุกฉบับต้องมี 5 ข้อ

1. ปัญหาของลูกค้า **พร้อมหลักฐาน** (ตัวเลข หรือจำนวนครั้งที่ถูกพูดถึง) — ห้ามมีข้อมูลส่วนบุคคลของลูกค้าปลายทาง
2. **ตัวชี้วัดความสำเร็จที่วัดได้** และ **ค่าปัจจุบันก่อนทำ**
3. **ขอบเขต**: ทำ / ไม่ทำในรอบนี้
4. **user story + เกณฑ์ตรวจรับ** ที่ QA เขียน test ได้
5. **ผลกระทบต่อเวอร์ชันอื่น** (ฟีเจอร์ใหม่ทำบน v2 เท่านั้น)

## วงจรชีวิตผลิตภัณฑ์ (ระบุขั้นใน PRD)

ไอเดีย (Product) → เบต้า: ลูกค้า 1–3 รายใช้ฟรี (Product + Sales) → GA มี SLA (Product + MD) → ดูแลอย่างเดียว → เลิกให้บริการ

## PDPA ที่เกี่ยวกับ PRD

กติกาทั้งหมดอยู่ใน skill `core:customer-data-policy` ส่วนเฉพาะ PRD:

- ticket ที่มีชื่อ/เบอร์ → อ้างด้วยรหัส feedback (F-xx) หรือรหัสเคส
- ฟีเจอร์ที่เก็บข้อมูลส่วนบุคคลใหม่ (เช่น LINE userId) → ระบุการขอความยินยอม + การเข้ารหัส และให้ `plat-may` รีวิว
- ข้อมูลทดสอบใน AC/ตัวอย่างต้องเป็นข้อมูลสังเคราะห์
