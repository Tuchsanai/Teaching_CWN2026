# brand-guide: คู่มือแบรนด์โนวาเทค v3.2

> ต้นฉบับจาก `company-kit/brand-guide.md` · ผู้ดูแล `plat-may` · ปรับปรุงล่าสุด 2026-06-15
> ใช้กับเอกสารทุกชิ้นที่ส่งออกนอกบริษัท และสไลด์ผู้บริหาร

## 1. สี (Colors)

| ชื่อ | HEX | ใช้กับ |
|---|---|---|
| Nova Navy (สีหลัก) | `#0B2545` | หัวเรื่อง, แถบหัวสไลด์, พื้นหลังหน้าปก |
| Nova Teal (สีรอง) | `#13A89E` | ตัวเลขที่ดี / ผ่านเป้า, ลิงก์, ไอคอน |
| Spark Orange (สีเน้น) | `#F26B38` | จุดที่ต้องตัดสินใจ, ตัวเลขต่ำกว่าเป้า — ใช้ไม่เกิน 1 จุดต่อหน้า |
| Cloud Gray | `#F4F6F8` | พื้นหลังกล่อง / ตาราง |
| Ink | `#1F2933` | ตัวอักษรเนื้อหา |
| Line Gray | `#CBD2D9` | เส้นตาราง, เส้นแบ่ง |

- ห้ามใช้สีแดงสด (`#FF0000`) และไล่สี (gradient) ในเอกสารลูกค้า
- กราฟ: ซีรีส์หลักใช้ Navy, ซีรีส์เทียบใช้ Teal, เป้าหมายเป็นเส้นประ Line Gray

## 2. ฟอนต์ (Fonts)

- ภาษาไทยและอังกฤษ: **IBM Plex Sans Thai** (Google Fonts, ฟรี)
  - หัวเรื่อง SemiBold 28–36 pt (สไลด์) / 20 pt (เอกสาร)
  - เนื้อหา Regular 16–20 pt (สไลด์) / 11 pt (เอกสาร)
- โค้ด, ตัวเลขในตาราง: **IBM Plex Mono**
- ห้ามใช้ TH Sarabun ในเอกสารภายนอก (ใช้ได้เฉพาะหนังสือราชการที่ลูกค้าบังคับ)

## 3. น้ำเสียง (Tone of Voice)

1. **ตรง ชัด สั้น** — ประโยคแรกของทุกหัวข้อบอกข้อสรุป แล้วค่อยให้รายละเอียด
2. **สุภาพแบบมืออาชีพ** — ใช้ "เรา" แทนโนวาเทค, "ท่าน" หรือ "ธนาคาร" แทนลูกค้า ไม่ใช้ภาษาวัยรุ่น ไม่ใช้อีโมจิในเอกสารภายนอก
3. **ไม่โอ้อวด** — ห้ามคำว่า "ดีที่สุด", "อันดับหนึ่ง", "100%" ให้ใช้หลักฐานแทน เช่น "ส่งมอบตรงเวลา 7 จาก 8 โปรเจกต์ในปี 2025"
4. **คำเทคนิคเขียนอังกฤษได้** (API, SLA, LINE OA) แต่ครั้งแรกให้อธิบายไทยสั้น ๆ ในวงเล็บ
5. ตัวเลขเงินใส่คอมมา หน่วย "บาท" และระบุเสมอว่า "ไม่รวม VAT" หรือ "รวม VAT 7%"

## 4. โครงสไลด์ (Slide Rules)

- อัตราส่วน 16:9, ขอบซ้ายขวา 48 px, โลโก้มุมขวาล่างทุกหน้า (ยกเว้นหน้าปก)
- **1 สไลด์ = 1 ข้อความหลัก** เขียนเป็นหัวสไลด์แบบประโยค เช่น "รายได้ ต.ค. โต 8% แต่กำไรขั้นต้นลดเหลือ 27.1%"
- ไม่เกิน 6 บรรทัดต่อสไลด์ ไม่เกิน 10 สไลด์ต่อชุด (ไม่รวมภาคผนวก)
- สไลด์ประชุมผู้บริหารเรียงแบบนี้เสมอ:
  1. ปก (เดือน + วันประชุม)
  2. **สรุป 3 บรรทัด** (ดี / น่าห่วง / ต้องตัดสินใจ)
  3. ตัวเลขการเงิน (รายได้ กำไรขั้นต้น เทียบเป้า)
  4. Pipeline และดีลที่รออนุมัติ
  5. การส่งมอบโปรเจกต์และเหตุขัดข้อง
  6. คน (headcount, ตำแหน่งว่าง)
  7. เรื่องที่ขอให้ MD ตัดสิน
- ตัวเลขที่ต่ำกว่าเป้าใช้ Spark Orange ตัวเลขที่ผ่านเป้าใช้ Teal

## 5. โครงเอกสาร (Document Rules)

- หน้าปก: โลโก้, ชื่อเอกสาร, ชื่อลูกค้า, วันที่ (พ.ศ. หรือ ค.ศ. ให้ตรงกับลูกค้า), เลขที่เอกสาร `NVT-<ประเภท>-<ปี>-<ลำดับ>` เช่น `NVT-PRP-2026-031`
- ทุกหน้ามีท้ายกระดาษ "โนวาเทค · ข้อมูลลับเฉพาะลูกค้า" และเลขหน้า
- หัวข้อมีเลขลำดับ (1, 1.1) ไม่เกิน 3 ระดับ
- ตาราง: หัวตารางพื้น Navy ตัวอักษรขาว, แถวสลับ Cloud Gray
- Proposal ใช้โครงตาม `won-proposals/` (สรุป → ความเข้าใจ → โซลูชัน → สถาปัตยกรรม → ทีม → แผนงาน → ราคา → SLA → ทำไมต้องโนวาเทค)

## 6. โลโก้ (Logo Usage)

- ไฟล์: `assets/logo.svg` (สี Navy บนพื้นขาว) — ถ้าพื้นเข้มให้ใช้เวอร์ชันสีขาว (เปลี่ยน fill เป็น `#FFFFFF`)
- พื้นที่ว่างรอบโลโก้ ≥ ความสูงตัว "N" ทุกด้าน, ขนาดเล็กสุด กว้าง 96 px / 24 mm
- ห้าม: ยืด บีบ หมุน เปลี่ยนสี ใส่เงา หรือวางบนรูปที่รก
- ชื่อบริษัทเขียน "โนวาเทค" (ไทย) หรือ "Novatech" (อังกฤษ) — ห้าม "NovaTech", "Nova Tech"
