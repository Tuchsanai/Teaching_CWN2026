# meeting-minutes: บันทึกประชุม 1 ครั้ง

## ขั้นตอน

1. รับโน้ตดิบ บทสนทนา หรือไฟล์ถอดเสียงจากผู้ใช้ และถามว่าบันทึกนี้ใช้ภายในหรือจะส่งให้คนนอก
2. เขียนตามโครงด้านล่าง ใช้เฉพาะสิ่งที่อยู่ในต้นทาง ถ้าไม่รู้ผู้รับผิดชอบหรือวันกำหนดให้เขียน `[ยังไม่ระบุ]` อย่าเดา
3. ตรวจข้อมูลส่วนบุคคลด้วย skill `core:customer-data-policy` ตามกติกาของ "บันทึกประชุม" ใน `references/doc-type-rules.md` ของ skill นั้น
4. ถ้าจะส่งให้คนนอก ให้ทำตาม `core:brand-guide` ด้วย
5. บันทึกที่ `work/<YYYY-MM-DD>-minutes-<เรื่อง>.md` แล้วบอกผู้ใช้ว่าจุดไหนยังต้องเติม

## โครงบันทึก

```markdown
# บันทึกประชุม: <เรื่อง>

- **วันที่:** <วัน เวลา>
- **สถานที่:** <สถานที่หรือช่องทาง>
- **จดโดย:** <ชื่อ> (ภายใน หรือ ส่งคนนอก)

## ผู้เข้าประชุม
| ฝั่ง | ชื่อ | ตำแหน่ง |

## สิ่งที่คุยกัน
1. <เรื่องและข้อสรุป>

## งานติดตาม
| # | เรื่อง | ใครทำ | ภายใน |
```

## ต่อจากนี้

ถ้าเป็นการประชุมกับลูกค้าและต้องตามงาน ให้ส่งต่อ `follow-up-email` ในแผนก Sales
