## ระบบที่ทดสอบ

- URL (UAT — ยังไม่มีระบบ ใส่จริงเมื่อขึ้น env `uat`): https://nlp-queue-uat.example
- Health check: `GET /healthz` ต้องตอบ 200 · Readiness: `GET /readyz` (DB + Redis + คิว)
- Reset ข้อมูลทดสอบ (เฉพาะ uat): `POST /api/test/reset`
- ระบบภายนอกใน UAT ใช้ **stub/sandbox**: Customer Lookup API (sandbox ธนาคาร), Q-Matic simulator, LINE (บัญชี OA ทดสอบ), SMS stub ที่อ่านข้อความได้

## ระดับ (Priority)

- **P1** = ต้องผ่านทั้งหมดถึงจะปล่อย (เงื่อนไข TOR / ความปลอดภัย / เงื่อนไขรับมอบ)
- **P2** = ต้องผ่าน ≥ 95%
- **P3** = ควรผ่าน แจ้งเป็นข้อสังเกต

## เกณฑ์ผ่าน (Exit criteria)

- อัตราผ่านรวม ≥ 95% · P1 ผ่านทั้งหมด · P2 พลาดได้ไม่เกิน 1 ข้อ (ผ่านอย่างน้อย 18 จาก 19) · ไม่มีบั๊ก Sev 1/Sev 2 ค้าง
