# Senior Full-stack Developer — โปรเจกต์ระบบจองคิวสาขาธนาคาร

ลูกค้าธนาคารกว่า 120 สาขาต้องรอคิวเฉลี่ย 38 นาที เรากำลังสร้างระบบให้ลูกค้าจองคิวล่วงหน้า และให้สาขารู้ล่วงหน้า 7 วันว่าวันไหนคนจะล้น เรากำลังมองหาคนที่อยากสร้างหน้าจอที่ลูกค้าและพนักงานสาขาใช้จริงทุกวัน ตั้งแต่วันแรกของโปรเจกต์

## สิ่งที่คุณจะได้ทำ
- พัฒนาหน้าจองคิวบนเว็บและ LINE LIFF (หน้าเว็บที่เปิดใน LINE OA ของธนาคาร) ให้จองเสร็จได้ไม่เกิน 4 ขั้น และอ่านง่ายสำหรับผู้สูงอายุ
- สร้าง branch console (หน้าจอสำหรับพนักงานสาขา) ให้ผู้จัดการปรับจำนวนช่องบริการทุกช่วง 15 นาที และเห็นคิวที่ได้รับผลกระทบก่อนยืนยัน
- สร้าง dashboard (หน้าสรุปตัวเลข) เวลารอ จำนวนคิว และผลพยากรณ์ 7 วัน ร่วมกับทีม ML ดูได้ทั้งรายสาขา รายภาค และทั้งประเทศ
- ต่อยอด booking engine (ระบบจัดสรรช่วงเวลาจองคิว) และ slot lock (การล็อกช่วงเวลาไม่ให้จองซ้ำ) ด้วย Redis ร่วมกับ tech lead
- เชื่อม core banking API (ระบบหลักของธนาคาร) ผ่าน mTLS (การยืนยันตัวตนด้วยใบรับรองทั้งสองฝั่ง) และเขียนเทสต์อัตโนมัติด้วย Playwright ให้ระบบรับช่วงคนเยอะได้ทั้ง 120 สาขา

## สิ่งที่เรามองหา
- ประสบการณ์พัฒนาซอฟต์แวร์ 5 ปีขึ้นไป และเคยดูแลระบบที่มีผู้ใช้จริงหลักหมื่นคนขึ้นไป
- ใช้ TypeScript และ Node.js ในงานจริงได้คล่อง
- เคยสร้างงานด้วย Next.js (App Router)
- ออกแบบฐานข้อมูล PostgreSQL ใช้ Redis และ BullMQ (คิวงานเบื้องหลัง) ได้ เข้าใจปัญหาการแย่งข้อมูลพร้อมกัน (concurrency)
- เขียนเทสต์อัตโนมัติ และอธิบายการตัดสินใจทางเทคนิคให้ทีมเข้าใจได้

## จะดีมากถ้ามี
- เคยทำงานกับธนาคารหรือ fintech หรือรู้มาตรฐานความปลอดภัยของธนาคาร
- เข้าใจ PDPA (กฎหมายคุ้มครองข้อมูลส่วนบุคคล)
- เคยพัฒนา LINE OA / LIFF
- เคยเป็น mentor ให้นักพัฒนาในทีม

ไม่ครบทุกข้อก็สมัครได้

## ทีมและวิธีทำงาน
ทีมโปรเจกต์ 9 คน (SA 1 · PM 1 · Senior Developer ที่เป็น tech lead 1 · Developer 2 รวมตำแหน่งนี้ · UX/UI 1 · QA 1 · DevOps 1 · ML 1) คุณจะทำงานกับ tech lead ของโปรเจกต์โดยตรง · ทำงานแบบ Hybrid เข้าออฟฟิศอังคาร + พฤหัส ที่โนวาทาวเวอร์ ถ.พระราม 9 (MRT พระราม 9 เดิน 5 นาที) · ทุกคนใช้ Claude Code พร้อมแพ็ก skill ของทีม · มีไป UAT (ทดสอบรับงาน) ที่ธนาคารประมาณ 4 วัน และผลัด on-call หลังระบบขึ้นจริงประมาณเดือนละ 1 สัปดาห์ (ค่า on-call 3,000 บาท/สัปดาห์)

## สิ่งที่คุณจะได้รับ
- เงินเดือน 75,000 – 105,000 บาท/เดือน ตามประสบการณ์
- เวลาเข้างานยืดหยุ่น 08:00–10:00 น. และ WFH ได้ 3 วัน/สัปดาห์
- พักร้อน 12 วัน/ปีตั้งแต่ปีแรก + หยุดวันเกิด 1 วัน
- ประกันสุขภาพกลุ่ม IPD สูงสุด 100,000 บาท/ครั้ง, OPD 2,000 บาท/ครั้ง, ทันตกรรม 3,000 บาท/ปี
- งบพัฒนาตัวเอง 20,000 บาท/ปี + วันเรียนรู้ 3 วัน/ปี
- MacBook Pro 14" + จอ 27" + ค่าอินเทอร์เน็ต WFH 500 บาท/เดือน
- กองทุนสำรองเลี้ยงชีพ บริษัทสมทบ 5% · โบนัสประจำปี (ปี 2025 เฉลี่ย 1.8 เดือน)
