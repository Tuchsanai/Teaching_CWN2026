## 3. เรื่อง ML — ห้ามสัญญาเกินหลักฐาน

- ใน `company-kit/ml-queue-forecast/` มีผลทดลองบนข้อมูลเกษตรไทย: r02 MAPE 19.8%, r03 MAPE 15.2% — **เป็นผลทดลอง ไม่ใช่ผลงานจริง** และ r03 เปลี่ยน data version (ตัด 2 สาขา, ลบแถวซ้ำ) ยังไม่ได้เทียบแบบแฟร์, ไม่ได้ fix seed, ยังไม่ลง MLflow, ไม่มี monitoring
- ข้อมูลเกษตรไทยเป็นของลูกค้ารายอื่น — ใช้ได้แค่เป็นวิธีการ ห้ามส่งข้อมูลดิบหรืออ้างตัวเลขของเขาให้นครหลวงฯ
- proposal จึงเขียนแค่ "เปิดใช้เมื่อผ่าน MAPE ≤ 20% บนข้อมูลของธนาคาร" + shadow mode + เกณฑ์ถอยกลับ ไม่อ้างตัวเลขผลทดลอง
- **ความเสี่ยง:** เราไม่เห็นข้อมูลนครหลวงฯ จนหลังเซ็นสัญญา ถ้าข้อมูลคุณภาพต่ำ อาจไม่ผ่าน 20% → เสนอให้สัญญากำหนดเงื่อนไขคุณภาพข้อมูล (ครบ 24 เดือน, ส่งภายในสัปดาห์ที่ 3) · จุดอ่อนที่รู้: พยากรณ์ต่ำกว่าจริงช่วงเที่ยง −20 ถึง −30% ในสาขาย่านออฟฟิศ จึงใส่การรายงานแยกช่วงเวลาไว้ในข้อ 4.3
- ทีม ML ภายใน (`ml-jay`, `ml-pim`) ควรรีวิวข้อ 4.3 ก่อนยื่น
