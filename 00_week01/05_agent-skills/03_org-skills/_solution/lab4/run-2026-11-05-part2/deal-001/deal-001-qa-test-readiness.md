# deal-001 — QA ตรวจความพร้อมของแผนทดสอบ

> เอกสารภายใน ห้ามส่งลูกค้า · ผู้ตรวจ: QA (`qa-mint`) · 2026-11-05
> อ่านจาก: `deal-001-proposal-nakhonluang.md` (หัวข้อ 4.2, 4.3, 5, 6, 7), `deal-001-sa-response-r2.md`, `approval.md` (รอบ 3), `company-kit/deal-001/tor-bank-queue.md`, `company-kit/customer-data-policy.md`, `company-kit/deploy-runbook.md`

## คำตอบ: ยังรันไม่ได้

1. **ไม่มีแผนทดสอบให้รัน** — โฟลเดอร์ดีลไม่มี `TEST-PLAN.md` (และไม่มีไฟล์ไหนที่มี URL ระบบ, test case หรือข้อมูลทดสอบ) skill `test-from-plan` เลยไม่มีอะไรให้อ่าน
2. **ยังไม่มีระบบให้ทดสอบ** — ดีลนี้อยู่ขั้นยื่นข้อเสนอ (ยื่น 13 พ.ย. 2026) ลงนามสัญญาคาดว่า 4 ม.ค. 2027 ระบบบน uat จะมีครั้งแรกเดือน ก.พ. 2027
3. สิ่งที่มีตอนนี้คือ **แผนการทดสอบในระดับ proposal** (หัวข้อ 6 เดือน 3–5) ซึ่งผมตรวจแล้วตามด้านล่าง: **ใช้ยื่นได้ แต่มี 3 จุดที่ต้องแก้หรือตกลงกับธนาคารก่อนเริ่มเขียน test plan จริง** (Q1–Q3) เพราะเกี่ยวกับงวดเงิน 40% และวันนำร่อง

ไม่ได้รัน test ใด ๆ และไม่ได้แก้ไฟล์อื่นในดีล
