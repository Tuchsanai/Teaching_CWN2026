## 5. แผน rollback

**rollback ทันทีถ้า:** smoke test ข้อใดไม่ผ่านและแก้ไม่ได้ใน 15 นาที · error rate > 5% ต่อเนื่อง 5 นาที · **ข้อมูลผิดแม้รายการเดียว** — ในระบบนี้หมายถึง:
- slot ถูกจองซ้ำ (2 คนได้ slot เดียวกัน) หรือคิวผิดสาขา/ผิดเวลา/ผิดประเภทบริการ
- ลำดับคิวผู้จองกับ walk-in เพี้ยน หรือเรียกคิวข้ามโดยไม่มีเหตุ
- **บัญชี LINE ผูกกับลูกค้าผิดคน / CIF ผิดคน** หรือแจ้งเตือนส่งผิดคน → นอกจาก rollback ต้องแจ้ง `plat-may` ภายใน 1 ชั่วโมง เพราะอาจเป็นเหตุละเมิดข้อมูลตามภาคผนวก ก ข้อ 3
- การค้นข้อมูลลูกค้าไม่ถูกบันทึก audit log
