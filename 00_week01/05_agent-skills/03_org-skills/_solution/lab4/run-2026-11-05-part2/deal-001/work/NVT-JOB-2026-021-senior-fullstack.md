# Senior Full-stack Developer — โปรเจกต์ระบบจองคิวสาขาธนาคาร

ลูกค้าธนาคารที่มีสาขากว่า 100 แห่งต้องรอคิวที่สาขาเฉลี่ยเกือบ 40 นาที เรากำลังสร้างระบบให้ลูกค้าจองคิวล่วงหน้า และให้สาขารู้ล่วงหน้า 7 วันว่าวันไหนคนจะล้น เรากำลังมองหาคนที่อยากเป็นแกนหลักของงานนี้ตั้งแต่วันแรกของโปรเจกต์

## สิ่งที่คุณจะได้ทำ
- ออกแบบและสร้าง booking engine (ระบบจัดสรรช่วงเวลาจองคิว) พร้อม slot lock (การล็อกช่องเวลา) ด้วย Redis ไม่ให้คิวเดียวกันถูกจองซ้ำ
- พัฒนาหน้าจองคิวบนเว็บและ LINE LIFF (หน้าเว็บที่เปิดใน LINE OA ของธนาคาร) ให้ลูกค้าจอง เลื่อน และยกเลิกคิวได้
- เชื่อม core banking API (ระบบหลักของธนาคาร) ผ่าน mTLS (การยืนยันตัวตนด้วยใบรับรองทั้งสองฝั่ง) และเชื่อมตู้กดบัตรคิวเดิมของสาขา โดยไม่แก้ระบบเดิม
- ทำให้ระบบรองรับการใช้งานพร้อมกันทุกสาขา ด้วยงานเบื้องหลังผ่าน BullMQ (ระบบคิวงาน) และทดสอบอัตโนมัติด้วย Playwright
- ทำงานร่วมกับทีม ML นำผลพยากรณ์ปริมาณคิวขึ้น dashboard ของผู้จัดการสาขา

## สิ่งที่เรามองหา
- ประสบการณ์พัฒนาซอฟต์แวร์ 5 ปีขึ้นไป และเคยดูแลระบบที่มีผู้ใช้จริงหลักหมื่นคนขึ้นไป
- ใช้ TypeScript และ Node.js ในงานจริงได้คล่อง
- เคยสร้างงานด้วย Next.js (App Router)
- ออกแบบฐานข้อมูล PostgreSQL และใช้ Redis ได้ เข้าใจปัญหาการแย่งข้อมูลพร้อมกัน (concurrency)
- เขียนเทสต์อัตโนมัติ และอธิบายการตัดสินใจทางเทคนิคให้ทีมเข้าใจได้

## จะดีมากถ้ามี
- เคยทำงานกับธนาคารหรือ fintech หรือรู้มาตรฐานความปลอดภัยของธนาคาร
- เข้าใจ PDPA (กฎหมายคุ้มครองข้อมูลส่วนบุคคล)
- เคยพัฒนา LINE OA / LIFF
- เคยเป็น mentor ให้นักพัฒนาในทีม

ไม่ครบทุกข้อก็สมัครได้

## ทีมและวิธีทำงาน
ทีมโปรเจกต์ 9 คน (Dev 3 · UX/UI 1 · QA 1 · DevOps 1 · ML 1 · Solution Architect 1 · PM 1) นำโดยคุณปอนด์ เจริญกิจ (tech lead) · ทำงานแบบ Hybrid เข้าออฟฟิศอังคาร + พฤหัส ที่โนวาทาวเวอร์ ถ.พระราม 9 (MRT พระราม 9 เดิน 5 นาที) · ทุกคนใช้ Claude Code พร้อมแพ็ก skill ของทีม · มีไปประชุมและ UAT (ทดสอบรับงาน) ที่ธนาคารเป็นบางช่วง (เบิกค่าเดินทางได้) และผลัด on-call หลังระบบขึ้นจริงประมาณเดือนละ 1 สัปดาห์ (ค่า on-call 3,000 บาท/สัปดาห์)

## สิ่งที่คุณจะได้รับ
- เงินเดือน 75,000 – 105,000 บาท/เดือน ตามประสบการณ์
- เวลาเข้างานยืดหยุ่น 08:00–10:00 น. และ WFH ได้ 3 วัน/สัปดาห์
- พักร้อน 12 วัน/ปีตั้งแต่ปีแรก + หยุดวันเกิด 1 วัน
- ประกันสุขภาพกลุ่ม IPD สูงสุด 100,000 บาท/ครั้ง, OPD 2,000 บาท/ครั้ง, ทันตกรรม 3,000 บาท/ปี
- งบพัฒนาตัวเอง 20,000 บาท/ปี + วันเรียนรู้ 3 วัน/ปี
- MacBook Pro 14" + จอ 27" + ค่าอินเทอร์เน็ต WFH 500 บาท/เดือน
- กองทุนสำรองเลี้ยงชีพ บริษัทสมทบ 5% · โบนัสประจำปีตามผลงาน (ปี 2025 เฉลี่ย 1.8 เดือน)
