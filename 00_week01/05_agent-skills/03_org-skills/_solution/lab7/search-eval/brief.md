# งาน: เขียนคำสั่งงานแบบที่พนักงานจริงพิมพ์ (ชุดทดสอบที่ผู้เขียน skill ไม่เคยเห็น)

อ่าน C:/t/org05/lab7/heldout/roles.json (บทบาทและงานที่ทำซ้ำของพนักงาน 20 คนในบริษัทซอฟต์แวร์ไทย)
สำหรับแต่ละคน เขียนคำสั่งภาษาไทยแบบที่คนนั้นจะพิมพ์ถาม AI ในวันทำงานจริง 3 ข้อ ให้หลากหลาย: แบบสั้นห้วน, แบบเล่าสถานการณ์, แบบใช้ศัพท์ภาษาอังกฤษปน
