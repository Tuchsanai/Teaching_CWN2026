## 4. ข้อควรระวังเรื่องคำกล่าวอ้าง

- ในประชุม 28 ต.ค. นิดาตอบคุณศิริพรว่า "ผ่าน pentest ทุกครั้ง" และ proposal 2024 เขียน "ทำระบบให้สถาบันการเงินมาแล้ว 6 โครงการ ผ่าน pentest ทุกครั้ง" — **ข้อเท็จจริงที่อ้างได้ (winning-patterns) มีแค่ Loan Tracking Portal ผ่าน pentest ของธนาคาร** จึงอ้างแค่นั้น ถ้าจะส่ง "หลักฐาน" ตามที่นิดารับปาก ต้องหาเอกสารผล pentest จริงที่เปิดเผยได้ (ได้รับอนุญาตจากลูกค้าเดิม)
- ไม่ใส่มูลค่าสัญญาลูกค้าเก่าในเอกสาร (ทำตามแล้ว)
- เป้า "เริ่มตรวจสอบภายใน 2 วันทำการ" เขียนเป็นเป้าหมายที่ระบบออกแบบให้รองรับ ไม่ใช่คำสัญญา (ขึ้นกับกำลังคนของธนาคาร)
- PCI DSS: พอร์ทัลรับเลขบัตรเต็มตอน login แล้วส่งต่อ CardLink → ระบบยังอยู่ในขอบเขต PCI (ส่งผ่านข้อมูลบัตร) แม้ไม่เก็บ ไม่ได้เขียนในเอกสารว่า "ไม่อยู่ในขอบเขต PCI" — ให้ SA ถาม IT Security ธนาคารว่าต้องผ่านการประเมินอะไรเพิ่ม (ASV scan, QSA) ซึ่งอาจกระทบราคา
