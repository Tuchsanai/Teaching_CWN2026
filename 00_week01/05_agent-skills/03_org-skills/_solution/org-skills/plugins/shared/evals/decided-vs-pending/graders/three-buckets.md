criteria: >-
  ฉบับภายในแยกเรื่องเป็น ตัดสินแล้ว / action item (รับปากว่าจะทำ) / คำถามค้าง (หรือ "ยังไม่ได้ข้อสรุป") ได้ถูก ดังนี้
  (1) หมวดตัดสินแล้วมีแค่เรื่องย้ายขึ้น PostgreSQL 16 ที่ ops-art อนุมัติ
  (2) dev-pond เขียน migration script ภายในศุกร์ 13 พ.ย. 2026 อยู่ในหมวด action item
  (3) ระยะเก็บ backup อยู่ในหมวดคำถามค้าง
  (4) วัน window ย้าย (เสาร์ 21 พ.ย.) อยู่ในหมวดคำถามค้าง หรือเป็น action item ให้ยืนยันวัน — ห้ามอยู่ในหมวดตัดสินแล้ว
  (5) read replica อยู่ในหมวดคำถามค้าง / ยกไปคุยครั้งหน้า หรือไม่ถูกจัดหมวดเลยก็ได้ — ห้ามอยู่ในหมวดตัดสินแล้ว
