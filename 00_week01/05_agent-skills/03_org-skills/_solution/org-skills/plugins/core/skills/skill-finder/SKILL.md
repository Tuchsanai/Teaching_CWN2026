# skill-finder — หา skill และดูผลกระทบ

`SKILL_DIR` = โฟลเดอร์ของ skill นี้ · ข้อมูลทั้งหมดอยู่ใน `references/catalog.md` (สร้างจาก header ของทุก SKILL.md ด้วย `scripts/build_catalog.py` ของคลัง — ห้ามแก้มือ)

## ขั้นตอน

1. **อ่าน `references/catalog.md`** ทั้งไฟล์ (ตาราง skill + ตารางผลกระทบ)
2. ตอบตามคำถาม
   - **"มี skill สำหรับ X ไหม"** → เทียบงานกับคำอธิบาย เลือก 1–3 ตัวที่ใกล้สุด บอก: ชื่อ · plugin · เจ้าของ · คำสั่งติดตั้ง `/plugin install <plugin>@novatech-skills` · ประโยคที่ใช้เรียก · ถ้าไม่มีตัวไหนตรง ให้บอกตรง ๆ ว่าไม่มี และเสนอว่าใกล้สุดคืออะไร/ควรเสนอให้แผนกไหนสร้าง (ห้ามแต่งชื่อ skill ที่ไม่มีในแค็ตตาล็อก)
   - **"แผนกอื่นทำเรื่องนี้ยังไง"** → ชี้ skill ของแผนกนั้น + ลำดับงาน (`follows` = กติกาที่ต้องทำตาม, `next` = งานถัดไป) — ผู้ใช้ไม่ต้องติดตั้งแพ็กแผนกอื่น ถ้าแค่อยากรู้วิธี
   - **"ถ้าแก้ skill X กระทบใคร"** → ดูตารางผลกระทบ: skill ที่ `uses` X (เรียกใช้ตรง ๆ — กระทบแรงสุด), skill ที่ `follows` X (ถ้า X เป็นกติกาใน core กระทบทุกตัวในรายการ), skill ที่มี X ใน `next` (ส่งงานต่อมาให้ X — กระทบรูปแบบ input) · บอก CODEOWNER ที่ต้อง approve PR
   - **"คนใหม่แผนก Y ต้องใช้อะไร"** → แพ็ก `core` + แพ็กของแผนก Y เท่านั้น (ไม่ติดแพ็กแผนกอื่น กัน skill เยอะจนหยิบผิด) · `shared` ติดเพิ่มได้ถ้างานข้ามแผนก เช่น จดบันทึกประชุม
3. ตอบสั้น เป็นตาราง ถ้ามีมากกว่า 1 ตัว

## ชั้นของ skill (layer)

| layer | อยู่ plugin | คือ |
|---|---|---|
| `core` | `core` | กติกา/เครื่องมือที่ทุกคนต้องใช้ (PDPA, แบรนด์, ราคา, หา skill) — ติดตั้งให้ทุกคน |
| `shared` | `shared` | งานข้ามแผนกที่หลายแผนกทำเหมือนกัน (เช่น บันทึกประชุม) |
| `department` | ชื่อแผนก | งานเฉพาะแผนก เจ้าของ = คนในแผนก, CODEOWNER = หัวหน้าแผนก |
