## กติกาเขียน requirement
- รหัส `FR-<MOD 3 ตัว>-NN` เช่น `FR-BKG-01` · NFR `NFR-<SEC|PRF|AVL|OPS|DAT|UX>-NN` · รหัสอยู่คอลัมน์แรกของแถวตาราง (สคริปต์อ่านจากตรงนี้)
- ระดับ: **M** TOR เขียน · **S** TOR ไม่เขียนแต่จำเป็น (ที่มา = `GAP`) · **C** ทางเลือก
- 1 แถว = 1 พฤติกรรมที่ทดสอบได้ มีตัวเลข/เงื่อนไขชัด (เวลา, จำนวน, รหัส error)
- ค่าที่มาจากสมมติฐาน เขียนต่อท้าย *(Q-NN)* · ค่าที่มาจากมาตรฐานบริษัท ที่มา = "มาตรฐานบริษัท" / "arch-standards 3"
- ห้ามรวม 2 เรื่องในแถวเดียวถ้าทดสอบแยกกัน (เช่น จอง กับ ยกเลิก)
