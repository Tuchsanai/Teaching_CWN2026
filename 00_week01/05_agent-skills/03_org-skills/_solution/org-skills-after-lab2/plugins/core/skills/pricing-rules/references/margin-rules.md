# กฎกำไรและส่วนลด (สรุปสำหรับ skill)

> สรุปจาก `company-kit/margin-rules.md` v2026.1 (เจ้าของ: fin-joy, มีผล 2026-01-01) · ราคา/ต้นทุนจาก `company-kit/price-list.csv` (สำเนาอยู่ใน `price-list.csv` ข้างกัน)
> ถ้าเครื่องนี้มี company-kit ที่ใหม่กว่า ให้ถือต้นฉบับ

## แหล่งราคา
- ทุกบรรทัดต้องมาจาก `price-list.csv` (`unit_price_thb`, `cost_thb`) — ห้ามตั้งราคาเอง
- ของนอกตาราง (license เฉพาะลูกค้า, ค่า API ผู้ผลิต ฯลฯ) = ต้นทุนจริงจากใบเสนอราคาผู้ขาย + **≥ 20%** + เขียนหมายเหตุ

## สูตร
```
ราคาขายรวม (ไม่รวม VAT) = Σ(จำนวน × unit_price_thb) − ส่วนลด
ต้นทุนรวม              = Σ(จำนวน × cost_thb)
กำไรขั้นต้น             = ราคาขายรวม − ต้นทุนรวม
Gross margin (%)       = กำไรขั้นต้น / ราคาขายรวม × 100      ← หลังหักส่วนลดเสมอ
```
- งาน **fixed-price** บวก **risk buffer 10%** ในจำนวน man-day ทุกบทบาท (ไม่แยกบรรทัดให้ลูกค้าเห็น) — script ปัดขึ้นเป็นวันเต็ม

## เกณฑ์ margin
| Gross margin | ผล | ผู้อนุมัติ |
|---|---|---|
| ≥ 25% | ผ่าน | หัวหน้าทีมขาย (`sales-nida`) |
| 15% – < 25% | ต้องให้ MD อนุมัติ + เหตุผลเชิงกลยุทธ์ (ลูกค้าใหม่ต่อยอดได้, reference) | MD (`md-somchai`) |
| < 15% | **ปฏิเสธ** ไม่ส่งลูกค้า ห้ามขอยกเว้น | — |

เป้า margin เฉลี่ยบริษัทปี 2026 = **30%**

## ส่วนลด (เทียบราคาตาม price-list)
| ส่วนลด | ใครให้ได้ |
|---|---|
| ≤ 5% | เซลส์เจ้าของดีล |
| > 5% – 10% | หัวหน้าทีมขาย |
| > 10% | MD เท่านั้น และ margin หลังลดต้อง ≥ 15% |

- **ห้ามลด MA (`MA-*`) และ cloud hosting (`CL-*`)** — ต้นทุนผูกกับผู้ให้บริการ
- ส่วนลดเป็นบรรทัดแยก **"ส่วนลดพิเศษ"** ห้ามแอบลดในราคาต่อหน่วย
- script คิด % ส่วนลดจาก "ยอดที่ลดได้" = ทุกบรรทัดยกเว้น MA/CL (ค่าแรง + license + ของนอกตาราง) — เข้มกว่าการหารยอดรวม · สรุปดีลเก่าบางใบหารด้วยค่าพัฒนาอย่างเดียว (DS-2026-031: 8.3% vs script 7.9%) ตัวเลขอาจต่างเล็กน้อยแต่ต้องตกขั้นสิทธิ์เดียวกัน ถ้าตกคนละขั้นให้ยึดตัวที่เข้มกว่า

## VAT และการแสดงผล
- ราคาใน price-list ไม่รวม VAT
- เอกสารลูกค้าแสดง 3 บรรทัดเสมอ: `รวมก่อน VAT` → `VAT 7%` → `รวมทั้งสิ้น` · VAT = ก่อน VAT × 0.07 ปัด 2 ตำแหน่ง
- **ห้ามแสดงต้นทุนและ margin ในเอกสารที่ส่งลูกค้า**
