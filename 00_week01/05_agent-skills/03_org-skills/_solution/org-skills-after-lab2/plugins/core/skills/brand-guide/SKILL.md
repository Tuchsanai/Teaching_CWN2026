## ขั้นตอน

1. **รู้ประเภทเอกสาร** — สไลด์ / เอกสาร (proposal, รายงาน, ใบแจ้งหนี้) / อีเมล / ประกาศ (JD, NOTICE) · ภายนอกหรือภายใน (ภายในใช้แค่ข้อ 3 น้ำเสียง + ข้อ 6 ชื่อบริษัท)
2. **อ่าน `references/brand-guide.md`** หัวข้อที่ตรงประเภท — สไลด์ = ข้อ 1, 2, 4, 6 · เอกสาร = ข้อ 1, 2, 5, 6 · อีเมล/ประกาศ = ข้อ 3, 6
3. **ไล่ checklist ขั้นต่ำ** (ใช้ได้กับทุกเอกสารส่งออก)
   - [ ] ประโยคแรกของทุกหัวข้อ = ข้อสรุป
   - [ ] "เรา" แทนโนวาเทค · "ท่าน"/"ธนาคาร" แทนลูกค้า · ไม่มีภาษาวัยรุ่น ไม่มีอีโมจิ
   - [ ] ไม่มี "ดีที่สุด", "อันดับหนึ่ง", "100%" — ใช้หลักฐาน/ตัวเลขแทน
   - [ ] คำเทคนิคอังกฤษครั้งแรกมีคำอธิบายไทยในวงเล็บ
   - [ ] เงินมีคอมมา + "บาท" + ระบุ "ไม่รวม VAT" หรือ "รวม VAT 7%"
   - [ ] ชื่อบริษัท "โนวาเทค" / "Novatech" เท่านั้น (ห้าม NovaTech, Nova Tech)
   - [ ] ไม่มีสีแดงสด `#FF0000` ไม่มี gradient · ไม่ใช้ TH Sarabun (ยกเว้นหนังสือราชการที่ลูกค้าบังคับ)
   - [ ] เอกสาร: เลขที่ `NVT-<ประเภท>-<ปี>-<ลำดับ>` · ท้ายกระดาษ "โนวาเทค · ข้อมูลลับเฉพาะลูกค้า" + เลขหน้า
4. **ตอบผล** เป็นตาราง `# | จุด | เดิม | ควรเป็น | ข้อในคู่มือ` เรียงจากที่ลูกค้าเห็นก่อน (หัวเรื่อง, บรรทัดแรก) แล้วตามด้วยฉบับแก้ถ้าผู้ใช้ขอ (แยกไฟล์ ห้ามเขียนทับต้นฉบับของคนอื่น)

- ให้ระบุใน header ว่า `follows: [brand-guide]` และเขียนในขั้นตอนว่า "ทำตาม `brand-guide`" — **ห้ามคัดลอกสี/ฟอนต์/น้ำเสียงไปไว้ใน references ของตัวเอง** (เคยคัดลอกไว้ 7 ที่ แล้วเวอร์ชันไม่ตรงกัน)
