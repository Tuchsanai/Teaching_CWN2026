# โครงการพอร์ทัลยื่นคำร้องโต้แย้งรายการบัตรเครดิต (Card Dispute Portal)

**ธนาคารเอเชียไทยสากล จำกัด (มหาชน)** — ฝ่ายปฏิบัติการบัตรเครดิต
เลขที่ TOR: ATI-IT-2026-052 · ออกเมื่อ 15 ตุลาคม 2026
กำหนดยื่นข้อเสนอ: **ภายในวันที่ 20 พฤศจิกายน 2026**

## 1. ความเป็นมา

ปัจจุบันผู้ถือบัตรที่ต้องการโต้แย้งรายการ (เช่น ถูกเรียกเก็บซ้ำ, ไม่ได้รับสินค้า, ไม่ได้ทำรายการเอง) ต้องกรอกแบบฟอร์มกระดาษหรือส่งอีเมลมาที่ call center มีคำร้องประมาณ 3,500 รายการ/เดือน ใช้เวลาเฉลี่ย 9 วันกว่าจะเริ่มตรวจสอบ เพราะข้อมูลไม่ครบและต้องโทรตามเอกสาร

## 2. วัตถุประสงค์

1. ให้ผู้ถือบัตรยื่นคำร้องโต้แย้งรายการออนไลน์ได้ครบในครั้งเดียว
2. ลดเวลาเริ่มตรวจสอบจาก 9 วันเหลือไม่เกิน 2 วันทำการ
3. ติดตามสถานะคำร้องได้เองโดยไม่ต้องโทร call center

## 3. ขอบเขตงาน

### 3.1 ฝั่งผู้ถือบัตร (เว็บ responsive)
- เข้าสู่ระบบด้วยเลขบัตร 16 หลัก + วันเดือนปีเกิด + OTP ทาง SMS
- เลือกรายการที่ต้องการโต้แย้งจากรายการย้อนหลัง 120 วัน (ดึงจากระบบบัตร)
- เลือกเหตุผล 6 ประเภทตามมาตรฐานเครือข่ายบัตร พร้อมคำถามเพิ่มเติมตามประเภท
- แนบหลักฐาน (PDF/JPG/PNG สูงสุด 5 ไฟล์ ไฟล์ละไม่เกิน 10 MB)
- ติดตามสถานะ 5 ขั้น และรับแจ้งเตือนทาง SMS/อีเมล

### 3.2 ฝั่งเจ้าหน้าที่
- คิวคำร้อง, มอบหมายงาน, ขอเอกสารเพิ่ม, บันทึกผล
- SLA timer ตามกฎเครือข่ายบัตร (เตือนเมื่อเหลือ 5 วันก่อนครบกำหนด)
- SSO ด้วย Active Directory ของธนาคาร

### 3.3 การเชื่อมต่อ
- ระบบบัตรเครดิต (CardLink) — ดึงรายการบัญชีบัตรและสร้างเคส dispute ผ่าน REST API
- SMS gateway และ email gateway ของธนาคาร

## 4. ข้อกำหนดด้านความปลอดภัย

- เป็นไปตาม PCI DSS: ห้ามเก็บเลขบัตรเต็มในระบบใหม่ (ใช้ token จาก CardLink), แสดงเลขบัตรแบบ 4 หลักท้ายเท่านั้น
- เข้ารหัสข้อมูลขณะส่งและขณะจัดเก็บ, audit log เก็บ 2 ปี
- ปฏิบัติตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
- ผ่าน penetration test ก่อนเปิดใช้งาน
