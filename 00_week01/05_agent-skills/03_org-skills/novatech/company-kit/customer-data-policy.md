# นโยบายข้อมูลลูกค้า (Customer Data Policy) v1.4

> ผู้ดูแล: เมย์ อรุณรัตน์ (`plat-may`) ทีมกลาง · อ้างอิง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) · ปรับปรุงล่าสุด 2026-03-10
> ใช้กับ: ทุกคนที่เขียนเอกสาร อีเมล สไลด์ ใบแจ้งหนี้ รายงานบั๊ก หรือข้อมูลทดสอบ ที่แตะข้อมูลลูกค้า

## 1. อะไรคือข้อมูลส่วนบุคคล

ข้อมูลที่ระบุตัวบุคคลได้ ทั้งทางตรงและทางอ้อม เช่น
- ชื่อ-นามสกุล, เลขบัตรประชาชน, เลขหนังสือเดินทาง
- เบอร์โทรศัพท์มือถือส่วนตัว, อีเมลส่วนตัว, ที่อยู่บ้าน
- เลขบัญชีธนาคาร, เลขบัตรเครดิต/เดบิต, เลขที่สัญญาสินเชื่อ, CIF (เลขลูกค้าในระบบธนาคาร)
- ภาพใบหน้า, IP address, ตำแหน่ง GPS, ประวัติการทำธุรกรรม
- **ข้อมูลอ่อนไหว** (มาตรา 26): ศาสนา สุขภาพ ประวัติอาชญากรรม ข้อมูลชีวภาพ — ห้ามเก็บถ้าไม่จำเป็นจริง

"ลูกค้า" ในนโยบายนี้มี 2 ระดับ:
- **ลูกค้าองค์กร** = บริษัท/ธนาคารที่จ้างเรา และพนักงานของเขาที่ติดต่อกับเรา
- **ลูกค้าปลายทาง (end customer)** = ประชาชนที่ใช้ระบบที่เราสร้าง เช่น ลูกค้าของธนาคาร

## 2. ห้ามเด็ดขาดในเอกสารที่ส่งออกนอกบริษัท

ห้ามใส่ข้อมูลต่อไปนี้ **แบบเต็ม** ใน proposal, ใบแจ้งหนี้, อีเมลถึงลูกค้า, สไลด์, รายงาน, ประกาศ หรือไฟล์ที่แชร์ให้คนนอก
1. **เลขบัตรประชาชน** ของใครก็ตาม
2. **เบอร์โทรศัพท์ส่วนตัว (มือถือ)** ของบุคคล — ทั้งลูกค้าปลายทาง และพนักงานของลูกค้าองค์กร (ใช้เบอร์สำนักงาน/อีเมลบริษัทแทน)
3. **เลขบัญชี / เลขบัตร** ของลูกค้าปลายทาง
4. ชื่อ-นามสกุลของลูกค้าปลายทาง (ใช้รหัสเคส เช่น `CASE-2026-0815` แทน)

เบอร์มือถือที่ลูกค้าให้ในที่ประชุมหรือใน TOR → เก็บใน CRM ภายในเท่านั้น ไม่คัดลอกลงเอกสาร

## 3. วิธีปิดบัง (Masking)

| ข้อมูล | ตัวอย่างเต็ม (ห้าม) | แบบปิดบัง (ใช้ได้) |
|---|---|---|
| เบอร์มือถือ | 081-234-4567 | `081-XXX-4567` |
| เลขบัตรประชาชน | 1-1037-01234-56-3 | `1-XXXX-XXXXX-XX-3` |
| เลขบัญชี | 123-4-56789-0 | `XXX-X-X6789-X` |
| เลขบัตรเครดิต | 4111 1111 1111 1234 | `4111 XXXX XXXX 1234` |
| อีเมลส่วนตัว | somying.jai@gmail.com | `s*****@gmail.com` |

- ในเอกสารภายนอก ถ้าไม่จำเป็นต้องอ้างถึงเลย **ให้ตัดทิ้ง** ดีกว่าปิดบัง
- ภาพหน้าจอ (screenshot) ที่มีข้อมูลข้างต้นต้องเบลอก่อนแนบ

## 4. ข้อมูลทดสอบและข้อมูลจริง

- ข้อมูลทดสอบต้องเป็นข้อมูลสังเคราะห์ (synthetic) เท่านั้น ห้ามคัดลอกฐานข้อมูลจริงของลูกค้ามาเครื่องตัวเอง
- log และรายงานบั๊กห้ามมีเลขบัตร/เบอร์/เลขบัญชีจริง — ถ้าเจอใน log ให้แจ้ง DevOps ปิดบังที่ระดับ logger
- การเข้าถึงข้อมูลจริงใน production ต้องขอผ่าน ticket และมีผู้อนุมัติฝั่งลูกค้า

## 5. การเก็บรักษา (Retention)

| ข้อมูล | เก็บนานเท่าไร | ที่ไหน |
|---|---|---|
| TOR, proposal, สัญญา | 5 ปีหลังจบสัญญา | ไดรฟ์ฝ่ายขาย (สิทธิ์เฉพาะ Sales + MD) |
| ข้อมูลติดต่อลูกค้าองค์กร | ตลอดช่วงมีความสัมพันธ์ + 2 ปี | CRM |
| สำเนาข้อมูลลูกค้าปลายทางที่ได้รับระหว่างโครงการ | ลบภายใน 90 วันหลังส่งมอบ | — |
| ใบแจ้งหนี้, เอกสารบัญชี | 5 ปี (ตามกฎหมายบัญชี) | ระบบบัญชี |
