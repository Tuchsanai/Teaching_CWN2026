# สรุปดีล DS-2026-031 — ระบบติดตามรถขนส่ง (Fleet Tracking)

| ช่อง | ค่า |
|---|---|
| ลูกค้า | บริษัท ไทยโลจิสติกส์ครบวงจร จำกัด (ลูกค้าเดิม ทำ MA กับเรา 2 ปี) |
| ประเภทลูกค้า | เอกชน — ขนส่ง (ไม่ใช่สถาบันการเงิน) |
| เซลส์เจ้าของดีล | กฤต ธนากร · หัวหน้า: นิดา แก้วมณี |
| คิดราคาโดย | จอย พัฒนสิน · 2026-10-27 |
| ส่งถึง MD | 2026-10-29 |

## ขอบเขต
เว็บ + แอปคนขับ ติดตามรถ 450 คันแบบเรียลไทม์, แจ้งเตือนออกนอกเส้นทาง, รายงานน้ำมัน, เชื่อม GPS box เดิม (ผู้ผลิตมี API)

## ตัวเลข (ไม่รวม VAT)

| รายการ | ราคาขาย | ต้นทุน |
|---|---|---|
| ค่าพัฒนา (SA 12, PM 25, Dev-Sr 35, Dev 90, UX 10, QA 30, DevOps 10 man-day) | 2,661,000 | 1,683,500 |
| Cloud hosting Medium (CL-M) 12 เดือน | 540,000 | 384,000 |
| MA Standard (MA-STD) 1 ปี | 360,000 | 220,000 |
| ค่า API GPS box ของผู้ผลิต 1 ปี (ของภายนอก ต้นทุน + 20%) | 120,000 | 100,000 |
| ส่วนลดพิเศษ (8.3% ของค่าพัฒนา, หัวหน้าทีมขายอนุมัติแล้ว) | −221,000 | — |
| **รวม** | **3,460,000** | **2,387,500** |

- กำไรขั้นต้น 1,072,500 บาท · **Gross margin = 1,072,500 / 3,460,000 = 31.0%**
- VAT 7% = 242,200 · รวมทั้งสิ้น 3,702,200 บาท

## แผนงานและทีม
- 5 เดือน (ม.ค. – พ.ค. 2027) · ทีม 6 คน · man-day รวม 212 วัน (รวม buffer 10% แล้ว)
- ใช้ทีมชุดเดียวกับที่ทำ MA ให้ลูกค้านี้อยู่ (รู้ระบบเดิม) · SA ไอศวรรย์ ถือ 1 โปรเจกต์ในช่วงนั้น
- UAT 3 สัปดาห์ (เม.ย. 2027)

## เงื่อนไขชำระเงิน
30% เซ็นสัญญา / 40% ผ่าน UAT / 30% go-live · เครดิตเทอม 30 วัน · MA + hosting เก็บล่วงหน้ารายปี

## สัญญาและความเสี่ยง
- ค่าปรับล่าช้า 0.1%/วัน เพดาน 5% ของมูลค่าสัญญา
- ความเสี่ยงหลัก: API ของ GPS box ผู้ผลิตจำกัด 10 request/วินาที → แก้ด้วยคิว + batch (มีใน spec แล้ว)
- เอกสารไม่มีข้อมูลส่วนบุคคลของคนขับ (ใช้รหัสคนขับ)

## เซลส์ขอ
อนุมัติให้ส่งใบเสนอราคาภายใน 5 พ.ย. 2026 (ลูกค้าจะเข้าบอร์ด 12 พ.ย.)
