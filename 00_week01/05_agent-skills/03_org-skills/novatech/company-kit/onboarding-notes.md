# โน้ตต้อนรับพนักงานใหม่ (Onboarding Notes)

> ผู้ดูแล: โอ๊ต สุขสวัสดิ์ (`hr-oat`) · รวบรวมจากหัวหน้าทุกแผนก · ปรับปรุง 2026-10-20
> ใช้กับ `onboarding-pack` — HR ต้องส่งคำขอให้แผนกที่เกี่ยวข้อง **อย่างน้อย 5 วันทำการก่อนวันเริ่มงาน**

## 1. ทุกคนได้เหมือนกัน (HR + ทีมกลางเตรียม)

| เรื่อง | รายละเอียด | ใครเตรียม |
|---|---|---|
| บัญชี | อีเมล `ชื่อ.นามสกุลย่อ@novatech.example`, chat บริษัท, Google Drive, HR system | ทีมกลาง (`plat-ken`) |
| Gitea | บัญชี + เข้าทีมของแผนก (สิทธิ์อ่านคลัง `org-skills`) | ทีมกลาง |
| Claude Code | license + ติดตั้ง **แพ็ก skill ของบริษัท: `core` (แบรนด์, นโยบายข้อมูลลูกค้า, หา skill) + แพ็กของแผนกตัวเอง** — ไม่ติดแพ็กแผนกอื่น เพื่อไม่ให้ skill เยอะจนหยิบผิด | ทีมกลาง |
| อุปกรณ์ | โน้ตบุ๊กตามแผนก (ดู `hr-benefits-faq.md`), บัตรเข้าอาคาร, จอ 27" ที่โต๊ะ | ธุรการ |

| Buddy | พนักงานแผนกเดียวกันที่อยู่ ≥ 1 ปี (ไม่ใช่หัวหน้า) ดูแล 30 วัน | หัวหน้าแผนก |
| อบรมวันแรก | 10:00 แนะนำบริษัท (HR) · 13:00 PDPA + นโยบายข้อมูลลูกค้า 45 นาที (`plat-may`) · 14:00 แบรนด์ 20 นาที | HR + ทีมกลาง |
| อาหาร | มื้อกลางวันวันแรกกับทีม (บริษัทจ่าย) | หัวหน้าแผนก |

## 2. แยกตามแผนก (วันแรก + สัปดาห์แรก)

| แผนก | เพิ่มวันแรก | งานสัปดาห์แรก |
|---|---|---|
| **Dev** | GitHub/Gitea repo ของโปรเจกต์, สิทธิ์ staging, **Claude Code แพ็ก `core` + `dev`** (มี `coding-standard` และ `project-scaffold`), อ่าน `coding-rules.md` + `project-scaffold-notes.md` | ขึ้นโปรเจกต์ตัวอย่างระบบสมาชิกด้วยแพ็ก dev แล้วให้ buddy รีวิวตาม coding-rules 10 ข้อ · แก้บั๊กเล็ก 1 ticket · ส่ง PR แรก |
| **QA** | สิทธิ์ staging, Playwright repo, แพ็ก `core` + `qa`, `qa/bug-template.md` | รัน test ตามแผนของโปรเจกต์ที่กำลัง UAT · เขียนรายงานบั๊ก 1 ฉบับ |
| **DevOps** | สิทธิ์ cloud console (อ่านอย่างเดียว 2 สัปดาห์แรก), แพ็ก `core` + `devops`, อ่าน `deploy-runbook.md` + `incident-2026-09.md` | ตาม deploy จริง 1 รอบในบทบาท Verifier · ยังไม่เข้าเวร on-call จนครบ 1 เดือน |
| **ML / MLOps** | สิทธิ์ MLflow, bucket ข้อมูล (ไม่ระบุตัวตนเท่านั้น), แพ็ก `core` + `mlops`, อ่าน `ml-queue-forecast/` | รันการทดลอง r03 ซ้ำให้ได้ผลเดิม |
| **Sales** | CRM, แพ็ก `core` + `sales`, อ่าน `won-proposals/` | ตามเซลส์ไปประชุมลูกค้า 2 นัด · ร่างอีเมลติดตาม 1 ฉบับให้หัวหน้าตรวจ |
| **SA** | แพ็ก `core` + `sa`, อ่าน `arch-standards.md` | วาด architecture ของโปรเจกต์ที่มีอยู่ 1 ระบบตามมาตรฐาน |
| **บัญชี / ธุรการ** | ระบบบัญชี, แพ็ก `core` + `finance`, `price-list.csv`, `margin-rules.md`, `invoices/invoicing-rules.md` | ตรวจใบแจ้งหนี้ร่วมกับพี่เลี้ยง 3 ฉบับ |
| **HR** | HR system สิทธิ์เต็ม, แพ็ก `core` + `hr` | เตรียมชุดต้อนรับให้คนถัดไป 1 คน |
| **ผู้บริหาร** | แพ็ก `core` + `exec`, `monthly-kpi.csv` | — |
