# ข้อเสนอโครงการ: ระบบติดตามสถานะสินเชื่อออนไลน์ (Loan Tracking Portal)

**เสนอต่อ:** ธนาคารสยามรุ่งเรือง จำกัด (มหาชน) — ฝ่ายสินเชื่อรายย่อย
**เลขที่เอกสาร:** NVT-PRP-2024-018 · **วันที่:** 26 สิงหาคม 2024
**จัดทำโดย:** นิดา แก้วมณี (หัวหน้าทีมขาย) · ต้นตระกูล มีชัย (SA อาวุโส)
**ผลการคัดเลือก:** ✅ ได้รับคัดเลือก 20 กันยายน 2024 · ส่งมอบ go-live 14 กุมภาพันธ์ 2025

---

## 1. บทสรุปผู้บริหาร

ปัจจุบันลูกค้าสินเชื่อบ้านและสินเชื่อ SME ของธนาคารต้องโทรถาม call center หรือสาขาเพื่อรู้ว่าคำขอสินเชื่อถึงขั้นไหน ทำให้มีสายเข้าเฉลี่ย 2,400 สาย/เดือน
เราเสนอ **พอร์ทัลติดตามสถานะสินเชื่อ** ให้ลูกค้าดูสถานะได้เองตลอด 24 ชั่วโมง พร้อมแจ้งเตือนเมื่อสถานะเปลี่ยน และหน้าจอสำหรับเจ้าหน้าที่สินเชื่อ
เป้าหมาย: ลดสายสอบถามสถานะลง 40% ภายใน 6 เดือนหลังเปิดใช้ · ส่งมอบภายใน 5 เดือน · มูลค่า 5,020,000 บาท (ไม่รวม VAT)

## 2. ความเข้าใจความต้องการ

- ลูกค้าดูสถานะคำขอ 7 ขั้น (ยื่นเอกสาร → ตรวจเอกสาร → ประเมินหลักประกัน → พิจารณา → อนุมัติ → ทำสัญญา → เบิกจ่าย)
- แจ้งเตือนทาง SMS และอีเมลเมื่อสถานะเปลี่ยน หรือเมื่อเอกสารไม่ครบ
- อัปโหลดเอกสารเพิ่มเติมได้เอง (PDF/JPG ไม่เกิน 10 MB)
- เจ้าหน้าที่ดูคิวคำขอค้าง, SLA ต่อขั้น, รายงานรายสาขา
- ต้องเชื่อมกับระบบ Loan Origination (LOS) เดิมของธนาคารผ่าน API ไม่แก้ระบบเดิม
- ผ่านการทดสอบเจาะระบบ (penetration test) ของธนาคารก่อนเปิดใช้

## 3. โซลูชันที่เสนอ

| ส่วน | รายละเอียด |
|---|---|
| Customer Portal | เว็บ responsive, เข้าสู่ระบบด้วยเลขที่คำขอ + OTP ทาง SMS |
| Staff Console | หน้าจอเจ้าหน้าที่, SSO ด้วย Active Directory ของธนาคาร, สิทธิ์ตามบทบาท |
| Notification Service | ส่ง SMS/อีเมลผ่าน gateway ของธนาคาร, คิวงานส่งซ้ำอัตโนมัติ |
| Integration Layer | ดึงสถานะจาก LOS ทุก 5 นาที + รับ webhook เมื่อสถานะเปลี่ยน |
| Report | รายงาน SLA ต่อขั้น, จำนวนคำขอรายสาขา, export Excel |

## 4. ภาพรวมสถาปัตยกรรม

- Modular monolith (Next.js + Node.js/TypeScript) ตามมาตรฐานบริษัท แยกโมดูล portal / staff / notification / integration
- PostgreSQL (managed, HA) + Redis cache สำหรับสถานะล่าสุด
- คิวงาน (queue) สำหรับส่งแจ้งเตือน แยกจาก request หลัก
- Hosting บน cloud ภูมิภาคประเทศไทย, WAF หน้าระบบ, เข้ารหัสข้อมูลทั้งตอนส่ง (TLS 1.2+) และตอนเก็บ (AES-256)
- Audit log ทุกการเข้าดูข้อมูลของเจ้าหน้าที่ เก็บ 1 ปี

## 9. ทำไมต้องโนวาเทค

- ทำระบบให้สถาบันการเงินมาแล้ว 6 โครงการ ผ่าน penetration test ของธนาคารทุกครั้งในรอบแรกหรือรอบที่สอง
- ทีมชุดเดียวตั้งแต่ออกแบบจนดูแลหลังขึ้นระบบ ไม่ส่งต่อให้ผู้รับเหมาช่วง
- มาตรฐานความปลอดภัย: เข้ารหัสข้อมูล, audit log, สิทธิ์ตามบทบาท, ทดสอบช่องโหว่ทุกรอบปล่อยงาน
- รายงานความคืบหน้าทุกสัปดาห์ เห็นปัญหาก่อนกลายเป็นความล่าช้า
