# ข้อเสนอโครงการ: แอปนัดหมายสาขา (Branch Appointment App) ผ่าน LINE OA และเว็บ

**เสนอต่อ:** ธนาคารออมทรัพย์เกษตรไทย — ฝ่ายบริหารเครือข่ายสาขา
**เลขที่เอกสาร:** NVT-PRP-2025-007 · **วันที่:** 10 มีนาคม 2025
**จัดทำโดย:** นิดา แก้วมณี (หัวหน้าทีมขาย) · ไอศวรรย์ บุญมา (SA)
**ผลการคัดเลือก:** ✅ ได้รับคัดเลือก 2 เมษายน 2025 · go-live 40 สาขานำร่อง 18 สิงหาคม 2025

---

## 1. บทสรุปผู้บริหาร

สาขานำร่อง 40 แห่งของธนาคารมีคิวรอเฉลี่ย 45 นาทีช่วงสิ้นเดือน ลูกค้าเกษตรกรหลายรายเดินทางไกลมาแล้วต้องกลับเพราะคิวเต็ม
เราเสนอ **แอปนัดหมายสาขา** ให้ลูกค้าจองวันและเวลาผ่าน LINE OA หรือเว็บ เลือกประเภทบริการได้ล่วงหน้า และให้สาขาเห็นคิวทั้งวันล่วงหน้า
เป้าหมาย: ลดเวลารอเฉลี่ยลง 30% ในสาขานำร่อง · ส่งมอบภายใน 4 เดือน · มูลค่า 3,597,000 บาท (ไม่รวม VAT)

## 2. ความเข้าใจความต้องการ

- ลูกค้าจอง/เลื่อน/ยกเลิกนัดผ่าน LINE OA (ช่องทางหลัก เพราะลูกค้า 78% ใช้ LINE) และเว็บ
- เลือกสาขา, ประเภทบริการ (ฝาก-ถอน, สินเชื่อ, เปิดบัญชี, อื่น ๆ), ช่วงเวลา 30 นาที
- แจ้งเตือนก่อนนัด 1 วันและ 1 ชั่วโมง ผ่าน LINE
- หน้าจอสาขา: รายการนัดของวัน, เรียกคิว, บันทึกว่าลูกค้ามา/ไม่มา
- ผู้บริหารเห็นสถิติรายสาขา: จำนวนนัด, อัตราไม่มาตามนัด, เวลารอเฉลี่ย
- รองรับขยายเป็น 300 สาขาในปีถัดไปโดยไม่ต้องเขียนใหม่

## 3. โซลูชันที่เสนอ

| ส่วน | รายละเอียด |
|---|---|
| LINE OA + LIFF | หน้าจองในแอป LINE, ผูกบัญชีด้วยเบอร์โทร + OTP |
| Web Booking | หน้าเว็บสำหรับผู้ไม่ใช้ LINE |
| Branch Console | แท็บเล็ตที่สาขา เรียกคิว, ปรับจำนวนช่องบริการต่อช่วงเวลา |
| Admin & Report | ตั้งค่าสาขา/วันหยุด, dashboard ผู้บริหาร |
| Notification | ข้อความเตือนผ่าน LINE Messaging API, คิวงานส่งซ้ำเมื่อส่งไม่สำเร็จ |

## 4. ภาพรวมสถาปัตยกรรม

- Modular monolith (Next.js + Node.js/TypeScript) โมดูล booking / branch / notification / report
- PostgreSQL (managed) + Redis เก็บจำนวนช่องว่างต่อช่วงเวลา ป้องกันจองซ้อน (slot lock)
- คิวงานสำหรับส่งข้อความ LINE แยกจาก request หลัก
- Hosting บน cloud ภูมิภาคประเทศไทย, TLS ทุกช่องทาง, เข้ารหัสเบอร์โทรในฐานข้อมูล
- ออกแบบให้เก็บข้อมูลคิวรายชั่วโมงแบบไม่ระบุตัวตน เพื่อใช้วิเคราะห์ในอนาคต
