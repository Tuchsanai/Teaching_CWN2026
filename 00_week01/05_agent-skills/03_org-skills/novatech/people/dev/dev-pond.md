## เก่งเรื่อง
มาตรฐานโค้ดของทีม (ตั้งชื่อ, โครงโฟลเดอร์, การจัดการ error, การเขียน test) ที่ทำให้ code review เร็ว

## งานที่ทำซ้ำ
รีวิวโค้ดและอธิบายมาตรฐานเดิมซ้ำให้ทุกคน

## ความเก่งนี้จะกลายเป็น skill
`coding-standard` (สร้างใน LAB 1)

## คำที่ชอบพิมพ์สั่ง AI
- "รีวิวโค้ดนี้ตามมาตรฐานทีม"
- "โค้ดนี้ผิดมาตรฐานตรงไหน"
- "เขียนให้ตรงสไตล์ทีม"
