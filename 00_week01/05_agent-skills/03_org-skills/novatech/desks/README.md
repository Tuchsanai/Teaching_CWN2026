# 💻 โต๊ะทำงาน (local)

1 โฟลเดอร์ = เครื่องของพนักงาน 1 คน · เปิด Claude Code ที่โต๊ะไหน = ทำงานในนามคนนั้น
`seed` สร้างโฟลเดอร์ให้ครบ 21 โต๊ะตอน `docker compose up` พร้อมไฟล์ `.gitea-token` (token ทดสอบของ Gitea ในเครื่อง ไม่ขึ้น git)

> ของจริง skill ส่วนตัวของแต่ละคนอยู่ที่ `~/.claude/skills/` แต่ในแล็บพนักงาน 21 คนอยู่ในเครื่องเดียว จึงใช้ `desks/<user>/.claude/skills/` แทน
