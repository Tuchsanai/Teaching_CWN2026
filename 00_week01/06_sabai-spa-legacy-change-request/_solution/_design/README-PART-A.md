# สบายใจ สปา: รับงานแก้ระบบเดิมด้วย Change Request (Copy & Paste)

บทนี้ **ไม่ได้เริ่มจากศูนย์** เราได้รับมอบระบบจองคิว "สบายใจ สปา" ที่ใช้งานจริงอยู่แล้ว (เว็บ + ฐานข้อมูลที่มีข้อมูลลูกค้า) พร้อมเอกสารเก่า ชุดทดสอบที่ผู้รับเหมาเดิมส่งมอบ และ **หนังสือขอเปลี่ยนแปลงระบบ (Change Request) 5 ฉบับ** จากคุณจันทร์
Claude Code ช่วยอ่านและอธิบายระบบเดิม ส่องด้วย REA ล็อกพฤติกรรมเดิม แล้ว **แก้ repo เดิม** ทีละ CR จนส่งมอบได้ (8 ใน 12 LAB เป็นงานแก้ repo ✏️)
หน้าที่ของเราคือ **คัดลอกพรอมต์ → วางใน Claude Code → อ่านผล → ตัดสินใจ** ไม่ต้องเขียนโค้ดเอง · บทนี้เราตัดสินหนักขึ้น: อนุมัติแผนก่อนแก้ · ดูว่าเทสต์ใหม่ **แดงก่อน** จริง · ไม่ยอมให้แก้เทสต์เดิมให้ผ่าน

![ป้ายไม้สีทอง รับงานแก้ระบบเดิม · คนงานผู้รับเหมา 3 คนชุดเทาโบกมือลาเดินออกประตู คนหน้ายื่นกล่องกระดาษ ระบบเดิม ที่แปะโน้ตเหลือง ผ่านหมดแล้ว ให้เด็กผู้ชาย บนกล่องมีแฟ้ม SPEC v1.0 ใยแมงมุมเกาะ หุ่นยนต์ส่องไฟฉายเข้ากล่องอีกใบ คุณจันทร์ยืนหลังเคาน์เตอร์ถือซอง หนังสือขอเปลี่ยนแปลง น้องบัวโบกธงจากกระถางกล้วยไม้](img/intro-01-legacy-handover.jpg)

ระบบจองคิวที่สร้างในบท 04 **ใช้งานจริงมาแล้ว** ผู้รับเหมาเดิม "บริษัท โค้ดไว จำกัด" (ชื่อสมมติ) ส่งมอบโค้ด เอกสาร `SPEC.md` และชุดทดสอบ 2 ชุด แล้ว **หมดสัญญา** ตั้งแต่ 30 ก.ย. 2026
คุณจันทร์จ้างทีมใหม่ = **เรา + Claude Code** · วันที่ 12 ต.ค. 2026 ร้านส่งหนังสือขอเปลี่ยนแปลงมา 5 ฉบับ
เหมือนงานภาครัฐจริง: ระบบมีข้อมูลลูกค้าอยู่ · เอกสารเก่าไม่ตรงโค้ด · ทุกการเปลี่ยนต้องมีหลักฐานให้กรรมการตรวจรับ · และต้องถอยกลับได้

| CR | เรื่อง (จากหนังสือ) | ชนิดงาน | ทำใน LAB |
|---|---|---|---|
| CR-02 | ส่วนลดกลุ่มแบบขั้นบันได มีผล 1 พ.ย. | เปลี่ยนกฎเดิม | 6 |
| CR-03 | ลูกค้าโดนจองซ้ำ 2 นัด (เรื่องร้องเรียน · **ด่วน**) | แก้บั๊ก | 7 |
| CR-04 | วันหยุดร้าน | เปลี่ยน schema บนฐานที่มีข้อมูล | 8 |

ลำดับในบทเรียง **เล็ก → ใหญ่** (กฎ → บั๊ก → schema → ฟีเจอร์ → รายงาน) ไม่ใช่ตามเลข CR · ปิดบทด้วยข้อสอบ [`EXAM.md`](EXAM.md) ที่ส่วนใหญ่เป็นการแก้ repo เดิม

ประโยคหลักของบท: **"ทำตามที่ขอ ≠ ของเดิมไม่พัง ≠ ส่งมอบได้"**
แต่ละช่วงต้องมีหลักฐานของตัวเอง ไม่ใช่คำพูดของ AI หรือของผู้รับเหมา

| ✅ ทำตามที่ขอ | 🛡️ ของเดิมไม่พัง | ✍️ ส่งมอบได้ |
|---|---|---|
| เทสต์ใหม่ตาม CR **แดงก่อนแก้ → เขียวหลังแก้** | regression ทุกชุดเดิม + ชุดใหม่ ครบ 3 เบราว์เซอร์ | CR → กฎ → เทสต์ โยงกันครบ · แผนถอยกลับที่ซ้อมแล้ว · คุณจันทร์ตรวจรับตามรายการ |

> 📅 หนังสือ CR บันทึกส่งมอบ และทะเบียน ใช้ปี พ.ศ. แบบหนังสือราชการ: **2569 = 2026** · ข้อความในบทเรียนใช้ ค.ศ.

### 2) มองระบบ 3 ตา + ตาที่ 4 คือฐานข้อมูล (ทบทวนบท 05 + เพิ่ม DB)

> 🔁 **ทบทวนบท 05** (ไม่สอนซ้ำ · ยังไม่ได้ทำบท 05 ให้อ่าน 🎓 ของ [บท 05](../05_rea-reverse-engineer-legacy-petshop/README.md) ข้อ 3 (3 ตา) · ข้อ 4 (หลักฐาน) · ข้อ 7 (ป้าย [E]) ก่อน ~15 นาที)

> - **หลักฐาน ไม่ใช่ความเห็น:** ทุกข้อสรุปของ REA มี digest · authority 🔵 static · 🟢 runtime · 🟡 inference · ⚪ unknown · ข้อจำกัด
> - **หาไม่เจอ ≠ ไม่มี:** coverage `partial` เป็นเรื่องปกติ · ห้ามสรุป "ระบบไม่มี X" จากหลักฐานที่ตรวจไม่ครบ
