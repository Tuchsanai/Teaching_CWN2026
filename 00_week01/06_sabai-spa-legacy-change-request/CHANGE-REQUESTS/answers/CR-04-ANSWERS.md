# คำตอบข้อซักถาม CR-04 · วันหยุดร้าน

## ① คำตอบของร้าน
- วันหยุดปิดทั้งวัน
- วันหยุดไม่ต่ออายุคอร์สหรือบัตรของขวัญ
- ถ้าวันที่เลือกเกินช่วงจองได้ (เกิน 30 วัน) ให้บอกเรื่องช่วงวันก่อน ส่วนเรื่องร้านหยุดบอกเมื่อวันนั้นอยู่ในช่วงที่จองได้
- ส่วนหน้าหลังร้าน (เพิ่ม/ลบวันหยุดเอง) เป็น "ส่วน ข" · ถ้าไม่ทันรอบนี้ ทำแค่ "ส่วน ก" (3 วันที่แจ้งไว้) ก่อนได้
- ส่วน ข: ห้ามปิดวันที่ผ่านมาแล้วหรือวันนี้ · วันที่มีนัดยืนยันอยู่ห้ามปิด

## ② สิ่งที่ตกลงร่วมกัน
| เรื่อง | ตกลง |
|---|---|
| ตาราง | `shop_holiday (holiday_date DATE PRIMARY KEY, name_th, name_en, name_zh)` |
| API อ่าน | `GET /api/holidays` → รายการวันหยุด เรียงตามวันที่ |
| error | 422 `SHOP_CLOSED` (มีชื่อวันหยุดตามภาษา) ใช้กับรอบเวลา ราคา และการจองทุกแบบ |
| ส่วน ข | `POST /api/admin/holidays {date, name}` → 201 · `DELETE /api/admin/holidays/:date` → 200 · วันที่มีนัดยืนยัน → 409 `HAS_BOOKINGS` · วันนี้/อดีต → 422 · ไม่ใช่เจ้าของร้าน → 403 |
| ข้อมูลเดิม | ห้ามหาย ทุกขั้นตอนต้องใช้กับฐานข้อมูลที่มีข้อมูลอยู่แล้วได้ |

| วันที่ | th | en | zh |
|---|---|---|---|
| 2026-10-23 | วันปิยมหาราช | Chulalongkorn Day | 五世王纪念日 |
| 2026-12-05 | วันพ่อแห่งชาติ | National Father's Day | 父亲节 |
| 2026-12-31 | วันสิ้นปี | New Year's Eve | 新年前夕 |

| ภาษา | ข้อความ `SHOP_CLOSED` |
|---|---|
| th | วันนี้ร้านหยุด ({name}) กรุณาเลือกวันอื่น |
| en | The shop is closed on this day ({name}). Please choose another date |
| zh | 本店当天休息（{name}），请选择其他日期 |

## ③ ตัวอย่างที่ร้านยืนยัน (วันนี้ = 10 ต.ค. 2569 10:00)
| # | สถานการณ์ | ผลที่ต้องได้ |
|---|---|---|
| 1 | ดูรอบนวดไทย 60 นาที วันที่ 23 ต.ค. | ไม่มีรอบ ขึ้นข้อความร้านหยุด (วันปิยมหาราช) |
| 2 | ดูรอบวันที่ 22 ต.ค. และ 24 ต.ค. | มีรอบตามปกติเหมือนก่อนเปลี่ยน |
| 3 | จองวันที่ 5 ธ.ค. ตอนนี้ (เกิน 30 วัน) | ขึ้นเรื่องช่วงวันจองได้ ไม่ใช่เรื่องร้านหยุด |
