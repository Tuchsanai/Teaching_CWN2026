# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 4/2569

| | |
|---|---|
| เลขที่ | CR-04 |
| วันที่ | 12 ตุลาคม 2569 |
| เรื่อง | วันหยุดร้าน |
| เรียน | ทีมดูแลระบบจองคิว |
| ความเร่งด่วน | ต้องใช้งานได้ก่อน 23 ตุลาคม 2569 |

ตอนทำระบบครั้งแรก ทีมเดิมถามว่าวันหยุดนักขัตฤกษ์ร้านเปิดไหม ตอนนั้นยังไม่ได้ตอบ
ตอนนี้ขอแจ้งว่า **ร้านปิดบางวัน** ค่ะ ปีนี้ปิด

- 23 ต.ค. 2569 วันปิยมหาราช
- 5 ธ.ค. 2569 วันพ่อแห่งชาติ
- 31 ธ.ค. 2569 วันสิ้นปี

วันที่ร้านปิดต้องจองไม่ได้ทุกช่องทาง (หน้าเว็บ แชท จองด้วยคอร์ส) และขึ้นข้อความบอกลูกค้าว่าร้านหยุดวันอะไร

**ข้อมูลลูกค้าและนัดที่มีอยู่ในระบบตอนนี้ห้ามหาย** (ระบบใช้งานจริงอยู่)

ถ้าเป็นไปได้ ขอให้ร้านเพิ่ม/ลบวันหยุดเองได้ในหน้าหลังร้าน
แต่ถ้าวันไหนมีลูกค้าจองไว้แล้ว ระบบต้องไม่ยอมให้ปิดวันนั้น (ร้านจะโทรเลื่อนลูกค้าก่อน)
