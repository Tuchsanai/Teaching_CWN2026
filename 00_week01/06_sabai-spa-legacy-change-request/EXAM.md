### 🚦 ขั้นเปิดระบบ (PowerShell)

| ขั้น | ทำ | ผ่านเมื่อ |
|---|---|---|
| ① ปิดระบบ LAB | ที่โฟลเดอร์บท 06: `docker compose -f web/compose.yaml down` แล้ว `docker compose -f db/compose.yaml down` · **ห้ามใส่ `-v`** (ข้อมูล LAB ต้องอยู่) | `docker ps --filter name=sabai06` ว่าง |

| ③ เปิดระบบข้อสอบ | ที่ `C:\exam\<รหัส>\`: `docker network create sabai06x-net` (ถ้ามีอยู่แล้วข้ามได้) → `docker compose -f db/compose.yaml up -d --wait` → `docker compose -f web/compose.yaml up -d --build --wait` (build นาน → ให้ Claude Code รันแบบ background) | http://localhost:4000 เปิดได้ · `docker ps --filter name=sabai06x` เห็น 2 container |

| ⑤ เริ่มจับเวลา | `git init` → `git add -A` → `git commit -m "EX0: base"` | **ห้ามแก้อะไรก่อน commit นี้** |

> หลังสอบ เปิดระบบ LAB กลับได้ตามปกติ: ปิดระบบข้อสอบ (`down` ไม่ใส่ `-v`) แล้ว `up` ระบบ LAB ที่โฟลเดอร์บท 06 · ข้อมูล LAB ยังอยู่ครบ
