# 📋 แผนการทดสอบ (Test Plan) — ค้นหาสินค้าแมวบน Shopee (ต้องเข้าสู่ระบบ)

## 1. ระบบที่ทดสอบ
เว็บ **Shopee ประเทศไทย** (`https://shopee.co.th`) เป็นเว็บจริงที่ใช้งานอยู่ (production) ไม่ใช่เว็บที่เราเปิดเองด้วย Docker
ทดสอบด้วย **Playwright MCP แบบ Extension** ที่สั่งงานผ่าน Claude Code โดย Playwright ทำงานใน **Google Chrome ที่ผู้เรียนใช้ประจำและ login Shopee ไว้แล้ว**

ความต่างจากงานที่ 1 (PawPantry)

| เรื่อง | งานที่ 1 PawPantry | งานที่ 2 Shopee |
|---|---|---|
| เว็บ | เปิดเองด้วย `docker compose` ข้อมูลคงที่ ล้างได้ | เว็บจริง ราคาและจำนวนสินค้าเปลี่ยนตลอด ล้างข้อมูลไม่ได้ |
| เบราว์เซอร์ | Chromium ของ Playwright (หน้าต่างใหม่ ไม่มีบัญชีใด) | **Chrome ของผู้เรียนเอง** ผ่าน Playwright Extension |
| การเข้าสู่ระบบ | test สมัครหรือ login ให้เองด้วยบัญชีทดลอง | **คนเป็นผู้ login เอง** (รหัสผ่าน, OTP, ยืนยันตัวตน) แล้ว Playwright ใช้ Chrome นั้นต่อ |
| ตรวจว่าเป็นคน (CAPTCHA) | ไม่มี | **มี** Shopee อาจขึ้นหน้า "เลื่อนเพื่อยืนยัน" **คนต้องเลื่อนเอง** |
| จำนวน test | 40 ข้อ รันพร้อมกันหลายตัว เร็วที่สุด | **3 ข้อ รันทีละข้อ ช้า ๆ แบบคน** เพื่อไม่รบกวนเว็บและไม่ให้ Shopee มองว่าเป็น bot |

## 6. เกณฑ์ (Entry / Exit criteria)
- **เริ่มทดสอบได้เมื่อ**
  1. **คน login Shopee เอง** ใน Google Chrome ของเครื่องตัวเอง (README LAB 0) จนมุมขวาบนเป็นชื่อบัญชี Playwright ไม่ login ให้ แค่มาใช้ Chrome ที่ login ไว้แล้ว
  2. ติดตั้ง **Playwright Extension** ใน Chrome และต่อกับ Claude Code แล้ว (กด Connect ใน extension)
  3. **ผู้เรียนนั่งอยู่หน้าจอตลอดการทดสอบ** เพื่อเลื่อน CAPTCHA เมื่อ Shopee ถาม
- **ผ่านเกณฑ์เมื่อ** ผ่านครบทั้ง 3 ข้อ (ทุกข้อเป็น P1)
- **เมื่อ Shopee ขึ้นหน้ายืนยันตัวตน / CAPTCHA / "ตรวจสอบการใช้งาน"**
  - Playwright **หยุดรอ** ให้คนเลื่อนยืนยันเอง แล้วจึงทำขั้นต่อไป (ห้ามให้ test หรือ AI พยายามผ่าน CAPTCHA)
  - ถ้าคนผ่านไม่ได้ ขึ้นซ้ำหลายรอบ หรือ session หมดอายุ ให้ **หยุดทดสอบ** และบันทึกผลเป็น **Blocked** (ไม่ใช่ Failed)

## 7. ข้อมูลและกติกาการทดสอบ
| เรื่อง | กติกา |
|---|---|
| บัญชี | บัญชี Shopee ของผู้เรียน **คน login เอง** ไม่ใส่รหัสผ่านไว้ในไฟล์ใด |
| ที่เก็บ session | อยู่ใน Chrome ของผู้เรียนเท่านั้น ไม่คัดลอก cookie หรือโปรไฟล์ออกมาเป็นไฟล์ และ **ห้ามล้าง cookie** |
| คำค้นที่ใช้ | อาหารแมว · ของเล่นแมว |
| จังหวะแบบคน | รันทีละ test พิมพ์ทีละตัวอักษร พักระหว่างขั้น 2–5 วินาที และไม่รันซ้ำถี่ ๆ (เว้นอย่างน้อยหลายนาทีระหว่างรอบ) |
| สิ่งที่ห้ามกด | ซื้อ / ซื้อโดยใช้โค้ด / สั่งสินค้า / แชท / ติดตาม / รีวิว / แก้ข้อมูลบัญชี |
| เก็บกวาด | ของที่ test ใส่รถเข็นต้องลบออกใน test เดียวกัน ลบ **เฉพาะแถวที่ test ใส่** ไม่แตะสินค้าเดิมของบัญชี |
| ภาพและวิดีโอ | เบลอชื่อบัญชี (user ID) รูปโปรไฟล์ ที่อยู่ เบอร์โทร และสินค้าอื่นในรถเข็น ก่อนนำไปใช้หรือส่งต่อ และไม่พิมพ์ชื่อบัญชีลงในรายงาน |
