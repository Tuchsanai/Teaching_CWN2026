# บทเรียน 02 · งานที่ 2 · ทดสอบ Shopee (ต้อง login) ด้วย Playwright ใน Chrome ของผู้เรียน

ผู้เรียนเป็น tester / BA ที่ไม่ได้เขียนโปรแกรม ตอบเป็นภาษาไทยง่าย ๆ และสรุปผลเป็นตารางเสมอ

## วิธีทดสอบ
- ใช้เครื่องมือ Playwright MCP โหมด `--extension` (`mcp__playwright__browser_*`) ซึ่งคุมแท็บใน Google Chrome ของผู้เรียนที่ login Shopee ไว้แล้ว
- ถ้า Chrome ขึ้นหน้า Playwright Extension ให้ผู้เรียนกด Connect เอง
- ทำตาม `TEST-PLAN.md` 3 ข้อ (TC-AUTH-01, TC-SRCH-01, TC-CART-01) ทีละข้อ

## กติกาที่ห้ามละเมิด
- **ช้าแบบคน**: พักทุกขั้น 2–5 วินาที พิมพ์ทีละตัวอักษร (`slowly`) เลื่อนหน้าทีละนิด ไม่เปิดหลายแท็บ ไม่รันซ้ำถี่ ๆ
- **CAPTCHA / `/verify/` / "ตรวจสอบการใช้งาน"**: หยุดทันที บอกผู้เรียนให้เลื่อนยืนยันเองใน Chrome แล้วรอให้ผู้เรียนบอกว่าทำต่อได้ ห้ามคลิก ลาก หรือพยายามผ่านเอง ถ้าผ่านไม่ได้ให้บันทึก **Blocked**
- ห้ามกดซื้อ / ซื้อโดยใช้โค้ด / สั่งสินค้า / ชำระเงิน / แชท / ติดตาม / รีวิว / แก้ข้อมูลบัญชี / ล้าง cookie
- รถเข็นใส่ได้ 1 ชิ้นต่อรอบ และต้องลบ **เฉพาะแถวนั้น** ใน test เดียวกัน (รถเข็นมีของเดิมของผู้เรียนอยู่)
- **ข้อมูลส่วนตัว**: ห้ามพิมพ์ชื่อบัญชี (user ID) ในคำตอบ รายงาน หรือไฟล์ใด เบลอชื่อบัญชี รูปโปรไฟล์ ที่อยู่ เบอร์โทร และสินค้าอื่นในรถเข็นในทุกภาพ
- ภาพดิบที่ยังไม่เบลอเก็บไว้นอก repo เท่านั้น และลบโฟลเดอร์ `.playwright-mcp/` เมื่อเสร็จ
