## 3. เหตุการณ์ระหว่างทดสอบ

| เหตุการณ์ | ใครจัดการ / จัดการอย่างไร | กระทบผลไหม |
|---|---|---|
| เปิดหน้าแรกรอบแรกของวัน Shopee พาไป `/verify/captcha` | **ผู้เรียนเลื่อนยืนยันเอง** ประมาณ 9 วินาที AI ไม่ได้แตะ CAPTCHA · รอบหลังไม่ขึ้นอีก | ไม่กระทบ |
| นับชื่อสินค้าก่อนโหลดครบ การ์ดที่ 16–20 ยังว่าง ได้ 15/20 = 75% | Playwright เลื่อนไปที่การ์ดที่ว่างให้โหลด แล้วนับใหม่ได้ 20/20 | ไม่กระทบ (ผลรอบแรกเป็นการนับผิด ไม่ใช่บั๊ก) |
| ลบคำค้นเดิมไม่หมด ค้นหาเป็น "อาหารสุนัขอาหารแมว" | ทิ้งผลรอบนั้น ล้างช่องค้นหาให้ว่างแล้วค้นหา "อาหารสุนัข" ใหม่ | ไม่กระทบ (ไม่นับผลรอบที่ค้นผิด) |
| หน้าต่าง Chrome ถูกบัง (`visibilityState: hidden`) คลิกและถ่ายภาพ timeout เป็นบางครั้ง | ทำขั้นนั้นใหม่ · ภาพที่ไม่ได้ใช้ภาพจากรอบเต็มแทน | ไม่กระทบ |
