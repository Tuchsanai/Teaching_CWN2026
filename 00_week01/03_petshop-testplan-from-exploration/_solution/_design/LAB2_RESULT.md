**ส่วน B · ฟีเจอร์ 22 รายการ** (ค้นหา · กรอง/เรียง · รายละเอียด · ขนาด/จำนวน · ใส่ตะกร้า · ซื้อคู่กัน · แนะนำ · รายการโปรด · finder · แก้ตะกร้า · คูปอง · สรุปยอด · สมัคร · login/logout · ที่อยู่ · วิธีส่ง · วิธีจ่าย · ยืนยันสั่งซื้อ · ประวัติ · หัวเว็บ/เมนูมือถือ · 404 · ฟอร์มรับข่าวสาร)

**งานหลักของลูกค้า 1 รอบ: สำเร็จ** ค้น "แซลมอน" (พบ 5) → ลูกแมว สูตรแซลมอน 1.5 kg ฿590 → ตะกร้า → PAW10 (−฿59) → ถูกส่งไป login → login demo → กลับหน้าชำระเงิน → กรอกที่อยู่ → **PP-100001 ยอด ฿581** (คำนวณเอง 590 − 59 + 50 = 581 ✅)

**จอมือถือ 390px:** เมนูหัวเว็บย่อเป็นปุ่ม ☰ เปิดเป็นลิ้นชักซ้าย (อาหารแมว · อาหารสุนัข · ของเล่น · ช่วยเลือกอาหาร · รายการโปรด · ตะกร้า · บัญชีของฉัน)

**ยังไม่รู้ (7 ข้อ):** ฟอร์มรับข่าวสารไม่มีผลตอบกลับ · PromptPay เป็น QR ตัวอย่าง · ไทม์ไลน์คำสั่งซื้อค้างที่ "รับคำสั่งซื้อ" · สูตรของ "แนะนำสำหรับคุณ"/"ตรงใจ %" · รีวิวเขียนไม่ได้ · `data-bug-mode="0"` ใน HTML · ไม่มีหน้าแก้โปรไฟล์/ลืมรหัสผ่าน/ยกเลิกคำสั่งซื้อ

นอกจากนี้พบ **API**: `/api/health`, `/api/test/reset` (POST), `/api/products`, `/api/orders` → จะถามทีมใน LAB 3 ว่าอยู่ในขอบเขตไหม

## ข้อสังเกต / ปัญหา (สำหรับ README "👀")
- Playwright MCP ที่ต่อกับ Chrome จริงของผู้ใช้: snapshot หน้าแรกยาวมาก (~400 บรรทัด) และมี error จาก extension อื่นในเบราว์เซอร์ (`Search engine null is not supported` ของ extension `searchAnalyzer.js`) — ไม่ใช่ error ของเว็บ ผู้เรียนอาจสับสน ควรบอกใน README ว่าให้ดูเฉพาะ error ที่มาจาก localhost
- ไฟล์ snapshot/console ของ MCP ถูกเขียนลง `.playwright-mcp/` ในโฟลเดอร์งาน — ควรใส่ใน `.gitignore`
- กด "ดำเนินการชำระเงิน" ตอนยังไม่ login: URL เปลี่ยนเป็น `/login?next=/checkout` **ช้ากว่า** การโหลดหน้า (ฝั่ง client) — สคริปต์ที่อ่านหน้าทันทียังเห็นหน้าตะกร้าอยู่ ต้องรอ URL
- หน้าชำระเงินกรอกชื่อผู้รับให้อัตโนมัติจากบัญชี ("สมใจ ใจดี") ส่วนเบอร์/รหัสไปรษณีย์มีแค่ placeholder `0812345678` / `10110` (ไม่ใช่ค่าจริง)
- หลังสั่งซื้อ หน้าแรก "แนะนำสำหรับคุณ" เปลี่ยนจาก "ยังไม่มีประวัติการดู…" เป็น "จากสินค้าที่คุณเคยดูและรายการโปรดของคุณ"
- ระหว่างเดิน finder ด้วยสคริปต์ ปุ่ม "ใส่ตะกร้า" ของผลลัพธ์ถูกกดโดยไม่ตั้งใจ (ตะกร้า +1) — ไม่กระทบผล
- เวลาจริงถ้าผู้เรียนใช้ MCP อย่างเดียว (ไม่มีสคริปต์): คาด 15–25 นาที เพราะ 28 หน้าสินค้า + snapshot ยาว
