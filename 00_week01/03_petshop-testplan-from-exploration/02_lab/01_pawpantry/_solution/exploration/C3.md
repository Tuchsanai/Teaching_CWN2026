## A. หน้า/สถานะที่เจอ
- `/cart` ตอนว่าง: "ตะกร้าของคุณยังว่างอยู่ … เลือกซื้อสินค้าต่อ"
- `/cart` ตอนมีของ: รายการ + สรุปคำสั่งซื้อ + ช่องโค้ด + แถบส่งฟรี ("ซื้อเพิ่มอีก ฿N เพื่อส่งฟรี" / "ได้ส่งฟรีแล้ว!") + กล่อง "🎁 ซื้อคู่กันคุ้มกว่า · มักซื้อคู่กับสินค้าในตะกร้า"
- สถานะคูปอง: "ใช้คูปอง X แล้ว" + "นำคูปอง X ออก" · error: "ไม่พบคูปองนี้", "คูปองนี้หมดอายุแล้ว", "ต้องซื้ออาหารแมวขั้นต่ำ ฿500" (กรณีหลังนี้คูปองค้างอยู่ + ปุ่มนำออก แต่ไม่ลด)
- `/checkout` (ล็อกอินแล้ว): ขั้น ✓ตะกร้า › 2 ที่อยู่และชำระเงิน › 3 สำเร็จ · ที่อยู่ (ชื่อผู้รับเติมให้จากบัญชี, เบอร์, รหัสไปรษณีย์, ที่อยู่, จังหวัด 10 จังหวัด) · วิธีจัดส่ง ส่งธรรมดา ฿50 (แสดง "ฟรี" เมื่อเข้าเงื่อนไข) / ส่งด่วน ฿120 · ชำระ: เก็บเงินปลายทาง / PromptPay · สรุปรายการ "ขนาด × จำนวน" + ปุ่ม "ยืนยันสั่งซื้อ ฿X" (ไม่ได้กด) · ไม่มีช่องคูปองในหน้า checkout ใช้ของตะกร้า
- toast หลังใส่ตะกร้า: "✅ เพิ่ม <ชื่อ> (<ขนาด>) ลงตะกร้าแล้ว 🛒"
## B. ฟีเจอร์
- ตะกร้าเก็บใน localStorage `pp-cart` = `[{slug,size,qty}]` (ไม่มี API ตะกร้า) และคูปองเก็บใน localStorage `pp-coupon` (เช่น `PAW10`)
- หน้า /cart: รายการพร้อม "ชิ้นละ ฿x", ช่องจำนวน −/+ (spinbutton), ✕ ลบ, ช่อง "โค้ดส่วนลด" + "ใช้โค้ด", ข้อความ "ใช้คูปอง X แล้ว" + ปุ่ม "นำคูปอง X ออก", สรุป ยอดรวมสินค้า/ส่วนลด/ค่าจัดส่ง/ยอดชำระทั้งหมด, แถบ "ซื้อเพิ่มอีก ฿N เพื่อส่งฟรี" / "ได้ส่งฟรีแล้ว!", กล่อง "ซื้อคู่กันคุ้มกว่า"
- ตะกร้าแบบ guest ยังอยู่หลังสมัครสมาชิก (สมัครแล้วถูกพาไป /account?welcome=1 และล็อกอินให้อัตโนมัติ)

## D. ความเสี่ยง
1. **P1 ปัดเศษส่วนลด % ลงเสมอ** (แถว 6–8, 39): ต่างจากการปัดปกติได้สูงสุด ฿0.99/ออเดอร์ ถ้าสเปกต้องการปัดครึ่งขึ้น ยอดจะผิดทุกออเดอร์ที่ยอดไม่ลงตัว 10
2. **P1 เกณฑ์ส่งฟรีคิดจากยอดก่อนส่วนลด** (แถว 5, 41): ยอดจ่ายจริง ฿900–960 ก็ได้ส่งฟรี ถ้าสเปกหมายถึงยอดหลังลด ร้านเสีย ฿50/ออเดอร์
3. **P1 FREESHIP ยกเว้นค่าส่งด่วน ฿120** (แถว 24): ถ้าไม่ตั้งใจ เสียรายได้ ฿120/ออเดอร์
4. **P1 ตะกร้าทั้งหมดอยู่ฝั่ง client (localStorage)**: แก้ qty เกินเพดานได้ (แถว 31) — ราคา/คูปองไม่ได้เก็บใน storage และถูกคำนวณใหม่ (แถว 26–27 ปลอดภัย) แต่ต้องพึ่งเซิร์ฟเวอร์ตรวจตอนยืนยัน (ส่งต่อ C4)
5. **P2 สองแท็บเขียนทับกัน** (แถว 37): ของที่ใส่จากอีกแท็บหายโดยไม่รู้ตัว
6. **P2 พิมพ์โค้ดผิดแล้วคูปองเดิมหาย / คูปองใหม่ทับคูปองเก่าเงียบ ๆ** (แถว 9, 14): ลูกค้าอาจจ่ายเต็มราคาโดยไม่ทันสังเกต
7. **P2 ออกจากระบบแล้วตะกร้า+คูปองค้าง, ตะกร้าไม่ตามบัญชี** (แถว 35–36)
8. P3 ช่องคูปองว่างได้ข้อความ "ไม่พบคูปองนี้", "ซื้อคู่กันคุ้มกว่า" ไม่มีส่วนลดจริง, checkout ไม่จำวิธีส่งด่วน
## E. คำถามถึงทีม
1. เกณฑ์ส่งฟรี ฿999 คิดจาก "ยอดรวมสินค้าก่อนส่วนลด" หรือ "ยอดหลังหักคูปอง"? ตอนนี้ ฿1,000 − PAW10 = ฿900 ยังได้ส่งฟรี
2. ส่วนลดเปอร์เซ็นต์ต้องปัดแบบไหน (ปัดลง / ปัดครึ่งขึ้น / เก็บสตางค์)? ตอนนี้ปัดลงเสมอ (99.8 → 99, 18.9 → 18)
3. NEWCAT50 "อาหารแมว" นับขนมแมว (ขนมแมวเลีย) ด้วยใช่ไหม? ตอนนี้นับ ส่วนของเล่น/ของใช้ไม่นับ
4. ใส่คูปองใบที่สองควรแทนที่ใบแรกเงียบ ๆ หรือต้องเตือน? และพิมพ์โค้ดผิดไม่ควรลบคูปองเดิม
5. FREESHIP ควรยกเว้นค่าส่งด่วน ฿120 ด้วยหรือแค่ค่าส่งปกติ ฿50? ตอนนี้ยกเว้นทั้งคู่ (ถ้าไม่ตั้งใจ = เสียรายได้ ฿120/ออเดอร์)
6. ตะกร้าควรผูกกับบัญชีไหม (ล็อกอินเครื่องใหม่แล้วตะกร้าว่าง / ออกจากระบบแล้วตะกร้ากับคูปองยังค้างในเครื่อง)?
