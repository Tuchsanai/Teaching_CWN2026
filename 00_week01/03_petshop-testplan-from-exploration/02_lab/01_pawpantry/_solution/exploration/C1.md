## A. หน้า/สถานะที่เจอ
- `/products` (H1 "สินค้าทั้งหมด", "พบ 28 รายการ", การ์ด 28 ใบ) — ตัวกรอง: ปุ่มสัตว์ (aria-pressed), select ประเภท (`all/dry/wet/treat/toy/accessory`), select ช่วงวัย (`all/baby/adult/senior`), checkbox เกรนฟรี, select เรียง (`popular/price-asc/price-desc/rating`)
- พารามิเตอร์ URL ที่ UI สร้างเอง: `pet=cat|dog`, `type=...`, `life=...`, `grainFree=1`, `sort=...` (ค่า default ไม่ถูกใส่ใน URL)
- H1 เปลี่ยนตาม `pet` เท่านั้น: `pet=cat` → "อาหารแมว", `pet=dog` → "อาหารสุนัข" · ตัวกรองอื่นยังเป็น "สินค้าทั้งหมด" · `<title>` เป็น "สินค้าทั้งหมด · PawPantry" ทุกกรณี
- สถานะว่าง: "พบ 0 รายการ" + "ไม่พบสินค้าที่ตรงกับการค้นหา / ลองเปลี่ยนคำค้นหรือล้างตัวกรองดูนะ" + ปุ่ม "ล้างตัวกรองทั้งหมด" (กลับไป `/products` 28 รายการ) — ภาพ `C1/03-empty-cat-treat-gf-senior.png`
- การ์ดสินค้าหมด (ไก่ฟรีซดราย): ป้าย "หมด" + ปุ่ม "สินค้าหมด" · การ์ดใกล้หมด (สูตรลดก้อนขน): ป้าย "เหลือ 3 ชิ้น" ยังมีปุ่มใส่ตะกร้า
- หัวเว็บมีช่อง "ค้นหาสินค้า" + ปุ่มค้นหา (ไม่อยู่ในแผนผังหน้าของ CHARTERS)

## B. ฟีเจอร์
- ตัวกรองทุกตัวอัปเดต URL ทันที (ไม่ต้องกดปุ่ม) และ back/reload คืนสถานะ UI + ผลลัพธ์ได้ถูกต้อง (ลองย้อน 2 ขั้นจาก `pet=cat&type=treat&life=senior&grainFree=1`)
- เรียงตามราคาใช้ราคา "เริ่มต้น" (= ขนาดแรก/ถูกสุดในหน้ารายละเอียด) ทั้ง 28 ชิ้น
- เปิดหน้ารายละเอียดครบ 28 ชิ้นเพื่อเทียบกับการ์ด (ป้ายช่วงวัย/เกรนฟรี/★/ราคาเริ่มต้น/สต็อก)

## D. ความเสี่ยง
1. **(P2) ตัวกรอง "วัยโต" ดึงของเล่น/ของใช้ 8 ชิ้นมาด้วย แต่ "วัยเด็ก"/"สูงวัย" ไม่ดึง** (กฎข้อ 5) — ผู้ซื้อกรองหาอาหารแมวโตจะเจอน้ำพุ/ที่ลับเล็บปน ส่วนคนหาของเล่นลูกแมวจะไม่เจออะไรเลย และถ้า Finder (C6) หรือคูปองใช้ฟิลด์ช่วงวัยเดียวกันอาจผิดตามไปด้วย
2. **(P2) หัวข้อ "อาหารแมว"/"อาหารสุนัข" ครอบคลุมของเล่นและของใช้** (กฎข้อ 7) — ทำให้ความหมายของคำว่า "อาหารแมว" ไม่ชัด ซึ่งกระทบเงื่อนไขคูปอง `NEWCAT50` (อาหารแมว ≥ ฿500) โดยตรง
3. **(P2) ช่องค้นหาไม่ sync กับ `q` ใน URL และไม่มีทางยกเลิกคำค้นเมื่อยังมีผลลัพธ์** (กฎข้อ 23, 26) — ผู้ใช้ที่เปิดลิงก์ที่แชร์มาหรือ reload จะไม่รู้ว่าถูกกรองด้วยคำค้น (เห็นแค่บรรทัดเล็ก ๆ "ผลการค้นหา") และการค้นหาจากหัวเว็บล้างตัวกรองเดิมทิ้งทั้งหมด (ข้อ 25)
4. **(P3) H1 ไม่สะท้อน `type` และ `<title>` ไม่เปลี่ยนตามตัวกรองเลย** (ข้อ 6, 8) — กระทบ SEO/การแชร์ลิงก์ และผู้ใช้ screen reader
5. **(P3) ตัวเลข 4.7★ บนหน้าแรกไม่ตรงกับค่าเฉลี่ยจริง 4.64–4.66** (ข้อ 30)
6. **(P3) ค่าใน query เป็นตัวพิมพ์ใหญ่ (`TOY`, `CAT`) ถูกเงียบ ๆ ไม่กรอง** และคำค้นยาวมากล้นกรอบ hero (ข้อ 16, 21)
