## 5. วิธีทำรอบนี้ (ทำซ้ำได้)

1. คัดลอกผลรอบปกติไว้ที่ `e2e/report-normal/` (index.html, triage.json, triage-parts, `test-report/{raw,data,list.json,shots,gifs,playwright-html}`) ภาพในหน้าเดิมยังเปิดได้
2. `cd petshop && BUG_MODE=1 docker compose up -d` รอจน healthy แล้วตรวจ `curl -s http://localhost:3000/ | grep data-bug-mode` ได้ `data-bug-mode="1"`
3. `cd e2e && TAG=bug bash run-project.sh api && TAG=bug bash run-project.sh chromium` (= `npx playwright test --project=api|chromium` ทุก test ใช้เวลาราว 46 นาที) จากนั้นรัน `node scripts/collect.mjs` เพื่อสร้างภาพจุดตรวจและ GIF ของรอบฝังบั๊ก
4. เทียบกับ `report-normal/test-report/data/results.json` ทั้งสถานะและค่าจริงทีละจุดตรวจ แล้วจำแนกลง `triage.json` และสร้างรายงานด้วย `node scripts/build-compare-report.mjs`
5. เปิดเว็บกลับเป็นโหมดปกติ `BUG_MODE=0 docker compose up -d` แล้วตรวจว่า `data-bug-mode="0"`
