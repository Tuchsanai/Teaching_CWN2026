**ข้อปฏิบัติร่วมของทุก test ในหัวข้อนี้**

- **การนับงบค้นหา (ตามนิยามหัวข้อ 2.3):** นับ 1 ครั้งเมื่อ เปิด `U1` · กด ← / Back / รีเฟรช แล้วได้**หน้าผลลัพธ์** · เปลี่ยนผู้โดยสารในหน้า booking แล้วกด "เสร็จ" (เปลี่ยนเงื่อนไข) · **ไม่นับ** การเปิดหน้า booking (กด "เลือกเที่ยวบิน"/ตัวแถว, เปิด `UB`, เปิดลิงก์แชร์, Back ที่ได้หน้า booking) เพราะไม่ใช่หน้าผลค้นหา แต่ให้จดจำนวนหน้า booking ที่เปิดจริงใน RESULTS และเปิดไม่เกิน 3 หน้า booking ต่อ test · การกดแท็บ "ถูกที่สุด" ไม่นับ (ไม่เปลี่ยนเงื่อนไข) ถ้ากดแล้วหน้าโหลดผลใหม่ ให้จดเพิ่มเป็น 1 ครั้ง
- **ห้ามคลิกเด็ดขาด:** "ดำเนินการต่อ" ของทุกผู้ขาย · "ดูตัวเลือก" (Q27) · ลิงก์นโยบายสัมภาระ และรายการในกล่อง "ค่าธรรมเนียมสัมภาระ" · ปุ่ม Facebook / X ในกล่องแชร์ · ก่อนคลิกปุ่มใดในหน้า booking ให้อ่าน snapshot ก่อนทุกครั้ง ถ้ามี href ออกนอก google.com ตาม `D-BKG-EXT` = ห้ามคลิก
- **ค่าที่ต้องอ่านจาก snapshot:** แถวผลลัพธ์อ่านจาก aria-label ของแถว (เวลาออก–ถึง และ +1, ชื่อสายการบิน, ระยะเวลา, จำนวนครั้งและสนามบินที่แวะ, สนามบินต้นทาง/ปลายทาง, CO2e, ราคา) · หน้า booking อ่าน หัวสรุป (ประเภทตั๋ว จำนวนผู้โดยสาร เส้นทาง วันที่) · "ราคารวมที่ต่ำที่สุด ฿…" · ส่วน "ตัวเลือกการจอง" (ชื่อผู้ขาย ราคา หมายเหตุ ปุ่ม) ตามลำดับที่แสดงจากบนลงล่าง · รายละเอียด ˅ (เลขเที่ยวบิน เวลา สนามบินแต่ละช่วง) · ช่วงราคาปกติ "฿a–฿b"
- **บันทึกทุกหน้า booking ที่เปิด** (ใช้ร่วมกันหลาย test): ตัวตนแถว (เวลาออก + ชื่อสายการบิน + กลุ่มที่อยู่) · จำนวนผู้ขาย N · มี/ไม่มี ⓘ "วิธีจัดอันดับตัวเลือก" · ผู้ขายที่มีหมายเหตุค่าธรรมเนียม · ถ้า N ≥ 2 ให้จดแถวนั้นเป็น `D-BKG-MULTI` (ใช้ใน TC-BKG-06)
- **ข้อสังเกต F53 (ไม่ทดสอบ ไม่มีผลต่อ ผ่าน/ล้ม):** ทุกหน้า booking ที่เปิด ให้จดว่าแถวผู้ขายมีชื่อประเภทค่าโดยสาร (fare class) หรือไม่ โดยอ่านจากข้อความที่แสดงอยู่แล้วเท่านั้น ห้ามกด "ดูตัวเลือก"
- เวลาบนหน้าเป็นเวลาท้องถิ่นของสนามบิน (K-TZ) · ราคาเป็นจำนวนเต็มบาท เทียบแบบตรงตัว ไม่มีค่าเผื่อ เว้นแต่ข้อใดระบุไว้
