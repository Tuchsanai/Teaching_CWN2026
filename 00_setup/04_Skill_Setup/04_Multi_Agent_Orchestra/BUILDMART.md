## 3) ฟีเจอร์หน้าเว็บ (frontend)

1. **หน้าแรก + รายการสินค้า** `/` และ `/products` — ค้นหาภาษาไทยแบบคำบางส่วน (เช่น "ปูน" เจอ CEM-*), กรองหมวด/ช่วงราคา/มีของ, เรียงราคา ต่ำ→สูง / สูง→ต่ำ, แบ่งหน้า 12 ชิ้นต่อหน้า
2. **หน้าสินค้า** `/products/[sku]` — สเปก น้ำหนัก ตารางราคาส่ง 3 ขั้น สต็อกแยก 3 สาขา (สาขาที่ 0 ชิ้นแสดง "หมด") ปุ่มเพิ่มลงตะกร้าพร้อมจำนวน
3. **เครื่องคำนวณวัสดุ** `/calculator` (5 แท็บ) — ทุกผลลัพธ์ปัดขึ้นเป็นจำนวนเต็ม และมีปุ่ม "เพิ่มทั้งหมดลงตะกร้า" ที่จับคู่ SKU ให้อัตโนมัติ
   - คอนกรีต (ส่วนผสม 1:2:4) ปริมาตร V ลบ.ม. → ปูน CEM-001 = ⌈V×7⌉ ถุง · ทรายหยาบ AGG-001 = ⌈V×0.5⌉ ลบ.ม. · หิน AGG-003 = ⌈V×0.9⌉ ลบ.ม.
   - ก่อผนัง พื้นที่ A ตร.ม. → อิฐมอญ BRK-001 = ⌈A×140⌉ ก้อน + ปูนก่อ CEM-002 = ⌈A×0.25⌉ ถุง · หรือ อิฐมวลเบา BRK-002 = ⌈A×8.33⌉ ก้อน + ปูนก่อ = ⌈A×0.12⌉ ถุง
   - ปูกระเบื้อง พื้นที่ A ตร.ม. + เศษเผื่อ 10% → TIL-001 = ⌈A×1.10/1.44⌉ กล่อง · ปูนกาว CEM-004 = ⌈A/4⌉ ถุง · ยาแนว TIL-003 = ⌈A/5⌉ ถุง
   - ทาสี พื้นที่ A ตร.ม. จำนวนเที่ยว N (ค่าเริ่มต้น 2) อัตรา 30 ตร.ม./แกลลอน/เที่ยว → ⌈A×N/30⌉ แกลลอน (ภายใน PNT-002 หรือ ภายนอก PNT-001) + รองพื้น PNT-003 = ⌈A/40⌉
   - เหล็กเส้น ขนาด (RB6/RB9/DB12/DB16) ยาวรวม L เมตร → จำนวนเส้น ⌈L/10⌉ และน้ำหนัก = L × (0.222/0.499/0.888/1.578) กก. (ทศนิยม 2 ตำแหน่ง)
4. **ตะกร้า + ชำระเงิน** `/cart` `/checkout` — แสดงราคาส่งที่ได้ต่อรายการ ใส่คูปอง เลือกสาขาที่ส่งของ วันส่ง (7 วันถัดไป ยกเว้นวันอาทิตย์) ช่วงเช้า/บ่าย แสดงรถที่ใช้ + ค่าส่ง + VAT + ยอดสุทธิ (ตามลำดับข้อ 1) · ตะกร้าเก็บใน DB ผูกกับ cookie session
5. **ใบเสนอราคา** — ปุ่ม "ขอใบเสนอราคา" จากตะกร้า → กรอกชื่อ/บริษัท/เลขผู้เสียภาษี (ไม่บังคับ) → หน้า `/quote/QT-YYYYMMDD-NNNN` พิมพ์ได้ (print CSS) มีอายุ 7 วัน และปุ่ม "แปลงเป็นคำสั่งซื้อ"
6. **คำสั่งซื้อ + ติดตาม** — สั่งซื้อแล้วได้เลข `BM-YYYYMMDD-NNNN` ตัดสต็อกสาขาที่เลือก (ถ้าไม่พอต้องแจ้งเตือนและไม่ให้สั่ง) · หน้า `/track` กรอกเลขคำสั่งซื้อ + เบอร์โทร → timeline: รับคำสั่งซื้อ → เตรียมสินค้า → กำลังจัดส่ง → ส่งแล้ว
7. **หลังร้าน** `/admin` (รหัสผ่านจาก env `ADMIN_PASSWORD` ค่า dev `admin1234`) — ตารางสต็อกแก้ไขได้, แจ้งเตือนสินค้าต่ำกว่าจุดสั่งซื้อซ้ำ, รายการคำสั่งซื้อ + เปลี่ยนสถานะ, แดชบอร์ดยอดขายวันนี้/7 วัน + 5 สินค้าขายดี (กราฟ SVG/CSS ไม่ต้องใช้ไลบรารี)
8. **แชทบอท** — ปุ่มลอยมุมขวาล่างทุกหน้า เปิดหน้าต่างแชท ประวัติแชทเก็บใน DB · มีปุ่มคำถามแนะนำ 3 ปุ่ม · ถ้าบอทสั่งเพิ่มลงตะกร้า ตัวเลขบนไอคอนตะกร้าต้องอัปเดตทันที

## 4) backend + แชทบอท

- **API** (Next.js route handlers): `/api/products` `/api/products/[sku]` `/api/calc/[type]` `/api/cart` `/api/checkout` `/api/quotes` `/api/orders` `/api/track` `/api/admin/*` `/api/chat`
- **ฐานข้อมูล PostgreSQL 16**: products, branches, stock, carts, cart_items, coupons, quotes, quote_items, orders, order_items, order_status_history, chat_sessions, chat_messages (สร้าง schema + seed ตอน container db เริ่มครั้งแรก)
- **แชทบอท "น้องช่าง"** (`/api/chat`) — พูดสุภาพลงท้าย "ครับ" ตอบภาษาไทย
  - ก่อนเรียก LLM ให้ค้นสินค้าที่เกี่ยวข้องจาก DB (ตามคำในคำถาม) แล้วใส่ชื่อ/SKU/ราคา/สต็อกลง system prompt พร้อมข้อมูลร้านข้อ 1 · **ห้ามแต่งราคาหรือสินค้าที่ไม่มีใน DB**
  - ใช้ **tag คำสั่ง** ในคำตอบของโมเดล แล้ว backend ทำงานจริง (ไม่ต้องพึ่ง function calling ของ server):
    - `[CALC]{"type":"concrete","volume":3}` → backend คำนวณด้วยฟังก์ชันเดียวกับ `/calculator` แล้วส่งผลกลับให้โมเดลตอบต่อ (วนได้ไม่เกิน 2 รอบ)
    - `[ADD_TO_CART]{"sku":"CEM-001","qty":21}` → เพิ่มลงตะกร้าจริง แล้วตอบยืนยัน
    - `[QUOTE]{}` → สร้างใบเสนอราคาจากตะกร้าปัจจุบัน แล้วตอบพร้อมเลข QT
    - ตัด tag ออกก่อนแสดงผลให้ลูกค้าเห็น
  - คำถามนอกเรื่อง (การเมือง ทำการบ้าน เขียนโค้ด) → ปฏิเสธสุภาพและชวนกลับมาเรื่องวัสดุก่อสร้าง
  - **โหมด** `MODE=ai` เรียก LLM จริง (OpenAI-compatible: `LLM_BASE_URL` `LLM_MODEL` `LLM_API_KEY` จาก `.env.vast`) · `MODE=mock` ใช้ `mock-llm` (server ตอบตาม pattern แบบ deterministic รองรับ tag ทั้ง 3 ตัว) เพื่อให้พัฒนา/ทดสอบได้โดยไม่ต้องเช่า GPU
  - ลบ `<think>…</think>` ออกจากคำตอบ (ถ้ามี) · timeout 60 วินาที · ถ้า LLM ล่มให้ตอบขอโทษ ไม่ใช่ error 500

## 5) เทคนิค (บังคับ)

- Next.js 14 (App Router) + TypeScript + `pg` · ไม่ใช้ UI library ใหญ่ (CSS ธรรมดา/ CSS modules ได้)
- `docker compose` 3 service: `db` (postgres:16-alpine, schema/seed ด้วย **COPY ใน Dockerfile** ไม่ใช้ bind mount), `web` (port **3400**→3000), `mock-llm` (profile `mock`)
- **ห้ามใช้ bind mount ใน compose** (compose ถูกสั่งจากใน container ผ่าน docker.sock ของเครื่อง host — path ใน container ไม่มีบน host)
- ตัวแปร: `.env.example` (MODE, LLM_*, ADMIN_PASSWORD, DATABASE_URL) · `.env` / `.env.vast` ห้าม commit
- คำสั่ง: `docker compose --profile mock up -d --build` (mock) · `docker compose up -d --build` + `.env.vast` (ai)
