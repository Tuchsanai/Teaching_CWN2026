- คัดลอกไฟล์ base ที่ Dockerfile ต้องใช้ (start.sh, jupyter_overrides.json) มาไว้ใน $OUT_DIR แล้วแก้เฉพาะที่จำเป็น
- สคริปต์/wrapper ที่ COPY เข้า image, docker-compose.yml, .dockerignore
- readme.md ภาษาไทย: build, run, ล็อกอินทีละบัญชี, โครงสร้างโฟลเดอร์, ต่างจาก base ตรงไหน

  Playwright MCP เปิดเว็บจริง + screenshot, ตารางสรุป PASS/FAIL) ห้ามจองหรือกรอกข้อมูลส่วนตัว

## ปรับ 2.4.3.1 ให้เข้ากับการติดตั้งใน image
- ข้อ "ห้ามติดตั้งซ้ำ" ใช้ไม่ได้ที่นี่: Dockerfile ต้องติดตั้ง Claude Code และ Codex CLI เอง
  เวอร์ชันปรับได้ด้วย ARG; pin @playwright/mcp; ถ้า npm ตอบ 404 เพราะเวอร์ชันเพิ่งออก ให้ลองใหม่หรือ pin เวอร์ชันก่อนหน้า
- credential/config/session ห้ามอยู่ใน image: $BASE_PATH=/root/ai-accounts เป็น volume
  โฟลเดอร์บัญชีและ shared (รวมค่าสุ่มของ shared-check) สร้างตอน container start ด้วยสคริปต์ที่รันซ้ำได้ ไม่เขียนทับของเดิม
- ของที่ใช้ร่วมและไม่ใช่ข้อมูลบัญชี (wrapper, @playwright/mcp, Chromium + system library) ติดตั้งใน image นอก volume
- wrapper วางใน PATH ของ image เช่น /usr/local/bin จึงไม่ต้องแก้ .bashrc
- start.sh ยังเปิด sshd, dockerd, jupyter lab ครบเหมือน base
- มีคำสั่ง ai-accounts-check ใน image: ตรวจแบบไม่ต้องล็อกอิน พิมพ์ตาราง PASS/FAIL/SKIP
  รวมการเปิด Playwright MCP ผ่าน stdio จริง (initialize, tools/list, browser_navigate) โดยไม่ผ่าน AI

## build และ run (Docker บนเครื่องนี้)
- docker build -t multiaccount_devtool:2569_1 $OUT_DIR
- ถ้ามี container MultiAccount_Devtool อยู่แล้วให้ลบ ตรวจ port SSH=2223 JUPYTER=8886 ถ้าชนใช้ port ว่างถัดไป
- docker run -dit --name MultiAccount_Devtool --hostname multiaccount-devtool --privileged \
    -p <SSH>:22 -p <JUPYTER>:8888 -v ai-accounts:/root/ai-accounts multiaccount_devtool:2569_1

## ทดสอบใน container ด้วย docker exec (PASS/FAIL/SKIP ตามจริง)
- ทุกข้อในหัวข้อ "ทดสอบ" ของ 2.4.3.1 และ ai-accounts-check ผ่าน
- docker restart แล้วยังผ่าน และค่าสุ่ม shared-check ไม่เปลี่ยน; ลบ container แล้วสร้างใหม่ด้วย volume เดิม ค่าสุ่มไม่เปลี่ยน
- ฟีเจอร์ base ยังทำงาน: sshd, dockerd (docker run --rm hello-world), JupyterLab ตอบที่ port
- อะไรที่ต้องล็อกอิน = SKIP

## รายงาน $OUT_DIR/build-report.md (ห้ามมี secret)
ไฟล์ที่สร้าง, สิ่งที่ต่างจาก base, ตาราง รายการ | หลักฐาน | PASS/FAIL/SKIP, port ที่ใช้จริง, ข้อจำกัด
