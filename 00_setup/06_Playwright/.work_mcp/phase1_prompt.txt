ทำงานใน container devtools-pwmcp-c34a6add ผ่าน docker exec / docker cp (ไฟล์ทดลองใน container ไว้ที่ /workspace/.probe_mcp แล้ว docker cp ผลกลับมาที่ 06_Playwright/.work_mcp/probe/)
1. เขียน Python stdlib ล้วน `mcp_client.py` (MCP client แบบ stdio, JSON-RPC 2.0, ข้อความคั่นด้วย newline) ที่ spawn `/usr/bin/playwright-mcp` เอง
   ลองหา config ที่ได้ viewport 1920x1080, deviceScaleFactor 2 (ถ้าทำได้), locale en-US, headless, isolated, no-sandbox, output-dir ใน /workspace (ดู `playwright-mcp --help` ทั้งหมด และ `--config` JSON)
   บันทึกทุกข้อความที่ส่ง/รับเป็น jsonl
2. handshake จริง: initialize (เก็บ serverInfo, capabilities, protocolVersion) → notifications/initialized → tools/list (บันทึกชื่อ tool + inputSchema เต็มลง tools.json และสรุปเป็นตาราง)
3. ลองทุก tool ที่บทเรียนจะใช้ บน example.com และ Google Flights (https://www.google.com/travel/flights?hl=en): navigate, snapshot, click, type/fill, press key, select option (ถ้ามี), take screenshot (ดูว่าได้ base64 หรือไฟล์ / ขนาดภาพจริง), evaluate (ทั้งทั้งหน้าและบน element ref), wait, tabs, close
   ตอบให้ได้ด้วยหลักฐานจริง:
   - response ของ tools/call หน้าตาอย่างไร (content blocks, ส่วน "### ..." ต่าง ๆ, โค้ด Playwright ที่รัน, Page URL, snapshot อยู่ตรงไหน)
   - หลัง click/type ได้ snapshot กลับมาอัตโนมัติไหม เป็น snapshot เต็มหรือแบบ diff/บางส่วน? ต้องเรียก snapshot เองเพื่อได้ของเต็มไหม
   - ref format (e.g. e107 / f1e2) เปลี่ยนอย่างไรเมื่อ navigate / reload / iframe, และ element ถูกสร้างใหม่
   - มี box/พิกัดใน snapshot ไหม ถ้าไม่มี วิธีหา bounding box จาก ref ด้วย evaluate ทำได้จริงไหม
   - ใช้ ref เก่าแล้วได้ error อะไร (ข้อความจริง, isError, หรือ JSON-RPC error)
   - ต้องส่ง "element" (คำอธิบาย) คู่ ref ไหม ถ้าไม่ส่ง/ส่งผิดเกิดอะไร
   - snapshot มีบรรทัดที่ถูกครอบด้วย '...' เมื่อชื่อมี ": " แบบ CLI ไหม, ลิงก์ผลค้นหาเที่ยวบินมี ref ไหม
   - อายุเบราว์เซอร์: ปิดเมื่อ process จบ? --isolated หมายถึงอะไร
4. วัดเทียบกับ playwright-cli (สร้าง wrapper ตาม LAB 1 ของบท CLI ใน container ถ้ายังไม่มี) ด้วย action เดียวกันบน Google Flights: ขนาด output (bytes/บรรทัด) ของ open/navigate, snapshot, click; เวลา; และสิ่งที่ได้/ไม่ได้
5. ลอง yolo1 ใน container แบบ LLM-in-control 1 ครั้ง (โจทย์สั้น: เปิด Google Flights แล้วบอกว่าช่อง Where from มีค่าอะไร ใช้ MCP playwright) ด้วย `--output-format json` เพื่อดูว่ามันเรียก tool อะไร กี่ครั้ง ใช้เวลา/ต้นทุนเท่าไร (ไว้เป็นตัวอย่างเทียบ)
