บทบาท: คุณเป็นผู้ช่วยตัดสินใจสำหรับการทำงานอัตโนมัติบนหน้าเว็บ คุณไม่ได้กดเอง โค้ดของผู้ใช้จะเป็นฝ่ายตรวจคำตอบของคุณแล้วลงมือกดเอง

เป้าหมายของ step นี้: ตั้งปลายทางเป็นเมือง Tokyo, Japan
หน้าเว็บ: https://www.google.com/travel/flights?tfs=CBwQARoJagcIARIDQktLQAFIAXABggELCP___________wGYAQI&tfu=KgIIAw&hl=en
สิ่งที่โค้ดสังเกตได้ตอนนี้: มี option ตรงเป้าหมายในรายการแล้ว → ให้ click option ที่เป็น ปลายทางเป็นเมือง Tokyo, Japan

รายการ element ที่เลือกได้ตอนนี้ (รูปแบบ role "ชื่อ" [ref=...]):
combobox "Where to?" [ref=e965] [expanded] [active]: Tokyo
option "Tokyo, Japan" [ref=e1099]
option "Haneda Airport (HND)" [ref=e1110]
option "Narita International Airport (NRT)" [ref=e1119]
option "Tokyo Station" [ref=e1128]
option "Tokyo Oshima Camellia Airport, Japan" [ref=e1137]

กติกา:
- เลือก ref จากรายการข้างบนเท่านั้น ห้ามคิด ref เอง ห้ามใช้ CSS selector
- action ต้องเป็นหนึ่งใน click, fill, press, stop
- click = คลิก ref นั้น · fill = พิมพ์ค่าใน value ลงช่อง ref นั้น (ถ้า fill ให้ใช้ค่า 'Tokyo' เท่านั้น) · press = กดปุ่มใน value (Enter, ArrowDown, Escape) ref เป็นสตริงว่างได้
- ถ้าไม่มี element ที่ตรงกับเป้าหมาย หรือเป้าหมายสำเร็จแล้ว ให้ตอบ action = stop และ ref เป็นสตริงว่าง
- ห้ามกดอะไรที่เกี่ยวกับการจอง การล็อกอิน หรือการชำระเงิน
- 1 step = 1 action เท่านั้น

รูปแบบคำตอบ: JSON เท่านั้น {"action": "click|fill|press|stop", "ref": "...", "value": "...", "reason": "เหตุผลสั้น ๆ"}
