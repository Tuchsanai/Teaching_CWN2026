ผู้ใช้ต้องการให้ใช้ **imagegen ของ cyolo1 สร้างรูปจำนวนมากพอให้เนื้อหาเข้าใจง่ายขึ้น** — ทุกหัวข้อทฤษฎีควรมีภาพประกอบ และทุก LAB ควรมีภาพแนวคิดอย่างน้อย 1 ภาพที่อธิบายว่า LAB นั้นทำอะไร

A. ภาพแนวคิดด้วย cyolo1 + skill imagegen (ตามสกิล cyolo: `cd <โฟลเดอร์> && cyolo1 exec -m gpt-6-astra -c model_reasoning_effort="high" -o <outfile.txt> "<prompt>" < /dev/null` สั่งให้ใช้ skill imagegen และบันทึก PNG ลง path ที่กำหนด) — cyolo1 คนละบัญชีกับ yolo1 รันขนานได้ (ไม่เกิน 4 งานพร้อมกัน)
   ข้อความในภาพเป็นไทยสั้น ๆ + ศัพท์อังกฤษ สะกดถูก ref/ชื่อ tool/ตัวเลขในภาพใช้ค่าจริงจาก notes/log เท่าที่ทำได้ พื้นหลังสว่าง อ่านง่าย
   ทฤษฎี (concept-XX-*.png):

   02 architecture: โค้ด Python (MCP client + ผู้คุม) ↔ stdio JSON-RPC ↔ Playwright MCP server ↔ Chromium; LLM ด้านข้างไม่มี tool ตอบ JSON; validator อนุญาตก่อน tools/call
   03 mcp-basics: host / client / server / tool + JSON-RPC message (id, method, params, result)
   04 mcp-handshake: initialize → notifications/initialized → tools/list → tools/call → result
   05 mcp-vs-cli: playwright-cli (คำสั่ง shell → daemon) vs playwright-mcp (tool call → server) จุดต่างหลักตาม notes
   06 snapshot-ref, 07 stale-ref, 08 loop (ชื่อ tool จริง), 09 decision-json, 10 trim-snapshot, 11 guardrail, 12 evidence-folder (มี rpc.jsonl), 13 red-circle (evaluate overlay → screenshot → ลบ), 14 flight-steps (แผน), 15 prompt-injection
