กติกา:
- เลือก ref ที่อยู่ใน snapshot ข้างบนเท่านั้น

- fill ต้องใส่ value = ข้อความที่จะกรอก, press ต้องใส่ value = ชื่อปุ่ม เช่น Enter, click ให้ value = ""
