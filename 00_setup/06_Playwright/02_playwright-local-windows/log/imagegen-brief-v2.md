# Image brief v2 (สำหรับ cyolo / Codex imagegen) — ภาพเปิดบทแบบไม่ใช้ศัพท์เทคนิค

ผู้อ่านคือมือใหม่ ไม่ใช่โปรแกรมเมอร์ ภาพต้องเล่าเรื่องได้เองโดยไม่ต้องอ่านคำอธิบายยาว
สไตล์: ภาพประกอบ infographic น่ารัก เป็นมิตร พื้นขาว/ครีม เส้นโค้งมน สีสดใส (ฟ้า เขียว ส้ม ม่วงอ่อน)
ตัวอักษรภาษาไทยเป็นหลัก ตัวใหญ่ อ่านง่าย คำน้อย (แต่ละป้ายไม่เกิน ~8 คำ) สะกดถูกต้อง
ใช้ศัพท์เทคนิคให้น้อยที่สุด ถ้าจำเป็นให้มีคำไทยกำกับ
โลโก้ Playwright เป็นหน้ากากละครสีเขียว-แดง ขนาด 1536x1024 แนวนอน

1. intro-01-what-is-playwright.png — หัวข้อใหญ่ "Playwright คืออะไร?"
   ตรงกลางเป็นหุ่นยนต์ผู้ช่วยตัวเล็กใส่หน้ากาก Playwright นั่งหน้าจอเบราว์เซอร์ ใช้เมาส์และคีย์บอร์ดเหมือนคน
   รอบ ๆ มี 4 การ์ดไอคอน: "เปิดเว็บ" (โลก) · "คลิกปุ่ม" (เคอร์เซอร์) · "พิมพ์ข้อความ" (คีย์บอร์ด) · "ตรวจว่าถูกไหม" (เครื่องหมายถูก)
   แถบล่าง: "หุ่นยนต์ที่ใช้เว็บแทนเรา เร็วกว่า ไม่เบื่อ ไม่ลืม"

2. intro-02-why-playwright.png — หัวข้อ "ทำไมต้องใช้ Playwright?" เปรียบเทียบซ้าย-ขวา
   ซ้าย "ทดสอบเอง": คนเหนื่อย เหงื่อตก กดเว็บซ้ำ ๆ นาฬิกาบอก "ทีละเบราว์เซอร์ หลายชั่วโมง" มีไอคอนพลาด/ลืม
   ขวา "ให้ Playwright ทำ": หุ่นยนต์ตรวจพร้อมกัน 5 เบราว์เซอร์ (ไอคอน Chrome, Edge, Firefox, Safari/WebKit, Chromium) นาฬิกาบอก "ไม่กี่วินาที" ป้าย "ผ่าน 15/15"
   แถบล่าง: "แถมให้ AI (Claude) ใช้เว็บแทนเราได้ด้วย" มีไอคอน Claude คุยกับหุ่นยนต์ Playwright

3. intro-03-install-on-windows.png — หัวข้อ "ติดตั้ง Playwright บน Windows ต้องลงอะไรบ้าง?"
   เล่าเหมือน "ลงแอป แล้วลงปลั๊กอินเสริม" เป็นเส้นทาง/บันไดขั้น 1→5 บนหน้าจอ Windows 11 แต่ละขั้นเป็นกล่องของขวัญ/แพ็กเกจที่แกะออก:
   ① "Node.js" ป้ายไทย "เครื่องยนต์" (ไอคอน node สีเขียว)
   ② "Playwright" ป้ายไทย "ตัวหุ่นยนต์" (หน้ากาก)
   ③ "เบราว์เซอร์ทดสอบ" ป้ายไทย "สนามให้หุ่นยนต์วิ่ง" (Chromium, Firefox, WebKit)
   ④ "Playwright MCP" ป้ายไทย "สายเชื่อมกับ Claude" (ปลั๊กเสียบ)
   ⑤ "Playwright Extension ใน Chrome" ป้ายไทย "ปลั๊กอินให้ AI ใช้ Chrome ของเรา" (ชิ้นจิ๊กซอว์บนไอคอน Chrome)
   ปลายทางมีธง "พร้อมใช้!" และคำใบ้เล็ก ๆ "ไม่ต้องจำคำสั่ง ให้พรอมต์ช่วยติดตั้ง"

4. intro-04-copy-paste-flow.png — หัวข้อ "เรียนบทนี้ยังไง? แค่ Copy → Paste"
   flow 4 ขั้นซ้ายไปขวา ลูกศรใหญ่:
   ① "Copy พรอมต์" (ไอคอนเอกสาร + ปุ่มคัดลอก)
   ② "Paste ใน Claude Code" (หน้าต่าง terminal มีโลโก้ Claude สีส้ม)
   ③ "Claude ตรวจและถามก่อนติดตั้ง" (กล่องข้อความ "อัปเดตไหม? ใช่ / ไม่") มีคนกดยืนยัน
   ④ "ได้ผล + ภาพหน้าจอ" (ตาราง ก่อน/หลัง และภาพเว็บ พร้อมเครื่องหมายถูก)
   แถบล่าง: "เราเป็นคนตัดสินใจ AI เป็นคนลงมือ"
