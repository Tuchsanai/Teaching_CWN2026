# Image brief v3 (cyolo / Codex imagegen) — "การ์ดพรอมต์" ประจำแต่ละ LAB

ทุกภาพใช้เทมเพลตเดียวกัน เพื่อให้ผู้เรียนเห็นทันทีว่า "พิมพ์อะไร แล้วได้อะไร"
- ขนาด 1536x1024 แนวนอน พื้นครีม/ขาว ภาพประกอบน่ารัก เส้นโค้งมน สีสดใส สไตล์เดียวกับภาพ intro-0x ในโฟลเดอร์ img/
- มุมซ้ายบน: ป้ายใหญ่ "LAB n" + ชื่อ LAB (ตามที่กำหนด)
- ครึ่งซ้าย: หน้าต่าง "Claude Code" (กรอบ terminal สีเข้ม มีโลโก้ดอกไม้สีส้มของ Claude) ข้างในมี "ฟองข้อความของผู้ใช้" ที่มีข้อความพรอมต์ตามที่กำหนด **ตัวอักษรไทยต้องตรงทุกตัว** และมีปุ่มเล็ก "Copy" มุมฟองข้อความ
- ลูกศรใหญ่จากซ้ายไปขวา
- ครึ่งขวา: "ผลที่ได้" เป็นภาพประกอบง่าย ๆ ตามที่กำหนด
- แถบล่าง: ข้อความสั้น 1 บรรทัดตามที่กำหนด
- มีหุ่นยนต์ Playwright (หุ่นยนต์ขาวตัวเล็ก ใส่หน้ากากละครเขียว-แดง) ตัวเดียวกับภาพ intro อยู่ในภาพ
- ห้ามมีข้อความอื่นนอกจากที่กำหนด (ลดโอกาสสะกดผิด)

1. lab1-prompt.png — ป้าย "LAB 1 · พรอมต์รวม"
   พรอมต์: "ตรวจและอัปเดตเครื่องมือ Playwright ทั้งหมด 5 ขั้น ถามผมก่อนอัปเดต"
   ผลที่ได้: รายการเช็กลิสต์ 5 ข้อ (ตรวจ → ตาราง → อัปเดต → ตรวจ MCP → ทดสอบ) มีเครื่องหมายถูก และตาราง "ก่อน / หลัง"
   แถบล่าง: "พรอมต์เดียว ทำครบทั้งบท"

2. lab2-prompt.png — ป้าย "LAB 2 · ตรวจเวอร์ชัน"
   พรอมต์: "ตรวจเวอร์ชันทุกเครื่องมือ สรุปเป็นตาราง ห้ามติดตั้งอะไร"
   ผลที่ได้: ตาราง 3 แถว ป้ายสี: เขียว "ล่าสุดแล้ว" · ส้ม "ต้องอัปเดต" · เทา "ยังไม่ได้ติดตั้ง" และแว่นขยาย
   แถบล่าง: "ดูก่อน ยังไม่แตะอะไร"

3. lab3-prompt.png — ป้าย "LAB 3 · ติดตั้ง Playwright"
   พรอมต์: "ติดตั้ง Playwright ในโฟลเดอร์ lab พร้อมเบราว์เซอร์ทดสอบ"
   ผลที่ได้: กล่องของขวัญแกะแล้ว มีไอคอน Chromium, Firefox, Safari/WebKit และหน้ากาก Playwright พร้อมเครื่องหมายถูก
   แถบล่าง: "ดาวน์โหลดไม่ผ่าน? ให้ Claude หาสาเหตุให้"

4. lab4-prompt.png — ป้าย "LAB 4 · เขียนและรัน test"
   พรอมต์: "เขียน test 3 ข้อ รันทุกเบราว์เซอร์ แล้วเปิดรายงาน"
   ผลที่ได้: หน้ารายงานผล มีป้ายใหญ่สีเขียว "15 passed" และไอคอน 5 เบราว์เซอร์ (Chrome, Edge, Firefox, Safari, Chromium) มีเครื่องหมายถูกทุกตัว
   แถบล่าง: "test ล้ม? ดูภาพหน้าจอก่อนแก้"

5. lab5-prompt.png — ป้าย "LAB 5 · ตรวจ Playwright MCP"
   พรอมต์: "ตรวจว่า Playwright MCP ใช้ได้จริง ไม่ใช่แค่ Connected"
   ผลที่ได้: ปลั๊กเสียบเชื่อม Claude กับหุ่นยนต์ Playwright และชิ้นจิ๊กซอว์บนไอคอน Chrome มีป้าย "Connected ≠ ใช้ได้" ขีดเส้นใต้ แล้วด้านล่างเครื่องหมายถูก "เปิดเว็บได้จริง"
   แถบล่าง: "ปลั๊กอินต้องอยู่ใน Chrome จริง"

6. lab6-prompt.png — ป้าย "LAB 6 · ใช้เว็บจริง"
   พรอมต์: "เปิด google.co.th ในแท็บใหม่ ค้นหา Playwright MCP แล้วจับภาพ"
   ผลที่ได้: หน้าค้นหาแบบ Google (ช่องค้นหา + ผลลัพธ์ 3 แถว) บนแท็บใหม่ ข้าง ๆ มีโล่ป้องกันพร้อมข้อความ "ไม่แตะแท็บเดิม" และไอคอนเบลอรูปโปรไฟล์
   แถบล่าง: "AI ใช้ Chrome ของเรา ต้องระวังข้อมูลส่วนตัว"

7. lab7-prompt.png — ป้าย "LAB 7 · สรุปก่อน/หลัง"
   พรอมต์: "ตรวจซ้ำ เทียบก่อน/หลัง และบอกสิ่งที่ผมต้องทำเอง"
   ผลที่ได้: ตาราง 2 คอลัมน์ "ก่อน" (เทา) → "หลัง" (เขียว) และกระดาษโน้ต "สิ่งที่ต้องทำเอง" มีช่องติ๊ก 2 ช่อง
   แถบล่าง: "รู้ว่าอะไรสำเร็จ อะไรต้องทำต่อ"
