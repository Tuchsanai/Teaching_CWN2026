# Image brief v4 (cyolo / Codex imagegen) — การ์ดพรอมต์แบบสว่าง ไม่มีหน้าจอดำ

ผู้เรียนเป็นนักเรียนมือใหม่ ภาพต้องเรียบง่าย สว่าง เป็นมิตร
**ห้ามมีหน้าจอสีดำ / terminal / หน้าต่างพื้นเข้มใด ๆ ทั้งสิ้น**

เทมเพลตการ์ดพรอมต์ (ภาพ 1–8)
- ขนาด 1536x1024 แนวนอน พื้นครีมอ่อน ภาพประกอบน่ารัก เส้นโค้งมน สีพาสเทลสดใส สไตล์เดียวกับ img/intro-01-what-is-playwright.png
- มุมซ้ายบน: ป้ายใหญ่ "LAB n · ชื่อ" ตามที่กำหนด
- ครึ่งซ้าย: **หน้าต่างแชตสีขาว** มุมโค้ง แถบหัวสีเทาอ่อนเขียนว่า "Claude Code" พร้อมโลโก้ดอกไม้สีส้ม ข้างในมีฟองข้อความของผู้ใช้สีฟ้าอ่อน ข้อความพรอมต์ตามที่กำหนด **ตัวอักษรไทยต้องตรงทุกตัว** และปุ่มเล็ก "Copy" มุมฟอง
- ลูกศรใหญ่สีส้มจากซ้ายไปขวา
- ครึ่งขวา: กล่อง "ผลที่ได้" ภาพประกอบตามที่กำหนด
- แถบล่างสีเหลืองอ่อน: ข้อความ 1 บรรทัดตามที่กำหนด
- มีหุ่นยนต์ Playwright (หุ่นยนต์ขาวตัวเล็ก ใส่หน้ากากละครเขียว-แดง) ตัวเดียวกับภาพ intro
- ห้ามมีข้อความอื่นนอกจากที่กำหนด ห้ามมีไอคอน Python / Docker

1. lab1-prompt.png — "LAB 1 · พรอมต์รวม"
   พรอมต์: "ตรวจและอัปเดตเครื่องมือ Playwright ทั้งหมด 5 ขั้น ถามผมก่อนอัปเดต"
   ผลที่ได้: เช็กลิสต์ 5 ข้อ "ตรวจ / ตาราง / อัปเดต / ตรวจ MCP / ทดสอบ" มีเครื่องหมายถูก และตาราง "ก่อน / หลัง"
   แถบล่าง: "พรอมต์เดียว ทำครบทั้งบท"

2. lab2-prompt.png — "LAB 2 · ตรวจเวอร์ชัน"
   พรอมต์: "ตรวจเวอร์ชันทุกเครื่องมือ สรุปเป็นตาราง ห้ามติดตั้งอะไร"
   ผลที่ได้: ตาราง 3 แถว: หน้ากาก Playwright + ป้ายเขียว "ล่าสุดแล้ว" · โลโก้ Node.js หกเหลี่ยมเขียว + ป้ายส้ม "ต้องอัปเดต" · โลโก้ Firefox + ป้ายเทา "ยังไม่ได้ติดตั้ง" และแว่นขยาย
   แถบล่าง: "ดูก่อน ยังไม่แตะอะไร"

3. lab3-prompt.png — "LAB 3 · ติดตั้ง Playwright"
   พรอมต์: "ติดตั้ง Playwright ในโฟลเดอร์ lab พร้อมเบราว์เซอร์ทดสอบ"
   ผลที่ได้: กล่องของขวัญแกะแล้ว มีไอคอน Chromium, Firefox, Safari/WebKit และหน้ากาก Playwright พร้อมเครื่องหมายถูก
   แถบล่าง: "ดาวน์โหลดไม่ผ่าน? ให้ Claude หาสาเหตุให้"

4. lab4-prompt.png — "LAB 4 · เขียนและรัน test"
   พรอมต์: "เขียน test 3 ข้อ รันทุกเบราว์เซอร์ แล้วเปิดรายงาน"
   ผลที่ได้: หน้ารายงานสีขาว ป้ายใหญ่สีเขียว "15 passed" และไอคอน 5 เบราว์เซอร์ (Chrome, Edge, Firefox, Safari, Chromium) มีเครื่องหมายถูกทุกตัว
   แถบล่าง: "test ล้ม? ดูภาพหน้าจอก่อนแก้"

5. lab5-prompt.png — "LAB 5 · ติดตั้งปลั๊กอินใน Chrome"
   พรอมต์: "เปิดหน้า Playwright Extension ใน Chrome Web Store ให้หน่อย"
   ผลที่ได้: หน้าต่าง Chrome สีขาว มีหน้ากาก Playwright ตรงกลาง และปุ่มสีน้ำเงิน "Add to Chrome" ที่มี **วงกลมสีแดง** ล้อมไว้ พร้อมมือชี้กด และชิ้นจิ๊กซอว์สีเขียวมีเครื่องหมายถูก
   แถบล่าง: "เรากดติดตั้งเอง แล้วให้ Claude ตรวจ"

6. lab6-prompt.png — "LAB 6 · ตรวจ Playwright MCP"
   พรอมต์: "ตรวจว่า Playwright MCP ใช้ได้จริง ไม่ใช่แค่ Connected"
   ผลที่ได้: ปลั๊กเสียบเชื่อมโลโก้ Claude กับหุ่นยนต์ Playwright และชิ้นจิ๊กซอว์บนไอคอน Chrome ป้าย "Connected ≠ ใช้ได้" ขีดเส้นใต้แดง และด้านล่างเครื่องหมายถูก "เปิดเว็บได้จริง"
   แถบล่าง: "ปลั๊กอินต้องอยู่ใน Chrome จริง"

7. lab7-prompt.png — "LAB 7 · ใช้เว็บจริง"
   พรอมต์: "เปิด google.co.th ในแท็บใหม่ ค้นหา Playwright MCP แล้วจับภาพ"
   ผลที่ได้: หน้าค้นหาแบบ Google สีขาว (ช่องค้นหา "Playwright MCP" + ผลลัพธ์ 3 แถว) บนแท็บใหม่ ข้าง ๆ มีโล่สีเขียว ป้าย "ไม่แตะแท็บเดิม" และรูปโปรไฟล์ที่ถูกเบลอ และกล้องถ่ายรูป
   แถบล่าง: "AI ใช้ Chrome ของเรา ต้องระวังข้อมูลส่วนตัว"

8. lab8-prompt.png — "LAB 8 · สรุปก่อน/หลัง"
   พรอมต์: "ตรวจซ้ำ เทียบก่อน/หลัง และบอกสิ่งที่ผมต้องทำเอง"
   ผลที่ได้: ตาราง 2 คอลัมน์ "ก่อน" (เทา) → "หลัง" (เขียว) มีเครื่องหมายถูก และกระดาษโน้ต "สิ่งที่ต้องทำเอง" มีช่องติ๊ก 2 ช่อง
   แถบล่าง: "รู้ว่าอะไรสำเร็จ อะไรต้องทำต่อ"

9. intro-04-copy-paste-flow.png — ภาพเปิดบท (ไม่ใช่การ์ด LAB) หัวข้อ "เรียนบทนี้ยังไง? แค่ Copy → Paste"
   flow 4 ขั้นซ้ายไปขวา ลูกศรใหญ่ แต่ละขั้นมีเด็กนักเรียนการ์ตูน:
   ① "Copy พรอมต์" (กระดาษ + ปุ่มคัดลอก)
   ② "Paste ใน Claude Code" (**หน้าต่างแชตสีขาว** แถบหัว "Claude Code" โลโก้ดอกไม้สีส้ม ห้ามเป็นจอดำ)
   ③ "Claude ตรวจและถามก่อนติดตั้ง" (กล่องข้อความ "อัปเดตไหม? ใช่ / ไม่" คนกดปุ่ม "ใช่")
   ④ "ได้ผล + ภาพหน้าจอ" (ตาราง ก่อน/หลัง และภาพเว็บ พร้อมเครื่องหมายถูก)
   แถบล่าง: "เราเป็นคนตัดสินใจ AI เป็นคนลงมือ"
