Multi-Account Chat

การเชื่อมต่อ

ค่าเริ่มต้นคือเว็บไซต์เดียวกับหน้านี้ แก้ได้ถ้าตั้ง API ไว้ที่อื่น

เก็บไว้ในหน่วยความจำของหน้านี้เท่านั้น ปิดหรือรีเฟรชหน้าแล้วจะหายไป

  • 1. เซิร์ฟเวอร์ตอบ /healthยังไม่ได้ตรวจ
  • 2. Token ผ่านการตรวจยังไม่ได้ตรวจ
  • 3. บัญชีตอบคำถามได้จริงยังไม่ยืนยัน จะยืนยันเมื่อได้คำตอบจริงครั้งแรก

ผู้ตอบ

แสดงเฉพาะระดับที่โมเดลนี้รองรับ

แสดงเฉพาะบัญชีที่ตั้งค่าไว้บนเซิร์ฟเวอร์

ส่งคำถามสั้น ๆ หนึ่งครั้งเพื่อยืนยันว่าบัญชีตอบได้ ไม่บันทึกลงบทสนทนา
