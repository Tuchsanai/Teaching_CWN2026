# ที่มาของภาพ `assets/architecture-single-app.png`

- **เครื่องมือ:** ImageGen ที่มีมาในตัว (built-in) · **ยังไม่ได้ยืนยันเวอร์ชันที่แน่นอน**
- **ประเภท:** แผนภาพอธิบาย (explanatory diagram) ไม่ใช่ภาพหน้าจอ และไม่ใช่หลักฐานว่าการ deploy แบบใหม่ใช้ได้
- **สถานะ:** ผ่านการอนุมัติให้ใช้ในหัวข้อ 1 ของ README

## brief ที่ใช้

- พื้นหลังขาว ข้อความภาษาไทย
- แนวนอน: Browser ↔ App (FastAPI + yolo/cyolo) ↔ Providers (Claude Code CLI / Codex CLI)
- devtools อยู่ด้านล่าง มีเส้นประชี้ขึ้นไปที่ App แทนการ deploy (devtools แค่สร้างและ deploy ไม่ได้อยู่ในเส้นทางของคำขอ)
- volume credential ส่วนตัวแยกเป็นกล่องต่างหาก ต่อกับ App เท่านั้น
- วงกลมหมายเลข 1–3 แทนพรอมต์สามชุด: ① Backend · ② index.html · ③ deploy
- พอร์ตแสดงว่ามาจาก `.env` (8004 เป็นแค่ค่าเริ่มต้น)
- ภาพหน้าจอย่อส่วนของหน้าแชตใช้ UI จริงของเวอร์ชันก่อนหน้า (`assets/13-current-chat-real.png`) เป็นภาพอ้างอิงเท่านั้น `index.html` ของแบบใหม่ต้องสร้างใหม่ตามพรอมต์ 2
