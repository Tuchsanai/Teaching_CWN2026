# การออกแบบภาพ `assets/architecture-prompt-map.png`

## เครื่องมือ

สร้างด้วยโหมด ImageGen ที่มีมาในตัว (builtin) ของเครื่องมือ AI ที่ใช้เขียนเอกสาร ยังไม่ได้ยืนยันชื่อหรือเวอร์ชันโมเดลที่แน่นอน

ภาพนี้เป็น **แผนภาพอธิบาย** ไม่ใช่หลักฐานการทำงานจริง หลักฐานจริงอยู่ในภาพหน้าจอและ log ในหัวข้อ 5 ของ README

## ภาพต้นทางที่ใช้อ้างอิง

- `assets/07-astra-ten-exchanges.png` — ภาพหน้าจอจริงของหน้าแชต ใช้เป็นแบบอ้างอิงหน้าตา UI ในแผนภาพ

## Prompt brief

- แผนภาพเชิงเทคนิคแบบมืออาชีพ พื้นเรียบ อ่านง่าย
- วงกลมหมายเลขแทนพรอมต์เท่านั้น:
  - 🔵 วงกลมสีน้ำเงิน ① = พรอมต์ 1 สร้าง Backend (README หัวข้อ 2)
  - 🟣 วงกลมสีม่วง ② = พรอมต์ 2 สร้างหน้าแชต HTML (README หัวข้อ 3)
  - 🟠 วงกลมสีส้ม ③ = พรอมต์ 3 deploy และทดสอบ (README หัวข้อ 4)
- ใช้ภาพหน้าจอจริงข้างต้นเป็นแบบอ้างอิงหน้าแชต
- แสดง container พี่น้องกันสามตัวบน daemon เดียวกัน: `devtools`, `lab04-api`, `lab04-web`
- เบราว์เซอร์โหลด HTML จาก `lab04-web` ที่พอร์ต `8005`
- เบราว์เซอร์ส่งข้อความตรงไปยัง `lab04-api` ที่พอร์ต `8004` (ไม่ผ่าน devtools)
- devtools เป็นศูนย์ควบคุม: สร้างไฟล์ สั่ง build และคัดลอก credential ส่วนตัวไปยัง volume ของ API

## สิ่งที่ต้องตรวจก่อนอนุมัติภาพ

- ปลายลูกศรทุกเส้นชี้ถูกต้นทาง/ปลายทาง: เบราว์เซอร์ → web:8005, เบราว์เซอร์ → API:8004, devtools → container ที่ควบคุม
- ไม่มีลูกศรจากเบราว์เซอร์ผ่าน devtools ไปยัง API
- หมายเลขและสีตรงกับพรอมต์ตามรายการข้างต้น ไม่มีตัวเลขอื่นที่สื่อความหมายต่างออกไป
- ข้อความในภาพไม่อ้างว่าเป็นผลการรันจริง
