**สิ่งที่ควรรู้:**
- หน้าเว็บเติม "Bangkok" ไว้ให้ก่อน ซึ่งรวมทั้งสนามบิน BKK และ DMK agent เปลี่ยนเป็นสุวรรณภูมิ (BKK) อย่างเดียวตามโจทย์
- ชื่อของช่องปลายทางไม่เปลี่ยนหลังเลือก option โค้ดจึงถือว่าผ่านเมื่อค่าในช่องเป็น "Tokyo" dropdown ปิดแล้ว และไม่เหลือ option บนหน้า
- ทางหยุดฉุกเฉิน (เจอ denylist, เจอ CAPTCHA, ครบ 25 action) มีอยู่ในโค้ด แต่ยังไม่เคยเกิดขึ้นจริงทั้งสองรอบ เลยยังไม่ได้ทดสอบ
- ภาพ `page.png` ฉันเปิดดูเองแค่สองภาพ คือหน้าผลลัพธ์ (วงราคาทั้ง 3 อันดับถูกที่) กับ step เลือก "Tokyo, Japan" (วงแดงพอดีแถว) ภาพของ step อื่นใช้โค้ดวาดชุดเดียวกัน แต่ฉันยังไม่ได้เปิดดู

**การทำงานของ agent โดยย่อ:**
- **ส่วนที่ LLM เห็น:** เฉพาะ button/combobox/textbox/option ที่มีชื่อและอยู่ในฟอร์มค้นหา ตอนเลือกวันจะเห็นแค่ปุ่มวันของเดือนเป้าหมาย ส่วน step search เห็นแค่ปุ่ม
- **ตรวจก่อนรันคำสั่งทุกครั้ง:** action ต้องอยู่ใน allowlist, ref ต้องมีใน snapshot ล่าสุด และอยู่ในรายการที่แสดงให้ LLM เห็น ถ้าชื่อ element ตรง Book/Sign in/Payment/Select flight/Select fare หรือหน้าเป็น CAPTCHA จะหยุดทันที
- **โค้ดเป็นผู้ตัดสิน PASS:** ตรวจเป้าหมายของแต่ละ step จาก snapshot ใหม่ ถ้าผ่านอยู่แล้วก็ข้าม step นั้น
