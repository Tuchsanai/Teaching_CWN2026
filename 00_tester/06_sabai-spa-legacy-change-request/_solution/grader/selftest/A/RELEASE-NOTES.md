# บันทึกการส่งมอบ · ถึงคุณจันทร์

## เปลี่ยนอะไรบ้าง
- ค่ารถรับส่ง: ไม่เกิน 7 กม. ฟรี · มากกว่านั้นถึง 15 กม. ฿350 ต่อคัน
- ติ๊กว่าต้องการรถแล้วต้องเลือกโรงแรมหรือใส่ระยะ ไม่งั้นจองไม่ได้
- ปิดประคบสมุนไพร (S03) ชั่วคราว · เจ้าของร้านเปิดกลับเองได้
- หน้าบัญชีมีประวัติแต้ม

## ปัญหาที่ยังเหลือ
- cookie หลังออกจากระบบยังใช้ได้ (TC-SEC-05 ล้มตั้งแต่ก่อนแก้)
- ปุ่มรีเซ็ต/ตั้งเวลาทดสอบยังเปิดถ้าไม่ตั้ง `ALLOW_TEST_RESET=0`

## ขั้นตอนขึ้นระบบ
1. สำรองฐาน (`pg_dump`) 2. รัน migration ตาม `exam/MIGRATION.md` 3. build/up เว็บ 4. `node tests/smoke.mjs` ต้องผ่าน
5. ถอยกลับ: รันไฟล์ `.down.sql` แล้วขึ้นเว็บเวอร์ชันก่อน (ไม่ลบ volume ฐานข้อมูล)
