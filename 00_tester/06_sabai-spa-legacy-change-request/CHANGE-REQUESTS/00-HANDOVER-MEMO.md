# บันทึกส่งมอบงาน ระบบจองคิว "สบายใจ สปา" (Sabai Jai Wellness Spa)

**จาก** บริษัท โค้ดไว จำกัด (ผู้รับเหมาพัฒนาระบบ ระยะที่ 1)
**ถึง** คุณจันทร์ เจ้าของร้านสบายใจ สปา และทีมดูแลระบบรายใหม่
**วันที่** 30 กันยายน 2569 · วันสิ้นสุดระยะรับประกัน

## 1. สิ่งที่ส่งมอบ

| รายการ | ที่อยู่ | หมายเหตุ |
|---|---|---|
| โค้ดเว็บ (Next.js + TypeScript) | `web/` | หน้าเว็บ + API + กฎร้านทั้งหมด |
| ฐานข้อมูล (PostgreSQL 16) | `db/` | `init/01-schema.sql` · `init/02-seed.sql` |
| เอกสารระบบ | `web/SPEC.md` | ฉบับ 1.0 เป็นปัจจุบัน ตรงกับระบบทุกข้อ |
| ชุดตรวจกฎร้าน | `web/scripts/check-rules.mjs` | 90 เคส |
| ชุดทดสอบหน้าเว็บอัตโนมัติ | `e2e-legacy/` | Playwright 42 เคส |

## 2. วิธีเปิดระบบ (Windows PowerShell)

```powershell
docker network create sabai06-net
docker compose -f db/compose.yaml up -d --wait
docker compose -f web/compose.yaml up -d --build --wait
```

- เว็บ: http://localhost:4000 · ฐานข้อมูล: localhost:5433 (ผู้ใช้ `sabai`)
- ข้อมูลทดสอบรีเซ็ตได้ที่ `POST /api/test/reset` · **ในการใช้งานจริงปิดไว้แล้ว** (`ALLOW_TEST_RESET=0`)
- บัญชีทดสอบแสดงอยู่ที่หน้าเข้าสู่ระบบ (เฉพาะโหมดทดสอบ)

## 3. ผลการทดสอบก่อนส่งมอบ

- ชุดตรวจกฎร้าน **ผ่าน 90/90**
- ชุดทดสอบหน้าเว็บ **ผ่านทั้งหมด** ยกเว้น 3 เคสที่ติดป้าย `KNOWN-ISSUE` ไว้แล้ว (ไม่กระทบการใช้งาน)
- ระบบรองรับการจองพร้อมกันหลายคน ไม่มีการจองซ้อน

## 4. ข้อจำกัดที่ทราบ

- ห้อง Couple Suite มี 1 ห้อง
- แชทบอทจองได้เฉพาะบริการเดี่ยว 1 คน

## 5. ติดต่อ

ระยะรับประกันสิ้นสุดวันนี้ หลังจากนี้ไม่มีผู้ดูแลจากบริษัท ขอให้ทีมใหม่ศึกษาจากโค้ดและเอกสารที่ส่งมอบ

ลงชื่อ ผู้จัดการโครงการ บริษัท โค้ดไว จำกัด
