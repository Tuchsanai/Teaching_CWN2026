# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 3/2569 (ด่วน)

| | |
|---|---|
| เลขที่ | CR-03 |
| วันที่ | 12 ตุลาคม 2569 |
| เรื่อง | ลูกค้าร้องเรียน โดนจองซ้ำ 2 นัด |
| เรียน | ทีมดูแลระบบจองคิว |
| ความเร่งด่วน | **ด่วน** (มีเรื่องร้องเรียนแล้ว) |

เมื่อวานมีลูกค้าร้องเรียนค่ะ คุณสมชายจองนวดผ่านมือถือ เน็ตค้างเลยกดใหม่ ได้ข้อความจองสำเร็จ 2 รหัส
ร้านเห็นในตารางคิวเป็น 2 นัด จัดหมอนวดไว้ 2 คน เสียคิวไปหนึ่งคิว
อีกรายจองผ่านแชทแล้วมาจองหน้าเว็บซ้ำเวลาเดียวกันก็ได้อีกนัด

ร้านขอว่า **คนเดียวกันต้องไม่มีนัดที่เวลาทับกัน** ถ้าจองซ้ำให้ขึ้นข้อความบอกว่ามีนัดอยู่แล้ว พร้อมรหัสนัดเดิม
(ถ้ามาหลายคนให้จองแบบคู่หรือกลุ่มอยู่แล้วค่ะ)

"คนเดียวกัน" คือบัญชีสมาชิกเดียวกัน หรือถ้าไม่ได้สมัครสมาชิกก็ดูจากเบอร์โทร (บางคนพิมพ์มีขีด บางคนไม่มีขีด)

ข้อมูลเรื่องร้องเรียน: คุณสมชาย เบอร์ 081-000-0003 นัดเดิมวันที่ 13 ต.ค. 2569 เวลา 10:00
