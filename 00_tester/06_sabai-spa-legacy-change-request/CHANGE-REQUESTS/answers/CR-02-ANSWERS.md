# คำตอบข้อซักถาม CR-02 · ส่วนลดกลุ่มขั้นบันได

## ① คำตอบของร้าน
- "วันที่จอง" = วันที่ลูกค้ากดยืนยันการจอง (วันนี้ของระบบตอนนั้น) **ไม่ใช่วันนัด**
- ปี 2569 = ค.ศ. 2026 · เริ่ม 1 พ.ย. 2569 เวลา 00:00 ตามเวลาไทย
- ถ้าส่วนลดเท่ากัน (เช่น กลุ่ม 3 คน 5% กับสมาชิก Gold 5%) ให้ขึ้นว่าเป็น "ส่วนลดกลุ่ม" เหมือนที่ระบบทำอยู่ (ลำดับเดิม: กลุ่ม → ระดับสมาชิก → เดือนเกิด)
- นัดที่จองไว้แล้วก่อน 1 พ.ย. ห้ามเปลี่ยนยอด แม้วันนัดจะอยู่หลัง 1 พ.ย.
- ลูกค้าที่เปิดหน้าสรุปราคาไว้ข้ามเที่ยงคืน 31 ต.ค. แล้วกดยืนยัน ให้ระบบบอกว่าราคาเปลี่ยน (เหมือนกรณีราคาเปลี่ยนที่ระบบมีอยู่แล้ว)

## ② สิ่งที่ตกลงร่วมกัน
| เรื่อง | ตกลง |
|---|---|
| API | ไม่มี endpoint ใหม่ · `/api/price` และ `/api/bookings` ใช้อัตราตามวันที่จอง |
| ข้อมูลเดิม | ไม่ย้อนแก้ส่วนลดของนัดเก่าในฐานข้อมูล |
| ข้อความ | ป้ายส่วนลดใช้รูปแบบเดิม (แสดง % ตามจริง) |
