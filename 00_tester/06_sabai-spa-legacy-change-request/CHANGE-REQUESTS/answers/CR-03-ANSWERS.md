# คำตอบข้อซักถาม CR-03 · จองซ้ำ

## ① คำตอบของร้าน
- สมาชิก: ดูจากบัญชี · ไม่ได้ล็อกอิน: ดูจากเบอร์โทรที่กรอก โดยตัดขีด ช่องว่าง วงเล็บออกเหลือแต่ตัวเลข
- สมาชิกกับคนที่ไม่ได้ล็อกอินไม่ต้องเอามาเทียบกัน (แม้เบอร์จะตรงกับเบอร์ในบัญชี)
- "ทับกัน" = ช่วงเวลาเหลื่อมกันแม้แค่บางส่วน · นัดที่ต่อกันพอดี (จบ 11:30 เริ่มใหม่ 11:30) จองได้
- นัดที่ยกเลิกแล้วไม่นับ
- ใช้กับทุกแบบการจองและทุกช่องทาง (หน้าเว็บและแชท)
- คนละคนจองเวลาเดียวกันได้ตามปกติ (ถ้านักบำบัดว่าง)

## ② สิ่งที่ตกลงร่วมกัน
| เรื่อง | ตกลง |
|---|---|
| ตรวจที่ไหน | ฝั่งเซิร์ฟเวอร์ตอนสร้างนัด (ไม่ใช่แค่ปิดปุ่ม) |
| error | 409 `DUPLICATE_BOOKING` body มี `existing` = รหัสนัดเดิม |
| หน้าจอ | ขั้นยืนยันแสดงใน `book-error` (มี `data-error-code="DUPLICATE_BOOKING"`) พร้อมรหัสนัดเดิม |
| กฎใหม่ | บันทึกเป็น BR-21 "คนเดียวกันห้ามมีนัดเวลาทับกัน" |

| ภาษา | ข้อความ |
|---|---|
| th | คุณมีนัดในช่วงเวลานี้อยู่แล้ว (รหัส {code}) |
| en | You already have a booking at this time (code {code}) |
| zh | 您在该时段已有预约（预约号 {code}） |
