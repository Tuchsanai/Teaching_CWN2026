# หนังสือขอเปลี่ยนแปลงระบบ ฉบับที่ 5/2569

| | |
|---|---|
| เลขที่ | CR-05 |
| วันที่ | 12 ตุลาคม 2569 |
| เรื่อง | รายงานยอดสำหรับเจ้าของร้าน |
| เรียน | ทีมดูแลระบบจองคิว |
| ความเร่งด่วน | ปกติ |

สิ้นเดือนร้านต้องส่งตัวเลขให้นักบัญชี ตอนนี้ต้องนั่งเปิดตารางคิวทีละวันแล้วจดเอง
ขอหน้า **รายงาน** ที่เลือกช่วงวันได้ (ไม่เกินครั้งละ 3 เดือน) และกดโหลดเป็นไฟล์ไปเปิดใน Excel ได้ ขอดู

- จำนวนนัดแยกสถานะ (ยืนยัน / ใช้บริการแล้ว / ยกเลิก)
- ยอดขายจากนัดที่ใช้บริการแล้ว แยกว่าจ่ายด้วยบัตรของขวัญเท่าไร ช่องทางอื่นเท่าไร และส่วนลดแต่ละแบบรวมเท่าไร
- แต้มที่ให้ลูกค้าไป · จำนวนครั้งคอร์สที่ใช้ · ยอดของนัดที่ยังไม่มา
- หมอนวดแต่ละคนทำไปกี่คิว

เห็นได้เฉพาะเจ้าของร้านนะคะ ภาษาไทยในไฟล์ต้องอ่านออกใน Excel
