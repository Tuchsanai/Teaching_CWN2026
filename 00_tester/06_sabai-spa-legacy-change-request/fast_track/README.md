## 🤖 จุดที่ต่างจากบทเรียนหลัก: ไม่มีคนกดอนุมัติ และไม่มีการเปิดเซสชันใหม่

บทเรียนหลักให้ผู้เรียน **อ่านแผนใน Plan mode แล้วอนุมัติเอง** ก่อนทุก CR และ **เปิดเซสชันใหม่** เพื่อทดสอบรั้ว fast track ทำแทนแบบนี้

1. **Claude อนุมัติแผนเองตามเช็กลิสต์** แผนใน `docs/impact/CR-0N.md` ต้องมีครบ 5 อย่าง (คำถามถึงร้าน · อธิบายของเดิมด้วย `ไฟล์:บรรทัด` · ตาราง impact · ค่าที่คาดหวังติดป้าย · รายการเทสต์ที่ต้องแดง) จึงลงมือได้ แล้วจดทุกครั้งใต้หัวข้อ "ตัดสินแทนผู้เรียน" ใน `CHANGE-REPORT.md` · **ตอนจบคุณต้องอ่านแผนเหล่านี้ย้อนหลังเอง**
2. **ทดสอบรั้วด้วย Claude อีกตัวที่เปิดใหม่จาก shell** (`claude -p`) เพราะ `.claude/settings.json` (กันแก้ `e2e-legacy/` + กันอ่าน `README.md` ของบท `fast_track/` `_solution/`) มีผลกับเซสชันที่เปิดหลังจากเขียนไฟล์เท่านั้น ถ้าเรียกไม่ได้ Claude จะติด ⚠️ ให้คุณทดสอบเองหลังจบ
3. **CR-04 ส่วน ข (หลังร้านเพิ่ม/ลบวันหยุดเอง) ไม่ทำ** เหมือนผู้เรียนที่ตอบ "รอบนี้ไม่ทำ" · จดเป็นงานค้างใน `RELEASE-NOTES.md`

## 🏷️ หัวใจที่พรอมต์บังคับไว้

**"ทำตามที่ขอ ≠ ของเดิมไม่พัง ≠ ส่งมอบได้"** ทุกช่วงต้องมีหลักฐานของตัวเอง: เทสต์ใหม่ **แดงก่อนแก้ → เขียว** (ทำตามที่ขอ) · regression ทุกชุดครบ 3 เบราว์เซอร์ และค่าที่คาดหวังเดิม **ไม่ถูกแตะ** (ของเดิมไม่พัง) · traceability + ซ้อมถอยกลับ + UAT (ส่งมอบได้)

ค่าที่คาดหวังทุกตัวติดป้ายที่มา: **[E …]** = "ระบบทำอยู่" (REA · HAR · golden · SQL) ใช้ล็อกพฤติกรรมเดิมเท่านั้น · **[D:CR-0N]** = "ร้านยืนยันว่าควรทำ" · **[E] ขัด [D] = ผู้ต้องสงสัยบั๊ก ไม่ใช่ค่าที่คาดหวัง**

![การ์ดเทสต์ 2 ใบบนโต๊ะ ใบซ้ายตัวเลขเปลี่ยน ฿3,000 เป็น ฿2,850 มีตราสีเขียว มี CR อนุญาต และคุณจันทร์พยักหน้า ใบขวาตัวเลข ฿760 เป็น ฿800 มีไซเรนสีแดง หุ่นยนต์ตกใจ ป้าย ไม่มีใครขอ เด็กชายจดลงสมุด ORACLE-CHANGES หัวเรื่อง เปลี่ยนตั้งใจ vs ไม่ตั้งใจ](../img/concept-12-intended-vs-unintended.jpg)

## ✅ จบแล้วตรวจอะไร

1. **ตารางสรุปท้ายแชท** ดูช่อง ⚠️ และ "เรื่องที่ตัดสินแทนผม" ก่อน · อ่านแผน `docs/impact/CR-0N.md` ทั้ง 5 ไฟล์ย้อนหลัง เหมือนเป็นคนกดอนุมัติเอง

3. **ค่าที่คาดหวังเดิมไม่ถูกแตะ** `git diff <commit baseline> HEAD -- web/scripts/check-rules.mjs e2e-legacy tests/golden` ต้องว่าง หรือทุกจุดมีแถวใน `docs/ORACLE-CHANGES.md` ที่อ้าง CR
