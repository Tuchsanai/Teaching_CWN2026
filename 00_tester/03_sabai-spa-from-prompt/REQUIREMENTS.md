# Requirements — สบายใจ สปา

อ้างอิงจาก `USER-STORIES.md` (US-01 ถึง US-34)

- **FR** (Functional Requirement) = ระบบต้องทำอะไรได้
- **BR** (Business Rule) = กฎของร้าน ทุกข้อมีตัวเลข และบอกค่าขอบที่ต้องทดสอบ
- **NFR** (Non-Functional Requirement) = ต้องดีแค่ไหน ทุกข้อวัดผลได้

> หมายเหตุ: ค่าขอบที่มี ⚠️ เป็นค่าที่ร้านยังไม่ได้ยืนยัน (ดูหัวข้อ "คำถามที่ยังไม่ชัด" ใน USER-STORIES.md) ตอนนี้ตั้งไว้ตามความหมายที่ใกล้เคียงที่สุดของคำพูดในบันทึกสัมภาษณ์
