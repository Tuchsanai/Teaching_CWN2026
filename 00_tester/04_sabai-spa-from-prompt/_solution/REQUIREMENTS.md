# REQUIREMENTS · สบายใจ สปา

ที่มา: USER-STORIES.md (US-01 – US-36)

- **FR** = ระบบต้องทำอะไรได้ · **BR** = กฎของร้าน (มีตัวเลข + ค่าขอบที่ต้องทดสอบ) · **NFR** = ต้องดีแค่ไหน (วัดผลได้)
- ⚠️ = ร้านยังไม่ได้บอกชัด ใช้ **สมมติฐาน** ที่เขียนไว้ในแถวนั้น (และสรุปรวมไว้ในหัวข้อ "รายการสมมติฐาน ⚠️" ท้ายไฟล์) ต้องยืนยันกับคุณจันทร์ก่อนส่งงานจริง
- ตัวอย่างวันที่ในไฟล์นี้ใช้ "วันนี้" = **10 ต.ค. 2026** (ล็อกได้ตาม NFR-13)
