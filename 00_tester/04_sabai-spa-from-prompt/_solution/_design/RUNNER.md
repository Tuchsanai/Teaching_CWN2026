# RUNNER · รัน LAB เหมือนผู้เรียน (บท 04 สบายใจ สปา)

คุณคือ "ผู้เรียน + Claude Code" ที่วางพรอมต์ของ LAB ที่กำหนด ลงในเซสชันใหม่

- โฟลเดอร์บท (working dir) = โฟลเดอร์ปัจจุบัน (`w/`) ทำงานทั้งหมดในนี้
- พรอมต์ทุก LAB อยู่ใน `../design/PROMPTS.md` — อ่านเฉพาะหัวข้อ LAB ที่ได้รับมอบหมาย แล้ว **ทำตามพรอมต์นั้นทุกข้อ ตรงตัว** เหมือนผู้ใช้เพิ่งวางมา
  ห้ามอ่าน LAB อื่นล่วงหน้า (ห้ามรู้ว่า LAB ถัดไปจะให้ทำอะไร)
- ถ้าพรอมต์บอกให้ "ถามผมก่อน" ให้ตัดสินใจแทนอย่างสมเหตุสมผล แล้วจดเป็นคำถาม + คำตอบที่เลือกใน result
- คำตอบสรุปที่ "จะแสดงให้ผู้เรียนเห็นในแชท" ให้เขียนลงไฟล์ result ด้วย (ตาราง สรุป)

## กติกาความปลอดภัย (สำคัญมาก)
1. ห้ามใช้คำสั่ง git ที่เปลี่ยนสถานะ repo (commit, stash, checkout, reset, branch ...)
2. **ห้ามใช้ Playwright MCP** (ตั้งเป็นโหมด --extension ที่เกาะ Chrome ตัวจริงของผู้ใช้) — ทุกที่ที่พรอมต์บอก "Playwright MCP" ให้ใช้
   Playwright แบบ headless ผ่านสคริปต์ node แทน (ผลเทียบเท่า) เก็บสคริปต์ชั่วคราวไว้ที่ `../tools/labN/` ไม่ใช่ในโฟลเดอร์บท
   ใช้ playwright ที่ติดตั้งไว้แล้วใน `../tools/node_modules` (ถ้ายังไม่มีให้ `npm i playwright@1.63.0` ใน ../tools)
3. ห้ามลบ cookie หรือยุ่งกับเบราว์เซอร์ของผู้ใช้ · ห้ามแตะ container อื่นนอกจาก sabai-web, sabai-db และ petshop (stop ได้อย่างเดียว)
4. ห้ามอ่านไฟล์นอกโฟลเดอร์ `w/` ยกเว้น `../design/PROMPTS.md`, `../design/RUNNER.md` และ `../tools/`
5. LAB 7–12: ปฏิบัติตามข้อห้ามในพรอมต์เคร่งครัด (ห้ามอ่านโค้ด web/ db/ · ห้ามเปิด web/BUGS.md จนถึงข้อที่พรอมต์อนุญาต)

## สิ่งที่ต้องส่งเพิ่ม (นอกเหนือจากที่พรอมต์สั่ง)
เขียน `../design/results/LAB<N>_RESULT.md` ภาษาไทย:
- เวลาเริ่ม/จบ และเวลาที่ใช้ (นาที)
- คำตอบสรุปที่แสดงในแชท (ตารางตามที่พรอมต์สั่ง)
- ตัวเลขสำคัญทั้งหมด (จำนวนข้อ ผ่าน/ล้ม ฯลฯ) — ต้องนับจากไฟล์จริง
- ตัวอย่างแถวเด่น 3–6 แถว (ไว้ใช้ใน README)
- ข้อสังเกต 👀 ที่ผู้เรียนควรรู้ ปัญหาที่เจอ และวิธีแก้
- ถ้าพรอมต์มีจุดกำกวม/ทำให้ได้ผลไม่ดี ให้เสนอแก้ถ้อยคำพรอมต์ (หัวข้อ "ข้อเสนอแก้พรอมต์")
- ภาพหน้าจอที่ควรใช้ใน README (headless, 1280x800) เก็บที่ `../design/shots/labN-*.png` และอธิบายแต่ละภาพ 1 บรรทัด
