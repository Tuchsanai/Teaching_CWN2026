## หมายเหตุสำหรับผู้สอน (README "✅ ผลจริง" / "👀 สังเกต")

**สิ่งที่ใช้จากบท 02 (ตามข้อยกเว้นที่อนุญาต)**: คัดลอก `package.json`, `playwright.config.ts`, `global-setup.ts`, `reporters/html-report.ts`, ส่วน helper ของ `tests/fixtures.ts` (step/check/markOnScreen/open/baht) — ตัด `registerByApi`, `CAT_SLUGS`, `CHICKEN_SLUGS` ทิ้ง (เป็นข้อมูล/ความรู้ของบท 02) · **ไม่ได้คัดลอก spec ใด ๆ**

**ที่ต้องปรับจากของบท 02**
1. `workers: 4 → 1`, `fullyParallel: false` — แผนเรากำหนด "ทุกข้อเริ่มจากสถานะสะอาด" = POST /api/test/reset ก่อน **ทุก** test (auto fixture `_cleanState`) ซึ่งล้างข้อมูลทั้งเซิร์ฟเวอร์ ถ้ารันขนานจะชนกัน (สต็อก 3 ชิ้น, อีเมล `new1@`/`other@` ซ้ำ, เลขคำสั่งซื้อ) · slowMo Chromium 450 → 300
2. reporter: อ่านคอลัมน์ที่ 7 "ที่มา" ของแผนเรา แสดงในตารางและหน้า detail · ตัดสินผลตาม **หัวข้อ 6.2 ของเรา** แยกทีละเบราว์เซอร์ (EX1 P1 100%, EX2 ≥ 95% และข้อที่ล้มต้องเป็น P2/P3, EX3, EX4 อ่าน `e2e/triage.json`, EX5 หลักฐาน) · เพิ่มตาราง "ผลตามเกณฑ์ แยกทีละเบราว์เซอร์" และคอลัมน์ "จำแนก" ในตาราง Defects
3. `plan(id, '@module')` อ่าน TEST-PLAN.md ตอนโหลด test → tag ระดับมาจากแผน (ไม่พิมพ์เอง) และ annotation `expected` = ข้อความเดียวกับแผนตัวต่อตัว

**การตีความที่ต้องทำตอนแปลงแผน (ควรเล่าเป็น "👀 สังเกต")**

**ปัญหาที่เจอ**
- Git Bash แปลง `/path` เป็น `C:/Program Files/Git/...` ตอนส่งอาร์กิวเมนต์ให้ node → ส่ง path แบบไม่มี `/` นำหน้า
- `"type": "module"` ทำให้ไม่มี `__dirname` ใน fixtures → ใช้ `fileURLToPath(import.meta.url)`
- ตอนรันเฉพาะบางข้อ (`-g`) `index.html` จะถูกเขียนทับเป็นสถานะ "ยังตัดสินไม่ได้" → ต้องรันเต็มอีกครั้งก่อนถ่ายภาพรายงาน
- ข้อความ array diff ของ `toEqual([])` อ่านไม่ออกในตาราง "ได้จริง" → เปลี่ยนเป็น `join(', ') || 'ไม่มี'` ให้รายงานแสดงชื่อสินค้าที่ผิดตรง ๆ (เช่น "สูตรลดก้อนขน")
