## 2. ฟีเจอร์แยกตามโมดูล

### 2.1 แคตตาล็อก / ค้นหา / กรอง / เรียง
- สินค้าทั้งหมด **28** รายการ (แมว 14 / สุนัข 14) · ประเภท: อาหารเม็ด 11, ขนม 5, ของเล่น 4, อาหารเปียก 4, ของใช้ 4
- ตัวกรอง: ปุ่ม `filter-pet-all|cat|dog`, select `filter-type` (`all/dry/wet/treat/toy/accessory`), select `filter-life` (`all/baby/adult/senior` = ทุกช่วงวัย/วัยเด็ก/วัยโต/สูงวัย), checkbox `filter-grainfree` ("เกรนฟรีเท่านั้น")
- เรียง `sort-select`: `popular` (ยอดนิยม, ค่าเริ่มต้น), `price-asc`, `price-desc`, `rating`
- ตัวกรองทุกตัวสะท้อนใน URL เช่น `/products?pet=cat&type=dry&life=senior&grainFree=1` และใช้ร่วมกันได้ (AND)
- จำนวนผลแสดงที่ `result-count` = "พบ N รายการ"
- ไม่พบผล: "ไม่พบสินค้าที่ตรงกับการค้นหา" + "ลองเปลี่ยนคำค้นหรือล้างตัวกรองดูนะ" + ปุ่ม "ล้างตัวกรองทั้งหมด"
- การ์ดสินค้าแสดง "เริ่มต้น ฿{ราคาไซซ์เล็กสุด}", ป้าย `stock-badge` ("หมด" / "เหลือ 3 ชิ้น"), ปุ่ม `quick-add` ("ใส่ตะกร้า" / "สินค้าหมด" แบบ disabled), `wishlist-toggle`

### 2.2 หน้าสินค้า
- ข้อมูล: ป้ายช่วงวัย, เกรนฟรี, ประเภท, โปรตีนหลัก, คะแนน + จำนวนรีวิว, คำอธิบาย, รีวิว (`review` 2–3 รายการ)
- เลือกขนาด `size-option` (`aria-pressed`) → ราคา `product-price` เปลี่ยนตามไซซ์ เช่น ลูกแมว สูตรแซลมอน 400 g ฿189 / 1.5 kg ฿590
- จำนวน `qty-minus` / `qty-input` (type=number, min=1, max=stock) / `qty-plus`
- `stock-info`: "มีสินค้า N ชิ้น" · "เหลือ N ชิ้น" (เห็นที่ stock 3) · "สินค้าหมด"
- `add-to-cart` → toast "เพิ่ม {ชื่อ} ({ไซซ์}) ลงตะกร้าแล้ว 🛒"
- "มักซื้อคู่กัน" (`bought-together`) + `add-bundle` "เพิ่มทั้งชุดลงตะกร้า" พร้อมราคาชุด ("ซื้อชุดนี้ (3 รายการ, ขนาดเล็กสุด) ฿297")
- "สินค้าที่คล้ายกัน" (`similar-products`)

### 2.3 รายการโปรด (Wishlist)
- กดหัวใจ → toast "เพิ่ม {ชื่อ} ในรายการโปรดแล้ว 💖", aria-label เปลี่ยน "เพิ่ม … ในรายการโปรด" ↔ "นำ … ออกจากรายการโปรด"
- หน้า `/wishlist`: `wishlist-item`, `move-to-cart` ("ย้ายไปตะกร้า"; สินค้าหมด → ปุ่ม "สินค้าหมด" disabled), `wishlist-remove` ("ลบ")
- ว่าง: "ยังไม่มีสินค้าในรายการโปรด" (`empty-wishlist`)
- เก็บใน localStorage → **ไม่ผูกกับบัญชี**

### 2.4 ตะกร้า
- `cart-item` → `item-name`, `item-size`, `item-minus`, `item-qty`, `item-plus`, `item-line-total`, `item-remove`
- แถบ `free-shipping-progress`: "ซื้อเพิ่มอีก ฿X เพื่อส่งฟรี" / "ได้ส่งฟรีแล้ว!"
- คูปอง: `coupon-input`, `coupon-apply` ("ใช้โค้ด"), `coupon-message`, `coupon-remove` ("นำคูปอง {CODE} ออก")
- สรุป: `summary-subtotal`, `summary-discount`, `summary-shipping`, `summary-total`, `checkout-button` ("ดำเนินการชำระเงิน →")
- "มักซื้อคู่กับสินค้าในตะกร้า" (`cart-recommendations`)
- ว่าง: "ตะกร้าของคุณยังว่างอยู่" (`empty-cart`, `continue-shopping`)

### 2.5 สมาชิก (สมัคร / ล็อกอิน / ออกจากระบบ)
- สมัคร: `reg-name`, `reg-email`, `reg-password` (มีตัววัด "ความแข็งแรงของรหัสผ่าน: อ่อน/ปานกลาง/…"), `reg-confirm`, `reg-pet-cat|dog|both` (ค่าเริ่มต้น = แมว), `reg-terms`, `reg-submit`
- ล็อกอิน: `login-email`, `login-password` (+ ปุ่มแสดงรหัสผ่าน aria-label "แสดงรหัสผ่าน"), `login-submit`, `register-link`
- หลังล็อกอิน header แสดง `user-menu` (อักษรย่อ + ชื่อ) และ `logout-button` ("ออกจากระบบ") → toast "ออกจากระบบแล้ว แล้วพบกันใหม่ 👋"

### 2.6 ชำระเงิน / คำสั่งซื้อ
- ต้องล็อกอิน; ชื่อผู้รับเติมให้จากโปรไฟล์
- ฟิลด์: `ship-name`, `ship-phone`, `ship-postcode`, `ship-address` (textarea), `ship-province` (select **10 จังหวัด**: กรุงเทพมหานคร, เชียงใหม่, ขอนแก่น, ชลบุรี, ภูเก็ต, นนทบุรี, นครราชสีมา, สงขลา, เชียงราย, อุดรธานี)
- วิธีส่ง: `shipping-standard` "ส่งธรรมดา (2–3 วัน) ฿50 · ส่งฟรีเมื่อซื้อครบ ฿999" (ค่าเริ่มต้น) / `shipping-express` "ส่งด่วน (ภายใน 24 ชม.) ฿120"
- ชำระเงิน: `pay-cod` "เก็บเงินปลายทาง" (ค่าเริ่มต้น) / `pay-promptpay` "PromptPay สแกน QR ชำระทันที" (ไม่มีหน้าจอ QR จริง สั่งซื้อสำเร็จทันที)
- ปุ่ม `place-order` "ยืนยันสั่งซื้อ ฿{ยอด}"
- **ไม่มีช่องคูปองในหน้า checkout** (ใช้คูปองที่ตั้งไว้จากตะกร้า)
- หน้าสำเร็จ `/orders/PP-xxxxxx`: `order-success`, `order-id`, `order-timeline` (4 `timeline-step`: รับคำสั่งซื้อ → แพ็คสินค้า → จัดส่ง → ถึงแล้ว), `order-item`, summary · ข้อความ "ขอบคุณ {ชื่อ} เลขที่คำสั่งซื้อของคุณคือ PP-100001"
- หลังสั่ง: ตะกร้าถูกล้าง (`pp-cart = []`), **สต็อกถูกตัดจริง** (เพาช์ทูน่า 60 → 58, ลูกแมวแซลมอน 25 → 24)
- `/account`: `profile-card` (ชื่อ, อีเมล, "ทาสแมว 🐱", จำนวนคำสั่งซื้อ, ยอดซื้อสะสม), `order-history`, `order-row` (ลิงก์ไป `/orders/{id}`) หรือ `no-orders` "ยังไม่มีคำสั่งซื้อ"

### 2.7 ระบบแนะนำ
- **Pet Food Finder** `/finder`: ขั้น 1 `finder-pet-cat|dog` → ขั้น 2 `finder-life-baby|adult|senior` → ขั้น 3 `finder-no-chicken`, `finder-grainfree`, `finder-type` (`any/dry/wet/treat`) → `finder-submit` "✨ ดูผลลัพธ์"
  - ปุ่ม `finder-next` disabled จนกว่าจะเลือก, มี `finder-back` (จำค่าที่เลือกไว้) และ `finder-restart`
  - ผล: `finder-results` → `finder-result` ×1–4 พร้อม `match-score` ("ตรงใจ 98%"), `match-reason` (เช่น "เหมาะกับแมวสูงวัย", "ไม่มีไก่", "เกรนฟรี", "รีวิว 4.6★"), `finder-add`; อันดับ 1 ติดป้าย "🏆 ตรงใจที่สุด"
  - เรียก `GET /api/recommendations?pet=cat&life=adult&noChicken=1&grainFree=1&type=dry`
- **แนะนำสำหรับคุณ** (หน้าแรก `recommended-for-you`): ไม่มีประวัติ → "ยังไม่มีประวัติการดู เลยขอแนะนำสินค้ายอดนิยมก่อนนะ"; มีประวัติ → "จากสินค้าที่คุณเคยดูและรายการโปรดของคุณ"
- **ดูล่าสุด** (`recently-viewed`) จาก `pp-recent`
- **มักซื้อคู่กัน** ในหน้าสินค้าและในตะกร้า (อิง field `boughtWith`)

### 2.8 มือถือ (375×812)
- เมนูหลักซ่อน, แสดง `menu-toggle` (aria-label "เปิดเมนู" ↔ "ปิดเมนู", `aria-expanded`, `aria-controls="mobile-menu"`)

- กดลิงก์ในเมนู → นำทางและเมนูปิดเอง · ไม่มี horizontal scroll (scrollWidth 363 ≤ 375)

## 3. กฎทางธุรกิจที่สังเกตได้ (พร้อมหลักฐาน)

| # | กฎที่สังเกตได้ | หลักฐาน |
|---|---|---|
| BR1 | ส่งฟรีเมื่อ **ยอดรวมสินค้า (ก่อนหักส่วนลด) ≥ ฿999** | ฿998 → ค่าส่ง ฿50 "ซื้อเพิ่มอีก ฿1 เพื่อส่งฟรี"; ฿999 → "ฟรี" "ได้ส่งฟรีแล้ว!"; ฿999 + PAW10 = ฿900 แต่ยังส่งฟรี |
| BR2 | ส่งด่วน ฿120 **เสมอ** แม้ยอด ≥ ฿999 | ยอด ฿1,890 + ด่วน → ค่าส่ง ฿120 รวม ฿2,010 (ทั้ง UI และ API PP-100003) |
| BR3 | FREESHIP ทำให้ค่าส่งเป็น 0 **รวมถึงส่งด่วน** | API: FREESHIP + express → shipping 0 (PP-100004) |
| BR4 | PAW10 ลด 10% ของยอดสินค้า **ปัดเศษลง** | ฿297 → -฿29 (29.7); ฿998 → -฿99; ฿189 → -฿18; ฿35 → -฿3 |
| BR5 | NEWCAT50 ลด ฿50 เมื่อสินค้าแมวประเภท **อาหาร (dry/wet/treat) ≥ ฿500**; ของใช้/ของเล่นแมวไม่นับ, ของหมาไม่นับ | ฿499 (อาหารแมว) → "ต้องซื้ออาหารแมวขั้นต่ำ ฿500"; ฿502 (มีขนม) → ใช้ได้; ขนมแมวล้วน ฿598 → ใช้ได้; น้ำพุแมว ฿890 → ไม่ได้; หมา ฿790 + แมว ฿189 → ไม่ได้ |

| BR7 | โค้ดคูปองไม่สนตัวพิมพ์เล็ก/ใหญ่ และตัดช่องว่างหัวท้าย | `paw10`, `" PAW10 "` → "ใช้คูปอง PAW10 แล้ว" |

| BR10 | จำนวนต่อสินค้า 1..stock; stock **นับรวมทุกไซซ์** ของสินค้าเดียวกัน | ลูกแมวแซลมอน stock 25: มี 1.5 kg ×2 แล้วเพิ่ม 400 g ×25 → ได้แค่ 23 |

## 7. ความเสี่ยงที่ร้ายแรง (เรียงตามความสำคัญ)

1. **ตะกร้าเชื่อ localStorage โดยไม่ตรวจกับสต็อกจริง** — ใส่ `pp-cart` ที่มีสินค้าหมด (×2) และสูตรลดก้อนขน ×50 (stock 3) หน้าตะกร้าแสดงยอด **฿26,318 ส่งฟรี** ไม่มีคำเตือน และกดไป checkout ได้ (`explore-cart-injected-state.png`). Server กันไว้ได้ (409) แต่ลูกค้าจะเจอ error ตอนกดยืนยันเท่านั้น ซึ่งเกิดได้จริงเวลาสต็อกลดระหว่างที่ของค้างอยู่ในตะกร้า **เหตุผลที่ร้ายแรง:** เป็นจุดที่ลูกค้าเห็นยอดเงินผิดและทิ้งตะกร้า
2. **Server รับข้อมูลคำสั่งซื้อที่ไม่ถูกต้องแล้วแก้ให้เงียบๆ** — qty ทศนิยม, qty string, shipping/payment ที่ไม่มีจริง, จังหวัดนอกรายการ ได้ 201 ทั้งหมด **เหตุผล:** สิ่งที่ลูกค้าเห็นกับสิ่งที่บันทึกไว้อาจไม่ตรงกัน (เช่น client ส่ง express แต่ระบบบันทึก standard) และไม่มีใครรู้ว่าเกิดขึ้น
3. **คูปองไม่ถูกต้องตอนสั่งซื้อถูกเมิน ไม่ถูกปฏิเสธ** — ถ้าคูปองหมดอายุ/ไม่ผ่านเงื่อนไขระหว่างอยู่ในตะกร้า (เช่น ลดจำนวนอาหารแมวจนต่ำกว่า ฿500 แล้ว NEWCAT50 ยังค้างใน `pp-coupon`) ยอดที่จ่ายจริงจะไม่ตรงกับยอดที่ลูกค้าคาดไว้ **เหตุผล:** เรื่องเงิน = ความเชื่อมั่น
4. **จำนวนถูกตัดให้เหลือน้อยกว่าที่ขอ แต่ toast บอกว่า "เพิ่ม…ลงตะกร้าแล้ว"** — ขอ 25 ได้ 23 (stock นับรวมทุกไซซ์) ปุ่ม `+` ในตะกร้าที่ max ก็ไม่ทำอะไรและไม่แจ้ง **เหตุผล:** ลูกค้าอาจได้ของไม่ครบโดยไม่รู้ตัว
5. **ไม่มีการจำกัดการล็อกอินผิด** — ผิด 6 ครั้งติดยังล็อกอินถูกได้ทันที ไม่มี lockout/หน่วงเวลา **เหตุผล:** เสี่ยงต่อการเดารหัสผ่าน โดยเฉพาะเมื่อกฎรหัสผ่านยอมรับ `12345678`
6. **นโยบายรหัสผ่านอ่อน** — `12345678` ผ่าน (ตรงตามข้อความ "8 ตัว และมีตัวเลข" แต่ไม่มีตัวอักษร) ตัววัดบอก "ปานกลาง"
7. **Finder แนะนำอาหารผิดช่วงวัย** — แมวสูงวัยได้ "ลูกแมว สูตรแซลมอน" (ตรงใจ 49%), แมวเด็กได้ "สูตรดูแลทางเดินปัสสาวะ" (สูตรแมวสูงวัย) **เหตุผล:** อาหารลูกแมวกับอาหารแมวสูงวัยต่างกันด้านโภชนาการ ลูกค้าที่เชื่อคำแนะนำอาจซื้อผิด

5. **NEWCAT50 "สมาชิกใหม่"?** ชื่อสื่อว่าใช้ได้แค่สมาชิกใหม่/ครั้งแรก แต่ในตะกร้าใช้ได้แม้ยังไม่ล็อกอิน (ยังไม่ได้ลองว่าใช้ซ้ำในหลายคำสั่งซื้อได้ไหม)
6. **กรอกโค้ดผิดทับโค้ดถูก ควรล้างโค้ดเดิมไหม?** ตอนนี้ล้าง (PAW10 หาย)
7. **กรอกคูปองว่างควรแจ้งว่า "กรุณากรอกโค้ด" หรือ "ไม่พบคูปองนี้"?** ตอนนี้เป็นอย่างหลัง
8. **ปุ่ม `−` ที่จำนวน 1 ในตะกร้าควรลบสินค้าหรือไม่ทำอะไร?** ตอนนี้ไม่ทำอะไร และปุ่มไม่ disabled ทั้ง `−` ที่ 1 และ `+` ที่ stock สูงสุด
9. **Stock ต่อสินค้าหรือต่อไซซ์?** ตอนนี้ต่อสินค้า (ไซซ์เล็กกับไซซ์ใหญ่ใช้ stock ร่วมกัน) ซึ่งแปลกในทางกายภาพ
10. **เกณฑ์ "เหลือ N ชิ้น"** อยู่ที่เท่าไร (≤3? ≤5?) เห็นแค่ 3 → "เหลือ", 6 → "มีสินค้า"
11. **Wishlist ควรผูกกับบัญชีไหม?** ตอนนี้อยู่ใน browser เท่านั้น ล็อกอินเครื่องอื่นจะหาย และคนที่ใช้เครื่องร่วมกันเห็น wishlist ของกันและกัน
12. **"แนะนำสำหรับคุณ" ควรแสดงสินค้าที่อยู่ใน wishlist อยู่แล้วไหม?** ตอนนี้แสดง (ลูกบอลมีเสียงใน wishlist ก็ไปโผล่ในส่วนแนะนำ)
13. **ช่วงวัยใน Finder เป็นเงื่อนไขบังคับหรือแค่ให้คะแนน?** (ดูความเสี่ยงข้อ 7)
14. **ค้นหาคำว่า "cat"/"แมว" ควรเจอสินค้าแมวไหม?** "cat" → 0 รายการ (แต่ "แมว" ยังเจอเพราะอยู่ในชื่อไทย)
15. **query ที่ไม่รู้จัก (`pet=bird`)** ควรแสดงทั้งหมดเงียบๆ (ตอนนี้) หรือแสดงว่าไม่พบ/400?
16. **ล็อกอินอยู่แล้วเข้า `/login` หรือ `/register`** ยังเห็นฟอร์ม ควร redirect ไหม?
17. **PromptPay** ไม่มีขั้นตอนสแกน/ยืนยันการชำระ คำสั่งซื้อสถานะ "รับคำสั่งซื้อ" ทันทีเหมือน COD ถูกต้องไหม?
18. **ช่องที่อยู่ ≥10 ตัวอักษร** นับช่องว่างหรือไม่? ชื่อผู้รับไม่มีความยาวขั้นต่ำ/สูงสุด
19. **Bundle "ซื้อชุดนี้"** ไม่ได้ลดราคา (฿297 = ผลรวมปกติ) คำว่า "ซื้อคู่กันคุ้มกว่า" ทำให้คาดว่าจะมีส่วนลด

## 9. ข้อสังเกตที่ "น่าสงสัย" 🤨

1. **กดเพิ่มทั้งชุด (bundle) แล้วได้ไม่ครบ แต่ไม่บอก** — ที่หน้าลูกแมวแซลมอน หัวข้อเขียน "ซื้อชุดนี้ (3 รายการ…)" แต่เมื่อลูกแมวแซลมอนในตะกร้าเต็ม stock แล้ว toast บอก "เพิ่มชุดสินค้า **2** รายการลงตะกร้าแล้ว" โดยไม่บอกว่าข้ามชิ้นไหน (ถ้าตะกร้าว่างจะได้ 3 รายการตามปกติ)
2. **ข้อความ error ของ API ทำให้เข้าใจผิด** — ส่ง JSON พัง หรือไซซ์/slug ผิด ได้ `"ไม่มีสินค้าในตะกร้า"` ทั้งที่ปัญหาคือ request ผิดรูปแบบ ส่วน qty `-2` ปนกับ item ถูกกลับสร้าง order ได้ (line ติดลบถูกตัดทิ้งเงียบๆ)
3. **ป้าย/หมวดไม่สอดคล้องกัน** — เมนู "🐱 อาหารแมว" และการ์ดหน้าแรก "14 รายการ สำหรับน้องแมว" รวมของเล่นและของใช้ (ไม้ตกแมว, น้ำพุแมว) ด้วย แต่ NEWCAT50 ที่เขียนว่า "อาหารแมว" ไม่นับของใช้ · การ์ดของเล่นใช้ป้ายช่วงวัยเป็น "🐶 ของเล่น" แทนช่วงวัย · Finder แนะนำ "ลูกแมว สูตรแซลมอน" ให้แมวโตและแมวสูงวัยพร้อมเหตุผล "เกรนฟรี"

## 10. หมายเหตุสำหรับคนเขียนเทสต่อ

- data-testid ซ้ำ: เมื่อเปิดเมนูมือถือจะมี `nav-cat|nav-dog|nav-toys|nav-finder` **2 ชุด** (desktop ที่ซ่อน + `mobile-menu`) ต้อง scope ด้วย `getByTestId('mobile-menu')` ไม่งั้นติด strict mode
- หลายหน้ามี `product-card`, `product-name`, `product-price`, `wishlist-toggle`, `quick-add` ซ้ำหลาย section (popular / recommended / recently-viewed / similar) ควร scope ตาม section testid
- `qty-input` / `item-qty` เป็น `input[type=number]` ใช้ `fill()` ได้แค่ตัวเลข
- ค่าเริ่มต้น: `reg-pet-cat` ถูกเลือกไว้, `shipping-standard` + `pay-cod` ถูกเลือกไว้, `ship-name` เติมชื่อจากโปรไฟล์
- ควรเรียก `POST /api/test/reset` และล้าง localStorage (`pp-cart`, `pp-coupon`, `pp-wishlist`, `pp-recent`) ก่อนแต่ละเทส เพราะคูปองและตะกร้าค้างข้ามหน้า
- order id เรียงจาก `PP-100001` หลัง reset
- ระหว่างสำรวจผ่าน Chrome ที่ display scaling 125% การคลิกด้วยพิกัดของ Playwright คลาดเคลื่อน (คลิก checkbox/submit ไม่โดน) ปัญหานี้เกิดจากสภาพแวดล้อม **ไม่ใช่บั๊กของเว็บ** ถ้าเจออาการเดียวกันให้ตรวจ `devicePixelRatio`
