8	## หลักการ

10	1. **ห้าม float** ตลอดการคำนวณ เก็บค่าเป็น `int` (สตางค์) หรือ `fractions.Fraction`
11	2. **ปัดเศษครั้งเดียว ตอนท้ายสุด** ห้ามปัดทุกขั้น การปัดทุกขั้นทำให้ผลเพี้ยน 1 สตางค์ได้ ซึ่งทำให้ test ที่เทียบทีละสตางค์ไม่ผ่าน

13	4. **ลำดับตามที่โจทย์เขียน**
14	   - "ลด X% แล้วลดอีก Y%" หรือ "คิดต่อจากข้อก่อน" = ตัวคูณทบกัน (คูณ `(1-X)` แล้วคูณ `(1-Y)`)
15	   - "เพิ่ม Z% เป็นขั้นสุดท้าย" = คูณ `(1+Z)` ตอนท้าย
16	   - เงื่อนไขขั้นต่ำ เช่น "ยอดตั้งแต่ N ลด X%" ให้ตรวจยอดตามที่โจทย์ระบุ (ยอดก่อนลด หรือยอดหลังลดขั้นก่อนหน้า) และเลือกความหมายที่ตรงตัวอักษรที่สุด
17	5. **ทิศทางการปัด** ดูตามความหมายของโจทย์
18	   - ถ้าโจทย์ไม่ระบุ ให้ใช้ **ปัดครึ่งขึ้น (half-up)**
19	   - ถ้าโจทย์บอกให้ "ปัดลง" หรือ "ไม่จ่ายเกินสิทธิ์" ให้ใช้ floor
20	   - ระบุทิศทางที่เลือกในคำตอบสุดท้าย
21	6. **ขีดจำกัด (cap / floor / ขั้นต่ำ)** ใช้กับผลลัพธ์หลังคูณตัวคูณทั้งหมดแล้ว เช่น ถ้า "สูงสุดต่อบิล" ให้ `min(...)` หลังจากคูณทุกอย่างเสร็จ

24	## ตัวช่วยปัดเศษ (จำนวนเต็มล้วน ไม่มี float)
25	
26	```python
27	from fractions import Fraction
28	
29	def half_up(x):
30	    """ปัดครึ่งขึ้นเป็น int, x ไม่ติดลบ (int หรือ Fraction)"""
31	    return int((Fraction(x) * 2 + 1) // 2)
32	
33	def floor_int(x):
34	    """ปัดลงเป็น int, x ไม่ติดลบ"""
35	    return int(Fraction(x) // 1)
36	
37	def percent_of(amount, pct):
38	    """amount * pct% โดยยังไม่ปัด คืนเป็น Fraction"""
39	    return Fraction(amount) * Fraction(pct, 100)
40	```

17	## รูปแบบโค้ดตรวจ
18	
19	```python
20	def require_int(value, name, low=None, high=None):
21	    if type(value) is not int:          # ปฏิเสธ bool, float, str, None
22	        raise ValueError(f"{name} ต้องเป็นจำนวนเต็ม")
23	    if low is not None and value < low:
24	        raise ValueError(f"{name} ต้องไม่น้อยกว่า {low}")
25	    if high is not None and value > high:
26	        raise ValueError(f"{name} ต้องไม่เกิน {high}")
27	    return value
28	
29	def require_bool(value, name):
30	    if type(value) is not bool:
31	        raise ValueError(f"{name} ต้องเป็น True หรือ False")
32	    return value
33	
34	def require_choice(value, name, choices):
35	    if type(value) is not str or value not in choices:   # ไม่ normalize
36	        raise ValueError(f"{name} ต้องเป็นหนึ่งใน {sorted(choices)}")
37	    return value
38	
39	def require_list_of_dicts(value, name):
40	    if type(value) is not list:
41	        raise ValueError(f"{name} ต้องเป็น list")
42	    for entry in value:
43	        if type(entry) is not dict:
44	            raise ValueError(f"แต่ละรายการใน {name} ต้องเป็น dict")
45	    return value
