# missing-test-file: ไม่ได้สร้าง test_solve.py ข้าง solve.py

## อาการ
- `tests` ตก: `ไม่มีไฟล์ test_solve.py ข้าง solve.py`
- ตกทั้ง 5 งาน

## สาเหตุ
- โจทย์ไม่ได้สั่งให้เขียนเทส แต่ตัวตรวจคาดว่าต้องมี `test_solve.py` วางอยู่ในโฟลเดอร์เดียวกับ `solve.py`
- Agent ทุกตัวมองว่างานจบเมื่อเขียน `solve.py` เสร็จ บางตัวรันทดสอบสั้น ๆ ผ่าน `python3 -c` แต่ไม่ได้เก็บเป็นไฟล์ถาวร
- ยังไม่ยืนยัน: ตัวตรวจจะรัน `test_solve.py` แล้วให้ผ่านจริงด้วยหรือไม่ หรือเช็กแค่ว่ามีไฟล์ (ข้อความตัวตรวจพูดแค่ “ไม่มีไฟล์”) ให้ถือว่าต้องมีไฟล์และผ่านเมื่อรันเองไว้ก่อน

## หลักฐาน
งานที่ล้ม (ทุกงาน ไม่มีงานผ่านให้เทียบ):
- t3-shipping-fee-r3, t1-cafe-bill-r1, t2-split-bill-r1: ทดสอบด้วย `python3 -c "from solve import ...; print(...)"` ครั้งเดียวแล้วจบ ไม่มีไฟล์เทส
- t4-cashback-r1, t4-cashback-r3: ไม่ได้รันอะไรเลยหลังเขียนไฟล์ และไม่มีไฟล์เทส

## วิธีแก้
1. สร้าง `test_solve.py` ในโฟลเดอร์เดียวกับ `solve.py` ทุกงาน ใช้ `unittest` หรือ `pytest` (ใช้ `unittest` ได้โดยไม่ต้องติดตั้งอะไรเพิ่ม)
2. เนื้อหาเทสควรครอบ: ตัวอย่างพื้นฐานตามโจทย์ ค่าที่ขอบของเงื่อนไข (เช่น พอดี 500 บาท, 100 บาท, 1,000/5,000 กรัม) กรณีปัดเศษ กรณีที่ต้อง `raise ValueError` (ค่านอกช่วง ชนิดผิด) และ CLI อย่างน้อยหนึ่งกรณีสำเร็จกับหนึ่งกรณีล้มเหลว (เรียกผ่าน `subprocess`)
3. รันเทสด้วย `python -m unittest` (หรือ `pytest`) ให้ผ่านก่อนส่งงาน อย่าส่งไฟล์เทสที่ไม่เคยรัน
4. ค่าคาดหมายในเทสให้คิดด้วยมือจากข้อความโจทย์ ไม่ใช่คัดผลที่โค้ดคืนมา ไม่เช่นนั้นเทสจะยืนยันความผิดเดิม
