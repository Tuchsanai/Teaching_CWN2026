# clean.py — ทำความสะอาดไฟล์ตั๋ว (ticket) CSV

## หน้าที่
อ่านไฟล์ CSV ของตั๋วแจ้งปัญหา แล้วพิมพ์ผลเป็น JSON ทาง stdout โดยใช้ `id` เป็นคีย์
แต่ละรายการมี 3 ฟิลด์:
- `time` — เวลาที่รับเรื่อง (จาก `received_at`) ปรับเป็นรูปแบบมาตรฐาน
- `order_id` — เลขออเดอร์ ปรับเป็นรูปแบบ `ORD-xxxxxx` (ใช้ข้อความใน `text` ช่วยเมื่อคอลัมน์ว่าง)
- `error_code` — รหัสข้อผิดพลาดที่พบใน `text` (เป็น `null` ถ้าไม่พบ)

ส่วน `id` จะถูกลบช่องว่างและอักขระที่มองไม่เห็นออกก่อนใช้เป็นคีย์

## ความต้องการ
- Python 3 และ `pandas`
- ไฟล์ `clean_code.py`, `clean_order.py`, `clean_time.py` อยู่โฟลเดอร์เดียวกับ `clean.py`

## คอลัมน์ CSV ที่ต้องมี
| คอลัมน์ | ใช้ทำอะไร |
|---|---|
| `id` | คีย์ของผลลัพธ์ |
| `received_at` | เวลาที่รับเรื่อง |
| `order_id` | เลขออเดอร์ |
| `text` | ข้อความตั๋ว (ใช้หา error_code / order_id) |

(คอลัมน์อื่น เช่น `channel` ไม่ถูกใช้ ส่วนคอลัมน์ที่ขาดจะถือเป็นค่าว่าง)

## ตัวอย่างคำสั่ง
```bash
python3 /workspace/team-demo/clean.py /workspace/team-demo/data/tickets.csv
```
ต้องส่งอาร์กิวเมนต์ไฟล์ CSV เพียงตัวเดียว ไม่เช่นนั้นจะแสดง usage และจบด้วยรหัส 2
