## สิ่งที่ปรับระหว่างทดสอบ

| ปัญหาที่พบ | การแก้ |
|---|---|
| อ่าน `state.json` บน bind mount ชนกัน ทำให้งานค้าง `pending` | ย้าย lock ไป `/tmp` · เพิ่ม retry · งานที่ตัวรันล้มถูกบันทึกเป็น failed แทนการค้าง |
| คำสั่ง BOARD ทำให้ agent พูดถึงมันในคำตอบ และผู้ตรวจไม่ผ่าน | เปิดใช้ด้วย `"board": true` · บรรทัด `BOARD:` ยังทำงานเสมอ |
| รอบแก้ใน review loop ตอบปนคำอธิบาย | สั่งให้ตอบผลงานฉบับเต็มเท่านั้น |
| หัวหน้าไม่หยุดเมื่อเกินงบ | สคริปต์ปฏิเสธ `dispatch` และ `finish` เมื่อเกินงบ |
| งบหัวหน้าไม่ถูกใช้เมื่อเหลือผู้สืบทอด 1 คน | แก้การนับผู้สืบทอด |

## ข้อเท็จจริงที่ต่างจากสเปกหรือควรรู้

- `auth status` ของ `yolo3` (เซสชันหมดอายุ) ตอบ `loggedIn: false` ไม่ใช่ `true` ส่วนการเรียกจริงยังให้ข้อความ OAuth expired สกิลจึงแยกสถานะจากการเรียกจริงเท่านั้น
- `Current session` ไม่ได้มีทุกบัญชี (`yolo1` มีเฉพาะ `Current week`) สกิลรายงานเฉพาะบรรทัดที่มี
- Codex มี rate limit เฉพาะหน้าต่าง 7 วันในเวอร์ชันนี้ และเป็นข้อมูลจาก rollout ล่าสุด จึงอาจเก่ากว่าเวลาปัจจุบัน สกิลแสดงเวลาของข้อมูลทุกครั้ง
- `/workspace` map มาจาก `C:\t\s04c\03_MultiAccount_Container\workspace` ไม่ใช่โฟลเดอร์งานนี้
- `docker exec` บน Git Bash แปลง path ที่ขึ้นต้นด้วย `/` ตัวอย่างบน host จึงใช้ `../root/...` ซึ่งอาศัย WORKDIR `/workspace`
