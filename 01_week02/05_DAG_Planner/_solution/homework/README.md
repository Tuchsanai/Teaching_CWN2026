แต่ละข้อมี 3 ส่วน: **พรอมต์ที่คัดลอกไปวาง** (โจทย์ + ให้ใช้สกิล) → **DAG** → **Gantt แผน** ไฟล์ครบชุดของแต่ละข้ออยู่ในโฟลเดอร์ชื่อเดียวกับแผน (`blocks.json` · `dag.png` · `gantt-plan.png` · `PLAN.md` · `ANSWER.md` · `prompt.txt`)

| เรื่อง | ค่าที่ใช้ในเฉลย |
|---|---|
| วิธีสร้าง | แตกบล็อกตามกติกาใน `SKILL.md` ของ `dag-planner` แล้วสั่ง `dag` และ `plan --max-agents 4` (10 พ.ย. 2026) |
| โควตา | **สมมติ** `--accounts yolo1:80,yolo2:60,cyolo1:90,cyolo2:70` (เหลือ 80 · 60 · 90 · 70%) สกิลจึงไม่เรียกบัญชีใดเลย ใครสั่งซ้ำก็ได้แผนเดียวกัน |
| ที่รัน | บนเครื่องโดยตรงด้วย `./base_skills` (ตอนทำเฉลย container `multi-account` ไม่ได้เปิดอยู่) ผลของ `dag` และ `plan` เหมือนกับที่รันใน container |
