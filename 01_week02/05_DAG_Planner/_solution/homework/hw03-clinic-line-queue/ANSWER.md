# ANSWER · hw03-clinic-line-queue

**โจทย์:** ระบบจองคิวคลินิกผ่าน LINE chatbot มีแจ้งเตือนก่อนถึงคิว และหน้า dashboard ของเจ้าหน้าที่

1. **สายวิกฤต:** B02 → B05 → B10 ยาว 7.5 ล้านโทเคน (1.5 + 3 + 3) · คิดย้อนจากบล็อกสุดท้าย: rank(B10) = 3 (ไม่มีใครรอ) · rank(B05) 3 + max(B10 3) = 6 · rank(B02) 1.5 + max(B05 6, B07 4.5, B09 3.6) = 7.5
2. **สกิลหลายบัญชีและสกิลภาพ:**
   - **B02** `review` เพราะโครงฐานข้อมูลเป็นคอขวดของ 3 บล็อก (B05 B07 B09) ผิดแล้วต้องแก้ทุกบล็อก
   - **B03** `best_of` เพราะถ้อยคำของบอทเป็นงานสร้างสรรค์ อยากได้ตัวเลือกที่ดีที่สุด
   - **B04** `image` สำหรับ rich menu
   - ไม่ใช้ `debate` เพราะไม่มีการตัดสินใจที่มีคำตอบถูกผิดชัดเจน
3. **ลูกศรที่ตัดไม่ได้:** B02 → B05: API ต้องใช้เงื่อนไขกันจองซ้ำจากโครงฐานข้อมูล ถ้าตัดออกจะได้ชื่อตารางและคอลัมน์ไม่ตรงกัน · **คู่ที่ตั้งใจไม่ใส่ลูกศร:** B06 กับ B05: webhook เรียก API ตาม docs/api.md ของ B01 จึงไม่ต้องรอ API เสร็จ
4. เหลือ agent สูงสุด 2: วางแผนได้แค่ **7/10 บล็อก** B03 ไม่มีบัญชีรับ เพราะ best_of ต้องใช้ 3 บัญชีพร้อมกัน เกินเพดาน 2 และ B06, B10 ที่รออยู่จึงถูกบล็อกตาม · ตัวเลขเวลารวม 70.6 นาที (เทียบกับ 83.4 นาทีที่ agent 4) จึงใช้เทียบไม่ได้ ต้องเปลี่ยนสกิลของบล็อกนั้นหรือใช้ agent อย่างน้อย 3
