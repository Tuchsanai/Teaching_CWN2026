คำตอบคือ… Linux container

"ห้องทดลอง" Linux ที่ติดตั้งเครื่องมือไว้พร้อม รันบนเครื่องของเราผ่าน Docker Desktop (Windows ใช้ WSL 2 ส่วน Mac ก็มี Docker Desktop) ทุกคนได้ Linux ชุดเดียวกัน แล้วใช้ VS Code ที่คุ้นเคยเข้าไปทำงานข้างใน

คำตอบ

ใช้เครื่องมือไหนก็ได้ → container เดียวกัน → ต่อยอดไปข้างนอก

ภาพแนวคิด สร้างด้วย Imagegen: Windows หรือ macOS จะสั่งงานผ่าน VS Code, Claude Code หรือ ChatGPT / Codex ก็ได้ ทุกทางเข้า container เดียวกันที่มี Bash, Python, Node.js, Git, Docker, Claude Code / Codex พร้อมใช้ และส่งงานไป AI model, GPU server หรือ deploy ขึ้น cloud ได้

ปั๊มใหม่ = กลับไปเหมือนแม่พิมพ์ ของที่แต่งไว้ในชิ้นเดิมไม่ตามมา ไฟล์ใน container หายเมื่อลบ งานสำคัญเก็บด้วย Git / volume / backup

สูตรจริงใน Dockerfile (ตัดมาเฉพาะส่วนสำคัญ)

FROM ubuntu:24.04                                   # ①
ENV TZ=Asia/Bangkok LANG=C.UTF-8

RUN apt-get install -y curl wget vim nano git \      # ②
      openssh-server python3 python3-pip python3-venv …
RUN add-apt-repository -y ppa:git-core/ppa …         # ③
RUN … apt-get install -y docker-ce docker-ce-cli \   # ④
      containerd.io docker-buildx-plugin docker-compose-plugin
RUN curl -fsSL https://deb.nodesource.com/setup_22.x | bash - \
 && apt-get install -y nodejs                          # ⑤
RUN pip install "jupyterlab>=4.3,<5" jupytext jupyterlab-git … # ⑥
RUN echo 'root:passwd' | chpasswd …                  # ⑦
COPY start.sh /usr/local/bin/start.sh
EXPOSE 22 8888
WORKDIR /workspace
CMD ["/usr/local/bin/start.sh"]                      # ⑧
①เริ่มจาก Ubuntu 24.04 ตั้งเวลาไทย
②เครื่องมือพื้นฐาน + Python + SSH server
③Git รุ่นล่าสุด (ใช้ git worktree ได้ครบ)
④Docker ข้างใน container (Docker-in-Docker)
⑤Node.js 22 สำหรับเว็บ Next.js / React / Vite
⑥JupyterLab และส่วนขยาย
⑦บัญชี root สำหรับ SSH (รหัสเดียวกันทุกเครื่อง ใช้เรียนบนเครื่องตัวเองเท่านั้น)
⑧ทุกครั้งที่ start รัน start.sh เปิด sshd, dockerd, JupyterLab

- ถ้ายังไม่มี ให้สร้างใหม่แบบ privileged (เพราะข้างในต้องใช้ Docker ได้)
  เปิด port 2222 → 22 สำหรับ SSH และ 8885 → 8888 สำหรับ JupyterLab ถ้า port ไหนชน ให้ใช้เลขว่างถัดไป
- ถ้ามีอยู่แล้ว ให้ใช้ตัวเดิม (ถ้าปิดอยู่ให้เปิด) ห้ามลบของเดิม

จากนั้นเข้าไปทำงานข้างใน container
1. ติดตั้ง Claude Code และ Codex ถ้ายังไม่มี และทำให้พิมพ์ claude ได้เลย
2. บอกว่าข้างในเป็น Linux อะไร มี Python, Node.js, Git, Claude Code และ Codex เวอร์ชันไหน
3. สร้างไฟล์ /workspace/hello.py ให้พิมพ์ว่า Hello from devtools แล้วลองรันให้ดู

สรุปผลเป็นตารางสั้น ๆ พร้อมบอก port ที่ใช้จริง
ขั้นที่ 3 · ผลจริง (รันครั้งแรก)

ไม่ได้พิมพ์คำสั่ง Docker สักบรรทัด… แต่ได้ห้องทดลองแล้ว

ตอนรันยังไม่มี container ในเครื่อง → Claude สร้างใหม่จาก tuchsanai/devtools:2569_1 แบบ privileged
  • port 2222 → 22 (SSH) และ 8885 → 8888 (JupyterLab) ตามที่ขอ
  • ติดตั้ง Claude Code 2.1.319 และ codex-cli 0.167.0 พิมพ์ claude ได้ทันที
  • Ubuntu 24.04.5 · Python 3.12.3 · Node.js v22.23.2 · Git 2.55.0
  • รัน /workspace/hello.py ได้ Hello from devtools

ผลจริงจาก Claude Code (Opus) บน Windows เครื่องตัวอย่าง เวอร์ชันที่ผู้เรียนได้อาจใหม่กว่า

วิธีเสริม · อยากเห็นเบื้องหลัง

สิ่งที่ Claude สั่งให้เรา หน้าตาเป็นแบบนี้

docker run -dit --name devtools --privileged \
  -p 2222:22 -p 8885:8888 \
  tuchsanai/devtools:2569_1

# ติดตั้ง Claude Code และ Codex ข้างใน container
docker exec -it devtools bash -c \
'curl -fsSL https://claude.ai/install.sh | bash && npm install -g @openai/codex'
