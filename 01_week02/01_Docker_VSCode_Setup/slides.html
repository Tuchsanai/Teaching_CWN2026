5 เหตุผลที่เลือก Linux container

🐧 ตรงกับ LAB

LAB ใช้ Bash, พาธแบบ Linux, สิทธิ์ไฟล์ และสคริปต์ติดตั้งของ Linux ใช้ environment เดียวกับตัวอย่าง ลดงานแปลงคำสั่ง Windows รัน Linux container ได้ผ่าน Docker Desktop + WSL 2

🧰 เครื่องมือชุดเดียวกัน

ไม่ต้องไล่ติดตั้ง Python, Node.js, Git บน Windows ทีละคน ทุกคนเริ่มจาก image ของวิชาเดียวกัน ผู้สอนช่วยตรวจปัญหาได้ง่าย

🔁 พังแล้วเริ่มใหม่ได้

เก็บงาน → ลบ container ที่มีปัญหา → สร้างใหม่จาก image → ตั้งค่าเพิ่มอีกครั้ง ไม่ต้องติดตั้งทุกอย่างบน Windows ใหม่

📦 แยกพื้นที่ทดลอง

แยกกระบวนการและไฟล์ออกจากระบบหลัก แต่ไม่ได้รับประกัน 100% โดยเฉพาะชุดนี้ที่ใช้ --privileged เพื่อรองรับ Docker-in-Docker

☁️ ต่อยอด cloud

ส่งงาน AI / GPU ออกไปข้างนอกแล้วรับผลกลับ และ deploy บน server ที่เป็น Linux เหมือนกัน

🤖 เรื่อง AI

สิ่งที่ต้องเข้ากันได้คือเครื่องมือที่ นำคำสั่งไปรันจริง (shell, runtime, ไลบรารี) ไม่ได้แปลว่า Windows ใช้ AI ไม่ได้ หรือ Linux ทำให้โมเดลฉลาดขึ้น

แนวคิดสำคัญ

Image = แม่พิมพ์ · Container = ชิ้นงานที่ปั๊มออกมา

ภาพเปรียบเทียบ (ภาพจำลอง สร้างด้วย Imagegen): แม่พิมพ์เดียว ปั๊มได้หลายชิ้น แต่ละชิ้นตกแต่งเพิ่มเองได้

Image คือต้นแบบที่ไม่เปลี่ยน เช่น tuchsanai/devtools:2569_1

Container คือพื้นที่ทำงานที่สร้างจาก image เราติดตั้งของเพิ่มหรือแก้ไฟล์ข้างในได้

สร้างใหม่ = กลับไปเหมือน image ของที่เพิ่มไว้ใน container เดิมไม่ตามมา

ไฟล์ใน container หายเมื่อลบ container ส่วนข้อมูลใน volume หรือโฟลเดอร์ที่เชื่อมจากเครื่องอยู่แยกต่างหาก งานสำคัญควรเก็บด้วย Git / volume / backup

3.1 · วางพรอมต์

New session → Ctrl+V → Enter

ภาพเคลื่อนไหวจำลองขั้นตอน (ประมาณ 7 วินาที) ครั้งแรกรอหลายนาที เพราะต้องดาวน์โหลด image และติดตั้งเครื่องมือ
ช่วยเตรียม container ชื่อ devtools ในเครื่องผม จาก image tuchsanai/devtools:2569_1

- ถ้ายังไม่มี ให้สร้างใหม่แบบ privileged (เพราะข้างในต้องใช้ Docker ได้)
  เปิด port 2222 → 22 สำหรับ SSH และ 8885 → 8888 สำหรับ JupyterLab ถ้า port ไหนชน ให้ใช้เลขว่างถัดไป
- ถ้ามีอยู่แล้ว ให้ใช้ตัวเดิม (ถ้าปิดอยู่ให้เปิด) ห้ามลบของเดิม

จากนั้นเข้าไปทำงานข้างใน container
1. ติดตั้ง Claude Code และ Codex ถ้ายังไม่มี และทำให้พิมพ์ claude ได้เลย
2. บอกว่าข้างในเป็น Linux อะไร มี Python, Node.js, Git, Claude Code และ Codex เวอร์ชันไหน
3. สร้างไฟล์ /workspace/hello.py ให้พิมพ์ว่า Hello from devtools แล้วลองรันให้ดู

สรุปผลเป็นตารางสั้น ๆ พร้อมบอก port ที่ใช้จริง

4 · อีกวิธี (ข้ามได้)

สร้าง container ผ่าน Claude Code ใน VS Code

เตรียม container `devtools`:

1. ถ้ามี container `devtools` อยู่แล้ว ให้ลบด้วย `docker rm -f devtools`
2. ตรวจ port <SSH_PORT>=2222 และ <JUPYTER_PORT>=8885 ถ้าชน ให้ใช้ port ว่างถัดไป
3. รัน:

docker run -dit --name devtools --privileged \
  -p <SSH_PORT>:22 -p <JUPYTER_PORT>:8888 \
  tuchsanai/devtools:2569_1

docker exec -it devtools bash -c \
'curl -fsSL https://claude.ai/install.sh | bash && npm install -g @openai/codex'

4. ตรวจด้วย `claude --version` และ `codex --version` แล้วสรุป port ที่ใช้
⚠️ พรอมต์นี้ ลบ devtools ตัวเดิม ก่อนสร้างใหม่ ถ้ามีงานอยู่ให้สำรองก่อน
