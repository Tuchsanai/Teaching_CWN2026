# ที่มาของภาพ `assets/architecture-single-app.png`

- **เครื่องมือ:** ImageGen ที่มีมาในตัว (built-in) · **ยังไม่ได้ยืนยันเวอร์ชันที่แน่นอน**
- **ประเภท:** แผนภาพอธิบาย (explanatory diagram) ไม่ใช่ภาพหน้าจอ และไม่ใช่หลักฐานว่าการ deploy แบบใหม่ใช้ได้
- **สถานะ:** ผ่านการอนุมัติให้ใช้ในหัวข้อ 1 ของ README

## brief ที่ใช้

- พื้นหลังขาว ข้อความภาษาไทย
- แนวนอน (คงเลย์เอาต์ที่แก้แล้ว): Browser ซ้าย ↔ App (FastAPI) กลางบน ↔ Providers (Claude Code CLI / Codex CLI) ขวา
- devtools อยู่ด้านล่าง เส้นประแทนการสร้าง/deploy เท่านั้น (ไม่ได้อยู่ในเส้นทางของคำขอ)
- volume บัญชีส่วนตัวแยกเป็นกล่องต่างหาก ลูกศรสีเขียวต่อกับ App เท่านั้น
- `index.html` แบบ standalone mount แบบอ่านอย่างเดียว
- วงกลมหมายเลข 1–3 แทนพรอมต์สามชุด: ① Backend · ② index.html · ③ deploy
- พอร์ตแสดงว่ามาจาก `.env` (8004 เป็นแค่ค่าเริ่มต้น)
- ภาพหน้าจอย่อส่วนของหน้าแชตอ้างอิง UI จริงของรอบทดลองใหม่ (`assets/new-trial/02-rounds-4-5-fable-1440x1000.png`) ไม่ใช่ภาพเก่า `assets/13-current-chat-real.png` ต้องตรงกับของจริง: header สีกรมท่า การ์ดสีขาว bubble สีน้ำเงิน
- แก้ไขเฉพาะจุดครั้งสุดท้าย: เพิ่มหัวลูกศรขวาที่หายไป ชี้เข้าขอบซ้ายของ App ไม่มีกล่อง web container เพิ่ม

> ภาพนี้เป็นแค่ภาพประกอบ หลักฐานจริงคือภาพหน้าจอ Playwright ที่ไม่ได้แก้ไขใน `assets/new-trial/`
