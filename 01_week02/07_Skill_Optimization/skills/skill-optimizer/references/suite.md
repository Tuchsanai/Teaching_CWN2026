# รูปแบบชุดโจทย์ (suite)

```text
<suite>/
├── suite.json      ← พรอมต์ + รายการโจทย์
├── grade.py        ← ตัวตรวจ: python3 grade.py <sandbox> <task.json> → พิมพ์ JSON บรรทัดเดียว
└── runs/           ← ผลของทุกรุ่น ทุกรอบ (skillopt.py สร้างให้)
```

## suite.json

```json
{"name": "web-builder", "skill_name": "web-builder", "timeout": 1200, "grader": "grade.py",
 "extra_skills": ["../base_skills/yolo"],
 "env": {"MY_DIR": "{sandbox}/out"},
 "prompt": "สร้างเว็บตาม brief ... ถ้าใน ./skills มีสกิลให้อ่านและใช้\n\n{brief}",
 "tasks": [{"id": "t1-coffee", "split": "train", "brief": "..."},
           {"id": "v1-plants", "split": "val", "brief": "..."}]}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `skill_name` | ชื่อโฟลเดอร์ที่สกิลถูกคัดลอกไปวางใน `sandbox/skills/` ของแต่ละรอบ |
| `prompt` | พรอมต์ที่ส่งให้เอเจนต์ · `{ชื่อ}` แทนด้วยฟิลด์ของโจทย์ · `{sandbox}` = โฟลเดอร์ทำงานของรอบนั้น |
| `extra_skills` | สกิลอื่นที่ต้องวางข้างกัน (path สัมพัทธ์จาก suite) เช่น base skills |
| `env` | ตัวแปรสภาพแวดล้อมของเอเจนต์ |
| `tasks[].split` | `train` = ใช้หาข้อบกพร่อง · `val` = ใช้ตัดสินที่ประตูรับเท่านั้น |
| `timeout` | วินาทีต่อรอบ |

พรอมต์ต้องเหมือนกันทุกรุ่น และไม่บอกวิธีทำ ให้บอกแค่ว่า "ถ้ามีสกิลใน ./skills ให้อ่านและใช้" เพื่อให้แขนที่ไม่มีสกิล (`--skill none`) ใช้พรอมต์เดียวกันได้

## ตัวตรวจ (grade.py)

พิมพ์ JSON บรรทัดเดียว คะแนน 0–1 และรายการข้อตรวจที่ผ่าน/ไม่ผ่านพร้อมเหตุผลสั้น ๆ

```json
{"score": 0.875, "checks": [{"id": "files", "pass": true, "note": ""},
                             {"id": "parallel", "pass": false, "note": "สายวิกฤต 70% ของงานรวม"}]}
```

หลักการเขียนตัวตรวจ

- ตรวจ**ผลงาน**ใน sandbox ไม่เชื่อคำตอบของเอเจนต์
- ทุกข้อผ่าน/ไม่ผ่านได้ด้วยโค้ด (ไฟล์มีจริง · สคริปต์รันผ่าน · Playwright กดแล้วได้ผล) ใช้ AI ตัดสินเฉพาะเมื่อจำเป็น
- `note` ต้องบอกสาเหตุพอให้คนอ่านรู้ว่าพลาดเพราะอะไร
- ข้อที่ผ่านทั้งตอนมีและไม่มีสกิลทุกรอบ ไม่ได้วัดอะไร ควรเปลี่ยนเป็นข้อที่ยากขึ้น
- แก้ตัวตรวจแล้วต้องสั่ง `skillopt.py grade` ให้ทุกรุ่นถูกตรวจด้วยตัวตรวจเดียวกัน
