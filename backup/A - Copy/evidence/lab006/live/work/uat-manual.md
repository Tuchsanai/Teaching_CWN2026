## 1. ตรวจก่อนว่า placeholder ถูกแทนแล้วหรือไม่ (ถ้ายังไม่แทน = SKIP, ห้ามเดา)

คำสั่งกำหนดว่า “ถ้ายังไม่แทน placeholder ให้บันทึก SKIP และห้ามเดา” จึงตรวจหลักฐานจากไฟล์จริงก่อนตัดสินใจ ไม่เดาค่าเอง

| หลักฐานที่ตรวจ | สิ่งที่พบ | สรุป |
|---|---|---|
| `index.html` → `#code-hint` | แสดง `<code>&lt;LEARNER_A&gt;</code> <code>&lt;LEARNER_B&gt;</code> <code>&lt;LEARNER_C&gt;</code> <code>&lt;LEARNER_D&gt;</code>` (render บนจอเป็น `<LEARNER_A>` … `<LEARNER_D>`) พร้อมข้อความ “รหัสจำลองที่ใช้ได้ 4 รหัส” | ชุดรหัสที่ยอมรับ = **สตริง literal มีวงเล็บแหลม** 4 ค่า |
| `index.html` → attribute ของช่องกรอก | `placeholder="เช่น &lt;LEARNER_A&gt;"` | หน้าจอบอกผู้ใช้ให้พิมพ์ `<LEARNER_A>` ตรงตัว |
| `preview.md` ข้อ 7 (วิธีเปิดดูด้วยตนเอง) | “กรอกรหัสจำลอง เช่น `<LEARNER_A>` แล้วกดปุ่ม ‘จองที่นั่ง’” | ยืนยันค่าที่ต้องพิมพ์จริง |
| `uat-results.md` ส่วน C แถว B02-X (คอลัมน์หลักฐาน) | `DOM codes=[<LEARNER_X>]`; `localStorage=[{"code":"<LEARNER_X>","seat":1}]` | รอบก่อนพิมพ์ `<LEARNER_X>` **ตรงตัว** และระบบเก็บค่าตรงตัว |
| ผลรันจริงรอบที่ 1 ของบันทึกนี้ | พิมพ์ `<LEARNER_X>` → `localStorage=[{"code":"<LEARNER_X>","seat":1}]` ตรงกับหลักฐานรอบก่อนทุกตัวอักษร | reproduce หลักฐานเดิมได้ = ตีความ placeholder ตรงกับผู้ตรวจรอบก่อน |

**สรุปข้อ 1:** ในชุดงานนี้ placeholder ถูกแทนค่าเสร็จแล้ว — รหัสที่ใช้ได้คือ literal `<LEARNER_A>`, `<LEARNER_B>`, `<LEARNER_C>`, `<LEARNER_D>` และ `<LEARNER_X>` คือรหัสนอกชุดเดียวกับที่ใช้ในหลักฐานเดิม → **ไม่บันทึก SKIP** และไม่มีการเดาค่าใด ๆ

### ตัดสิน: **SKIP** (ไม่ใช่ PASS และไม่ใช่ FAIL)

**เหตุผล:**

1. **ตรงตามกฎที่ผู้ใช้กำหนดในขั้นนี้** — คำสั่งระบุว่า “ถ้ายังไม่แทน placeholder ให้บันทึก SKIP และห้ามเดา” และผลตรวจ ก.1 พบว่าค้างครบทั้ง 5 ช่อง
2. **ตัดสิน PASS/FAIL ไม่ได้ในทางตรรกะ** — คำตัดสินต้องเทียบ `เห็นจริง` กับ `คาดหวัง` เมื่อทั้งสองฝั่งไม่มีค่า จึงไม่มีสิ่งใดให้เทียบ การเขียน PASS หรือ FAIL ลงไปจะเป็นการ**แต่งผล**
3. **ไม่รันแทนผู้เรียน** — คำสั่งห้าม “ทำ UAT อื่นแทนผู้เรียน” ขั้นนี้จึง **ไม่เปิด browser ไม่คลิก ไม่วัดค่าใด ๆ** สำหรับเคสนี้ (ต่างจากภาคผนวกส่วน 2–5 ด้านบน ซึ่งเป็นการยืนยัน/แก้บั๊ก B02-X ที่มีหลักฐานเดิมรองรับ)
4. **ไม่เข้าเงื่อนไขรอบแก้ไข** — SKIP ไม่ใช่ FAIL จึงไม่เปิดรอบแก้ `index.html` โควตา “รวมไม่เกิน 2 รอบ” จึง **ยังไม่ถูกใช้ในขั้นนี้ (ใช้ 0 รอบ)**
5. **ไม่ลดเกณฑ์** — เกณฑ์ B01–B09 และ UAT-01–09 ใน `requirements.md` ยังคงเดิมทุกข้อ ไม่มีการผ่อนค่าตัวเลขใด
