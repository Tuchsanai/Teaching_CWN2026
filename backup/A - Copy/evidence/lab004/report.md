## 5. การปรับพรอมท์และรันซ้ำ

ไม่มีขั้นใดเกิน 3 attempts รายละเอียดเวลา exit code และ SHA-256 ทุกครั้งอยู่ใน `live-run.tsv`

1. ขั้น 2 รอบแรก Qwen ติดป้ายจำลองทั้งที่ใช้ต่างค่าย และเติมรายละเอียดเกิน source จึงกำหนดว่าป้ายจำลองใช้เมื่อชื่อ CLI ซ้ำ จำกัดจำนวน AC และห้ามแต่งฟิลด์หรือนโยบาย
2. ขั้น 3 รอบแรกขยายคำถามและนโยบายเกินข้อมูล จึงบังคับใช้เฉพาะข้อเท็จจริง และถามมนุษย์เพียง “เจ้าของนโยบายอนุมัติให้ยืมสูงสุดกี่วัน?”
3. ขั้น 5 รอบแรกเปลี่ยนชื่อ negative case จึงล็อกข้อความ “ขั้น 1: WAITING_FOR_WORKERS และไม่สร้าง merged.md”
4. ตรวจ stream รอบ 2 ของ Worker A พบการเรียก CLI ลูก จึงเพิ่มข้อห้ามเรียก AI หรือ CLI ลูกในพรอมท์ทั้งหก และรัน workflow รอบสุดท้ายใหม่ทั้งหมด รอบสุดท้ายไม่พบการเรียกลูก

Expected Output ปรับเฉพาะถ้อยคำและรูปแบบ ไม่แก้รหัส ตัวเลข สถานะ หรือกฎธุรกิจเพื่อรองรับคำตอบผิด
