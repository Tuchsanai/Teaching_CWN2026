ให้เตรียม Docker container ชื่อ `devtools` ตามเงื่อนไขนี้:

* ถ้ามี container `devtools` อยู่แล้ว ให้ลบก่อน
* ตรวจสอบ port `2222` และ `8885`
* หาก port ชน ให้เปลี่ยนเป็น port ว่างที่เหมาะสม
* จากนั้นรัน:

```bash
docker run -dit --name devtools --privileged \
  -p <SSH_PORT>:22 \
  -p <JUPYTER_PORT>:8885 \
  tuchsanai/devtools:2569_1
```


ให้ ssh ไปยัง devtools  จากนั้น ให้ไปยัง floder /workspace
