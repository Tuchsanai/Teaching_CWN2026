# ชุด C — ต้องเปลี่ยนตามนโยบาย (ข้อมูลสมมติ)
[C-P1] นโยบาย v2 มีผลกับชุด C และแทน v1 สำหรับคำร้องใหม่: ชำรุดแจ้งภายใน 14 วันพร้อมรูป ให้เจ้าหน้าที่ตรวจและเสนอเปลี่ยนสินค้า; เปลี่ยนใจภายใน 3 วัน สินค้ายังไม่เปิดใช้ เสนอรับคืนเพื่อตรวจสภาพก่อนคืนเงินได้ ไม่มีคำรับรองว่าอนุมัติแล้ว
[C-P2] ระดับคิวคงเดิม: P1 อันตรายส่งหัวหน้าทันทีและหยุดใช้; P2 ชำรุดทั่วไป; P3 ขอข้อมูลหรือเปลี่ยนใจ ไม่รับประกันเวลาตอบ
[C-P3] ข้อยกเว้นส่งผู้จัดการ AI อนุมัติไม่ได้
[C-O1] ออเดอร์ C101: แก้วร้าว รับแล้ว 10 วัน มีรูป ไม่มีอันตราย
[C-M1] ขอเปลี่ยนแก้วของ C101
[C-M2] ของเสีย อยากได้เงินคืน ไม่ให้เลขออเดอร์ วันรับ หรือรูป
[C-O3] ออเดอร์ C303: กระเป๋ายังไม่เปิดใช้ รับแล้ว 2 วัน เปลี่ยนใจ
[C-M3] ขอคืนกระเป๋า C303 เพราะเปลี่ยนใจ
[C-O4] ออเดอร์ C404: กาต้มน้ำรับแล้ว 20 วัน รูปปลั๊กไหม้ ยังไม่มีผู้บาดเจ็บที่รายงาน
[C-M4] ขอคืนเงินกาต้มน้ำ C404 กรณีพิเศษ
