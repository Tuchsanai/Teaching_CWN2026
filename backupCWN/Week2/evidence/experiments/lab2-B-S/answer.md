อ่าน native Skill จาก `.agents/skills/shop-recovery/SKILL.md` ผ่านเครื่องมือแล้ว และอ่าน `input.md` กับ `manual.md` ครบ ร่างนี้วินิจฉัยสองเหตุการณ์แยกกันจากหลักฐานก่อนกู้ โดยไม่ได้รันบริการหรือแก้ไฟล์ ร้านนี้เป็นร้านจำลอง ใช้ข้อมูลฝึก ไม่มีการชำระเงินจริง

**หลักฐานก่อนกู้**

บริการคือโปรแกรมที่รับคำขอจากเว็บ; รุ่นคือชุดพฤติกรรมของโปรแกรม; logs คือบันทึกเหตุการณ์; rollback คือการกลับไปใช้รุ่นก่อนที่ตรวจแล้วว่าดี

| ID | สิ่งที่เห็นจริง | ความหมาย |
|---|---|---|
| B-S1 | `STOPPED version=v1` | บริการรุ่น v1 หยุดอยู่ |
| B-S2 | Browser แจ้ง `ERR_CONNECTION_REFUSED` | เปิดร้านไม่ได้ สอดคล้องกับบริการหยุด |
| B-S3 | `SERVICE_STOPPED` และ `SERVICE_NOT_STARTED` | บันทึกระบุว่ายังไม่ได้เริ่มบริการ |
| B-U1 | `RUNNING version=v2 bookings=0` | บริการ v2 ทำงานอยู่ แต่จำนวนจองเป็นศูนย์เพียงอย่างเดียวยังบอกสาเหตุไม่ได้ |
| B-U2 | Browser จองไม่สำเร็จ พร้อม `UPDATE_V2_BOOKING_BROKEN` | มีหลักฐานว่าการจองบน v2 ใช้งานไม่ได้ |
| B-U3 | `UPDATE_APPLIED` และ `BOOKING_ERROR` ระบุ `UPDATE_V2_BOOKING_BROKEN` | บันทึกเชื่อมปัญหาการจองกับรุ่นอัปเดต v2 |

**สาเหตุและสิ่งที่ยังต้องตรวจ**

- **รอบ basic — สาเหตุหลัก: ยังไม่ได้เริ่มบริการ** ความมั่นใจสูงจาก B-S1–B-S3 จึงเลือก `start` ได้หากสถานะปัจจุบันยังเป็นบริการหยุดรุ่น v1
- **รอบ advanced — สาเหตุหลัก: รุ่นอัปเดต v2 จองสินค้าไม่ได้** ความมั่นใจสูงจาก B-U1–B-U3 บริการทำงานอยู่แล้ว และคู่มือระบุว่า `start` ไม่แก้ปัญหา v2
- **ข้อสันนิษฐานที่ยังยืนยันไม่ได้:** มี v1 ที่ตรวจแล้วว่าจองได้พร้อมให้ย้อนกลับ หลักฐาน B-U1–B-U3 ไม่แสดงผลทดสอบ v1 ส่วน B-S1–B-S3 เป็นคนละเหตุการณ์และแสดงเพียง v1 ที่หยุดอยู่
- **สิ่งที่ต้องถามแทนการรอคำตอบ:** “รอบ advanced มีรุ่น v1 ที่ตรวจแล้วว่าจองสำเร็จและพร้อมให้ย้อนกลับหรือไม่ มีหลักฐานใด?” ต้องยืนยันเงื่อนไขนี้ก่อนแนะนำให้ลงมือ `rollback` หากยังไม่มี ให้เก็บ `status`/`logs` ของรอบปัจจุบันและแจ้งผู้สอน โดยยังไม่เปลี่ยนรุ่น

**คำแนะนำให้คนทำตามลำดับ**

ทำแต่ละรอบแยกกัน ไม่ใช้ผลของรอบหนึ่งยืนยันอีกรอบ ตารางนี้เป็นแผนและผลคาดหวัง ยังไม่ใช่ผลที่ทำแล้ว

| ลำดับ / คำสั่ง | เมื่อใด | เหตุผล | ผลคาดหวัง |
|---|---|---|---|
| 1. `./shop preflight` | ก่อนเริ่มแต่ละรอบ | ตรวจ Python และพอร์ตตามคู่มือ | `PREFLIGHT OK` และ URL; หากมีเหตุขัดข้องให้หยุดแจ้งผู้สอน |
| 2. `./shop status` | ก่อนเลือกคำสั่งกู้ | ยืนยันว่าสถานะยังตรงภาพหลักฐาน | basic: `STOPPED version=v1`; advanced: `RUNNING version=v2` |
| 3ก. `./shop start` | เฉพาะ basic ที่ยังหยุดบน v1 ตาม B-S1–B-S3 | เริ่มบริการรุ่นปัจจุบัน | `STARTED version=v1` |
| 3ข. `./shop rollback` | เฉพาะ advanced ที่ยังเป็นปัญหา B-U1–B-U3 **และยืนยันว่ามี v1 ที่ดีแล้ว** | กลับจากรุ่นที่จองเสียไปยังรุ่นที่ตรวจแล้วว่าดี | `ROLLED BACK version=v1` |
| 4. `./shop status` | หลังคำสั่งกู้ของรอบนั้น | ตรวจบริการและรุ่นหลังทำ | `RUNNING version=v1` |
| 5. `./shop check` | หลังสถานะถูกต้อง | ตรวจหน้าเว็บและการจองผ่านช่องทางรับคำขอของระบบ | `CHECK PASS booking=... version=v1` พร้อมเลขจริง |
| 6. `./shop open` | หลัง check ผ่าน | รับ URL ไปเปิด browser | URL ร้านฝึก จากนั้นกด **จองสินค้า** ต้องเห็นเลขจองจริงและรุ่น v1 |
| เมื่อไม่ผ่าน: `./shop logs` | คำสั่งกู้หรือการตรวจไม่สำเร็จ | เก็บเหตุการณ์เพื่อให้ผู้สอนตรวจ | บันทึก UTC รุ่น และข้อผิดพลาด แล้วหยุดขั้นตอนกู้และแจ้งผู้สอน |

หากสถานะก่อนทำต่างจาก B-S1 หรือ B-U1 ให้เก็บ `./shop logs` และประเมินหลักฐานใหม่ก่อนเปลี่ยนแปลง ไม่ใช้คำสั่งกู้ทั้งสองต่อกัน ไม่ `reset` ระหว่างกู้ และไม่แก้ไฟล์ภายใน

การเปิดหน้าเว็บได้หรือได้ HTTP 200 ยังไม่ยืนยันว่าจองได้ แม้ `check` ผ่านก็ต้องทดสอบจองผ่าน browser เพิ่มตามคู่มือ

**ช่องรอหลักฐานหลังทำ**

| รายการบันทึก | basic | advanced |
|---|---|---|
| คำสั่งที่คนทำจริงและผลตอบกลับ | รอกรอก | รอกรอก |
| รุ่นก่อน → หลังจาก status จริง | ภาพก่อนกู้: v1; รอยืนยันก่อนทำและหลังทำ | ภาพก่อนกู้: v2; รอยืนยันก่อนทำและหลังทำ |
| หลักฐานว่า v1 ดีและพร้อมย้อนกลับ | ไม่ใช้กับการ start | รอยืนยันก่อน rollback |
| ผล status หลังทำ | รอกรอก | รอกรอก |
| ผล check / เลขจองจาก check | รอกรอกเลขจริง | รอกรอกเลขจริง |
| ผล browser / เลขจองจาก browser / รุ่น | รอทดสอบและกรอกเลขจริง | รอทดสอบและกรอกเลขจริง |
| logs หากไม่ผ่าน | รอเก็บเมื่อพบปัญหา | รอเก็บเมื่อพบปัญหา |
| สถานะ: รอทดสอบ / ผ่าน / ไม่ผ่าน | **รอทดสอบ** | **รอทดสอบ** |

ทั้งสองรอบยังไม่มีหลักฐานหลังทำ จึงยังยืนยันว่ากู้คืนสำเร็จไม่ได้
