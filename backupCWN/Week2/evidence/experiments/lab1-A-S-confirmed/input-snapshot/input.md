# ชุด A — ร้านละมุน (ข้อมูลสมมติสำหรับฝึก)
[A-C1] แชตฝ่ายขาย: แคมเปญลด 10% และลูกค้าน่าจะใช้คูปองร่วมได้
[A-C2] แชตเจ้าหน้าที่รับออเดอร์: ลูกค้าจ่ายแล้วก็ยกเลิกได้ก่อนแพ็กนะ
[A-M1] บันทึกประชุม: ต้องบันทึกชื่อผู้รับ เบอร์ติดต่อ และรายการสินค้าก่อนยืนยันออเดอร์
[A-M2] บันทึกประชุม: อยากรับคืนเมื่อเปลี่ยนใจภายใน 7 วัน ยังไม่ได้ระบุสภาพสินค้าและค่าขนส่ง
[A-P1] เอกสารกติกา: ส่วนลด 10% ใช้ร่วมกับคูปองไม่ได้
[A-P2] เอกสารกติกา: ยกเลิกได้เฉพาะก่อนชำระเงิน
[A-P3] เอกสารกติกา: รับคืนเฉพาะสินค้าชำรุด แจ้งภายใน 7 วันหลังได้รับ
[A-N1] หมายเหตุ: ไม่มีเอกสารระบุลำดับอำนาจของแชต ประชุม และกติกา ไม่มีคำอนุมัติเปลี่ยนนโยบาย และยังไม่มีข้อตกลงค่าขนส่งคืน
