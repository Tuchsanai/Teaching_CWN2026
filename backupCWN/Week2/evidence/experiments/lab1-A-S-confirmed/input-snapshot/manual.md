# คู่มือร่วมทั้ง Prompt และ Skill
ข้อมูลทุกชุดเป็นเรื่องสมมติ ไม่มีแหล่งไหนสำคัญกว่าโดยอัตโนมัติ
คำว่า ความต้องการ หมายถึงสิ่งที่ร้านอยากให้ทำ; กติกา คือเงื่อนไขตัดสิน; ตรวจรับ คือยกเหตุการณ์มาดูว่าทำตามข้อตกลงหรือไม่
แหล่งหลักฐานคือรหัส [A-C1] ฯลฯ การอ้างรหัสไม่พอถ้าเนื้อความไม่รองรับข้อกล่าวอ้าง
แบบผลลัพธ์: ตารางความต้องการ / คำถาม / กติกา / สถานการณ์ตรวจรับ
ใช้เวลาเครื่องไม่เกิน 240 วินาทีต่อร่าง ผู้เรียนไม่เกิน 12 นาทีต่อชุด ไม่ต้องเขียนโปรแกรม
