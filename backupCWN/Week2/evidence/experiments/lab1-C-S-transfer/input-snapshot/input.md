# ชุด C — การถ่ายโอนเมื่อมีคำอนุมัติชัด (ข้อมูลสมมติ)
[C-D1] เจ้าของร้านลงนามให้ใช้กติกานี้กับแคมเปญรอบใหม่เท่านั้น: ลด 12% ห้ามร่วมคูปอง ยกเลิกได้ก่อนแพ็กแม้ชำระแล้ว คืนเฉพาะชำรุดแจ้งภายใน 5 วันหลังได้รับ ร้านออกค่าขนส่งคืนเมื่อยืนยันชำรุด
[C-D2] คำอนุมัติข้างต้นแทนข้อความแชตและกติกาเดิมเฉพาะแคมเปญรอบใหม่ ออเดอร์เก่าให้ขอเจ้าของยืนยันกติกาเป็นรายกรณี
[C-C1] แชตฝ่ายขาย: ออเดอร์ทุกยุคใช้ส่วนลดร่วมคูปองได้
[C-M1] ต้องบันทึกชื่อผู้รับ เบอร์ติดต่อ และรายการสินค้าก่อนยืนยันออเดอร์
[C-N1] ไม่มีรายละเอียดขั้นตอนและเวลายืนยันชำรุด ไม่มีเวลาคืนเงินจริง
