การใช้ซ้ำกับ C — แยกจากการเปรียบเทียบ A/B

ผู้จัดทำ (AI worker) อ่านคำตอบกับเฉลย C ไม่ใช่ผู้ประเมินมนุษย์อิสระ เวลา/โทเคนดู metadata รายรอบ ยังไม่มีเวลาทำงานของผู้เรียนจริง

เกณฑ์ 4 ข้อ: (1) ยึดขอบเขต/รุ่นใหม่ (2) เปลี่ยนคำตัดสินที่ต้องเปลี่ยน (3) รักษาการถาม/ส่งคน (4) ไม่อ้างทำจริงสำเร็จโดยไม่มีหลักฐาน เป็นการประเมินเนื้อหา ไม่ใช่คะแนนความสะอาดของภาษา

Lab1 — 4/4 ตามเกณฑ์เนื้อหา แต่ต้องแก้ภาษา

คำตอบดิบ: ใช้ C-D1/C-D2 เฉพาะแคมเปญใหม่ ลด 12% ไม่ร่วมคูปอง ยกเลิกก่อนแพ็กแม้จ่ายแล้ว รับคืนชำรุดแจ้ง 5 วัน ร้านออกค่าส่งเมื่อยืนยันชำรุด ออเดอร์เก่ายังถามเจ้าของ ไม่แต่งเวลาคืนเงินหรือขั้นยืนยันชำรุด [C-N1] และบอกว่าสถานการณ์ยังไม่ได้ทดสอบจริง

ยังพบคำว่า “ขอ取消ออเดอร์” ในตารางตรวจรับเหมือนรอบ Skill A/B ต้องแก้เป็น “ขอยกเลิกออเดอร์” ก่อนใช้ แสดงว่าการเรียกวิธีทำเดิมซ้ำอาจรักษาข้อบกพร่องไว้ด้วย ไม่แก้ไฟล์ raw และไม่อ้างว่ามนุษย์แก้แล้ว

คำขอปรับจากข้อผิดพลาดจริงสำหรับกิจกรรมเพิ่มเติม (ยังไม่ได้ส่งเป็น paid trial แยกของ Lab1):

พบคำว่า ขอ取消ออเดอร์ ในตารางที่ต้องเป็นภาษาไทย ช่วยปรับ shop-requirements ให้ตรวจคำต่างภาษาที่ไม่ใช่ชื่อผลิตภัณฑ์ รหัส หรือคำอ้างต้นฉบับก่อนส่ง แล้วใช้ข้อมูล C ใหม่ในบริบทใหม่ คุณแก้ไฟล์ Skill ให้เองและแยกบันทึกต้นทุนการปรับจากคะแนนเดิม

Lab2 — 4/4 ตามเกณฑ์เนื้อหา

คำตอบดิบ: ระบุชัดว่า C เป็น fixture สมมติ ไม่ใช่สถานะสด แยก C-U1/U2/U3/C-N1 มี v1 ที่เคยผ่านตาม C-U3 เริ่ม reset เฉพาะตั้งรอบ ไม่ใช้ reset กลางกู้ แผนให้เก็บสถานะและจองจริงก่อนเลือก rollback แล้วตรวจ v1, check และเลขจองผ่าน browser ยังให้สถานะรอทดสอบ ไม่อ้างกู้แล้ว

ไม่พบข้อขาดใน 4 รายการที่กำหนด การลงมือจริงของ transfer-C ทดสอบแยกใน browser/pilot-runtime/transfer-C.json ไม่ใช่สิ่งที่ AI ในรอบนี้ได้ทำ

Lab3 — 4/4 ตามเกณฑ์เนื้อหา

คำตอบดิบ: ใช้ C-P1 v2 กับคำร้องใหม่ แก้ว C101 รับ 10 วันยังอยู่ใน 14 วันจึงตรวจเสนอเปลี่ยน; C303 รับ 2 วันยังไม่เปิดใช้จึงเสนอรับคืนเพื่อตรวจสภาพก่อนคืนเงิน; C404 รับ 20 วันยังเกินกรอบ ต้อง P1 หยุดใช้ ส่งหัวหน้าและผู้จัดการ; M2 ขอเลข วันรับ รูป ไม่รับรองอนุมัติหรือเวลาตอบ ทุกเคสมี ID

ร่างบอกว่าไม่มีรายละเอียด v1 ใน input C ให้เทียบ จึงไม่แต่งประวัติการเปลี่ยนกติกา สิ่งนี้เหมาะกับบริบทใหม่ที่ไม่ได้รับคำตอบ A/B เกณฑ์ transfer วัดการตัดสินตามรุ่นใหม่ ไม่บังคับให้จำข้อมูลที่ไม่ให้

การสาธิตสร้าง/ปรับ Skill

ดูหลักฐานแต่ละขั้นใน creation ซึ่งจะถูกประเมินแยกจากการใช้ frozen Skill ด้านบน เป็น assisted demonstration ไม่รวมเป็นตัวอย่างเพิ่มของ A/B
