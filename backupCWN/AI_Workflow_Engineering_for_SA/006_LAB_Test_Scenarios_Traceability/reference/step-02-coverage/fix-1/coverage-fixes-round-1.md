## ผลตรวจ regression ของเอกสาร

- เปรียบเทียบนิยาม TestID เดิมทั้ง107บล็อกกับไฟล์ต้นทาง: ข้อความตรงกันทุกบล็อก รวมขั้นตอน/expected/สถานะ/Actual/หลักฐาน; ไม่เปลี่ยนความหมาย ID เดิม. เพิ่มเพียง7นิยามตาม D01–D07 เป็น114นิยาม: customer35, kitchen-front42, manager37
- เทียบ AC เต็มทุก114นิยามกับแถวต้นฉบับ และแถว US ทั้ง26แถวในชุดสำเนา: ตรงตัว คงหน่วย สูตร ตัวเลข จำนวนตัวอย่างและสัดส่วน. ตรวจช่อง template ครบทุกนิยาม; ID ไม่ซ้ำและต่ำกว่า101 ไม่ชน fixture14ID
- ตรวจผลรวม fixture อิสระด้วยการคำนวณ:115/105,17จาก20,ค่าเฉลี่ย10/4/6และETA26/24/56,ยอด10โต๊ะ185–545และ155/215,ผู้กด8จาก10และความถี่5/3/2เทียบ4/4/2. เป็นการตรวจตัวเลขในแผน ไม่ใช่ผลรันระบบหรือผล mutation test
- รายการเดิม auto51/manual6/mock-not-testable50 คงเดิม; รายการใหม่7เป็น mock-not-testable ทั้งหมด รวม57. Status เดิม NOT_RUN57/NOT_TESTABLE50 คงไว้; ใหม่ MOCK_NOT_TESTABLE7 ตาม template. ทุก Actual/หลักฐานยังไม่มีข้อมูล
- แก้นอกบล็อกเฉพาะดัชนีของ US ที่เพิ่ม, ข้อมูลรอบ/จำนวนและฐาน path P01/ลิงก์ต้นทาง; ข้อความบันทึกก่อนแก้ระบุว่าเป็นต้นทางเพื่อไม่ใช้จำนวนเก่าปนรอบนี้. ตรวจ JSON ครบสาม role และ path resolve จาก LAB ถึงไฟล์รุ่นเดียวกัน
- ตรวจแฮชไฟล์ input/manifest/scenarioเดิม/รายงานเก่าที่อ่านก่อนและหลังสร้าง: ไม่เปลี่ยน. ไม่สร้างไฟล์สคริปต์/ผลรัน/work/หรือรายงานนอก Output ที่กำหนด

## สิ่งที่ยังไม่ได้ทดสอบ
