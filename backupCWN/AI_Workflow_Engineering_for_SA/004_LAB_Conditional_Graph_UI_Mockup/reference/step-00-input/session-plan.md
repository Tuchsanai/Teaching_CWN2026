# แผนการทดลอง

ใช้ชื่อหลักฐาน round-1 เป็นรอบสร้างครั้งแรก (เทียบ baseline รอบ 0 ในคู่มือ); round-2 และ round-3 เป็นรอบแก้ครั้งที่ 1 และ 2
เพดานชุดผลรันล่วงหน้านี้: รวมไม่เกิน 3 รอบ (เข้มกว่ากิจกรรมผู้เรียนที่แก้ได้ 3 ครั้ง)
อ่าน edge จาก JSON จริง: pass หยุดแก้; fix แทน FAILED_CHECKS จาก JSON แล้วตรวจทั้งชุดพร้อม --prev; cancel หยุดทันที
หากถึง round-3 แล้วยัง fix ให้ workflow cancel โดยไม่แก้ raw edge
ตรวจ AI หนึ่งครั้งหลังรอบสุดท้าย คงข้อค้างต้นทางและแยกการอ่านโค้ดจากผลคลิกจริง
เพดานเวลาและงบเงิน: ไม่ได้กำหนด; เก็บ wall time และ usage จริง ไม่ประเมินต้นทุนที่ไม่มีราคาอ้างอิง
