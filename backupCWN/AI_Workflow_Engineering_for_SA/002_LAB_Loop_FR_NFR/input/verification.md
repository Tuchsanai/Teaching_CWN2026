# วิธีทดสอบสคริปต์โดยไม่เรียกโมเดล

ชุดทดสอบนี้ใช้ executable จำลองเพื่อตรวจการควบคุม Loop ในเครื่อง ไม่มีการเรียกบริการ AI และผลจำลองไม่ใช่ผลรันล่วงหน้าของบทเรียน

## เตรียมและรัน

รันจากโฟลเดอร์ LAB 002 ต้องมี Bash, Python 3, GNU date/timeout และแพ็กเกจ Python `jsonschema` สำหรับตรวจ log กับ schema ในชุดทดสอบ ส่วน run-loop.sh และ loop-support.py ใช้ Python standard library

```bash
python3 -c 'import jsonschema'
bash -n input/run-loop.sh
python3 -c 'import json; json.load(open("input/loop-log.schema.json"))'
python3 input/test-loop.py
```

ถ้าไม่พบ jsonschema ให้ติดตั้งในสภาพแวดล้อม Python ที่ใช้เรียนด้วย `python3 -m pip install jsonschema` แล้วรันใหม่ ผลสำเร็จของชุดทดสอบต้องลงท้ายด้วย `OK` และ exit code เป็น 0 หากมี FAIL หรือ ERROR ให้อ่านชื่อกรณีและ traceback ก่อนใช้งาน Loop

## สิ่งที่ทดสอบ

- หยุดเมื่อ PASS โดยไม่เรียก fixer ต่อ และหยุดเมื่อคะแนนไม่เพิ่มสองรอบติด
- หยุดตามเพดานรอบ รวมการลด MAX_ROUNDS และตรวจ regression แม้คะแนนรวมเพิ่ม
- ปฏิเสธ SCORE ที่ไม่ตรงตาราง และผลที่มี event ล้มเหลว
- เก็บ usage ที่อ่านไม่ได้เป็น null และหยุดเมื่อไม่ทราบ usage ขณะเปิดงบโทเคน
- หยุดเมื่อถึงเพดานโทเคนหรือหมดเวลา
- รองรับเกณฑ์เพิ่ม E1 และอ่านรูปแบบผลอีกเครื่องมือด้วยข้อมูลจำลอง
- ตรวจ log ทุกกรณีกับ JSON Schema และตรวจว่าการรันซ้ำไม่เขียนทับหลักฐานเดิม

ชุดทดสอบสร้างโฟลเดอร์ `.test-loop-*` ใต้ input/ และใช้ `TemporaryDirectory` ลบโฟลเดอร์นั้นเมื่อแต่ละกรณีจบ ไม่แก้ work/ ของนักศึกษา หากโปรเซสถูกบังคับปิดจนมีโฟลเดอร์ค้าง ให้ตรวจว่าไม่มีการทดสอบทำงานอยู่แล้วลบเฉพาะโฟลเดอร์ชั่วคราวจากการทดสอบครั้งนั้น

## การตีความผล

การทดสอบนี้ยืนยันพฤติกรรมของสคริปต์กับข้อมูลจำลอง ไม่ยืนยันคุณภาพ FR/NFR ความแม่นยำของ checker หรือการเชื่อมต่อ CLI จริง ผู้เรียนยังต้องตรวจหลักฐานราย US และ regression จากผลรันจริง เวลา/รอบ/โทเคนของโมเดลที่ไม่มี log ให้ระบุ “ไม่มีข้อมูล”
