สร้าง skill ชื่อ second-opinion-ai สำหรับใช้บนเครื่องนี้ ห้ามอ่านไฟล์ README ของ LAB ห้ามล็อกอินแทนฉัน ห้ามอ่าน คัดลอก หรือแสดงไฟล์ credential ใด ๆ

## สิ่งที่มีอยู่แล้ว (ตรวจจริงก่อน ห้ามเดา)
- คำสั่ง yolo2 = Claude Code อีกบัญชี เรียกแบบไม่เปิดหน้าจอด้วย: yolo2 -p --model <model> --effort <effort> "<prompt>" < /dev/null (ค่าเริ่มต้น opus, high)
- คำสั่ง cyolo1 = Codex CLI เรียกแบบไม่เปิดหน้าจอด้วย: cyolo1 exec --skip-git-repo-check -m <model> -c model_reasoning_effort=<effort> -o <ไฟล์ผลลัพธ์> "<prompt>" < /dev/null (ค่าเริ่มต้น gpt-6-astra, medium) อ่านคำตอบจากไฟล์ -o
- ตรวจล็อกอินด้วย yolo2 auth status --text (exit 0 = ล็อกอินแล้ว) และ cyolo1 login status (ข้อความ Logged in)

## สิ่งที่ skill ต้องทำ
- ใช้เมื่อผู้ใช้พูดว่า "ขอความเห็นที่สอง", "ให้ทั้ง Claude และ Codex ตอบ", "เทียบคำตอบสองค่าย"
- ส่งคำถามเดียวกันให้ yolo2 และ cyolo1 พร้อมกัน (ขนาน) แล้วรายงานเป็นตาราง: โมเดล/effort | คำตอบแต่ละฝั่ง | ตรงกันหรือไม่ และสรุป 1 บรรทัด
- ตรวจล็อกอินก่อนเรียก บัญชีที่ยังไม่ล็อกอินให้ระบุว่า "ข้าม (ยังไม่ล็อกอิน)" ห้ามสลับบัญชีเอง
- ใส่ลอจิกการเรียกขนานไว้ในสคริปต์ scripts/ask-both.sh ที่ exit 0 เสมอ ไม่พิมพ์ข้อมูลลับ
- description ต้องบอกว่าใช้เมื่อไร ห้ามยาวเกิน 3 บรรทัด และห้ามใส่ขั้นตอนทั้งหมดไว้ใน description
