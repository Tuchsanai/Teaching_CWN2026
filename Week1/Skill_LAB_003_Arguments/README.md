# Skill_LAB 003 · Arguments: ส่งค่าเข้า skill ด้วย `/discount 1500 10` (★★)

## 1. วัตถุประสงค์

1. ทำให้ skill รับค่าจากผู้ใช้ได้ 3 แบบใน Claude Code: ต่อท้ายอัตโนมัติ (`ARGUMENTS:`), ตามตำแหน่ง (`$0`, `$1`) และตามชื่อ (`arguments: [amount, rate]`)
2. เห็นจาก session log ว่า CLI **แทนค่าลงใน body ก่อนส่งถึงโมเดล** และเกิดอะไรขึ้นเมื่ออาร์กิวเมนต์ขาดหรือมีช่องว่าง
3. รู้ว่า Codex **ไม่มี** การแทนค่า และเห็นว่าข้อความหลัง `$discount` ไปถึงโมเดลในรูปแบบใด

## 2. ข้อกำหนดเบื้องต้น

| รายการ | ข้อกำหนด |
|---|---|
| ต้องผ่านก่อน | [Skill_LAB 001](../Skill_LAB_001_Hello_Skill/README.md) (มี skill `discount` ใน `shared/skills` ทั้งสองฝั่ง) และทฤษฎีหัวข้อ 7 |
| บัญชี | `yolo1`, `cyolo1` |
| โมเดล | Claude = Opus · high, Codex = gpt-6-astra · medium |
| เวลา | 30 นาที |

## 3. ความรู้พื้นฐาน

ใน Skill_LAB 001 เราเห็นว่าเมื่อพิมพ์ `/discount ซื้อ 1500 บาท` Claude Code ต่อท้าย `ARGUMENTS: ซื้อ 1500 บาท` ให้เอง นั่นคือแบบที่ 1 ในตารางนี้

| แบบ | เขียนใน frontmatter | เขียนใน body | ผู้ใช้พิมพ์ | โมเดลเห็น |
|---|---|---|---|---|
| 1 ต่อท้ายอัตโนมัติ | – | ไม่มีตัวแปร | `/discount 1500 10` | body เดิม + บรรทัด `ARGUMENTS: 1500 10` |
| 2 ตามตำแหน่ง | `argument-hint` (ทางเลือก) | `$0`, `$1` | `/discount 1500 10` | `$0`→`1500`, `$1`→`10` |
| 3 ตามชื่อ | `arguments: [amount, rate]` | `$amount`, `$rate` | `/discount 1500 10` | `$amount`→`1500`, `$rate`→`10` |

การแทนค่าเกิดครั้งเดียวตอนโหลด skill และ **Codex ไม่มีกลไกนี้** ข้อความหลัง `$discount` เป็นข้อความผู้ใช้ตามปกติ ส่วนตัวแปร `$0` ใน body จะไปถึงโมเดลทั้งดุ้น

skill ทั้งสามฉบับใน LAB นี้ตั้ง `disable-model-invocation: true` เพื่อให้ทดสอบเฉพาะการเรียกเองด้วย `/discount` (สวิตช์นี้เรียนใน Skill_LAB 002)

## 4. ขั้นตอนการทดลอง

ทุกขั้นแทนที่ไฟล์ `discount/SKILL.md` ทั้งสองฝั่งด้วยฉบับใหม่ แล้วรันคำสั่งทดสอบจาก shell (ไฟล์ทั้งสามฉบับอยู่ใน [skills/](skills/))

```bash
BASE_PATH="$HOME/ai-accounts"
put() { for ROOT in "$BASE_PATH/.Claude/shared/skills" "$BASE_PATH/.Codex/shared/skills"; do mkdir -p "$ROOT/discount"; cp "$1" "$ROOT/discount/SKILL.md"; done; }
```

### ขั้นที่ 1 · แบบต่อท้ายอัตโนมัติ (~5 นาที)

`put skills/args-plain/SKILL.md` (body เหมือน LAB 001 ไม่มีตัวแปร) แล้วรัน

```bash
yolo1 -p '/discount 1500 10'
yolo1 -p '/discount 1500'
```

ผลรันจริง ([evidence/args-plain-A2-claude.transcript.txt](evidence/args-plain-A2-claude.transcript.txt)) — สิ่งที่โมเดลได้รับ:

```text
USER: <command-name>/discount</command-name>
<command-args>1500 10</command-args>
USER: Base directory for this skill: /root/ai-accounts/.Claude/yolo1/skills/discount

# กฎส่วนลดของร้าน
...
ARGUMENTS: 1500 10
ASSISTANT: ยอดซื้อ 1500 บาท ≥ 1000 จึงได้ส่วนลด 10%
| ยอดซื้อ | ส่วนลด | ยอดจ่าย |
| 1500.00 | 150.00 | 1350.00 |
หมายเหตุ: อาร์กิวเมนต์ตัวที่สอง (10) ตรงกับอัตราส่วนลดตามกฎอยู่แล้ว จึงคิดที่ 10%
```

ทั้งสองคำสั่งตอบ 1,350 ใน 1 turn (8.2 s และ 5.7 s) โมเดลต้องตีความเองว่า `1500 10` หมายถึงอะไร วิธีนี้พอใช้เมื่ออาร์กิวเมนต์มีค่าเดียวหรือความหมายชัด

### ขั้นที่ 2 · แบบตามตำแหน่ง `$0` `$1` (~10 นาที)

`put skills/args-index/SKILL.md`

```markdown
---
name: discount
description: คำนวณยอดจ่ายตามกฎส่วนลดของร้าน โดยรับยอดซื้อและอัตราส่วนลดจากอาร์กิวเมนต์ ใช้เมื่อผู้ใช้พิมพ์ /discount <ยอดซื้อ> <อัตรา%>
disable-model-invocation: true
argument-hint: "<ยอดซื้อ> <อัตราส่วนลด%>"
---

คำนวณยอดจ่ายสำหรับยอดซื้อ **$0 บาท** โดยใช้อัตราส่วนลด **$1%** ซึ่งให้เฉพาะเมื่อยอดซื้อครบ 1000 บาท

ตอบเป็นตาราง ยอดซื้อ | ส่วนลด | ยอดจ่าย ทศนิยม 2 ตำแหน่ง แล้วบอกด้วยว่าได้รับอาร์กิวเมนต์อะไรมาบ้าง ไม่ต้องสร้างไฟล์หรือรันคำสั่ง
```

รัน 3 คำสั่ง

```bash
yolo1 -p '/discount 1500 10'
yolo1 -p '/discount 1500'
yolo1 -p '/discount "1 500" 10'
```

| คำสั่ง | body ที่โมเดลได้รับ (ตัดมา) | คำตอบ | turn / เวลา |
|---|---|---|---|
| `/discount 1500 10` | "ยอดซื้อ **1500 บาท** โดยใช้อัตราส่วนลด **10%**" | ตาราง 1350.00 + "อาร์กิวเมนต์ที่ได้รับมา: `1500 10` — สองค่า" | 1 / 18.7 s |
| `/discount 1500` | "ยอดซื้อ **1500 บาท** โดยใช้อัตราส่วนลด **$1%**" ← `$1` **คงเป็นข้อความเดิม** | โมเดลเปิดอ่าน SKILL.md เองด้วย Bash แล้วตอบว่า `$1` ไม่ได้รับค่า จึงแสดงตาราง 4 อัตรา (5/10/15/20%) และแนะนำให้เรียกใหม่ `/discount 1500 10` | 2 / 34.3 s |
| `/discount "1 500" 10` | "ยอดซื้อ **1 500 บาท** … **10%**" | `$0` = `1 500` (เครื่องหมายคำพูดทำให้ช่องว่างอยู่ในอาร์กิวเมนต์เดียว) ตอบ 1350.00 | 2 / 19.6 s |

หลักฐาน: [evidence/args-index-A2-claude.transcript.txt](evidence/args-index-A2-claude.transcript.txt), [args-index-A1-claude.transcript.txt](evidence/args-index-A1-claude.transcript.txt), [args-index-AQ-claude.transcript.txt](evidence/args-index-AQ-claude.transcript.txt)

จุดสังเกต: อาร์กิวเมนต์ที่ขาดทำให้ `$1` โผล่ในข้อความทั้งดุ้น โมเดลเดาไม่ได้ว่าอัตราเท่าไร จึงต้องมี "ค่าเริ่มต้น" ในแบบที่ 3

### ขั้นที่ 3 · แบบตามชื่อ `arguments: [amount, rate]` (~5 นาที)

`put skills/args-named/SKILL.md` — เพิ่ม `arguments: [amount, rate]` ใน frontmatter และใช้ `$amount`, `$rate` ใน body พร้อมบรรทัด "ถ้าอัตราส่วนลดว่าง ให้ใช้ 10%"

```bash
yolo1 -p '/discount 1500 10'
yolo1 -p '/discount 1500'
```

| คำสั่ง | body ที่โมเดลได้รับ (ตัดมา) | คำตอบ |
|---|---|---|
| `/discount 1500 10` | "ยอดซื้อ **1500 บาท** โดยใช้อัตราส่วนลด **10%**" | ตาราง 1350.00 + "`amount` = 1500, `rate` = 10 — ระบุมาโดยตรง" |
| `/discount 1500` | "ยอดซื้อ **1500 บาท** โดยใช้อัตราส่วนลด **%**" ← `$rate` **กลายเป็นข้อความว่าง** | ตาราง 1350.00 + "`rate` *(ว่าง — ไม่ได้ส่งมา)* → 10% (ค่าเริ่มต้น)" |

![หน้าสนทนา Claude Code: /discount 1500 10 กับ skill ฉบับ arguments: [amount, rate]](img/claude-args.png)

ต่างจากแบบตำแหน่ง: ตัวแปรชื่อที่ไม่มีค่า **หายไปเงียบ ๆ** (ไม่ทิ้ง `$rate` ไว้) จึงต้องเขียนกฎค่าเริ่มต้นไว้ใน body เสมอ ([evidence/args-named-A1-claude.transcript.txt](evidence/args-named-A1-claude.transcript.txt))

ข้อสังเกตจากทั้งสองขั้น: เมื่อ body สั่งให้ "บอกด้วยว่าได้รับอาร์กิวเมนต์อะไรมาบ้าง" Claude มัก **เปิดอ่านไฟล์ SKILL.md เอง** อีกครั้งด้วย Bash (2 turn, 15–34 s) เพื่อดูเทมเพลตต้นฉบับ เพราะข้อความที่มันได้รับถูกแทนค่าไปแล้วจนไม่เห็นว่าเดิมเป็น `$0` หรือ `$amount` ถ้าไม่ต้องการให้เสียรอบนี้ ให้ตัดคำสั่งนั้นออก

### ขั้นที่ 4 · ฝั่ง Codex: `$discount 1500 10` (~5 นาที)

Codex ไม่แทนค่า แต่ให้ลองทั้งสามฉบับเพื่อดูว่าโมเดลได้อะไร

```bash
cyolo1 exec --skip-git-repo-check '$discount 1500 10'
```

สิ่งที่ Codex ฉีดให้โมเดล (จาก rollout ทั้งสามฉบับ [evidence/args-index-X2-codex.rollout.jsonl](evidence/args-index-X2-codex.rollout.jsonl)):

```text
user: $discount 1500 10
user: <skill>
<name>discount</name>
<path>/root/ai-accounts/.Codex/shared/skills/discount/SKILL.md</path>
---
name: discount
description: ...
disable-model-invocation: true
argument-hint: "<ยอดซื้อ> <อัตราส่วนลด%>"
---
คำนวณยอดจ่ายสำหรับยอดซื้อ **$0 บาท** โดยใช้อัตราส่วนลด **$1%** ...
</skill>
```

| ฉบับ | โมเดลเห็นใน body | คำตอบ | เวลา |
|---|---|---|---|
| args-plain | body เดิม | ตาราง 1,350.00 | 9.7 s |
| args-index | `$0 บาท`, `$1%` ทั้งดุ้น | ตาราง 1,350.00 + "ได้รับอาร์กิวเมนต์: `1500` และ `10`" (โมเดลจับคู่เอง) | 12.2 s |
| args-named | `$amount บาท`, `$rate%` | ตาราง 1,350.00 + "`amount = 1500`, `rate = 10`" (โมเดลจับคู่เอง) | 10.6 s |

ข้อสรุปฝั่ง Codex: ไฟล์ทั้งไฟล์รวม frontmatter ถูกส่งให้โมเดลใน `<skill>` และโมเดลจับคู่ `1500 10` กับ `$0`/`$amount` **ด้วยความเข้าใจภาษา ไม่ใช่การแทนค่า** ใช้ได้ในกรณีง่าย แต่ไม่รับประกันเหมือน Claude Code ถ้าต้องการ skill ที่ใช้ได้ทั้งสอง CLI ให้เขียนใน body เป็นภาษาคนว่า "ผู้ใช้จะพิมพ์ยอดซื้อและอัตราต่อท้ายชื่อ skill" แทนการพึ่ง `$0`

## 5. ผลการทดลองเปรียบเทียบ

| แบบ | อาร์กิวเมนต์ครบ | อาร์กิวเมนต์ขาด | Codex |
|---|---|---|---|
| ต่อท้ายอัตโนมัติ | `ARGUMENTS: 1500 10` โมเดลตีความเอง | `ARGUMENTS: 1500` ใช้กฎ 10% จาก body | ส่งข้อความตามปกติ |
| `$0 $1` | แทนค่าถูกต้อง | `$1` ค้างในข้อความ โมเดลสับสน ต้องถามอัตรา | เห็น `$0 $1` ทั้งดุ้น จับคู่เอง |
| `arguments: [amount, rate]` | แทนค่าถูกต้อง | `$rate` หาย ใช้ค่าเริ่มต้นตามที่ body บอก | เห็น `$amount $rate` ทั้งดุ้น จับคู่เอง |

## 6. สรุป

1. Claude Code แทนค่าอาร์กิวเมนต์ลง body **ก่อน** ส่งถึงโมเดล (เห็นได้ใน session log ที่ข้อความผู้ใช้เป็น body ที่แทนค่าแล้ว) โมเดลไม่เคยเห็น `$0`
2. ไม่มีตัวแปร → ได้ `ARGUMENTS:` ต่อท้าย; `$N` ที่ขาด → ค้างเป็นข้อความ; `$name` ที่ขาด → ว่าง จึงควรใช้แบบตั้งชื่อ + เขียนค่าเริ่มต้นใน body
3. ใส่ `argument-hint` เพื่อให้เมนู `/` บอกผู้ใช้ว่าต้องพิมพ์อะไร และใช้ `"..."` เมื่ออาร์กิวเมนต์มีช่องว่าง
4. Codex ฉีดไฟล์ทั้งไฟล์ใน `<skill>` และไม่แทนค่า skill ข้ามค่ายควรอธิบายอาร์กิวเมนต์เป็นภาษาคน
