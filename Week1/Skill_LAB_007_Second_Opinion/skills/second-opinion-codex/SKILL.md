# ความเห็นที่สองจากสองค่าย

คำถาม = ข้อความของผู้ใช้ที่ตามหลังชื่อ skill (ถ้าว่าง ให้ใช้คำถามล่าสุดของผู้ใช้ในบทสนทนา)

## ขั้นตอน

1. รันหนึ่งครั้ง: `bash <โฟลเดอร์ของ skill นี้>/scripts/ask-both.sh "<คำถาม>"` (โฟลเดอร์ของ skill คือโฟลเดอร์ที่มีไฟล์ SKILL.md นี้; สคริปต์ตรวจล็อกอินเอง เรียกสองบัญชีขนานกัน และพิมพ์คำตอบทั้งสองฝั่ง; ตั้งค่า `CLAUDE_MODEL`, `CLAUDE_EFFORT`, `CODEX_MODEL`, `CODEX_EFFORT` ได้ถ้าผู้ใช้ระบุ ค่าเริ่มต้น opus/high และ gpt-6-astra/medium)
2. อ่านผลทั้งสองฝั่ง แล้วเขียนรายงานตามรูปแบบใน `references/report.md` ของ skill นี้
3. ห้ามเรียก yolo2 หรือ cyolo1 เองซ้ำนอกสคริปต์ ห้ามอ่านไฟล์ credential ห้ามล็อกอินแทนผู้ใช้ และไม่ต้องคำนวณคำตอบเอง หน้าที่ของคุณคือเทียบและสรุป
