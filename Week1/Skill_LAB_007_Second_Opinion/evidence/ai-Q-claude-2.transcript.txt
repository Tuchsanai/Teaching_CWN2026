# Second Opinion AI

ขอความเห็นที่สองโดยส่งคำถามเดียวกันไปยังสองบัญชี/สองค่ายพร้อมกัน แล้วสรุปว่าตรงกันหรือไม่

## ขั้นตอน

1. เรียกสคริปต์ครั้งเดียว (สคริปต์จัดการทั้งการตรวจล็อกอินและการเรียกแบบขนานให้แล้ว):

   ```bash
   ~/ai-accounts/.Claude/shared/skills/second-opinion-ai/scripts/ask-both.sh "<คำถามของผู้ใช้>"
   ```

   ปรับโมเดล/effort ได้เมื่อผู้ใช้ระบุ (ค่าเริ่มต้น Claude = opus/high, Codex = gpt-6-astra/medium):

   ```bash
   ask-both.sh "<คำถาม>" --claude-model sonnet --claude-effort medium \
                         --codex-model gpt-6-astra --codex-effort high
   ```

   สคริปต์ exit 0 เสมอ — ให้ดูค่า `status:` ของแต่ละบล็อกเพื่อรู้ผลจริง

2. อ่านผลลัพธ์ที่แบ่งเป็นบล็อก `=== CLAUDE (yolo2) ===` และ `=== CODEX (cyolo1) ===`
   แต่ละบล็อกมี `model:`, `effort:`, `status:` (`ok` / `skipped` / `error`) และ `answer:`

3. รายงานผู้ใช้เป็นตารางเสมอ:

   | ฝั่ง | โมเดล / effort | คำตอบ | ตรงกันหรือไม่ |
   |---|---|---|---|
   | Claude (yolo2) | opus / high | ... | ✅ ตรงกัน |
   | Codex (cyolo1) | gpt-6-astra / medium | ... | ✅ ตรงกัน |

   แล้วปิดท้ายด้วย **สรุป 1 บรรทัด** ว่าทั้งสองฝั่งเห็นตรงกันไหม และคำตอบที่ควรใช้คืออะไร

## กติกา

- `status: skipped` ให้ลงในตารางว่า **ข้าม (ยังไม่ล็อกอิน)** และห้ามสลับบัญชี/ล็อกอินแทนผู้ใช้เอง
  ให้บอกผู้ใช้ไปตรง ๆ ว่าต้องล็อกอินบัญชีนั้นเองก่อน
- `status: error` ให้ลงว่า **ผิดพลาด** พร้อมเหตุผลสั้น ๆ จากบรรทัด `reason:`
- ถ้าเหลือฝั่งเดียวที่ตอบได้ ยังต้องแสดงตาราง แต่ระบุชัดว่าเทียบไม่ได้เพราะมีคำตอบฝั่งเดียว
- ห้ามอ่าน คัดลอก หรือแสดงไฟล์ credential ของบัญชีใด ๆ
- อย่าตอบคำถามเองแทนสองฝั่งนั้น — หน้าที่ของ skill นี้คือรายงานสิ่งที่ทั้งสองฝั่งตอบจริง
