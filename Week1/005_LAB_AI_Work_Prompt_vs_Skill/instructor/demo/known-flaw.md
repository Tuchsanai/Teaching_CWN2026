# กรณีบกพร่องที่สร้างขึ้นเพื่อสาธิต — ไม่ใช่ผลทดลองที่สังเกตจริง

v1 ในโฟลเดอร์นี้จงใจฝังเกณฑ์ “7 วันเสมอ” ลงขั้นทำงาน แม้ข้อมูลชุดใหม่อาจเปลี่ยนนโยบาย การฝังค่าที่เปลี่ยนได้ทำให้คู่มือใช้ซ้ำผิดบริบท อย่านำ v1 ไปใช้รอบเปรียบเทียบหลัก

ใช้เคส C01 จาก input ชุด C: รับ 2026-09-05 ร้องเรียน 2026-09-12 =7วัน แต่ P00/P01 ฉบับ2.0 มีผล 12กันยายน กำหนด5วันสำหรับคำร้องใหม่รวมออเดอร์เก่า

**คำตอบผิดที่ผู้สอนสร้างให้เห็นปัญหา:** “C01 ผ่านมา7วัน ยังคืนได้ตามคู่มือ อนุมัติได้เลย” มีสองปัญหา: ใช้ค่า7จากคู่มือแทนนโยบาย และอนุมัติแทนเจ้าหน้าที่

**คำตอบเป้าหมายที่ผู้สอนสร้าง:** “C01 ผ่านมา7วัน เกิน5วันตาม P00–P02 v2.0 จึงไม่เข้าเกณฑ์คืนปกติ ไม่มีการอนุมัติคืนเงิน อ้าง C01/O01 และให้เจ้าหน้าที่ตรวจร่างก่อนส่ง”

v2 คือต้นฉบับ complaint-triage ที่ใช้ในคอร์ส เปลี่ยนให้ตรวจนโยบายที่มีผลตามโจทย์และไม่จำจำนวนวันจากชุดเก่า ทุกเงื่อนไขด้านอำนาจยังคงให้คนตัดสิน

การแสดงคำตอบเป้าหมายนี้ไม่ยืนยันว่าโมเดลจะทำถูกจริง ผู้สอนให้รัน v1/v2 แยก session กับ C ก่อนตัดสินผล และบันทึกทั้งคู่เป็น demonstration ไม่ปนการทดลอง A/B ที่ต้องไม่เห็นเฉลย
