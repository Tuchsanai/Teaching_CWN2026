## เฉลย transfer C

OW01 ระบุเจ้าของ ผู้อนุมัติ วันมีผล และขอบเขตแทนข้อเก่าชัดเจน จึงใช้ OW02–OW04 แก้ R5–R7 ได้ ไม่ใช่เพียงเพราะวันที่ใหม่กว่า

- R1–R4, R8–R10 และ Q4–Q6 คงเดิม
- R5 ยืนยันให้ใช้ร่วมกัน คูปอง 10% ก่อนคะแนน (OW02); Q1 ปิดแล้วตามมติ ไม่ถามซ้ำเป็นเรื่องค้าง
- R6 ยืนยันยกเลิกก่อนแพ็กได้แม้จ่ายแล้ว ไม่จำกัด 30 นาที (OW03); Q2 ปิด
- R7 ยืนยันชำรุดหรือเปลี่ยนใจภายใน 10 วันหลังรับ (OW04); Q3 ปิดตามขอบเขตมติ แต่หากจะทดสอบชั่วโมง/ขอบวันต้องขอนิยามเพิ่ม ไม่เดานาทีตัดรอบ
- T5 เลือกสินค้ายอด 1,000 ใช้คูปอง 10% และคะแนนเทียบมูลค่า 100 → ลดยอดเป็น 900 ก่อนหักคะแนนเหลือ 800 (โจทย์ UAT สมมติให้มูลค่าคะแนน 100 แล้ว ไม่กำหนดอัตราแลกคะแนนใหม่)
- T6 จ่ายแล้ว ยังไม่แพ็ก แม้เกิน 30 นาที → ยกเลิกได้; ถ้าแพ็กแล้ว → ไม่เข้าเงื่อนไข (OW03)
- T7 สินค้าปกติรับมา 5 วัน ขอคืนเปลี่ยนใจ → เข้าเงื่อนไขคืน (OW04); 11 วัน → เกิน 10 วัน
- T8–T10 ยัง pending อย่านำมติสามเรื่องไปปิดข้อมูลขาดที่ OW05 ยืนยันว่าไม่ตัดสิน

คำตอบเต็ม C ใช้ตาราง A เปลี่ยนเฉพาะรายการข้างต้นและอ้าง OW ทุกแถวที่เปลี่ยน ไม่มีข้อขัดแย้งค้างในสามประเด็นเดิม แต่ต้องแสดงประวัติการแก้โดยเจ้าของ

## Rubric รายข้อและตัวหาร

ให้คะแนนร่างแรกและฉบับแก้แยกกัน แต่ละรายการ 0 หรือ 1 ไม่ให้ครึ่งคะแนนเพื่อให้ตรวจตรงกัน

| กลุ่มรายการ | Accuracy ผ่านเมื่อ | Completeness ผ่านเมื่อ | จำนวน |
|---|---|---|---:|
| R1–R4 ทีละข้อ | ความหมาย/สถานะ/แหล่งตรงตารางข้างบน | มีแถวของเรื่องและหลักฐานที่ระบุชัด | 4 |
| R5–R7 ทีละข้อ | ชี้ทั้งสองแหล่ง ไม่เลือกเองและสถานะ pending; C ต้องแก้ตาม OW | มีแถวเรื่องนั้นและแหล่งทั้งสองด้าน; C มีมติแทน | 3 |
| R8–R10 ทีละข้อ | บอกไม่ทราบ ไม่แต่งตัวเลขหรือช่องทาง | มีแถวแต่ละสิ่งที่ขาด | 3 |
| Q1–Q6 ทีละข้อ | ถามตรงช่องตัดสินใจและผู้มีอำนาจ; C Q1–3 ระบุปิดตาม OW ได้ | มีคำถามหรือสถานะปิดพร้อมมติของแต่ละหัวข้อ | 6 |
| T1–T10 ทีละข้อ | ก่อนทำ/การกระทำ/ผลคาดหวังสอดคล้องหลักฐานหรือ pending ตามตาราง | มีสถานการณ์และผลคาดหวังที่ระบุ แม้ยังผิด | 10 |

Accuracy = จำนวนถูก / **26** ×100; Completeness = จำนวนรายการที่มี / **26** ×100 ต่างกันตรงมีแต่ผิดนับครบแต่ไม่ถูก

Conflict coverage = ตรวจพบ R5,R6,R7 พร้อมคู่หลักฐานและไม่ตัดสินเอง / **3**; Missing coverage = R8,R9,R10 ที่ระบุว่ายังขาด / **3** ไม่มีการเพิ่มตัวหารหลังเห็นคำตอบ ข้อเกินหลักฐานนอก rubric จดจำนวน unsupported claims แยก; ถ้าเปลี่ยนความหมายรายการใน rubric ให้รายการนั้น 0 ด้วย

Transfer reuse = accuracy C /26; conflict coverage C ใช้ N/A เพราะมติเคลียร์แล้ว ไม่ใช้ 0/0 แทน 100% ข้อมูลขาด C ยัง /3 ผู้เรียนผ่านเพื่อการเรียนรู้เมื่อ accuracy ≥21/26 และ R5–R7/T5–T7 ไม่มีการปิดประเด็นเอง เกณฑ์นี้เป็นเกณฑ์ผู้สอนกำหนด ไม่ใช่ผลวิจัย

ตัวอย่างผิดที่ต้องจับ: “นโยบายเก่ากว่าเลยไม่ใช้” → R5–R7 และ T5–T7 ผิด; “ค่าส่ง 50 คืนเงิน 3 วัน แจ้ง SMS” → R8–R10 และ T8–T10 ผิด ทั้งที่ตารางอาจครบ
