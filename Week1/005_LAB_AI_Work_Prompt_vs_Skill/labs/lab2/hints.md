# คำใบ้ Lab 2 — เปิดเท่าที่จำเป็น

บันทึกเวลาขอและระดับทุกครั้ง เปิดเฉพาะส่วนที่ผู้สอนอนุญาตเหมือนกันทั้งสองแบบ

## ระดับ 1 · สังเกต

RUNNING กับใช้งานได้ต่างกัน อ่าน release และผล verify พร้อมกัน

## ระดับ 2 · ขั้นถัดไป

ใช้ status, logs, verify จากรอบปัจจุบัน: หยุด v1-good กับรัน v2-bad/503 ต้องใช้การแก้คนละอย่าง

## ระดับ 3 · วิธีแก้พร้อมเหตุผล

STOPPED/v1-good ใช้ ./labctl start; RUNNING/v2-bad/503 ใช้ ./labctl rollback เพราะ start ไม่เปลี่ยน release จากนั้น verify ทั้งสามหน้าและเปิด URL ล่าสุดในเบราว์เซอร์ ถ้ายังเสียให้ส่งผู้สอน

## เมื่อติดขัด

ถ้า AI อ่านไฟล์ไม่เจอ ให้ส่งชื่อไฟล์ที่ผู้สอนเตรียมและข้อความผิดพลาด ห้ามเดาเนื้อหา หากคำตอบไม่ตรง ให้คัดลอกเฉพาะแถวที่สงสัยพร้อมบรรทัดต้นทางกลับไปถาม “ข้อสรุปนี้มีหลักฐานอะไร ถ้าไม่มีให้แก้เป็นรอข้อมูล”

Lab เว็บให้คัดลอกผลคำสั่งทั้งชื่อคำสั่ง เวลา และผลล่าสุด ถ้าหน้าเว็บเปิดไม่ได้หลัง verify ผ่าน ให้ส่ง URL ล่าสุดและข้อความจากเบราว์เซอร์แก่ผู้สอน อย่าสั่งแก้ network เอง

ถ้า native Skill ไม่ปรากฏ ให้ผู้สอนแก้การเตรียมพื้นที่และเริ่ม session ใหม่ บันทึกเหตุขัดข้องของ setup แยกจากเวลาทำงาน ห้ามแอบนับการแนบ SKILL.md ว่าเป็นการเรียก Skill สำเร็จ
