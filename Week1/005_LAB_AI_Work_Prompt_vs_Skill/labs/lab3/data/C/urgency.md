# เกณฑ์ความเร่งด่วน v1 — อนุมัติพร้อมนโยบาย
[U01] P1 เร่งที่สุด: รายงานตัดเงินซ้ำ → การเงิน
[U02] P2: สินค้าชำรุด → ทีมคุณภาพ
[U03] P3: เปลี่ยนใจ/ข้อมูลออเดอร์ไม่ครบ/ขอยกเว้น → บริการลูกค้า หรือผู้จัดการตามนโยบาย
[U04] เรียง P1 ก่อน P2 ก่อน P3 ภายในระดับเดียวเรียงเวลารับคำร้องเก่าก่อน ถ้าเวลาเท่ากันใช้รหัสเคสตามตัวอักษรและตัวเลขน้อยก่อน ความยาวข้อความหรือการพิมพ์เร่งไม่เปลี่ยนระดับ
