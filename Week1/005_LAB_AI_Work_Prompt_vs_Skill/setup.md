# เตรียมเครื่องก่อนเริ่มนับเวลา

ผู้สอนเตรียมล่วงหน้า 30–60 นาที: Linux ที่มี Python 3.12 และเบราว์เซอร์ในเครื่องเดียวกัน พร้อม Codex CLI ที่ล็อกอินและเลือกโมเดลได้แล้ว ผู้เรียนไม่ติดตั้งเครื่องมือ ไม่แก้ config และไม่อ่าน credential ในคาบ ใช้ข้อมูลสมมติทั้งหมด ไม่ต้องมี Docker, pip หรือบริการภายนอกสำหรับร้านจำลอง ส่วน AI ต้องเชื่อมต่ออินเทอร์เน็ตและมีโควตา

## ผู้สอนเตรียม

1. แจกสำเนาแพ็กเกจแยกคนละโฟลเดอร์ หรือแยกบัญชีระบบต่อคน เปิด Terminal ณ รากสำเนานั้นให้พร้อม ห้ามหลายคนควบคุม instance เดียว
2. ตรวจ `python3 --version`, `cyolo1 --version` และสิทธิ์โมเดลตามวิธีของห้องเรียน บัญชี cyolo1 และ gpt-6-astra/high ถูก parent ตรวจไว้แล้วสำหรับเครื่องผู้เขียน สถานะผู้เรียนต้องตรวจใหม่โดยผู้สอน
3. เตรียมพื้นที่ทดลองแยกตาม [คู่มือทดลอง](experiments/README.md) หลีกเลี่ยงเฉลยและประวัติคำตอบ ผู้สอนรับผิดชอบการตั้งเครื่องและสิทธิ์ ไม่ให้ผู้เรียนแก้ไฟล์ใดเอง
4. ลองร้านบนเครื่องสอนก่อนด้วยคำสั่งเดียวจากรากแพ็กเกจ:

```bash
./labctl setup
```

ควรเห็น `READY basic-A` และตำแหน่ง runtime; เว็บไซต์ยังหยุดอยู่ตามโจทย์ จะได้ URL เมื่อ start ไม่ต้องเดาหรือกรอก port เอง `setup` ซ้ำไม่ล้างงาน; `reset` ใช้เมื่อเริ่มรอบใหม่ตามผู้สอนเท่านั้น

5. ผู้สอนทดสอบด้วย `python3 instructor/runtime/test_runtime.py` ก่อนคาบ ร้านทำงาน offline ได้ เบราว์เซอร์ต้องเข้าถึง loopback ของเครื่องที่รัน หากเป็นเครื่องระยะไกลให้ผู้สอนจัดเบราว์เซอร์/การเข้าถึงให้ก่อน ไม่ให้ผู้เรียนตั้ง SSH หรือแก้ network
6. เปิดช่องสนทนา Codex CLI ในพื้นที่งานที่เตรียม โดยใช้คำสั่งห้องเรียนด้านล่าง จากนั้นให้ผู้เรียนวาง Prompt ในช่องสนทนา ไม่วาง Prompt ภาษาไทยลง shell

```bash
cyolo1 -m gpt-6-astra -c model_reasoning_effort=high
```

`cyolo1` เป็น wrapper ท้องถิ่นจากชุดเตรียมเครื่องของผู้สอน **ไม่ใช่คำสั่งมาตรฐานที่ติดตั้ง Codex แล้วจะมีทุกเครื่อง** wrapper เครื่องนี้ข้าม approval/sandbox จึงใช้เฉพาะพื้นที่ Lab ที่จัดไว้ การแจกสำเนาไฟล์ไม่ใช่การแยกสิทธิ์ระดับระบบ ผู้สอนต้องจัดขอบเขตเครื่องให้เหมาะสมและใช้เงื่อนไขเดียวกันทั้งสองแบบ ไม่สอนให้ติดตั้งหรือแก้ wrapper ในคาบ

## ผู้เรียนตรวจพร้อม 5 นาที ก่อนเริ่มจับเวลา

- เปิดเอกสารที่ผู้สอนให้และเห็นอักษรไทย อ่านชื่อไฟล์ได้
- วางคำสั่งที่ผู้สอนเตรียมใน Terminal ได้ และคัดลอกผลกลับช่องสนทนาได้
- เปิดช่องสนทนาใหม่ และรู้ว่าจะส่งไฟล์ใด (CLI ใช้ Prompt บอกให้อ่านไฟล์ในพื้นที่งาน แทนปุ่มแนบไฟล์)
- เข้าใจว่า AI เสนอคำตอบได้ แต่ผลที่ยังไม่ตรวจต้องเขียนว่า “ยังไม่ตรวจ”

## การค้นพบและเรียก Skill

แพ็กเกจเก็บต้นฉบับใน `skills/` เพื่อไม่เปิดให้รอบ Prompt ค้นพบโดยอัตโนมัติ เมื่อต้องใช้จริงให้ AI หรือผู้สอนคัดลอก SKILL.md ไป `.agents/skills/ชื่อสกิล/SKILL.md` ในโปรเจกต์เฉพาะของผู้เรียน จากนั้นเริ่ม Codex ใหม่ในโปรเจกต์นั้น พิมพ์ `/skills` หรือ `$` ในช่องสนทนาแล้วเลือกชื่อที่ตรง

เส้นทางและวิธีเลือกนี้อ้างอิง [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills) ตรวจ 2026-09-12; ตรวจ syntax `$skill-name` เพิ่มจากข้อความที่ติดมากับ binary 0.154.0 ใน [หลักฐาน local](evidence/cli-local.txt) การเห็นไฟล์หรือแนบข้อความเฉย ๆ **ไม่พิสูจน์ native discovery** ต้องเก็บรายการ Skill และหลักฐานการโหลดจาก session ทดลองด้วย สถานะการเรียกจริงของแพ็กเกจนี้ยัง pending

ถ้าไม่พบชื่อ ให้ผู้สอนตรวจตำแหน่ง/ชื่อซ้ำ/ข้อผิดพลาดส่วนหัวและเปิด session ใหม่ ห้ามสรุปว่าเป็นรอบ Skill โดยสั่งอ่านไฟล์ทดแทนอย่างเงียบ ๆ บันทึกเป็นรอบฝึกอ่านคู่มือและไม่นับในการเปรียบเทียบ native Skill
