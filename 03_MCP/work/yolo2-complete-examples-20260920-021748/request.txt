1. บท 3 ต้องมีโค้ดการเรียก MCP โดยตรงฉบับเต็มที่คัดลอกแล้วรันได้ มี import/main/การจัดการ error/ขั้นตอนเตรียมและคำสั่งรัน ผลลัพธ์จริงและอธิบายทุกขั้น พยายามใช้ server จริงที่มีใน labs/my-mcp-server ไม่สร้าง API ที่เดาขึ้นเอง ตัวอย่างหลักเป็นการเรียก Kokoro ผ่าน MCP ตามบท 3 เดิม เพิ่ม hello/add sanity check ได้ เก็บ client ฉบับเต็มเป็นไฟล์ตัวอย่างที่เหมาะสมและแสดงโค้ดเต็มใน README ไม่ใช่ลิงก์อย่างเดียว ห้ามใช้ ... แทนส่วนจำเป็น ระบุบริบท working directory ชัดเจน
2. บท 4 ผู้สอนต้องการคำสั่งติดตั้ง/ตั้งค่าของแต่ละเครื่องมือครบและคัดลอกใช้ได้จริง ไม่ใช่บอกชื่อไฟล์อย่างเดียว ต้องรักษาคอมเมนต์ก่อนหน้าที่ให้เส้นทางหลักเริ่มจาก repo ต้นทาง + คำขอภาษาธรรมดาสั้น ๆ ไม่ต้องเป็นพรอมป์ต์ยาวละเอียดทุกคำสั่ง จัดเป็นเส้นทางหลักแบบ prompt และส่วน manual/reference ครบใน 4.6 ทั้ง Claude Code/Codex ให้พอร์ต path dependencies สอดคล้องกับของจริง Kokoro upstream เป็น library ไม่ใช่ MCP server; แยกสิ่งที่ต้องสร้าง wrapper จากสิ่งที่ติดตั้งได้เลย
