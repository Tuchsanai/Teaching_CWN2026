# Lab 6.1–6.7 — ให้ AI Agent ควบคุมเว็บ Kokoro TTS ผ่าน Playwright MCP

เตรียม: เริ่มเว็บด้วย `labs/kokoro-web/run.sh` แล้วตรวจ `curl http://127.0.0.1:8765/api/health`

```text
ใช้ Playwright MCP ทำตามลำดับต่อไปนี้กับเว็บ http://127.0.0.1:8765/ และรายงานผลทุกขั้น
1. เปิดเว็บไซต์ (browser_navigate) และบอกชื่อหน้า (title)
2. ทำ accessibility snapshot (browser_snapshot) แล้วสรุปว่ามี element อะไรบ้าง: textbox, select เสียง, ปุ่ม, ส่วนผลลัพธ์, เครื่องเล่นเสียง พร้อม ref ของแต่ละตัว
3. กรอกข้อความ "Hello students. This audio was generated by Kokoro through a web form controlled by Playwright MCP." ลง textbox และเลือกเสียง am_adam (browser_fill_form)
4. กดปุ่ม Speak (browser_click)
5. รอจนข้อความ "สร้างเสียงสำเร็จ" ปรากฏ (browser_wait_for) แล้วอ่านค่า ความยาวเสียง เวลาที่ใช้สร้าง sample rate เสียงที่ใช้ และ URL ไฟล์เสียง จาก snapshot
6. ถ่าย screenshot ทั้งหน้า (browser_take_screenshot fullPage) ชื่อ cs2-03-result.png
7. ใช้ screenshot และค่าที่อ่านได้เป็นหลักฐานสรุปว่าการทดลองสำเร็จ พร้อมตรวจ browser_console_messages และ browser_network_requests ว่า POST /api/tts ได้ 200 และไม่มี error จาก JavaScript
เพิ่มเติม: ทดสอบกรณีผิดพลาดด้วยการล้าง textbox ให้ว่างแล้วกด Speak อีกครั้ง บันทึกข้อความผิดพลาดที่หน้าเว็บแสดง
กติกา: ถ้า tool ใดล้มเหลว (เช่น click timeout) ห้ามเดา ให้ใช้ browser_evaluate ตรวจสถานะหน้าเว็บ (เช่น document.visibilityState) หาสาเหตุ แก้ แล้วลองใหม่ และบันทึกข้อความ error ตามจริง
```

ผลที่คาดหวัง: ไฟล์ใน `lab-results/playwright/run-*/` (screenshot 4 ภาพ, snapshot .yml, console.log, trace.md)
