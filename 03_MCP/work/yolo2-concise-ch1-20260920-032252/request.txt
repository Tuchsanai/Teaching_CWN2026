เป้าหมาย: คงรายละเอียดสำคัญมากกว่าฉบับดั้งเดิมเล็กน้อย แต่สั้นลงอย่างชัดเจนจากฉบับขยาย ประมาณ 45-60 บรรทัด Markdown หรือราวหนึ่งในสามถึงครึ่งของเนื้อหาปัจจุบัน ไม่ต้องใช้หัวข้อย่อย 1.2.1-1.2.7
คงหัวข้อ 1.2, 1.3, 1.4 เดิม ใช้ภาษาบทเรียนไทยสำหรับผู้เริ่มต้น อ่านต่อเนื่อง คงนิยาม MCP และ 3 แก่นสำคัญ (ภาษากลาง discovery แยกบทบาท) พร้อมตัวอย่าง flow สั้นหนึ่งบรรทัด
1.3 ใช้ตารางสองคอลัมน์ประมาณ 4 แถว อธิบายประโยชน์และตัวอย่าง Excalidraw/Playwright/Kokoro สั้น ๆ
1.4 เหลือ bullet สั้น 4-5 ข้อ ไม่ซ้ำความข้างบน ตัดตาราง/คำอธิบายลึกเรื่อง JSON-RPC และรุ่นออกได้โดยชี้ไปบท 2 ไม่ต้องย้ำบันทึกการตรวจหลายย่อหน้า
รักษาความถูกต้อง: MCP ไม่จำเป็นทุกงาน, discovery ไม่ใช่ติดตั้งเอง, Host กำหนดนโยบายอนุมัติไม่จำเป็นถามทุก call, MCP ไม่รับประกันปลอดภัย, ใช้ร่วมกันต้องรองรับเวอร์ชัน/ฟีเจอร์/transport, ไม่มี MCP ก็ทำ approval/discovery ได้
คงลิงก์ทางการที่จำเป็นจากฉบับปัจจุบัน ไม่ต้องวิจัยใหม่ถ้าไม่เพิ่มข้อเท็จจริง ห้ามแต่งผลทดสอบ Codex หรือเรียกหลักฐาน Claude ว่าเป็น Codex
ห้ามแก้ส่วนอื่น ห้ามแก้ .env/config/credentials/labs/หลักฐาน ห้ามติดตั้งหรือรัน prompt ในบทเรียน ห้าม commit/push
