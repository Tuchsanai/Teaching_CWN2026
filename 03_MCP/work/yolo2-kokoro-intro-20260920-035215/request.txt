แก้ readme.md ใน /root/workspace/CWN/Teaching/03_MCP บน Remote เท่านั้น ผู้ใช้ขอเพิ่มคำอธิบายว่า Kokoro คืออะไร ที่ต้นบท 3 เรียกใช้ Kokoro ผ่าน MCP ด้วย MCPServer
ใช้ yolo2 Fable medium ห้าม delegate ต่อ
อ่านต้นบท3 แล้วเพิ่มย่อหน้าสั้นภาษาไทย 3-4 ประโยคใต้ชื่อบท ก่อนตัวอย่างโค้ด/ขั้นติดตั้ง อธิบาย Kokoro เป็นโมเดล Text-to-Speech แปลงข้อความเป็นเสียงพูด Kokoro-82M มีประมาณ82ล้านพารามิเตอร์ ส่วนแพ็กเกจ Python kokoro ให้เรียกผ่าน KPipeline ในบทนี้ใช้ข้อความอังกฤษ voice af_heart และ MCPServer ห่อความสามารถนี้เป็น tool ให้ Host เรียก Kokoro ไม่ใช่ MCP server สำเร็จรูป ไม่ต้องเพิ่มหัวข้อย่อย/ตาราง/ประวัติยาว
ตรวจข้อเท็จจริงสั้นจากแหล่งต้นทาง https://github.com/hexgrad/kokoro หรือ https://huggingface.co/hexgrad/Kokoro-82M แบบ read-only และใส่ลิงก์ต้นทางในย่อหน้า อย่าอ้างว่ารองรับภาษาไทย หรือกล่าวว่าโมเดลพูดได้เฉพาะอังกฤษ ให้ระบุเฉพาะตัวอย่างบทนี้ใช้ภาษาอังกฤษ
