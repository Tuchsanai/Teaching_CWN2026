## เป้าหมาย
ช่วยปรับเอกสาร LAB 001–007 
0. ไม่ต้องการให้มีการระบบ path ประมาณว่า /root/workspace/yyy/xxx/
1. อ่านเนื้อหาเดิมของทุกแลปก่อนปรับ รักษาวัตถุประสงค์และโจทย์หลักของแต่ละแลป โดยแต่ละโฟลเดอร์มีเอกสาร Markdown สำหรับผู้เรียนเพียงไฟล์เดียว คือ README.md
2. เรียบเรียงกิจกรรมให้ผู้เรียนทำทีละขั้น ตามลำดับ “อ่านโจทย์ → คัดลอกพรอมท์ → วางใน AI ภายในคอนเทนเนอร์ → ดูผลลัพธ์จริง → เทียบ Expected Output → ทำขั้นถัดไป”
3. ในแต่ละขั้น ให้มีองค์ประกอบตามลำดับดังนี้:
   - เป้าหมายของขั้นนี้
   - ข้อมูลตั้งต้นที่ต้องใช้
   - พรอมท์สำหรับคัดลอก
   - Expected Output หรือตัวอย่างผลลัพธ์ที่คาดหวัง
   - จุดที่ผู้เรียนต้องตรวจ
   - วิธีทำต่อเมื่อผลไม่ตรง
4. ใส่ข้อมูลตั้งต้นที่จำเป็นไว้ใน Markdown ให้ครบ เช่น โจทย์ธุรกิจ กฎธุรกิจ Use Case และ User Story ไม่ให้ผู้เรียนต้องหาไฟล์ประกอบเอง หากขั้นใดใช้ User Story ให้แสดงเนื้อหา User Story จริงพร้อมรหัส แล้ววางพรอมท์ที่อ้างถึงข้อมูลนั้นต่อจากเนื้อหา
5. จัดกรอบที่คัดลอกให้ครอบคลุมทั้งข้อมูลตั้งต้นและพรอมท์ที่ต้องส่งพร้อมกัน เพื่อให้ AI ได้รับข้อมูลครบ อย่าอ้างว่า AI มองเห็นเนื้อหาใน Markdown หากผู้เรียนยังไม่ได้ส่งให้ หากใช้ผลจากขั้นก่อนหน้า ให้ระบุชัดว่าใช้คำตอบก่อนหน้าหรืออ่านไฟล์ใดที่สร้างไว้แล้ว
6. แต่ละพรอมท์ต้องสั่งให้ AI ทำเฉพาะขั้นปัจจุบัน แสดงผลลัพธ์ที่ผู้เรียนต้องตรวจบนคอนโซล แล้วหยุดรอ ห้ามทำขั้นถัดไปเอง และห้ามแสดงเพียงชื่อไฟล์หรือข้อความว่าเสร็จแล้ว หากสร้างไฟล์ ให้แสดงเนื้อหาสำคัญที่ใช้ตรวจด้วย
7. มี Expected Output ให้เป็นรูปธรรม ที่ควรได้ พร้อมอธิบายว่าส่วนใดต้องตรงตามโจทย์และส่วนใดใช้ถ้อยคำต่างกันได้ ระบุชัดว่าเป็นตัวอย่างสำหรับเทียบ ไม่ใช่ผลการรันจริง 
11. ตรวจความต่อเนื่องของทุกขั้น ข้อมูลที่อ้างถึงต้องมีอยู่จริงจากโจทย์หรือขั้นก่อนหน้า พรอมท์ต้องคัดลอกไปใช้ได้ครบ และ Expected Output ต้องสอดคล้องกับงานที่สั่ง จากนั้นสรุปสิ่งที่ปรับและสิ่งที่ทดสอบจริง โดยไม่อ้างว่ารันแล้วหากยังไม่ได้รัน


## LAB
- **ไม่เกิน 7 LAB ** รันได้จริง → `001_LAB_...` ถึง `007_LAB_...`
- ทุกโฟลเดอร์มี `README.md` ครบถ้วน · 
- แยก agent ต่อ LAB (≤ 7 container) · แต่ละ agent ลบ container ตัวเองก่อนส่งงาน


## กติกา
- เอกสาร LAB ใช้ **placeholder เท่านั้น** — ห้ามใส่ email/ชื่อจริง/token/username จริง
- วาดรูปด้วย **Excalidraw MCP** · ทดสอบ web + capture ภาพจริงด้วย **Playwright CLI**
- สร้าง LAB ในลักษณะที่ เป็น prompt copy แล้ว plate ไป
- โดยกำหนด LAB ที่ 001 เป็น setup lab  
- โดย lab อื่นๆ ให้สรา้ง file prompt ย่อยๆ .md แล้ว สร้างตัว main ให้ไปเรียกอ่าน จาก .md เพื่อความสะดวกแล้วเข้าใจง่าย
- ไม่ควรมีการรัน code หรือ เรียกใช้ code อะไร เลย อยากให้เป็น แบบ vibe coding ที่ทุกอย่างบริหารจัดการด้วย prompt เท่านั้น ขอแบบ copy plate วาง แล้ว ตรวจสอบผล
