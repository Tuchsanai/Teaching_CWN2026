# 01-stories.md — User Stories ระบบจองห้องประชุม

SIMULATION

## บริบท
- ห้องที่ให้จอง: `<ROOM_A>`, `<ROOM_B>` เปิด 09:00–17:00 เฉพาะวันทำการ
- วันที่ใช้อ้างอิงในตัวอย่าง: `<BOOKING_DATE>`
- บทบาท: `<REQUESTER_A>` (ผู้ขอจอง), `<RECEPTION_A>` (ต้อนรับ), `<ADMIN_A>` (ผู้ดูแล)
- นอกขอบเขต: การจ่ายเงิน, อีเมลแจ้งเตือน, การอนุมัติ

| B03 | ห้อง/วันเดียวกันห้ามมีรายการที่ไม่ถูกยกเลิกทับกัน; เวลาติดกันได้; กดพร้อมกันช่วงทับสำเร็จหนึ่งรายการ |

## User Stories
| ID | บทบาท | ฉันต้องการ…เพื่อ… | Source B | Acceptance criteria |
|---|---|---|---|---|
| US-01 | `<REQUESTER_A>` | ฉันต้องการดูห้องและช่วงเวลาว่างของแต่ละห้องตามวันที่เลือก เพื่อเลือกช่วงที่จะจองได้ถูกต้อง | B01 | 1. ระบุวัน `<BOOKING_DATE>` แล้วเห็นรายการห้อง `<ROOM_A>`, `<ROOM_B>` พร้อมช่วงที่ว่างและช่วงที่ถูกจองแล้วในกรอบ 09:00–17:00<br>2. รายการที่ถูกยกเลิกแล้วไม่แสดงเป็นช่วงจอง (ช่วงนั้นแสดงเป็นว่าง)<br>3. ห้องที่ `<ADMIN_A>` ปิดรับจองใหม่แสดงสถานะ "ปิดรับจอง" แต่ยังเห็นรายการเดิมของวันนั้น |
| US-02 | `<REQUESTER_A>` | ฉันต้องการจองห้องโดยระบุห้อง วัน เวลาเริ่ม เวลาจบ เพื่อให้ได้ช่วงเวลาที่ไม่ทับกับผู้อื่น | B02, B03 | 1. จอง `<ROOM_A>` วัน `<BOOKING_DATE>` 09:00–10:00 โดยห้องเปิดรับและช่วงว่าง → สำเร็จ<br>2. เริ่ม ≥ จบ (เช่น 10:00–10:00 หรือ 11:00–10:00) → ปฏิเสธ<br>3. ช่วงอยู่นอก 09:00–17:00 (เช่น 08:30–09:30 หรือ 16:30–17:30) → ปฏิเสธ<br>4. ห้องที่ปิดรับจองใหม่ → ปฏิเสธ<br>5. มีรายการเดิม `<ROOM_A>` `<BOOKING_DATE>` 09:00–10:00; ขอ 09:30–10:30 → ปฏิเสธ (ทับกัน)<br>6. มีรายการเดิม 09:00–10:00; ขอ 10:00–11:00 → อนุญาต (เวลาติดกัน ไม่นับว่าทับ)<br>7. ผู้ขอสองคนกดจอง `<ROOM_A>` `<BOOKING_DATE>` ช่วงที่ทับกันพร้อมกัน → สำเร็จเพียงหนึ่งรายการ อีกรายการถูกปฏิเสธ<br>8. รายการที่ถูกยกเลิกแล้วไม่นับเป็นรายการทับ (จองซ้ำช่วงเดิมได้) |
| US-03 | `<REQUESTER_A>` | ฉันต้องการยกเลิกรายการจองของตนเองก่อนเวลาเริ่ม เพื่อคืนช่วงเวลาให้ผู้อื่นใช้ได้ | B04 | 1. เจ้าของยกเลิกรายการของตนที่ยังไม่ถึงเวลาเริ่ม → สำเร็จ และช่วงนั้นกลับเป็นว่าง (ผู้อื่นจองช่วงเดิมได้)<br>2. ผู้ใช้อื่นที่ไม่ใช่เจ้าของ (รวม `<RECEPTION_A>`) พยายามยกเลิกรายการนั้น → ปฏิเสธ รายการคงอยู่<br>3. เจ้าของพยายามยกเลิกรายการที่ถึงหรือเลยเวลาเริ่มแล้ว → ปฏิเสธ<br>4. ยกเลิกรายการที่ถูกยกเลิกไปแล้ว → ปฏิเสธ/ไม่มีผลเพิ่ม |
| US-04 | `<RECEPTION_A>` | ฉันต้องการดูตารางจองรายวันของทุกห้อง เพื่อตอบคำถามผู้มาติดต่อและเตรียมห้องได้ | B05 | 1. ระบุวัน `<BOOKING_DATE>` แล้วเห็นรายการจองที่ยังไม่ถูกยกเลิกของ `<ROOM_A>` และ `<ROOM_B>` ในวันนั้น พร้อมห้อง เวลาเริ่ม–จบ และผู้จอง<br>2. รายการที่ถูกยกเลิกแล้วไม่แสดงในตาราง (หรือแสดงแยกสถานะยกเลิกชัดเจน)<br>3. `<RECEPTION_A>` ไม่มีปุ่ม/ช่องทางแก้ไขหรือยกเลิกรายการ; หากพยายามทำ → ปฏิเสธ |
| US-05 | `<ADMIN_A>` | ฉันต้องการเปิดหรือปิดการรับจองใหม่ของแต่ละห้อง เพื่อควบคุมการใช้ห้องช่วงซ่อมบำรุงหรือเหตุพิเศษ | B06 | 1. `<ADMIN_A>` ปิดรับจองใหม่ `<ROOM_A>` → หลังจากนั้นคำขอจองใหม่ `<ROOM_A>` ถูกปฏิเสธ<br>2. หลังปิดรับจอง รายการจองเดิมของ `<ROOM_A>` (เช่น `<BOOKING_DATE>` 09:00–10:00) ยังคงอยู่และยังแสดงในตารางรายวัน<br>3. `<ADMIN_A>` เปิดรับจอง `<ROOM_A>` อีกครั้ง → จองใหม่ได้ตามปกติ<br>4. `<REQUESTER_A>` หรือ `<RECEPTION_A>` พยายามเปิด/ปิดรับจอง → ปฏิเสธ |

## คำถามค้าง (ไม่เกิน 3 ข้อ)
1. วันหยุดนักขัตฤกษ์ที่ตรงกับวันจันทร์–ศุกร์ ให้ถือเป็นวันทำการหรือไม่ (นิยาม "วันทำการ" ยังไม่ชัด)
2. ระยะเวลาจองล่วงหน้ามีขอบเขตหรือไม่ (จองวันเดียวกันได้ไหม / ล่วงหน้าได้สูงสุดกี่วัน)
3. NFR ที่ต้องรองรับ เช่น จำนวนผู้ใช้พร้อมกันและเวลาตอบสนองสำหรับกรณีกดจองพร้อมกัน ยังไม่ระบุ
