# หมายเหตุหลักฐานเดิม

ก่อนเริ่มงาน ผู้จัดทำได้ย้าย `report.md` และ `ssh-checks.json` เดิมมาไว้ในโฟลเดอร์ `previous/` ตามคำสั่งแล้ว ต่อมาระหว่างการทดสอบ live โครงสร้าง `evidence/` ถูกกระบวนการภายนอกแทนที่ ทำให้ไฟล์เดิมที่ย้ายไว้ไม่อยู่ใน working tree ปัจจุบัน จึงบันทึกเหตุการณ์นี้ไว้โดยไม่สร้างเนื้อหาเดิมขึ้นใหม่หรือกล่าวอ้างว่าเก็บสำเนาไว้ได้
