# หมายเหตุหลักฐานเดิม

ก่อนเริ่มงานได้ย้ายรายงานและ checksum เดิมเข้ามาในโฟลเดอร์นี้ตามข้อกำหนด ระหว่างตรวจปิดงานมี process ภายนอกเปลี่ยนโฟลเดอร์หลักฐานพร้อมกัน ทำให้ไฟล์เดิมสองรายการไม่เหลืออยู่ เหลือ checkpoint ของ README เดิมซึ่งย้ายมาเก็บใน `legacy-lab/` โดยไม่แก้เนื้อหา

เหตุการณ์นี้ไม่กระทบ README, พรอมท์, session ของการรันจริง หรือไฟล์งานฉบับสุดท้าย หลักฐานรอบใหม่ที่ได้รับผลกระทบถูกกู้จาก session บน host และตรวจ checksum กลับมาตรงกับค่าที่บันทึกไว้ก่อนเกิดเหตุ
