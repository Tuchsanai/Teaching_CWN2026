### 3.2 ส่งคำถามได้สองวิธี: ในหน้า AI หรือจาก shell

ลองทั้งสองวิธีด้วยโจทย์เดียวกัน ใช้ **Fable · medium** กับ **Astra · medium** เหมือนกัน เพื่อเปรียบเทียบวิธีป้อนคำถามและผลตอบ

#### วิธีที่ 1 · เลือกโมเดลในหน้า AI แล้ววางคำถาม

ใช้หน้าสนทนาที่เปิดและล็อกอินไว้จากหัวข้อ 3.1 พิมพ์คำสั่งเลือกโมเดลในช่องของ AI โดยตรง

**คำถามสำหรับคัดลอกไปวางทั้งสองค่าย**

```text
ร้านค้าลดราคา 10% เมื่อซื้อครบ 1000 บาท จงคำนวณยอดจ่ายสำหรับยอดซื้อ 999, 1000 และ 1500 บาท ตอบเป็นตารางยอดซื้อและยอดจ่ายทศนิยม 2 ตำแหน่ง ตามด้วยคำอธิบายสั้น ๆ และข้อควรระวัง 1 ข้อ ไม่ต้องสร้างไฟล์หรือรันคำสั่งอื่น
```

**A · ในหน้า yolo1 / Claude Code**

1. พิมพ์ `/model` แล้วกด Enter เลื่อนเลือก **Fable**
2. ใช้ปุ่มลูกศรซ้าย/ขวาปรับ effort ให้เป็น **Medium** แล้วกด Enter ยืนยัน

![เลือก Fable และ Medium ในหน้า Claude Code](img/terminal-ui-fable-model-medium.png)

3. คัดลอกคำถามด้านบนมาวางในช่องสนทนา ตรวจชื่อโมเดลและ medium บนหน้าจอก่อนส่ง

![วางคำถามในหน้า Claude Code หลังเลือก Fable medium](img/terminal-ui-fable-question.png)

4. กด Enter แล้วรอคำตอบ เมื่อจบยังอยู่ในหน้าสนทนาและถามต่อได้

![คำตอบจริงจาก Fable medium ผ่านหน้าสนทนา](img/terminal-ui-fable-answer.png)

**B · ในหน้า cyolo1 / Codex**

1. พิมพ์ `/model` แล้วกด Enter เลือก **gpt-6-astra** แล้วกด Enter

![เลือก Astra ในหน้า Codex](img/terminal-ui-astra-model.png)

2. ในหน้าเลือกระดับ reasoning เลือก **Medium** แล้วกด Enter ยืนยัน

![เลือกระดับ Medium ของ Astra](img/terminal-ui-astra-effort.png)

3. คัดลอกคำถามเดียวกันมาวางในช่องสนทนา ตรวจว่าหน้าจอแสดง `gpt-6-astra medium`

![วางคำถามในหน้า Codex หลังเลือก Astra medium](img/terminal-ui-astra-question.png)

4. กด Enter แล้วรอคำตอบ เมื่อจบยังอยู่ในหน้าสนทนาและถามต่อได้

![คำตอบจริงจาก Astra medium ผ่านหน้าสนทนา](img/terminal-ui-astra-answer.png)

#### วิธีที่ 2 · ส่งคำถามจาก shell โดยตรง

ออกจากหน้า AI กลับมาที่ shell ก่อน รันคำสั่งด้านล่างในโฟลเดอร์งานเดียวกัน โดยใช้คนละหน้าต่างเพื่อดูคำตอบเทียบกัน

**หน้าต่าง A — yolo1: Fable · medium**

```bash
yolo1 --model fable --effort medium -p 'ร้านค้าลดราคา 10% เมื่อซื้อครบ 1000 บาท จงคำนวณยอดจ่ายสำหรับยอดซื้อ 999, 1000 และ 1500 บาท ตอบเป็นตารางยอดซื้อและยอดจ่ายทศนิยม 2 ตำแหน่ง ตามด้วยคำอธิบายสั้น ๆ และข้อควรระวัง 1 ข้อ ไม่ต้องสร้างไฟล์หรือรันคำสั่งอื่น'
```

![ผลตอบจริงจาก yolo1: Fable ระดับ medium](img/terminal-fable-medium-response.png)

**หน้าต่าง B — cyolo1: Astra · medium**

```bash
cyolo1 exec --skip-git-repo-check --model gpt-6-astra -c model_reasoning_effort=medium 'ร้านค้าลดราคา 10% เมื่อซื้อครบ 1000 บาท จงคำนวณยอดจ่ายสำหรับยอดซื้อ 999, 1000 และ 1500 บาท ตอบเป็นตารางยอดซื้อและยอดจ่ายทศนิยม 2 ตำแหน่ง ตามด้วยคำอธิบายสั้น ๆ และข้อควรระวัง 1 ข้อ ไม่ต้องสร้างไฟล์หรือรันคำสั่งอื่น'
```

![ผลตอบจริงจาก cyolo1: Astra ระดับ medium](img/terminal-astra-medium-response.png)

คำสั่งทั้งสองส่งโจทย์ให้ AI ตอบจริงแล้วจบการทำงาน จึงใช้ตรวจได้มากกว่าการเปิดโปรแกรมหรือดู `--version`
