# LAB 002 · ส่งคำตอบจาก Claude ให้ Codex ผ่าน Terminal

**เป้าหมาย:** ให้ Claude ตอบโจทย์ แล้วส่งทั้งโจทย์และคำตอบให้ Codex ตรวจต่อ

**ก่อนเริ่ม:** ทำ [แลปตั้งค่า](../README.md) และล็อกอิน `yolo1` กับ `cyolo1` ให้พร้อม เปิด Terminal ในโฟลเดอร์งานเดิม

คัดลอกคำสั่งทีละบรรทัด กด Enter และรอให้ทำงานจบก่อนทำบรรทัดถัดไป โดยเฉพาะวิธีที่ 2 ให้ใช้ Terminal หน้าต่างเดิมตลอด

| วิธี | เก็บคำตอบไว้ที่ไหน |
|---|---|
| 1 · ผ่านไฟล์ | ไฟล์ข้อความ เปิดอ่านภายหลังได้ |
| 2 · ผ่านตัวแปร | หน่วยความจำชั่วคราวของ shell ไม่สร้างไฟล์คำตอบ |

ผลตอบด้านล่างมาจากการทดลองจริง ถ้อยคำอาจต่างกัน แต่ยอดจ่ายควรเป็น **900 บาท** หากคำสั่งล้มเหลวหรือไม่มีคำตอบ ให้แก้ปัญหาก่อนส่งต่อ

---

## วิธีที่ 1 · ส่งผ่านไฟล์

### 1.1 · ให้ Claude ตอบและบันทึกลงไฟล์

```bash
yolo1 --model fable --effort medium -p 'ซื้อของ 1000 บาท ลด 10% ต้องจ่ายกี่บาท อธิบายสั้น ๆ ไม่สร้างไฟล์หรือรันคำสั่ง' > claude-answer.txt
```

คำสั่งนี้เก็บคำตอบลงไฟล์ จึงยังไม่แสดงคำตอบบนหน้าจอ และจะเขียนทับไฟล์คำตอบเดิมเมื่อรันซ้ำ

### 1.2 · เปิดดูคำตอบ

```bash
cat claude-answer.txt
```

**ผลตอบจริง:**

```text
ต้องจ่าย **900 บาท**

ลด 10% ของ 1000 บาท = 100 บาท
1000 − 100 = 900 บาท
```

### 1.3 · ให้ Codex ตรวจคำตอบ

```bash
cyolo1 exec --skip-git-repo-check --model gpt-6-astra -c model_reasoning_effort=medium "โจทย์คือซื้อของ 1000 บาท ลด 10% ต้องจ่ายกี่บาท ตรวจคำตอบจาก Claude ต่อไปนี้แล้วสรุปสั้น ๆ ไม่สร้างไฟล์หรือรันคำสั่ง: $(cat claude-answer.txt)"
```

**ผลตอบจริง:**

```text
คำตอบถูกต้อง: ลด 10% ของ 1,000 บาท คือ 100 บาท จึงต้องจ่าย **900 บาท**
```

ส่วน `$(cat claude-answer.txt)` นำคำตอบจากไฟล์ใส่ในคำถามที่ส่งให้ Codex

## วิธีที่ 2 · ส่งผ่านตัวแปรในหน่วยความจำ

### 2.1 · ให้ Claude ตอบ เก็บไว้ และแสดงคำตอบ

```bash
ANSWER=$(yolo1 --model fable --effort medium -p 'ซื้อของ 1000 บาท ลด 10% ต้องจ่ายกี่บาท อธิบายสั้น ๆ ไม่สร้างไฟล์หรือรันคำสั่ง') && printf '%s\n' "$ANSWER"
```

**ผลตอบจริง:**

```text
ต้องจ่าย **900 บาท**

ส่วนลด 10% ของ 1000 = 1000 × 0.10 = 100 บาท
ราคาหลังลด = 1000 − 100 = 900 บาท

หรือคิดทางลัด: จ่าย 90% ของราคาเต็ม = 1000 × 0.90 = 900 บาท
```

`ANSWER` คือชื่อที่ใช้เก็บคำตอบชั่วคราว ส่วน `printf` แสดงคำตอบนั้นบนหน้าจอ

### 2.2 · ให้ Codex ตรวจคำตอบ

```bash
cyolo1 exec --skip-git-repo-check --model gpt-6-astra -c model_reasoning_effort=medium "โจทย์คือซื้อของ 1000 บาท ลด 10% ต้องจ่ายกี่บาท ตรวจคำตอบจาก Claude ต่อไปนี้แล้วสรุปสั้น ๆ ไม่สร้างไฟล์หรือรันคำสั่ง: $ANSWER"
```

**ผลตอบจริง:**

```text
คำตอบของ Claude ถูกต้อง: ลด 10% ของ 1,000 บาท เท่ากับ 100 บาท จึงต้องจ่าย **900 บาท**
```

`$ANSWER` นำคำตอบที่เก็บไว้ใส่ในคำถามที่ส่งให้ Codex ตัวแปรนี้จะหายไปเมื่อปิด shell จึงต้องทำทั้งสองขั้นในหน้าต่างเดิม

---

## จุดที่ต้องเข้าใจ

ทั้งสองวิธีส่ง **คำตอบของ Claude** ไปให้ Codex อ่านและตรวจ ความต่างอยู่ที่ใช้ไฟล์หรือตัวแปรพักคำตอบระหว่างทาง

ตัวแปรเป็นหน่วยความจำของ shell แต่ละโมเดลไม่ได้ใช้ความจำร่วมกัน และ CLI อาจเก็บประวัติตามการตั้งค่าของตัวเอง
