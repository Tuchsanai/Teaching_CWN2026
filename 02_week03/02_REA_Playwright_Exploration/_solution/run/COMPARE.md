# COMPARE — SkyThai Mini (v1) กับ SkyThai Plus (v2) เทียบกับฟีเจอร์ Google Flights

- วันที่รัน: 1 พ.ย. 2026 (Playwright 1.64.1, Chromium 155 headless, viewport 1280×800)
- v1 = SkyThai Mini `http://localhost:5081` (LAB ก่อน · สร้างจาก REA อย่างเดียว)
- v2 = SkyThai Plus `http://localhost:5082` (สร้างจาก Playwright + REA)
- เกณฑ์: ส่วน B ของ `EXPLORATION.md` มี **35 ฟีเจอร์** ใช้ **1 test ต่อ 1 ฟีเจอร์** (`compare/tests/features.spec.ts`)
  - ทั้งสองแอปใช้ test ชุดเดียวกัน (Playwright project `v1` / `v2` ต่างกันแค่ `baseURL`)
  - หาองค์ประกอบด้วย role, ชื่อที่ผู้ใช้อ่านได้ และข้อความที่เห็นเท่านั้น ไม่ใช้ `data-testid`, class, id หรือ URL ภายในของแอปใด ๆ และไม่ได้แก้โค้ดของทั้งสองแอป
  - test เริ่มที่หน้าแรก `/` ถ้าหน้าแรกยังไม่มีรายการเที่ยวบินก็กดปุ่ม "ค้นหา" เหมือนผู้ใช้ทั่วไป
  - **ผ่าน** = ทำสิ่งที่ Google Flights ทำได้ในฟีเจอร์นั้นและได้ผลตามที่ตรวจ ถ้าแอปทำได้เฉพาะส่วนหลัก แต่ขาดส่วนย่อยบางอย่าง จะให้ผ่านและบันทึกส่วนที่ขาดไว้ในหมายเหตุ (เช่น B12 และ B16 ของ v1)
- ผลดิบ: `compare/results.json` · สรุปผลด้วย `node compare/summarize.mjs compare/results.json`
- รันซ้ำ 2 รอบหลังแก้ test แล้วได้ผลตรงกันทั้ง 2 รอบ
