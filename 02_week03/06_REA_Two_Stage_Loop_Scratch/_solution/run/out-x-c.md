**สิ่งที่น่าสนใจ**
- **ราคาในรายการคือราคาของผู้ขายที่ถูกที่สุด** ไม่ใช่ราคาของสายการบินเจ้าของเที่ยวบิน และผู้ขายไม่ได้เรียงจากถูกไปแพง (เที่ยวบิน JAL เป็นตัวอย่าง)
- **เที่ยวบินที่เปลี่ยนสนามบินโผล่หลังกด "ดูเที่ยวบินเพิ่มเติม" เท่านั้น** หลังกดเจอ 23 รายการ เว็บมีไอคอนเตือน ⚠ สีแดงทั้ง 3 จุด คือในแถวผลค้นหา (`มีการเปลี่ยนสนามบิน`) ตอนขยายรายละเอียด (`เปลี่ยนจาก KIX ไปยัง ITM`) และในหน้าจอง
- **คลิกตัวแถวที่ยังไม่ขยายก็ไปหน้าจองทันที** ไม่ต้องขยายแล้วกด "เลือกเที่ยวบิน"
- **ลิงก์หน้าจองเปลี่ยนเป็น `/travel/flights/booking?tfs=…&tfu=…`** โดย `tfs` เก็บข้อมูลแต่ละขาของเที่ยวบิน (วันที่ สนามบิน สายการบิน เลขเที่ยวบิน) และได้ค่าเดิมทุกครั้งที่เลือกเที่ยวบินเดิม ส่วน `tfu` เปลี่ยนทุกครั้ง ลิงก์นี้เอาไปเปิดในเบราว์เซอร์ใหม่ที่ไม่มี cookie ก็ยังได้หน้าจองครบ
- **ปุ่ม "ย้อนกลับ" และ "เปลี่ยนเที่ยวบิน" ในหน้าไม่ได้พาย้อนประวัติจริง** แต่เปิดหน้าใหม่ที่ `/travel/flights/search?tfs=…` (ไม่ใช่ลิงก์ `?q=` เดิม) หลังจากนั้นกด Back ของเบราว์เซอร์จะกลับไปหน้าจองอีกรอบ
- **ผลค้นหาหลังกดย้อนกลับเริ่มใหม่หมด** คือกลับไปอยู่บนสุด แถวที่ขยายไว้ยุบหมด และรายการยาวจาก "ดูเที่ยวบินเพิ่มเติม" หายไป เหลือ 21 รายการเหมือนตอนเปิดครั้งแรก
