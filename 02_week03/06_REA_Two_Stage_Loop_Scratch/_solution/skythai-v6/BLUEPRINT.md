# BLUEPRINT — SkyThai Zero (v6)

ที่มา: `rulers/structure/original.yml` (หน้าผลค้นหาต้นฉบับ 18:16 · 21 แถว) + `spec/EXPLORATION.md` A–F + `spec/snapshots/*.yml` + `spec/data/*.json`
ข้อมูลทั้งหมดมาจาก PostgreSQL (seed จาก `data/*.json` ซึ่งสร้างด้วย `scripts/prepare-data.mjs` จาก `spec/data` โดยไม่แต่งค่า)

## สถาปัตยกรรม
- `docker compose` : `db` (postgres:16-alpine) + `app` (Next.js · พอร์ต **5095** → 3000)
- ตอนเริ่ม container: `scripts/seed.mjs` สร้างตาราง `flights` (300 ใบ · jsonb + คอลัมน์ที่ใช้กรอง/เรียง), `initial_order` (21 ใบ), `insights`, `booking_options` แล้วจึง `next start`
- API: `GET /api/flights` (scope=initial|all · stops · airlines · maxPrice · depFrom/depTo · arrFrom/arrTo · bags · lowEmissions · connect · layoverMax · maxDuration · sort) — กรองและเรียงด้วย SQL · `GET /api/facets` (สายการบิน/สนามบินต่อเครื่อง/ช่วงราคา) · `GET /api/insights` · `GET /api/booking?id=`
- หน้า: `/` (หน้าแรก+ฟอร์ม) → `/search?…` (ผลค้นหา) → แถวขยายในที่ (รายละเอียด) → `/booking?id=…&…` (ตัวเลือกการจอง)

### กฎลำดับ (diff)
- ไม่กรอง/ยังไม่กดดูเพิ่ม: ตามลำดับ `initial_order` (3 ยอดนิยม + 18) · กดดูเพิ่ม: 300 ใบตามลำดับในข้อมูล (3 ยอดนิยม แล้วไล่ราคา)
- มีตัวกรอง: กรองจาก 300 ใบ · 3 แถวแรก = "ดีที่สุด" (ยอดนิยมที่ผ่านตัวกรองก่อน แล้วเติมด้วยคะแนน ราคา+ความสะดวก) · ที่เหลือเรียงราคาน้อย→มาก · แสดงทั้งหมดไม่มีปุ่มดูเพิ่ม
