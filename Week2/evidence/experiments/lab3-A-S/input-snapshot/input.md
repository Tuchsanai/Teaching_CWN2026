# ชุด A — ร้านมะลิ (ข้อมูลสมมติ)
[A-P1] นโยบาย v1 มีผลกับชุดนี้: สินค้าชำรุดแจ้งภายใน 7 วันหลังรับและมีรูป ให้เจ้าหน้าที่ตรวจหลักฐานก่อนเสนอเปลี่ยนสินค้า ไม่รับคืนเพราะเปลี่ยนใจ
[A-P2] ระดับคิว: P1 มีความเสี่ยงอันตรายหรือบาดเจ็บ ส่งหัวหน้าทันทีและแนะนำหยุดใช้; P2 สินค้าชำรุดทั่วไป; P3 ขอข้อมูลหรือเปลี่ยนใจ ไม่มีเวลารับประกันการตอบ
[A-P3] ข้อยกเว้นนโยบายต้องให้ผู้จัดการพิจารณา AI และเจ้าหน้าที่รับเรื่องอนุมัติเองไม่ได้
[A-O1] ออเดอร์ A101: แก้ว รับแล้ว 3 วัน รูปแสดงรอยร้าวแนบครบ ยังไม่บาดเจ็บ
[A-M1] ลูกค้าออเดอร์ A101: แก้วร้าว ขอเปลี่ยนใบใหม่ค่ะ
[A-M2] ลูกค้า: ของเสีย ขอเงินคืนด่วน! ไม่ให้เลขออเดอร์ วันรับ หรือรูป
[A-O3] ออเดอร์ A303: กระเป๋าปกติ รับแล้ว 2 วัน ลูกค้าเปลี่ยนใจ
[A-M3] ลูกค้าออเดอร์ A303: สีไม่ถูกใจ ขอคืนเงิน ไม่มีความเสียหาย
[A-O4] ออเดอร์ A404: กาต้มน้ำ รับแล้ว 12 วัน มีรูปปลั๊กไหม้ ไม่มีผู้บาดเจ็บที่รายงาน
[A-M4] ลูกค้าออเดอร์ A404: ใช้แล้วปลั๊กไหม้ ขอคืนเงินกรณีพิเศษ
