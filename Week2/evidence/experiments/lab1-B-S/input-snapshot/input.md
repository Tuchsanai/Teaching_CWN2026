# ชุด B — ร้านอุ่นใจ (ข้อมูลสมมติสำหรับฝึก)
[B-C1] แชตฝ่ายขาย: แคมเปญลด 15% และลูกค้าน่าจะใช้คูปองร่วมได้
[B-C2] แชตเจ้าหน้าที่รับออเดอร์: ลูกค้าจ่ายแล้วก็ยกเลิกได้ก่อนแพ็กนะ
[B-M1] บันทึกประชุม: ต้องบันทึกชื่อผู้รับ เบอร์ติดต่อ และรายการสินค้าก่อนยืนยันออเดอร์
[B-M2] บันทึกประชุม: อยากรับคืนเมื่อเปลี่ยนใจภายใน 10 วัน ยังไม่ได้ระบุสภาพสินค้าและค่าขนส่ง
[B-P1] เอกสารกติกา: ส่วนลด 15% ใช้ร่วมกับคูปองไม่ได้
[B-P2] เอกสารกติกา: ยกเลิกได้เฉพาะก่อนชำระเงิน
[B-P3] เอกสารกติกา: รับคืนเฉพาะสินค้าชำรุด แจ้งภายใน 10 วันหลังได้รับ
[B-N1] หมายเหตุ: ไม่มีเอกสารระบุลำดับอำนาจของแชต ประชุม และกติกา ไม่มีคำอนุมัติเปลี่ยนนโยบาย และยังไม่มีข้อตกลงค่าขนส่งคืน
