# เกณฑ์ตรวจ Coverage และเงื่อนไขหยุด

ต้นทาง: ../../docs/case-study-source.md (เมื่อเปิดจาก input/)
ครอบคลุมทั้ง 26 US; ลูกค้า 01–09, ครัว/หน้าร้าน 10–18, ผู้จัดการ 19–26

| รายการตรวจ | เกณฑ์ |
|---|---|
| ต่อ US | สำเร็จอย่างน้อย 1 และผิดพลาดหรือข้อยกเว้นอย่างน้อย 1 |
| clause | ทุกกฎ/เงื่อนไข/ตัวเลขมี scenario หรือข้อค้างที่อธิบายได้ |
| ทางเลือก | มีเมื่อ AC ระบุหลายทาง; N/A ต้องมีเหตุผล |
| Expected | ตัดสินได้จากสิ่งที่สังเกต ไม่ใช้ความเห็น AI แทนผลรัน |
| AC | รักษาข้อความ ตัวเลข หน่วย สูตร ขอบเขต และสัดส่วนต้นฉบับ |
| ID | TS-<US>-<n> ไม่ซ้ำ; ช่วง 101 ขึ้นไปสงวน fixture |
| Traceability | อ้าง FR/Flow/Screen ที่มีจริง; ขาดให้ MISSING |
| Automation | auto/manual/mock-not-testable พร้อมเหตุผลและข้อจำกัด |
| หลักฐาน | แยกออกแบบครบ รัน Mock-up ผ่าน และผ่านระบบจริง |

ตารางผู้ตรวจต้องมี 26 แถวและคอลัมน์สำเร็จ/ทางเลือก/ผิดพลาด/ข้อยกเว้น
ช่องที่มี coverage ต้องใส่ TestID; ช่องขาดใส่ MISSING; ไม่เว้นว่างจนตรวจไม่ได้
อย่างน้อย 52 scenario เชิงออกแบบเป็นเพียงขั้นต่ำ ไม่รับรองว่าครบทุก clause
scenario ของระบบจริงที่ยังรันไม่ได้ออกแบบให้ครบและระบุ mock-not-testable ได้
กรณีผิดพลาดที่ผลลัพธ์ไม่ชัดต้องติดสมมติฐาน/รอยืนยัน ห้ามสร้างกฎร้านใหม่
หมายเหตุ ก./ค./ช. และข้อสงสัยการอ้าง US-20 ให้ส่งต่อพร้อมข้อค้าง

## Loop

ตรวจครั้งแรก round-0 แล้วแก้ได้ไม่เกิน 2 รอบ (round-1 และ round-2)
ตรวจหลังแก้ทุกครั้งจาก manifest รอบเดียวกัน; ห้ามวน generate แบบเดาสุ่ม
COVERED เมื่อผ่านเกณฑ์ออกแบบทั้งหมดและ mapping ที่จำเป็นครบ
GAPS ให้ระบุ clause/เจ้าของ/หลักฐาน/แนวแก้ที่ชัดก่อนส่งผู้แก้
STOP_WITH_GAPS เมื่อครบเพดาน หรือชุดช่องว่างเดิมไม่ลด หรือข้อมูลธุรกิจจำเป็นขาด
เมื่อหยุดแล้วรวมเอกสารได้พร้อมข้อค้าง แต่ห้ามเรียกผลนั้นว่าครบหรือผ่านทั้งหมด
งานใหม่ที่รับ input upstream เปลี่ยนต้องตรวจ regression และบันทึกเหตุผลของรอบใหม่

## เกณฑ์ UI

ชุด ui-scenarios.json เป็น smoke suite ไม่ใช่ครบ 26 US และไม่แทน 52 scenario
pass ต้องผ่านทุก step รวม assertion และมี screenshot; fail ต้องมี reason
skip ใช้สำหรับ steps ว่างหรือ automation ไม่ใช่ auto ไม่ถือเป็น pass
ระบบ/browser เปิดไม่ได้ให้ auto scenario เป็น fail แบบ infrastructure ไม่ใช่ skip
การเปิด file:// และนาฬิกาจำลองไม่พิสูจน์เวลา LAN, load, security หรือ Ubuntu deployment
