# โครงสร้างระบบครัวคุณยาย — structure

ผลอ้างอิง pre-run สำหรับวิเคราะห์และส่ง UI; ยังไม่ทดสอบระบบจริง; ไม่มีการรับรองโดยนักศึกษาหรือเจ้าของร้าน

เฉพาะ 18 แถว US; รหัสในเซลล์ไม่เพิ่ม scope ตาม A-06; ยืนยัน dependency customer, kitchen-front, manager ตาม input/graph.json และ ACCEPTED ใน input-audit/review-record สำหรับ pre-run นี้ ไม่มีการอ่านผล state-machine; ส่งจุดเทียบให้ merge ภายหลัง

ชื่อทางเทคนิคและ cardinality ที่เสนอเป็น A-ST01; ข้อบังคับต้นฉบับแยกใน constraints; Screen ID/Module ID เป็นชื่อแบบจำลองตาม A-ST05 ไม่ใช่ FR ใหม่

เกณฑ์รับใน flows เป็นเกณฑ์สำหรับตรวจในอนาคต; งานนี้ตรวจเอกสาร/schema/hash/การคัดข้อความเท่านั้น; ไม่มีผลรันระบบ, Mock-up, security, LAN หรือการติดตั้ง

รายละเอียด Flow/หลักฐานฉบับเต็ม: [flow-structure.md](flow-structure.md); ข้อมูลโครงสร้างที่ตรงกัน: [flow-structure.json](flow-structure.json)
