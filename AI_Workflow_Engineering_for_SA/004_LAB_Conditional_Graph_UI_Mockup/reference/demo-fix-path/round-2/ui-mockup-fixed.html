สลับบทบาท จำลอง ข้อมูลร่วมกันเฉพาะในแท็บนี้ • เข้าแท็บพนักงานหรือผู้จัดการใหม่ต้องล็อกอินทุกครั้ง

วิธีเล่นและข้อค้างที่ต้องทบทวน
  1. ลูกค้าเลือกโต๊ะ (แทน QR โต๊ะจำลอง) หรือสั่งกลับบ้าน เลือกช่วงรับ แล้วเปิดเมนู เพิ่มอาหารและส่งออเดอร์
  2. เลือกครัวและหน้าร้าน ใช้ demokitchen / PIN 0000 เพื่อเปลี่ยนสถานะหรือกดวัตถุดิบหมด ใช้ demofront / PIN 0000 เพื่อยืนยันเงินและปิดโต๊ะ
  3. ผู้จัดการใช้ demomanager / PIN 0000 จัดการเมนู แมป บัญชี และเปิด/ปิด PromptPay ทั้งหมดเป็นบัญชีและสิทธิ์จำลอง
  4. ลองเพิ่มไข่ในตะกร้า แล้วไปครัวกดไข่หมด กลับมากดส่งเพื่อดูการปฏิเสธ หรือเลือก PromptPay แล้วกด +10 นาทีเพื่อดูทางออกเงินสด
  5. ใช้ Tab / Shift+Tab เดินฟอร์ม, Enter กดปุ่ม, Space เลือก checkbox รีเซ็ตคืน seed เวลา บัญชี แมป และคิวทั้งหมด การรีเฟรชไฟล์ก็เริ่มใหม่
